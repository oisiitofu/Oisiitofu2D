# マエルの専用リミットブレイク

対戦用に採用済みの最終形態、レイピア、髪と衣装の配色を全身姿勢とカットインの基準にする。原作の構えの切り替えは手首・剣先・踏み込みと光で示し、衣装は同じ参照から描く。

床を長く滑るフェイントで相手を誘い、手元で受け流して剣先の低い切り返しへ。途中で踏み込みを止め、武器を引きつける構えから狭い間合いで三連突き。最後は一歩引いて刃を正面にそろえ、ヴィルトゥオーズの構えからスタンダールへつなぐ。オクタンのパッドを踏んで弧を描く軌道に対し、足場を離れず、間合いと剣先の高さを変える。切り返しと決め技ではカメラを別々に止め、攻撃の間を見せる。

- [Xbox Wireのマエルの3種の構え](https://news.xbox.com/en-us/2025/03/03/clair-obscur-expedition-33-preview/)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。受け流しと三連突きから、ヴィルトゥオーズの構えとスタンダールへ。途中7ヒット、決め技27ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
