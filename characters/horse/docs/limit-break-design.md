# ウマの専用リミットブレイク

既存の対戦用全身絵のたてがみ、胴体と四肢、表情の形をカットインにも保つ。走り、設置、横木をまたぐ姿勢と着地をそれぞれ作る。

短い建築時間で横木とばね、回転足場を置き、走りながら設置した順に仕掛けを通過する。相手は横木、ばね、回転足場の順に別の高さへ押し出され、ウマは最短の道を登って旗へ先に到着する。決め技は旗の前で倒れる最後の足場を受けた吹っ飛び。サンズの重力反転と遠隔射撃に対し、本人の蹄が仕掛けに触れる位置と、ゴールまで積み上がる足場が画面を動かす。

- [Clever Endeavour Games公式 足場・罠の設置とゴール](https://www.cleverendeavourgames.com/uch-press-kit)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。足場を置いてゴールへ走り、横木・ばね・回転足場を連携させる。途中7ヒット、決め技26ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
