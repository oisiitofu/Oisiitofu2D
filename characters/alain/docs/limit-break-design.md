# アレイン：専用リミットブレイク制作設計

状態：専用素材と演出コードを実装し、ローカルの対戦・トレモ・CPU戦・代表オンライン同期を確認済み。Sites v329へ公開し、公開描画・発動・トレモ・専用音・通信同期まで確認済み。

## 2026-11-06 の動線指定

直近の「左から連撃し、一度右へ抜ける」構成から変える。アレインは盾で受けて間合いを作り、ハイロードの騎乗能力を使って相手の周囲を広く回り、停止して決める。ウィルの上下移動と区別し、地上の重心移動・盾・馬の旋回を見せる。公式サイトでロードからハイロードへの騎乗化を確認済み。馬の外見は公式埋め込み映像、決め技はアストラルブレードの資料を照合して専用素材を制作した。

| 段階 | 本人と相手の動き | 姿勢・画角の意図 |
|---|---|---|
| 接触 | 盾を前に出し、踏ん張って相手を受け止める | 攻撃開始を走り込みに固定せず、盾・腕・脚の受け姿勢を見せる |
| 反撃 | 盾で押し返し、一歩引いて剣で間合いを切る | 打撃と剣の音・停止感を分け、相手との距離を広げる |
| 展開 | ハイロードの騎乗姿勢へ移り、相手の周囲を奥へ回り込む | 移行・駆け出し・旋回の全身素材を使う。横から同じ姿勢を滑らせない |
| 追撃 | 奥から手前へ斜めに接近し、弧を描いて離脱する | 相手を基準にした遠近の変化を見せ、画面外からの不可視攻撃を避ける |
| 決着 | 馬を制止して正面寄りの構えを作り、聖なる決め技を放つ | 最後も横へ走り抜けず、制動・剣を掲げる姿勢・発動・収めを見せる |

決め技は終盤の力を活かすアストラルブレード。技名を剣の名前として扱わず、技を可能にするアクセサリーと、剣の名前を混同しない。動線は対戦用の専用演出として設計し、原作のアニメーションをそのまま再現したとは断定しない。

## 比較と検証

- ウィルの上下移動に対し、アレインは盾の迎撃→地上の遠近と旋回→停止した決め技を中心とする。
- 馬を含む全身の中間画像を制作し、騎手の顔・青髪・鎧・盾の意匠を既存 selection / poses / actions と比較する。関節リグは使わない。
- 本人と馬が別々に滑らず、駆け出し・接地・旋回・制動が連続動作として読めるかを確認する。
- 遠近で騎手の顔が小さくなり続けないよう、受け・反撃・制動を近い画角にする。カットインと全身画像の縦横比を維持する。
- 左右両向き、明るい背景での攻撃の芯、見やすさ設定、対戦・トレモ・代表オンライン同期を検証し、全編再生で直近キャラと構成を比較する。

## 実装とローカル検証

本人8姿勢＋騎乗8姿勢。盾・剣・騎乗追撃の途中4回×4ダメージ＋アストラルブレード25ダメージ。402フレームの同期が一致。相手の周囲を遠近込みで一周し、制動・掲剣・決め技へつなぐ。旋回後に剣が相手と逆を向く一撃は削除した。馬と本人は800pxで描画し、発動光を本人の背面へ置いて顔を保護。隣コマから剣先が混入した騎乗シートは画像生成で間隔を修正した。専用2音を制作。
対戦・トレモでゲージ、発動、空振り、盾、無敵、途中ヒット合計、最終吹っ飛び、他プレイヤーと時計の停止を確認。CPUは接敵距離から各1戦、実際の撃墜と結果への進行を確認。左右の実描画、カットイン縦横比、source-overの主攻撃、専用効果音再生も確認。最終素材の連続再生と公開検証も完了。
