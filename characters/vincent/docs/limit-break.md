# ヴィンセントの専用リミットブレイク

赤いマントと対戦用の銃で、滑りながら低い弾道と上への射撃をつなぐ。暗赤色の粒子が収束した瞬間に対戦用のカオス姿へ切り替え、翼で上を取り、斜め下へ急襲する。ザックスの同じ剣で間合いを詰め続ける構成と異なり、射線と高さを変え、変身区間を明示する。

改修では対戦中の赤いマント、三連銃、金色の爪、カオスの翼を参照した。組み込みImageGenで黒い翼の影が開く横長カットイン、夜の工業都市の屋上、射撃の閃光、爪の軌跡、カオス・デスペナルティの暗赤色の衝撃を制作し、`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-effects.webp` に収録。地上の射撃ポーズは銃口を着弾点へ向け、演出92フレームで既存のカオス姿に切り替え、232フレームで通常形態に戻す。切り替わりと復帰には暗赤色の光と効果音を合わせる。

再比較では低い銃撃から上空を取る既存の流れを使い、カオスが先に翼を引いて光を集め、斜め下にデスペナルティを放つ。杖を正面に掲げ続けるエアリスとは、背後へ引いてからの降下と地表への衝撃で区別する。屋上には冷色の月明かりを入れ、赤い翼の外周、白紫の射線、着弾の三つを画面上で追えるようにする。

組み込みImageGenでは「赤い頭帯と高い襟、金の爪、三連銃を手前へ向ける横長の通常形態」と「白紫の螺旋状の射線、紫の破片が地表からはじける透過素材」を制作した。配信用は `assets/limit-cutin.webp` と `assets/limit-finish.webp`。
