# 星見雅の専用リミットブレイク

対戦用の長い黒髪と耳、濃い青緑に金刺繍の上衣、黒いプリーツスカートと黒い鞘を全身姿勢とカットインで維持する。

落霜を溜める抜刀を軸にする。半身で踏み込み、相手の周囲に霜の線を引き、短く納刀する。氷が相手の足元に集まった瞬間に軸足を変えて抜き、二段の斬撃を重ねて最後に氷を砕く。バトルメイジの設置点を追う三角形の移動に対し、雅自身は足元の半円と納刀時の静止で緩急を付ける。

- [ゼンレスゾーンゼロ公式 星見雅と落霜](https://zenless.hoyoverse.com/ja-jp/news/127445)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。青緑の上衣と黒い鞘を維持し、霜の描線、納刀、抜刀と氷の破砕を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
