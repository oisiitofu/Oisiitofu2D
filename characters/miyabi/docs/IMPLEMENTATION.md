# 星見雅 / Hoshimi Miyabi

基本の外見と技は添付1、落霜アイコンと下必殺は添付2を基準に制作。バトルメイジの次、ID miyabi、人型サイズ2の94px。おまかせ最後・非表示進化形態を維持。濃紺/青緑と金の上着、白いシャツ、黒いネクタイ、黒髪と狐耳、赤い目、刀と鞘を保持。上着を中心に5カラー。

builtin image_genで48全身ポーズ、追加8全身ポーズ、16FX、専用の高解像度上半身画像とゲージアイコンを制作。元画像は characters/miyabi/assets/miyabi-poses.png、miyabi-specials.png、miyabi-effects.png、miyabi-gauge.png、miyabi-selection.png。崖用全身の補修は同miyabi-ledge.png、組立て済みは同miyabi-native.png。正確な生成/修正プロンプトとモードは [image-prompts.json](image-prompts.json)。関節リグを使わず全身ラスターを切り替える。通常技15種類を別の全身絵にし、NB5段もすべて別姿勢。選択画像は小さいゲーム用画像の拡大ではなく専用1536×1024。合計57フレーム（56全身＋ゲーム用ポートレート）と16FX。

- NB「落霜・五連」：タップは1段、長押しで最大5段。攻撃窓は8〜11F、20〜23F、33〜36F、47〜50F、64〜69F。次段の受付は15/28/42/58F。途中で離した場合は次段を追加せず終了。水平斬り、踏み込み斬り、回転からの斬り、X字斬り、全方位斬りの専用姿勢。4段目は大きなXの素材と1つの判定、5段目は左右へ広がる霜の輪。1ウィンドウ1ヒット、最大5ヒットで、余分な多段を足さない。飛び道具は生成しない。
- NBのゲージ獲得：同じ相手に全5段が命中したとき1個、1回の連撃につき1度だけ。相手別のbitmaskで管理し、複数相手へのバラバラの命中や5段目だけの命中では獲得しない。ガードはonHitへ到達しない。空中から着地しても連撃を維持。
- 横B「氷雪」：9〜13Fに踏み込み斬り。いったん離して16〜29Fに必殺を再入力すると跳ぶ追撃、左右で逆方向も指定できる。落霜があれば1個を使い追撃を11→18ダメージ、リーチ132→163、踏み込み速度5.8→7.5へ強化し、吹っ飛びも強める。長押しだけでは自動追撃しない。無敵や技終了後の時間式クールダウンは付けない。
- 上B「水鳥」：8Fまで落下慣性を抑え、最初の14Fは入力で左右を調整して斜め上昇。続く20Fは空中で静止して方向を整えられる。初段と別の必殺再入力で横向きの斬り抜けへ移行し、上下で角度を調整できる。落霜1個で9→16ダメージ、リーチ122→162、移動速度8→11へ強化。ステージ真下では端へ抜けてから上昇。終わると専用の尻もち絵になり、着地/崖つかまりまで攻撃不可。
- 下B「霜月」：添付2の居合技。所持数から2/4/6個の最大使用可能段階を選んで発動し、開始時に消費。Lv1は26F、Lv2は30F、Lv3は34Fで斬る。威力20/28/38、リーチ165/205/245、判定半径27/30/33、基礎吹っ飛び6/7/8と成長0.095/0.105/0.115。強い段ほど発生が遅く、斬った後は24Fの後隙。消費なしでは発動できず、空中でも使える。途中被弾は消費済みで中断される。

落霜は最大6個。対戦中600F（10秒）ごとに1個、ヒットストップは進めず、上限時は追加しない。復活時にゲージと時間をリセット。HUDへ青い炎と丸い赤芯の専用アイコン6個、所持数と次回回復の進捗を表示。通常攻撃の命中だけではゲージを追加しない。

斬撃0/2と居合5/6/7の凸側は右、上曲線1は上、X素材3は前方へ交差、輪素材4は両側。ローカル回転後に左右反転。AttackEffects.imageで見える効果を最終判定へ合わせ、上強/上スマ/空上は頭上の曲線1個。共通MeleeBalance.coverageを近接へ一度だけ適用。後方斬り14だけ元絵を反転して左へ正規化。25番の歩きの自動抽出が隣の手袋だったため、確認した元座標から全身を切り出す。追加ポーズは立ち姿の比率で一律縮小し、頭身/縦横比/足底を維持。通常投げは前=位置変更、後=撃墜、上=浮かせ、下=追撃。

ルートから node characters/miyabi/tests/assemble-art.cjs で組立て。register.cjsは初回登録用なので登録後に再実行しない。サーバー起動後ART_IDS=miyabiで配信アートを生成。起動時の元シート解析や全アトラス先読みには戻さない。

元シートの崖絵に脚の欠落があったため、37〜39は同じデザインの全身画像を生成して置き換えた。補修シートの基準立ち姿から倍率を一度だけ測定し、元の待機画像は保持。38の最高点の空の手から崖グリップを測定。選択画像は顔の寄りと両耳の完全な輪郭を確認して調整。ゲージ8も星形の芯から添付2の丸い赤芯の専用画像へ交換。
