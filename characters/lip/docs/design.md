# リップの固有設計

添付の大きな赤桃色の髪と高いポニーテール、花の飾り、桃色の花びらドレス、赤い靴、花のステッキ、小さな妖精の羽を維持。人型1（78px）、重量72。顔・頭身・衣装を固定した全身画像と専用の顔肩アップを制作。

- NB「パネルショット」：次の色のパネルを1枚飛ばす。ホールドで色を巡回して、離した色を発射。パネルは相手に命中すれば単発で割れるほか、同色の設置パネルへ当たると連鎖の種になる。色はハート/星/三角/四角/ひし形の5種類で色覚だけに頼らず形でも示す。
- 横B「チェインポップ」：本人はステッキで前方を指し、近くの設置パネルから同色隣接のパネルへ時間差で連鎖する。突進しない。配置がない場合は前方へ短い3枚の仮パネルを並べ、予告後に順番に割れる。設置を使えば範囲と連鎖数が伸びるが、敵は割れる順を見て避けたり、本体へ詰めたりできる。全パネルが同時に大爆発しない。
- 上B「フラワーリフト」：足元に花を咲かせ、花の風に乗る。最初に左右入力で花の位置をずらし、花が開くまで本人は短く待つ。花から斜めに運ばれ、上昇中に横入力を変えると一度だけ弧を曲げられる。自分の同色パネルが近くで連鎖すると花びらの流れが伸びる。2回攻撃の上昇にせず、発動位置・弧の曲げ方・設置の連鎖が判断になる。有限時間、空中1回、台下から復帰できる位置を確保する。
- 下B「パネルセット」：足元前方に現在の色のパネルを1枚置く。上限5枚、隣に並べる位置を少しずらして設置。同色3枚を連鎖させると次の射撃が強化。ハートの連鎖は本人の小回復、星は大きな単発、三角は上への打ち上げ、四角は横の位置替え、ひし形は長い予告から広めのポップ。空中設置は最初の足場へ落ち、本人の下Bは浮遊台を降りない。

空Nは花びらとステッキの踊る斬り、空前は花の突き、空後は背後へのハート、空上は頭上へ星、空下は下方へパネルを押し出す。通常/スマッシュ/空中技で全身姿勢を分ける。パネルや花の魔法が見える外縁と判定を合わせ、花びらの残光で持続を延ばさない。

既存キャラとの差は、5枚までの配置と色/形、隣接判定、割れる時間差による盤面作り。CPUは設置と発火を分け、オンラインでは色順・隣接・連鎖予約時刻・命中済み集合を決定的に処理する。
