# リップ実装

スカポンの直後。人型1/78px・重量72。全身76枚+専用選択アップ、16FX、5カラー。固定待機 `assets/lip-neutral-locked.png`、全身画像による予備/攻撃/戻り。下スマ/花の復帰準備/空Nは1本のステッキが明確な修正版を使用。攻撃シートの最下段5体を正しく分離し、余分な姿勢を除外。

NBはタップで1枚、ホールドで8Fごとに色/形を巡回して離した色を発射。下Bは足元へ最大5枚を設置。同色が56px内で隣接すると、横Bや同色弾から12F予告+9F間隔で連鎖。配置なしの横Bは短い仮パネル3枚。同色3枚で次の弾だけ強化。ハートは波ごとに小回復、星は単発威力、三角は打ち上げ、四角は横移動、ひし形は長い予告と広い範囲。上Bは花の曲線上昇で、途中に一度だけ左右の弧を曲げ、近いパネルのポップで流れが伸びる。空中1回、台下からの復帰と着地時の補充を確認。

設置パネルは最初の足場へ落ち、本人の下Bは浮遊台へ着地しても技を維持。設置数/色/時刻/命中済み集合を決定的に処理。近接は画像のステッキ座標と共通coverage、遠隔爆発は専用の範囲。花びら0は右、頭上の曲線1は上。ハート/星/パネルの破裂を曲線へ分類しない。共通エンジン変更なし。

検証：96項目、CPU2戦、通常/予備/戻り/色75場面+必殺14場面、2端末331F一致。77枚/16FX/385色別画像一致。設置上限、色/距離による連鎖切れ、時間差、次の弾だけの強化、各色カウンター、浮遊台/復帰を確認。結果はpreviews、制作記録はart-prompts.jsonとart-correction.json。
