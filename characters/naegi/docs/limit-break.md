# 苗木 誠の専用リミットブレイク

学級裁判の言弾を使う。正面から小さく踏み込み、矛盾の札を三つの高さに出す。相手の前を向いたまま机の内側を一度くぐり、下から札を見上げて撃ち返す。最後は既に割った札の間に残る大きな矛盾を中央で捉え、手元の証拠から「それは違うよ！」の言弾を通す。カイが本人ごと斜め上に走る構成と違い、苗木は裁判席に踏みとどまり、証拠と打ち抜く方向を変える。

対戦用素材の髪、制服とフード、靴を全身姿勢とカットインの参照にする。最初の連撃は札・紙片の動きに合わせ、決め技は指先と命中点をカメラ内に残す。画面の文字は左向きでも読める向きで表示する。

専用絵には学級裁判場の背景、反論時の横長カットイン、札・証拠片・言弾・破砕の透過素材と、ノートを持って踏み込み指し示す全身姿勢3種を用意した。標準カラーでは専用全身姿勢、別カラーでは対戦用の対応姿勢を使う。証拠を出す音と、矛盾の札が砕ける音は個別に制作した。
