# サキ・アマミヤのリミットブレイク

『罪と罰』のガンソードによる射撃と斬り返しから、終盤のラフィアン形態へつなぐ。人間形態の専用カットインと全身ポーズ、ラフィアンの全身、終末の都市、ビームと爆発を分けて描画し、変身でカメラを引く。

射撃2発、反射弾、ビーム、爆発は2・2・3・2・3ダメージ。最後に24ダメージと斜め上の吹っ飛びを適用する。銃声、反射音、砲撃音を段階ごとに切り替える。
