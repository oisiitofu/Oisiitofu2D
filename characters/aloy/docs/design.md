# Aloy from Horizon Zero Dawn

画像制作前の固有技設計案。ゲーム側で最終調整する。

固有能力・操作：フォーカスの標識・属性矢・罠・グラップル。NBは押す長さで通常/炎/氷/電撃矢を選び、矢の用途は距離を取る/継続ダメージ/足止めで異なる。DBは地面へ二端点式のワイヤートラップを置き、NB属性矢を線へ当てると対応属性に変わる。SB「狩動」は低姿勢で滑りながらワイヤー端を打ち込む設置行動、既存罠がある時は反対端を打ち、接触ダッシュ攻撃はしない。UB「クライム」は斜め上の地形や設置したワイヤー端をロープで掴み、振り子からジャンプを離して跳ぶ。地形なしでは一度だけプルキャスターを空中のグライダーへつなぐ短い退避。既存との差：横Bは罠の配置/端点操作、上Bは接続先で軌道が決まるロープ復帰。相手の対処：ワイヤーを飛び越す/端点を壊す、属性射撃中を詰める、掴んだ縄の出口を狙う。槍の近接と弓射撃を別の全身姿勢・斬音/弦音で表現。

原画の顔・体型・衣装を固定し、全身画像を切り替える方式。関節リグは使用しない。選択/勝利には専用の高解像度上半身アートを使う。
