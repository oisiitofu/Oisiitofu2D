# アーロイの専用リミットブレイク

『Horizon Forbidden West』のプルキャスター、シールドウイング、機械のオーバーライドをつなぐ。フォーカスで相手と足場の支点を捉え、膝をついて矢を放つ。遺跡の梁にプルキャスターを掛けて斜めに引き上がり、短い滑空の間に弓へ持ち替えて撃ち下ろす。着地は高所から正面へ落ちる形にせず、トレマータスクの横へ降りて槍を接続する。機械のオレンジの目が青に切り替わり、アーロイは牙の軌道から低く飛び退く。最後に踏み込みと牙の振り上げを引きで見せ、アーロイの矢で追撃する。

ピポサルは頭のローターで宙に止まり、サムは地面の傾斜と足場を使う。アーロイは梁に張ったケーブルと滑空で高さを変え、着地してから機械の状態と攻撃方向を切り替える。赤い編み髪、顔、武器、既存のノラ装束を保つ。ケーブルが手首から伸びる位置、シールドウイングを握る手、槍の先と機械の接続位置を実描画で照合する。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中6ヒットで21ダメージ、決め技で26ダメージ。プルキャスターのワイヤと手首、シールドウイングの持ち手と両手、槍とオーバーライド端子、トレマータスクの四本の牙と逆方向の吹っ飛びを確認。CPU同キャラ戦はストック切れ。ローカルオンラインは414フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
