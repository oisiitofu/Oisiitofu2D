通常15攻撃と投げは長剣/盾/肘のポーズを使う。判定を身体から先端へ連続させ、小さい相手に密着しても当たる。攻撃後の余分な必殺技クールダウンは付けず、飛び道具と持続設置物だけを個別に制限する。使い魔は地形で消え、各相手に1回だけ命中する。

## 素材と再パッキング

**内蔵 image_gen** で制作。生成指示の全文は [image-prompts.json](image-prompts.json)。参照 [reference](../assets/alucard-reference.png)、生成した [poses](../assets/alucard-poses.png)・[motion](../assets/alucard-motion.png)・[effects](../assets/alucard-effects.png)・[selection](../assets/alucard-selection.png)、結合元 [native](../assets/alucard-native.png) を保存。

`tests/assemble-art.cjs` は透過RGBAを保持し、元ポーズを再生成せず切り抜く。動作シートの実際の配置は8/6/6/4枚、最初のシートは各行6枚。元シートの隣の刀先が混ざる欠片を分離し、盾だけ周辺の余白を詰める。待機基準を固定し、しゃがみや走りを同じ高さまで引き伸ばさない。足底と崖の手は生成後に計測。色替えは赤いマント部分だけ、金の装飾・髪・顔・白い襟は維持。

斬撃0の先行する凸側と、波/動物は右向き。素材ローカル補正→回転→キャラ左右反転→平行移動の順で適用し、前後上下の実判定と一致させる。変身は全身の狼/コウモリ/霧の絵を使い、人体パーツを変形しない。
