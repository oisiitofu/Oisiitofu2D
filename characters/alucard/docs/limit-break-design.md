# 高速連斬からソウルスティール

2026-11-05の「もっと動き回ってよい・非常に品質の高いアニメーション」の指定を適用する。既存の待機・基本技・選択画像は維持し、専用全身ポーズ8枚を2つのアトラスに制作する。顔、長い淡金髪、黒金のコート、赤い裏地、白い胸飾り、剣の長さを参照から固定する。

構成は、命中停止とカットイン、深い踏み込み、高速横断の斬撃、上への斬り上げ、空中の追撃、着地、魂を集める詠唱、決め技、残光の順。左右を切り替える場面は向きと刀の進行を揃え、攻撃地点へカメラを滑らかに追従させる。姿勢ごとに予備・切断・振り抜き・戻りを区別する。カメラだけを揺らして動きの代わりにはしない。

原作の高速剣技とソウルスティールを題材に、対戦用の一連の演出へ構成する。通常必殺技の挙動や体力回復の仕様は変更しない。斬撃は凸側・攻撃方向を素材と比較し、魂や光が濃くても本人と相手を追える描画順にする。ローカルで対戦・トレモ・両向き・カットイン比率・攻撃の濃さ・専用音を確認。CPUは60秒1ストック設定の1戦が結果まで進行。オンライン347フレームが一致。連続再生を録画し姿勢と移動を比較した。公開検証は `docs/limit-break-rollout.md` に記録する。

内蔵imagegenの最終プロンプト、参照、元出力と保存先は `limit-break-assets.json`。連続再生の録画はGit管理外の `previews/alucard/limit-break/playback.webm`（映像のみ）。主攻撃はart.strike、補助光はart.glow、カットインは共有LimitCinematic.portrait。新しい全身画像の間は共通のカメラ時間軸で移動させ、顔・頭身・衣装の連続性を維持する。
