# ディートリヒの専用リミットブレイク案

黒炎の印を地面に残し、相手が印の上へ来る順に斬撃を返す。黒翼で斜めに飛び、最後は三方向の印から黒炎が集まる。プネウマの光点は本人の通過点として使うのに対し、ディートリヒの印は相手の着弾点に置く。対戦の衣装、剣、黒翼を使用する。

「黒翼・黒炎の牢獄」は銀髪、黒紫の甲冑、金装飾の柄と赤い剣閃を維持する。ImageGen で描いた横長カットインの後、対戦素材の黒翼を展開して頭上を横切る。相手を左右の印へ運び、地面に戻った後で三つの印から黒炎を点火する。沈んだ紫の城壁を背景に、斬撃の赤い先端と炎の黒い芯を見せる。

配信素材は `assets/limit-cutin.webp`、`assets/limit-citadel.webp`、`assets/limit-effects.webp`、`assets/limit-marks.webp`。決め技の音は三度の点火音と低い爆発音を重ねた専用サンプルを使用する。
