# コジコジの専用リミットブレイク

対戦用の顔の輪郭・衣装と配色を維持する。低い位置から宙へふわりと浮き、メルヘンの国の三日月に背中を預けて向きを変える。次は小さな星を押して自分と相手の位置が入れ替わる。最後は体を丸めて空へ抜け、星が落ちて相手を押し出す。ちいかわの足元を支点にした動きに対し、浮遊中の姿勢と三日月の反動でカメラを動かす。途中の命中間隔は17〜22フレームとする。

- [日本アニメーション公式 メルヘンの国とコジコジ](https://www.nippon-animation.co.jp/work/1777/)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。三日月で向きを変えて宙を渡り、メルヘンの星降りへ。途中7ヒット、決め技27ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
