# オクタン / APEX LEGENDS

添付octane.pngのマスク・緑のゴーグル・黒い頭部装備・緑のハーネス・義足・バタフライナイフを保つ。人型サイズ3（98px）。顔〜肩の専用高解像度選択画像を制作する。

## 固有の能力と操作

- NBフラグブースト：近くへ投げたグレネードの爆風を利用して移動する。爆発直前のスティックで自身の飛ぶ方向を選択（無入力は前斜め上）。相手には爆発の攻撃判定、自分には4%の自己負担と移動の反動。自分の既存の被弾硬直や吹っ飛びは上書きしない。空中で再使用できるが、爆弾の同時数と再使用間隔を制限する。爆発から離れて牽制にも使える。
- 横Bスティムスライド：2%自己負担の注射から高速走行。地上では低姿勢のスライディング接触へ派生し、ジャンプ入力でスライドを中断して跳び越せる。空中では水平突進攻撃を繰り返さず、義足の蹴りと短い方向調整に変える。スティム中は地上のスライドが長く、飛び越しを選ぶ余地も広い。ガード・空振りで終端の隙をさらす。
- 上Bジャンプパッド：パッドを足元へ投げ、最初は自分がその反発で飛び上がる。パッドは地形へ落ち着き、自分・味方・相手の全員が着地して使える。左右入力で前方へ飛ぶ低い軌道、無入力/上入力で高い軌道。空中から設置する初回反発も認め、場外復帰を保証するが、再設置による空中連続使用は着地まで禁止。上昇攻撃ではなく共有する経路の設置。相手にも復帰や追跡を許すリスクがある。
- 下Bスティム：5%自己負担で約5秒の移動・ジャンプ・攻撃速度強化。技の色替えだけでなく、横Bの滑走距離と入力派生の猶予、地上/空中の移動を変える。重ね掛けで無限延長せず、強化中は再注射不可。
- 戦闘狂/Swift Mend：注射と自分のフラグブーストで負担したダメージのみを時間で少しずつ回復。相手から受けたダメージは回復しない。自己負担の残量をHUDに表示する。

## 技の連携と相手の対処

パッドを置いて高低の経路を用意し、注射で走り回りながら、グレネードの反動で別の軌道へ移る。パッドは相手も使えるため設置場所を選ぶ。グレネードは起爆まで間があり、相手はその場を離れる/ガードできる。スライドはジャンプで避け、注射の始動・空振り後の隙を狙える。自己負担は自然回復に時間が必要。

ジェットの無攻撃方向ダッシュと上昇→横移動とは異なり、設置パッドを双方が踏む経路の読み合い、自己負担と回復の管理、地上の滑走→任意ジャンプを中心にする。上Bの二段攻撃・横Bの往復突進を基本形にしない。

## 制作と検証

通常技はナイフ・義足・肩・肘を使い分け、専用の全身姿勢と刃/蹴り/爆発エフェクト、対応する命中音を作る。密着・先端の補正は共通coverageを同じヒットIDで使用し、設置物と爆発には無条件に掛けない。元の立ち姿を固定し、関節変形を使わず全身画像を表示する。左右の見た目・命中・復帰、パッドの共用、自己負担のみの回復、CPU1戦、短いオンライン同期を確認する。
