# オクタンの専用リミットブレイク

対戦時のマスク、ゴーグル、緑の装備と義足の接地を基準にする。興奮剤の光が重なっても顔と義足の輪郭を残し、全身姿勢とカットインでゴーグルや配色が変わっていないか確認する。

地上でランチパッドを滑らせ、踏み込んで手前の低い軌道へ跳ぶ。相手を追い越した先で一度着地し、急停止から二枚目のパッドで急角度に跳ね返り、義足で追撃する。最後は最初のパッドがある高さへ戻り、相手と着地点を同時に映しながら両足で踏み抜く。ジェットの長い滑空と下向きの投擲に対し、足の接地と二つのパッドの反発を軌道の節目にする。

- [EA公式 オクタンとランチパッド](https://help.ea.com/en/articles/apex-legends/abilities/)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。二枚のランチパッドで向きと高さを切り替え、義足の連撃からダブルストンプへ。途中7ヒット、決め技27ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
