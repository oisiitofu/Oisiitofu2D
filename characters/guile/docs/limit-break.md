# ガイルのリミットブレイク

ストレートからソリッドパンチャーのソニックブーム6連射、ソニックハリケーンによる打ち上げ、クロスファイアサマーソルトへつなぐ。公式で紹介されたスーパーアーツを組み合わせたゲーム用の演出。途中10ヒットは合計16ダメージ、最後に22ダメージと斜め上への吹っ飛びを適用する。

初撃は近接でガードと無敵に防がれる。空振り時はゲージを消費し、被弾でため直せる。命中時は1人を捕捉し、途中の弾には吹っ飛びを付けず、最後の蹴りで解放する。ほかの参加者と対戦時間は演出中停止する。弾幕は相手へ届くタイミングに合わせ、最後の蹴りは逆さの全身ポーズと足先を追う上向きのカメラで見せる。

素材はビルトイン画像生成で制作した。元の選択画像を顔・金髪・迷彩のタンクトップ・ドッグタグ・体格の参照とし、16対9のカットイン、夕方の空軍基地の背景、ストレート・ソニックブーム・逆さのサマーソルト・着地の透過全身4姿勢、ソニックブーム・ハリケーン・蹴りの軌跡・命中火花の透過4種を指定した。弾は右向き、蹴りの軌跡は元から右上へ伸びるため、追加で約0.42rad上へ回転する。共通の画面反転で左向きにも対応する。

カットインはLimitCinematicで比率を保つ。攻撃はart.strike、溜めの光はart.glow。揺れと明滅は見やすさ設定へ従う。専用のソニック音は空気を圧縮する高音の下降、最後の蹴りは上昇する空切りから硬い破裂へつなぐ。

素材はこのキャラの `assets/limit-*.webp`、効果音は `assets/audio/se/guile-limit-*.wav` に保存した。
