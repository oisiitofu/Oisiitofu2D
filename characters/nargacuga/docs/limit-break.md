# ナルガクルガの専用リミットブレイク

「迅竜・双刃尾撃」は、肩の翼刃で相手を追い、低い姿勢で横を通り抜けて向きを変え、高さを変えた飛び込みと尾棘をつなぐ。アイルーが離れてタルを転がす構成と違い、本人が相手の死角へ待ち伏せ、赤い目の残像が移動を示す。最後は着地した前脚で踏ん張り、尾を頭上から叩きつけ、尾の進行方向へ相手を飛ばす。[『モンスターハンターライズ』の実機映像](https://www.youtube.com/watch?v=y6kUiY3Pmfo)

紺の体毛、翼刃と耳の赤い縁、長い尾、目の位置と四足の体型を対戦素材で確認した。ImageGen で横長カットイン、夜の竹林、爪・尾棘・粉塵と、低い構え、跳躍、尾の打ち下ろしの全身姿勢を制作した。標準カラーは専用姿勢、別カラーは対応する対戦姿勢で表示する。

配信素材は `assets/limit-cutin.webp`、`assets/limit-bamboo.webp`、`assets/limit-effects.webp`、`assets/limit-trace.webp`、`assets/limit-motion.webp`。尾と地面の衝突には専用効果音を使う。
