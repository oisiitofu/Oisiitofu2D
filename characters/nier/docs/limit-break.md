# ニーアのリミットブレイク

白の書が開くと舞台が魔王の城に変わり、ニーアは魔王の姿をまとう。黒い翼で地を蹴って相手の背後に回り、異なる角度から斬りかかる。最後は魔力の槍で動きを封じ、急降下の一太刀で決着する。魔王への変化はこのゲーム独自の演出。
