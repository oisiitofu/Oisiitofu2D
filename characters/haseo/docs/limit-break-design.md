# ハセヲの専用リミットブレイク

対戦用の白髪、黒い鎧、赤い棘、金縁の黒い大鎌をカットインと通常姿勢で維持する。現行の姿から八相アーツの武器変化へ入り、最後は大鎌に戻る。

熾烈なる斬首で相手を浮かせ、二本のランスに変えて空中で引き戻し、巨大な槌を振り下ろす。床に着地してから間を取り、光弾の凶つ神の裁きで締める。グランが甲板の同じ高さから召喚と剣を合わせるのに対し、ハセヲは地上、空中、床への落下で武器と間合いを切り替える。

- [.hack//G.U. Last Recode 公式 八相アーツ](https://hackgul.bn-ent.net/new_elements/phase.php)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。白髪と黒赤の装備を対戦素材に合わせ、大鎌から二本のランスと槌、光弾への流れを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
