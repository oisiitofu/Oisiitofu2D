# 専用リミットブレイク

一歩ずつ異なる高さで跳ね、踊りから風を巻き起こす。本人が短く飛ぶたびに羽音と風の方向を変え、最後は足元から風を巻き上げる。アルスの剣と雷の一点への集中と区別し、風が地面を進む。既存の白い体、紫の翼、赤いポンポンを使用。

改修では対戦用の白い丸い体、紫の翼、赤い鼻とポンポン、閉じた弧の目を参照した。組み込みImageGenで、風に乗って跳び蹴りする横長カットイン、月明かりの森、蹴りと風の着弾、緑の竜巻、風に流れる葉を描き起こした。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-effects.webp`、`assets/limit-motes.webp` に収録。ラプソディは着弾火花より背後に竜巻を置き、跳ねる本人と風に巻き込まれる相手の両方を追える構図にする。
