# 専用リミットブレイク

杖を中心に雷・火・氷のエレメントを召喚し、発射した反動で斜めに移りながら次のエレメントを射出する。最後は高い位置に並べ、頭上から順に着弾させる。ナミネの紙片が一度に中央へ集まる構図と区別し、高度を変えた砲撃をつなぐ。 対戦用の髪・衣装・装備を使用。

[任天堂のキャラクター資料](https://www.nintendo.com/en-gb/Games/New-Nintendo-3DS/Xenoblade-Chronicles-3D-961136.html)

改修版では、対戦用の薄紫の髪、白い羽飾りと青金の衣装、輪型の杖を参照し、杖を横に振りながらエレメントを召喚するカットインを ImageGen で制作した。月夜のテラスを背景に、雷は紫の稲妻、炎は橙の渦、氷は水色の結晶に分けて描く。決め技では頭上に並ぶ三つの紋が順に降下し、縦の落雷、横に広がる炎、足元から伸びる氷の順に着弾する。主攻撃の大部分は相手の背後に置き、命中点を手前の小さなエフェクトで示す。

配信素材は `assets/limit-cutin.webp`、`assets/limit-terrace.webp`、`assets/limit-effects.webp`、`assets/limit-elements.webp`。
