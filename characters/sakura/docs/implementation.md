# 真宮寺さくら

アルルの次。サイズ2、94px。荒鷹・桜の霊力に合わせた63枚の全身画像、16種のVFX、高解像度の顔・肩専用選択画像。

- NB桜華放神は溜められる貫通衝撃波。横B百花繚乱は上下入力で方向を選ぶ3本の花びら斬撃。踏み込みは短く、長距離突進とは使い分ける。近接の窓だけmeleeCoverageを適用。
- 上Bは斬り上げから花びらの弧へ移る2段階の軌道。左右で操舵でき、入力待ちで浮かない。台の下では側面へ抜けてから上昇し、専用尻もちへ移る。
- 下Bは無防備な瞑想。霊力を蓄積し、100で次の攻撃必殺を1度だけ強化。下B自身は満開を消費しない。
- 空Nは前方から頭上へ開く花びらの扇状斬撃。2枚の全身姿勢を使い、既存の1攻撃窓・ヒットIDを維持。上スマ・空上は頭上の曲線1つ、柄打ちは打撃のまま。
- 構図が欠けた元シートの上強等は個別の全身画像で補い、隣ポーズの足や武器をセル矩形で切り込まない。

検証: 専用121項目、密着・先端を左右両向き、復帰両側・台下、通常30場面・特殊24場面・待機10場面、連続映像48サンプル、CPU1戦。新4キャラのアート読み込み・透過・全5カラーも照合。
