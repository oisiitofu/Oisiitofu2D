# 真宮寺さくらの専用リミットブレイク

真宮寺さくら本人の霊剣・荒鷹と北辰一刀流から、専用の霊子甲冑・光武での破邪剣征へつなぐ。相手の打点より下へ姿勢を落として抜刀、踏み込みで斜めに斬り上げ、後ろへ跳んで舞台の迫りへ着地する。せり上がる光武に乗り込み、低い構えから蒸気で踏み切って相手の上へ出る。刀を縦に振り下ろして着地し、刀身の先から扇状に広がる桜華放神で締める。光武の姿は公式の真宮寺さくら専用機を参照する。

桐生は相手を持ち上げて投げ、リーンベルは自ら越えて遠距離から撃つ。さくらは後方の迫りへ退き、そこから光武の重量と刀の軌道で高低差を作る。鞍部十郎のコクピット操作と遠隔砲撃に対しては、乗り込む動作を外から見せ、機体の踏み切り、刀の落下線、接地から決め技への連続動作を一画面で追えるようにする。和装・髪飾り・顔はゲーム既存素材を基準に全身を描く。金属の着地、蒸気、鋭い桜色の斬撃、花弁と剣の音を分ける。

## ローカル検証

本人8姿勢、光武8姿勢、専用背景・カットイン・斬撃素材、オリジナル効果音2点を制作。途中5ヒットで20ダメージ、決め技で25ダメージ。光武のハッチが閉じた直後の接地位置をそろえ、決め技の扇形の根元を刀側へ寄せた。斬撃アトラスは隣のコマから混入した光を除去するため再制作。対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。CPU戦は時間切れで終了。ローカルオンラインで408フレームと決め技の吹っ飛びが一致。
