# イーノック — 実装前の技設計
位置: メタビーの直後。添付 e-nock.png の白銀の鎧・長い金髪・アーチ/ゲイル/ヴェイルを基準にする。
固有操作: 下Bで3武器をアーチ→ゲイル→ヴェイルへ切り替え、武器純度を浄化。攻撃で純度が下がり、浄化の隙を相手に狙われる。最大純度での浄化を連打して無敵/強化を重複させない。
アーチ: NBは足を止めたチャージ斬波。横Bは刃を投げて戻すアークカッターで空間を作る。上Bは武器を翼として上昇後、保持入力と左右で滑空し、離すと落下へ。二段攻撃の追加入力ではない。
ゲイル: NBで最大6枚の自動追尾刃を時間差射出。横Bは刃を指定方向の固定陣に展開し、次の入力で一斉に交差させて回収。設置が残る間に浄化を選ぶ判断。上Bは周回刃の上昇気流を維持し、方向入力で緩く移動する有限の浮上。被弾/終了で解除し無限浮遊させない。
ヴェイル: NBは構えた盾に短い耐え時間を設けた一撃。横Bは盾のステップを短距離だけ行い、離す/方向で踏み込みか守りを選択。上Bは盾で地面/ステージ側壁に接触すると強く反発する復帰。空中でも一度小さく反発できるが、壁を使うと到達方向が変わる。
既存との差: 3武器で攻撃距離、遠隔刃の管理、滑空/維持浮上/接触反発の復帰が切り替わる。変身ゲージだけの差分にしない。
対処: 浄化とチャージの隙を詰める。ゲイルの展開位置から離れて射線を切る。ヴェイルの反発先を読み、滑空の終了と着地を狙う。
画像: 全身の元ポーズを維持し、全身画像の連続姿勢を使用。専用の顔～肩選択画像。各武器の通常/空中/スマッシュとVFXを描き分ける。

## 実装・検証

専用の全身フレームと16種類の素材、顔と肩の専用選択画像を内蔵 imagegen で制作。元の待機ポーズは neutral-locked.png と一致。前後上下を左右両向きで確認し、近接補正はMeleeBalance.coverageを一度だけ使用する。新キャラ4人とイーノック3武器を対象に通常技の密着/先端・全必殺・有限時間・復帰を440項目確認。CPU戦、2画面オンライン960F、個別の設置/引き寄せ/武器切替/台上発動を確認。実描画と連続姿勢の検証画像・動画は各previewsに保存。

画像と最終プロンプトは同じdocsのart-prompts.jsonに記録。素材はassets、配信はassets/readyのmanifestとハッシュ画像。
