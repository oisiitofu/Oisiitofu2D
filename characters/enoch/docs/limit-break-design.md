# イーノックの専用リミットブレイク

対戦時の金髪、銀の装甲、黒い脚衣と白布を維持する。アーチ、ゲイル、ヴェイルを対戦中の装備と照合する。

アーチで相手を打ち上げ、ゲイルを放ちながら垂直に離れる。ヴェイルの両盾で着地を受け止め、近づいた相手を弾き返し、アーチへ戻って光の一撃で締める。ハセヲの空中での左右の入れ替わりに対し、同じ側で上下の距離を変え、攻撃、後退、迎撃の間を見せる。

- [El Shaddai 公式ポータル](https://elshaddai.jp/)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。金髪と銀色の装備を対戦素材に合わせ、アーチ、ゲイル、ヴェイルの切り替えを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
