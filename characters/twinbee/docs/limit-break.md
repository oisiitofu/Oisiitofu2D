# 分身連射 → ビッグショット

青い丸い機体、表情のない黄色いキャノピー、白い翼と手、ピンクの足を維持。既存のキャラ本体・通常技・必殺技・選択画像には変更を加えない。ベルから射撃姿勢へ切り替え、4回のツインショット、上下の分身を伴う5回の集中射撃、溜め、巨大なビッグショット、余韻へつなぐ。途中9回のダメージを共有時間軸で処理し、最後の一撃だけで吹っ飛ばす。

[コナミ公式説明](https://www.konami.com/games/jp/ja/products/dl_win_detanatwinbee_egg/)のベル強化・分身・3方向ショット・ビッグショットを題材に、単独プレイヤーでも完結する最大強化時の攻撃として構成。相棒や合体ロボを新しく創作する構成にはしない。専用ポーズ4枚を全身画像で制作し、分身も同じ比率で描画する。弾は右に芯、左に尾。画像の比率を保って大弾の頭が丸く見えるようにした。

素材は `assets/limit-{cutin,court,poses,effects}.webp`。内蔵imagegenの最終プロンプト・参照・保存先を `limit-break-assets.json` に記録。攻撃をポーズに焼き込んだ初稿は手だけの姿勢に修正し、出入りをart.strikeで制御。翼の端が切れないよう実画像の外形を確認してセル範囲を設定。銃口と弾の高さは戦闘画面で調整。カットインは共有LimitCinematic.portraitで縦横比を維持する。

専用効果音は高域の二重音を持つ連射音と、重い起動・明るい和音を持つビッグショット。ローカルで発動・密着・ガード・無敵・空振り後の充填・時計と他プレイヤーの停止・トレモ・両向き・効果音2音・カットイン比率・濃い主攻撃を確認。CPUは60秒1ストック設定で1戦が結果まで進行。`LIMIT_FIGHTER=twinbee` で既存の `characters/dragoon/tests/limit-break-online-test.cjs` を実行し306フレームが一致。公開検証は `docs/limit-break-rollout.md` に記録する。
