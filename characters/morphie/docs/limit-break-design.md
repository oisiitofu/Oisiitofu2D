# モーフィーズロウの専用リミットブレイク

対戦用の彩色、顔の絵柄、金属の継ぎ目を基準にする。原作の質量移動は脚と片腕の比率が変わる専用の全身ポーズで示す。小さいまま飛び退いて相手を射撃し、大きくなった脚で高く跳ね、片腕を着いて向きを変え、さらに大きなアバターへ接続する。最後は遠景のアバターの手と、手前の二人を同時に映す。シェフの調理台移動に対し、体の比率と接地する部位が変わる動きを中心にする。追撃は17〜22フレーム間隔を目安にする。

- [Cosmoscope公式 質量移動とアバター](https://morphieslaw.com/morphies/)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。質量を移し、脚と片腕を大きくしてアバターの一撃へ。途中7ヒット、決め技27ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
