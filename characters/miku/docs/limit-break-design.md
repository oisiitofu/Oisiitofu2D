# 初音ミクの専用リミットブレイク

バーチャルステージを開き、低いステップでビートを刻み、身体をひねるターンとジャンプを経てステージ中央に着地する。マイクで歌う短い音符の連撃に続き、跳躍からの着地に合わせて左右のスピーカーが応答し、最後の伸びる歌と照明の展開で相手を押し出す。ナイツの空中ループや直近の兵装・瞬間移動と異なり、ダンスの足運び、歌う手と視線、フレーズの間、左右の音源が攻撃順を決める。

既存の長い青緑のツインテール、青緑の瞳、黒とピンクのヘッドセット、灰色のノースリーブと青緑のネクタイ、黒い袖・プリーツスカート・ブーツを基準にする。マイクは既存の黒いハンドマイクに合わせる。ライブで歌とダンスと照明が一体になる構成を参考に、楽曲と歌声の質感はゲーム用のオリジナルのシンセ音とリズムで制作する。

横移動はステップ、跳躍は片足での踏み切り、着地は膝の曲がりを専用全身画像で示す。歌唱の口元とマイク、相手に届く音符、スピーカーの波、決め技の輪郭を実描画で確認する。青緑の光が髪と顔を埋めないよう、照明と主攻撃の合成を分ける。

## ローカル検証

途中8ヒットで19ダメージ、決め技で23ダメージ。音符の軌道を相手の手前へ調整し、音波から隣接コマの混入を除去した。ローカルオンラインは391フレーム一致。 対戦、トレモ、ガード、空振り、無敵、複数人戦、決め技の撃墜、両向きの描画、カットインの縦横比、専用効果音と全編の連続再生を確認。CPU戦は1戦を実施し、時間切れで結果へ進んだ。

## 公開検証

Sites v333とGitHub 05f829dへ反映。公開URLで対戦・トレモ・発動・ガード・空振り・決め技の撃墜を確認し、専用素材とバンドルのSHA-256を照合した。公開オンラインは固定入口のHTTP 503で部屋作成に進めず、同期は未確認。
