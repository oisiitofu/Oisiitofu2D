# アグモンのリミットブレイク

アグモンの火球からグレイモンの火炎、メタルグレイモンのミサイルへつなぎ、ウォーグレイモンを経てオメガモンのガルルキャノンとグレイソードで決める。オメガモン登場時は専用のカットインを挟み、砲撃と最後の斬撃にはそれぞれ専用の効果音を使う。進化の見せ場は演出中の描画で、対戦の進化段階は発動時の状態を保つ。進化済みのときはその形態から始まる。

連撃は6ヒットで合計14ダメージ。最後に22ダメージと斜め上への吹っ飛びを適用する。
