# アルフェンのリミットブレイク

『テイルズ オブ アライズ』の「灼炎楼・焔」を題材にした。剣で踏み込んで連斬し、斬り上げから火柱へつなぐ。炎をまとった剣を両手で構え、引きのカメラで炎の大きな斬撃を見せる。カットインと全身ポーズはゲーム内の半仮面、白髪、青い布、黒い鎧を基準にした。

途中は2・2・2・3・2・3ダメージ。最後に22ダメージと斜め上への吹っ飛びを適用する。
