# アルフェン / Alphen

テイルズ オブ アライズのアルフェン（alphen）をカサネの前へ追加。銀髪、片側の鉄仮面、黒と銅の鎧、青い裂けたスカーフ/マントを添付に合わせる。人型サイズ3・98px。

builtin image_genで全身53姿勢・16FX・専用1536×1024上半身画像を制作。ゲーム用54フレーム/5カラー。保存先は[assets](../assets/)、正確なプロンプトは[image-prompts.json](image-prompts.json)。関節リグを使わず全身画像を切り替える。待機0を固定し、追加シートは同じ立ち姿で校正。通常技15種は別の実画像。下スマ後半は専用の薙ぎ46で振り返り、空後14を使い回さない。window index/hitIDと時刻は維持。専用肖像の頭頂を補修し、実際のカードでカサネ等の顔の寄りと比較。

- NBデモンファング：14Fに9ダメージの衝撃波。12Fに保持していれば14Fの7と27Fの9ダメージの二連波。自身の弾の生存と発射間隔30Fだけ再射出制限。空中から着地しても二発目を保持。他の近接技へクールダウンを加えない。
- 横Bドラゴンスウォーム：その場で8〜12Fの低段3、18〜22Fの上斬り4、28〜33Fの横薙ぎ4、40〜45Fの突き10ダメージ。全4段で別の全身姿勢。前3段の吹っ飛びを小さくしてつなぎ、最後に飛ばす。前進は抑える。空中では落下する。
- 上Bゼプリングウィンド：7Fまで慣性を止め、13Fの上昇、10Fの風の渦、11Fの斜め上への斬り抜けへ自動で進む（6/5/9ダメージ）。最初と渦は左右入力へ滑らかに追従し、最後の入力で出口の向きを決定。元から回転する風の素材を使用。左右から地上へ復帰し、最後は専用尻もち35。
- 下Bフレイムエッジ：10F以降に離して解放。24FでLv2、48FでLv3、70Fで自動発動。保持中は毎F0.07（最大約4.5）の自己ダメージ、解放時に2/5/9追加。攻撃は13/20/28ダメージで範囲と吹っ飛びも強化。解放4〜10F後の単発近接判定。最大段階は広い噴出。自己ダメージで被弾硬直/吹っ飛びは発生しない。空中の溜めと解放待ちは着地しても保持する。既存キャラの着地ルールは維持。

AttackEffects.imageで可視切断面を武器より先の最終判定へ合わせ、近接coverageを一度だけ適用。弾/つかみへ適用しない。素材0/2/4/5/6/11は右凸、1は上凸、13は下凸。ローカル回転後に左右反転。上強/上スマ/空上は頭上の曲線1つ。噴出10は上向きを維持し横倒しにしない。投げは後ろ撃墜/上浮かせ/下追撃/前位置変更。弱い単発の専用攻撃上がりを維持。

機能128項目、左右54描画、CPU対ビビ2400F、54姿勢/16FX/270カラーのchecksum差0。実サーバー2ブラウザ6場面720F同期一致（テストのsnapshotプロパティ名をwindowsへ修正）。previewsはGit管理外、公開結果はBALANCE.md。
