# モノ：描いた仲間への命令

- 固有操作：仲間がいなければDBで従来の召喚。生きた仲間がいるときのDBは再召喚ではなく方向付きの命令にする。COLOR6、命令間隔48F。通常召喚の15消費・100F再使用待ちと別に扱う。
- 操作と連携：命令は本体10Fの描き込み、仲間12Fの予告後に発動。本体は28Fまで拘束。騎士の前進斬り、ユニコーンの直進、コウモリの斜行、ウサギの跳躍、スライムの短い広範囲攻撃を使い分ける。NBの色選択、SBの描線と乗り換えは維持する。
- 差：自動追尾・無制限の召喚増加は行わない。明示的な1命令につき1回だけヒット履歴を更新し、連続フレームで多段化しない。命令で150Fの寿命を更新しない。消滅まで予告＋命令の時間が残っていない場合は命令不可。
- 対処：予告中の召喚には攻撃判定を出さず、敵の近接で消せる。予告中に本体を被弾させれば命令を中断できる。方向は予告時に固定するため回避・ジャンプ・ガードで対応可能。COLORは使った分を返さない。
- リスクの明確化：NB/SBの再使用待ちを通常攻撃やつかみへ誤適用していた隠れ硬直を除く。描き終わるまでの既存の戻りは残し、戻り後は通常攻撃・防御を使える。
- 表示：仲間の残り寿命、命令可能／待機、固定方向と予告を既存の召喚画像・筆跡で表示する。既存の全身ポーズを維持する。
