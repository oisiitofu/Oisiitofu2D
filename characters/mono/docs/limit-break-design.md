# モノの専用リミットブレイク

対戦時の黄色い髪、緑の目、白い服、青いケープ、赤い胸飾り、茶の靴と色鉛筆を維持する。全身素材は元の角ばった造形を参照する。

床に描いたスライムを弾ませ、次の線からユニコーンを走らせる。モノ自身は地面に弧を描いて戻り、大きなラクガキが線から立ち上がって決め技を放つ。レイマンが足場から滑空して自分の拳を飛ばす構成に対し、モノが描く位置と召喚したラクガキの動きを同時に見せる。対戦中のラクガキ召喚を広げたゲーム独自演出。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。角ばった髪と服、ケープ、色鉛筆を対戦素材に合わせ、描線、スライムとユニコーンの連携を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
