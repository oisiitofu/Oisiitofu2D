# 専用リミットブレイク

杖で空間に魔法陣を三つ置き、最初の二つで押し返し、最後の一つへ歩いて移る。聖なる魔法陣から光を反射させて相手を捕らえ、収束したジャッジメントレイで締める。ティナの高速空中移動とは異なり、陣間の短い移動と射線の組み替えで場面を作る。リボン、赤い上着、桃色のドレスと杖には対戦素材を使う。

改修では現行の全身素材と選択肖像を参照し、茶色の編み髪、桃色のリボンとドレス、赤い上着と細い杖を合わせた。組み込みImageGenで制作したのは、花の教会で杖を掲げる横長カットイン、教会の背景、花弁の魔法陣、光弾、ジャッジメントレイの白金の射線。素材は `assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-sigil.webp`、`assets/limit-effects.webp` に保存。床の三つの陣から光を時間差で杖先へ集め、射線と命中の花弁を分けて描く。

再比較では、三つの陣を作って滞空するエアリスの動線を残す。直近のザックスが踏み込んで刃を当てるのに対し、エアリスは相手との距離を取り、陣から頭上の杖へ光を集めて斜め下へ放つ。教会の明るさを発射前から落とし、翠と金の射線、相手位置に残る着弾光、杖を構える全身を同時に読めるようにする。対戦のリボン・編み髪・赤い上着・細い杖をカットインの参照に使う。

組み込みImageGenでは「対戦のリボン・編み髪・赤い上着・桃色のドレスを維持し、夜の教会で杖を前へ構える横長構図」と「翠と金のステンドグラスの射線、花弁と結晶片を放つ着弾の透過素材」を制作した。配信用素材は `assets/limit-cutin.webp` と `assets/limit-finish.webp`。
