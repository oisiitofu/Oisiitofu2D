# モノクマの専用リミットブレイク

『ダンガンロンパ』の学級裁判と学園長の仕掛けを、ゲーム内の架空の野球ノックへつなげる。証言台へ跳び乗って木槌を鳴らし、床の円盤が回って相手の足場が奥から手前へ移る。モノクマ自身は欄干を手でつかんで下段へ降り、側面のレバーを両手で引く。球が高く曲がって三方から戻り、モノクマは回転する発射台の横を追いながら最後の球をバットで弾く。最後の命中を黒・白・マゼンタの紙吹雪と衝撃線で見せる。

ピポサルのグローブは本人の手に戻り、サックボーイはピストンで垂直に上がる。モノクマは円盤の回転で奥行きと相手の位置を変え、本人は欄干とレバーに体重を預けて下へ降りる。顔の白黒の左右、赤い稲妻目、既存の頭身を保ち、床の回転とボールの軌跡が重なっても誰がどこにいるか追える構図にする。

- [スパイク・チュンソフト公式 学級裁判と学園長モノクマ](https://www.danganronpa.com/pages/sp/)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中6ヒットで21ダメージ、決め技で25ダメージ。裁判台からの降下、床の回転と奥行き、投球機から弧を描く球とバットの振り抜き、相手との見分けを確認。CPU同キャラ戦はストック切れ。ローカルオンラインは413フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
