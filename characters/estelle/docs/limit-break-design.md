# エステルの専用リミットブレイク

『空の軌跡』の棒術と「桜花無双撃」を軸にする。柄尻の突きで相手を止め、半歩下がって両手の持ち位置を入れ替える。長棍を低く突いて支点にし、相手の前を斜め上へ回り、空中で身体を返して別の高さから打つ。着地は片膝で衝撃を受け、長棍の左右を使って間合いを詰める。最後は棍の先端が描く弧から花びらが開き、踏み込みの打撃と一緒に広がる。

澄野は列を踏み替えて刀を通し、エステルは長い棍の支点に体重を預けて弧を描く。既存の髪と衣装に合わせ、手を移す動き、支点、上段と下段の打点、決め技の花びらの奥に相手が見えるかを実描画で確認する。
