# コレットの専用リミットブレイク案

投げた左右のチャクラムを別方向から戻し、羽で浮いて相手を追う。最後は頭上からジャッジメントの光が順に落ちる。エーデルガルドの地表を詰める連撃と異なり、高さと軌道を変えながら離れて攻める。対戦用の衣装、翼、チャクラムを使用する。

「ホーリージャッジメント」は白と青の上着、金髪と青い目、赤金のチャクラムと青白い翼を対戦画面に合わせた。ImageGen で描いたカットインは二つの輪を投げる姿を使う。本人は相手の手前で上昇と下降を繰り返し、チャクラムだけが相手の上下を交差する。決め技では聖堂上空から異なる高さと位置へ三本の光柱を落とし、光が消える前に相手の吹っ飛びを見せる。[原作の秘奥義の実機映像](https://www.youtube.com/watch?v=XbxxyAr6FzY)

配信素材は `assets/limit-cutin.webp`、`assets/limit-sanctuary.webp`、`assets/limit-effects.webp`、`assets/limit-angel.webp`。翼は既存の上必殺と同じ画像で、決め技は三音の鐘を重ねた専用サンプルを使う。
