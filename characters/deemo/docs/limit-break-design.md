# DEEMOの専用リミットブレイク

対戦素材の顔のない黒いシルエット、細い手足、衣装の輪郭を保つ。逆光を使い、ピアノ、手、相手の輪郭を別々に読める明度で描く。

低い音でピアノの脇から相手を浮かせ、鍵盤の手元へ寄る。左右の手を異なる拍で鍵盤へ落とすたびに根が走り、相手を枝の段へ一段ずつ持ち上げる。DEEMOはピアノから立ち、伸びた根を二歩で渡り、高い枝で腕を振る。最後の和音で天窓まで伸びた木と相手を引きで見せ、葉と音の波を重ねて締める。ロックマン.EXEの格子上の接近に対し、演奏の間と木の成長で攻撃位置が変わる構成にする。効果音は収録曲の引用を避け、専用のピアノ音と木がきしむ音を作る。

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。ピアノで根を伸ばし、枝へ上がって最後の和音へ。途中7ヒット、決め技26ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
