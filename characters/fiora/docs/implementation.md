# 機械化フィオルン

リキの直前。元デザイン fiorun.png から内蔵 image_gen で全身48姿勢、選択ポートレート、専用11エフェクトを制作。崖つかまりだけ二重人物を検出し単体画像を再制作。関節リグなし。身長100、左右とカラー5種、追加キャラだけの配信画像・サイズ補正を生成。

- NB ダブルブレード：8–10F、14–16F、22–25Fの双剣3段。3+3+7ダメージ。約26px踏み込む接近技。
- 横B ソードドローン：16Fに2機を送り、25Fかけて前方200pxで交差し20Fで戻る。各機同じ相手へ1回のみ5ダメージ。110F再使用待ち。22–35Fに必殺を押し直すと交差点へ追撃。押し続けるだけでは移動しない。地上追撃は崖際で停止。空中は1回まで。
- 上B ゼログラビティ：9F準備後35Fの旋回上昇、その後19Fの浮遊。左右入力で弧を変える。初動4ダメージ、終了後しりもち。左右の場外から復帰可、ステージ下では外側へ抜けてから上昇。
- 下B スピードシフト：16Fで発動。12秒、移動速度15%・攻撃力12%増。終了後8秒再使用待ち、上書き延長不可。攻撃開始時に威力を固定し、元技データを変更しない。撃墜時解除、空中発動は急降下なし。

検証：専用115項目、CPU2戦×2,400F、独立2クライアント161F一致、追加キャラのアート49姿勢・11エフェクト・245カラー画像のチェックサム一致。全キャラの総当たりは実施しない。CPU結果は対人バランスの評価ではない。
