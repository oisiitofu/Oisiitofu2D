# フィオルンのリミットブレイク

機械化したフィオルンの「ファイナルクロス」を軸に、双剣とソードドローンで相手の位置を囲み、左右から高速で斬り込む。最後に二色の刃が交差し、機神界をイメージした橋の上で巨大なXを刻む。ドローンの連携はこのゲーム独自の演出。
