# ビューティフルジョー

成歩堂龍一→アーサー→ジョーの順。サイズ2、94px。専用の高解像度上半身選択画像、79枚の全身画像、16種のVFXを制作。元の待機姿を固定し、関節変形は使用しない。

- NBは往復するVブーメラン。長押しで高い軌道、往路・復路で各1回だけ命中。有限寿命と1個制限。
- 横Bのマックスピードは命中を確認して再入力する最大4段。空振りでは派生しない。段ごとに全身姿勢・判定が変わり、フィルムを消費する。
- 上Bはシックスマシンで動きながら螺旋上昇し、ジャンプで飛び降りる。停止した入力待ちは設けず、終了後は専用尻もち姿で左右操作できる。
- 下Bタップは移動速度だけを鈍らせるSLOW範囲。被弾硬直・ヒットストップ・つかみ中の速度は触らない。長押しはZOOM。専用の全身パンチ／キック／ドリル姿勢になり威力を上げる。
- フィルム0では45F通常ジョーに戻り20回復。通常姿の待機・移動・防御・被弾・崖・尻もちも用意。
- 空Nは3姿勢のバイシクルキック。1つの既存攻撃窓・ヒットIDのまま、蹴る方向が上前→前→下前へ変わる。全周の斬撃円は使わず、コミック調の力線を足先に合わせる。

検証: 専用127項目、通常技30場面（左右）、特殊技24場面、待機5カラー×左右、48連続映像サンプル、CPU1戦。329ポーズ・64エフェクト・1645カラーフレームの新4キャラ共通読み込み検証で差分ゼロ。全キャラの総当たりは行わない。

画像は組み込みimage_genで制作。最終素材は `assets/`、正確な制作プロンプトは `image-prompts-complete.json`。検証画像・動画はGit対象外の `previews/`。
