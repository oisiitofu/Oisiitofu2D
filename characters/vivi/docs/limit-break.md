# ビビの専用リミットブレイク

杖を振って火球を送り、跳ねながら足元の氷柱と頭上の稲妻を順に起こす。横へ大きく回り込むティファとは違い、詠唱位置を保ちながら相手の周囲で攻撃の方向と高度を変える。最後は杖をかざし、空を落ちる暗黒の球と衝撃波でジハードを描く。帽子・青い服・杖は対戦素材を使う。

## カットイン・攻撃素材の改修

対戦用の帽子・青いコート・赤いリボン・木の杖を参照し、杖を突き上げてジハードを呼ぶ専用の構図に更新。月夜の遺跡、火球、氷晶、雷、亀裂が光る暗黒の隕石を使用。 ImageGenで新規制作し、全身の対戦素材は同じものを使用する。

ララフェルとロクサスの画面と見比べ、杖と目を収めた斜めのカットインと、ジハードの発生・着弾・余韻を再演出した。空の裂け目、落下する光、地上から噴き上がる柱、地面を走る波の専用素材を追加。カメラは裂け目を見せてから着弾点へ寄り、衝撃波と吹っ飛ぶ相手が収まる位置へ引く。連撃は17〜20フレーム間隔で、両向きの命中と効果音が同じフレームで起きることを確認した。
