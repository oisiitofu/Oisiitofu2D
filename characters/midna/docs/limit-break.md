# ミドナのリミットブレイク

「影の結晶」を集め、影の宮殿をイメージした橋で原作終盤の異形へ変身する。原作ゲームの画像に合わせ、紋様のある黒い仮面と長い腕を描いた。引きの画面で腕を広げた後、相手に向けて腕を突き出す。橋上での攻防と影が弾ける構図は本作独自の演出。
