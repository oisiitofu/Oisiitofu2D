## 専用挙動

- NB「風の弾」: 11Fに風の弾、速度9/寿命24F/半径14、55F待ち、同時1発。命中した実際の相手を短時間捕獲し、頭上の泡へ持ち上げる。捕獲後4Fから必殺/攻撃で9ダメージの投げ、上下入力で投げ分け。ジャンプは5ダメージで相手を下へ放して自分が速度-15で跳び上がる。入力がなければ46F後に投げて解放。相手は連打で脱出でき、再捕獲防止90F。ガード・無敵・アーマーでは捕獲しない。捕獲できない通常命中は2ダメージ。持ち主/対象の撃墜、持ち主への被弾、第三者による対象への被弾でも解放し、他者の吹っ飛びを維持する。
- 横B「ムゥキャッチ＆スロー」: 16Fにムゥを投げる、威力10/半径19、速度8、地上は上向き放物線、空中は浅い弧、80F待ち・同時1発。クロノア本体は突進しない。持ち上げる42番と放す43番の全身ポーズ、ムゥ専用素材で表示。
- 上B「ジェッティモライド→耳ホバリング」: 9F始動、19Fの斜め上飛行の後、耳を広げて18F滑空。横入力で進行方向を調整でき、10F以降の必殺押し直しで早く離脱できる。有限時間で落下/しりもちへ移る。内側下では側面へ抜けてから改めて上昇。ジェッティモが足元を運び、離脱後は耳の全身ポーズと風だけになる。
- 下B「ボムヘイ・カウントダウン」: 地上では構えて28Fで投げ、15F以降の押し直しで早投げ。空中は着地で投げ損なわないよう12Fで下へ放す。ボムヘイは接触/床/壁/48F経過で爆発、威力12/半径55、各相手に一度、ガード可能。150F待ち、爆発中を含め同時1個。本人を急降下にしない。

通常/空中攻撃は耳・手・足に対応したカプセル判定。弱63–82、横強90、横スマ118、後空中91px＋半径。上下も本体からつなぎ密着の穴を防ぐ。空中下は一度の実命中で小さく跳ねる。風の元画像はRIGHTを進行方向とし、ローカルX反転→回転で判定の方向へ合わせる。前後上下を両向きで確認。
