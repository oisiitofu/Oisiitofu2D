# ナミネ：固有能力・操作と対処

KHのナミネ。青い目、肩までの淡い金髪、白いノースリーブの膝上丈ワンピース、白い平たいサンダル。添付の少女らしい顔と細身の自然な頭身を維持し、幼児化やセクシー化をしない。スケッチブックとクレヨン。

NB スケッチの記憶：保持で描くものを選び、離すと実体化。キツネは地上を走る攻撃、ウサギは近づいた相手へ跳ねる設置、ネコは漂って相手に記憶の印を付ける。形・経路・使い道が違う。絵は有限時間で消える。
横B 偽りの記憶：ナミネの幻影だけを相手へ近づけ、本人は離れた位置で操作する。保持中の方向入力で幻影の進路を変え、必殺の押し直しで遠隔の記憶破砕。ガードで戻すとフェイント。記憶の印が付いた相手へ寄せると強化。幻影は敵の攻撃で壊れる。本人を横へ突進させない。
上B 闇の回廊：入口を開き、方向を保持して出口を予告。必殺を離すと短い通過の後に出口へ移る。描いたウサギのページ付近へ出口を合わせられる。移動先は有限距離、地形内へ埋めない。出現後に隙があり、無敵は通過の短い区間だけ。左右・下方からの復帰を確認。
下B 記憶の糸：その場で糸を描き、予告後の範囲へ入った相手を短時間だけ縛って記憶の印を付ける。一度の設置で同じ相手へ拘束を繰り返さない。既に吹っ飛び中の相手の速度や予約を消さない。持続は有限で、本人の準備・解除を狙われる。印は横Bの幻影や記憶破砕と連携する。
相手は描いている本人へ近づく、絵や幻影を壊す、範囲から離れる、回廊の予告出口を待つ。原作の記憶と描画の力を題材にしたゲーム向けの操作で、単なるゲージや突進の色替えにしない。

全身の固定ポーズと専用の予備動作・戻りを制作。関節リグを使わない。近接判定はMeleeBalance.coverageとNativeStrikesを経由し、武器先端と密着を両向きで確認。飛び道具・遠隔設置は近接補正の対象外。選択用は別制作の高解像度の顔・肩。画像生成が拒否された場合はそのキャラの作業を直ちに停止し、再試行や切り抜きで継続しない。
