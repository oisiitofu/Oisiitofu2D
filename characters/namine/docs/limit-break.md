# ナミネの専用リミットブレイク

対戦時の服と髪、スケッチブックを使う。描いた記憶の紙片を離れた位置に置き、頁が破れる瞬間を連撃の着弾に合わせる。モーグリの本人が移動して風を広げる構成と区別し、紙片と線で相手の動きを導き、最後は記憶の輪を閉じる。

改修では、白い服、金髪とスケッチブックを現行の対戦素材から参照した。組み込みImageGenで、紙片を金色の糸で操る横長カットイン、白い城の広間、四種のスケッチ、着弾の紙片と光、記憶の鎖を描き起こした。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-paper.webp`、`assets/limit-effects.webp` に収録。連撃では開いた紙が別方向から着弾点へ走り、決め技では紙の輪が収束して、糸の先で記憶の光が広がる。
