# リース

参照は `assets/riesz-reference.png`。builtin imagegen で透過の全身48ポーズ、追加8ポーズ、12エフェクトを制作。元デザインの頭身・衣装を保持し、関節変形は使わない。元生成PNGは保持。抽出とパッキングは `tests/assemble-art.cjs riesz`。同スクリプトはイデアにも使う。

横必殺は本人が動かず、上空から青いマルドゥークが斜めに急降下。接地すると低く跳ね上がり、同じ鳥がいる間だけ再召喚不可。上必殺は槍の反動を使い、発生前は落下を停止、上昇中に左右を調整できる。ステージの深い内側では共通の崖下脱出処理を使う。

通常必殺はゆっくり前進する旋風を生成。接触3回と最後の打ち上げは意図的な4段で、1つの旋風につき同じ相手に各段1回。下必殺は6秒の攻撃強化。近接の使用に待ち時間を追加しない。

ポートレート48、横強49/50、尻もち51、移動追加52..55、NB予備56。上強8・上スマ13・空上45は異なる全身姿勢。横強と空前も専用の画像/連続姿勢。攻撃の曲線0/2は凸側が右、上側1は凸側が上。描画は局所回転後に左右反転し、上側は1曲線のみ。

生成プロンプト: 参照画像を唯一のデザイン基準とした、全身・右向き・同じ頭身・8列6行の技別48ポーズ、エフェクトなし、完全透過。追加は横強/後続/尻もち/歩行2/走行2/NB準備の4列2行。FXは3列4行、青い風の曲線・上側曲線・槍斬撃・竜巻・青緑の鳥・槍反動・金色強化・ヒット・風突き・羽根・着地・衝撃。全プロンプトは builtin image_gen を使用し、API/CLI fallback は未使用。

テスト: `node characters/riesz/tests/newcomers-test.cjs`、`node characters/riesz/tests/cpu-test.cjs`。登録に必要な値は `tests/registration.json`。

検証結果（2026-10-20）：両キャラ合計222件成功。15通常技を左右両向き、密着と先端で確認。上必殺の左右場外復帰、召喚の存続制限、強化、BP各段、デフォルト軽減/被弾解除を確認。CPUは各1戦2400Fで両者の命中とKOが発生し、有限値を維持。左右24場面ずつの実描画を比較。

選択画面は専用ポートレートの頭部/肩へ切り抜き範囲を合わせ、他キャラと同程度の顔の大きさで表示。頭頂の飾りを残し、戦闘用ポーズやサイズは変更しない。
