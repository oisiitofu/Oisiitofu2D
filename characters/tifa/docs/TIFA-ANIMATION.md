# ティファ：元絵の間に全身画像を足す方式

2026-10-12、ユーザーが arsenal の立ち姿→パンチの中割りを承認したため、同じ方法でティファ1体の強化を進めた。次キャラへの移行は手動。

基準はユーザーが明示した `characters/tifa/assets/tifa-arsenal.png`。左上の両手を下げた立ち姿40と上段3枚目のパンチ42を使用する。別シートの待機0・ジャブ6に戻さない。元シートのSHA-256は `dc821962dd1d2c72b6f328a236fdfd3b9b05b412bc691fe864c284e2a1b325e4`。中割り前の Git 3204911 と同一で、固定端点の情報は `tests/pre-inbetween-baseline.json`。

組み込み image_gen で全身の中間画像を計41枚作成した。承認されたパンチ3枚に加え、上蹴り・後ろ蹴り・膝・かかと落とし各3枚、タックル・低い蹴り・前蹴り各3枚、歩き・走り各4枚、つかみ・ガード・被弾各3枚。生成画像と最終プロンプトは `assets/*-inbetweens-v1.png` と隣の `.prompt.json`。地上技シートは透過修正を実施し、生成された立ち姿の列は採用せず元の40を使う。

元の49ポーズ・8エフェクトと5カラー、選択画像を画素チェックで保持し、中割りを49〜89として追加した。元絵と中割りは全身画像を1枚ずつ表示する。関節回転・部品分割・メッシュ変形・横伸ばし・クロスフェードは使わない。元ポーズへの切り替えは、元絵の一様倍率と足底・左右原点を調整し、しゃがむ画像全体を高さで縮小しない。

`tifa-raster-animation.js` は描画専用。通常攻撃の完成絵は拳6/7→arsenal42、蹴り8/15→43、膝10/12/41→46、後ろ蹴り14→44、かかと16→45として、ユーザー指定シートの姿を使う。タックル9・低い蹴り11・前蹴り13・つかみ17・ガード20・被弾21は既存の完成絵を使い、その直前を中割りでつなぐ。内部の pose・技データ・VFX・CPU・通信形式は変更しない。

ジャブの発生は5F、持続は5〜7F、終了は15Fのまま。表示は40,49,50,51,42,42,42,42,51,51,50,50,49,49,40。多段技は各有効時間の前後で進め、動的な派生の窓を読む。攻撃は fighter.timer、移動は stateFrame を使うためヒットストップ中に中割りだけが進まない。全身の回転・着地の潰しも追加しない。

崖つかまり・崖上がりは手の接点を維持する既存描画、ダウン・起き上がりも既存の原画表示を残した。このパスでこれらの中割りを追加したとは扱わない。

配信画像は `ART_IDS=tifa node .tools/build-art.cjs` で可逆WebP化。新アトラスに対して MotionSize の tifa.atlas の参照だけを更新し、元49ポーズの倍率・判定用データは維持。公開起動時に元シートを解析しない。

検証：元画像・5カラー保持と描画による判定不変17207項目、技挙動176項目、オンライン同期56項目、全113形態の操作可能タイミング16922項目、実描画のサイズ・縦横比117360項目を通過。アート全5319ポーズ・932エフェクト・26595カラー画像に不一致なし。CPU対戦は小さい相手と剣士を相手に各1800F、中割り描画を含めて正常。CPU戦は動作確認であり、人間対戦の勝率評価ではない。

`tests/tifa-raster-visual.cjs` は左右の実描画動画、11種類の端点・中間比較と全5カラー画像を `previews/` に生成する。動画は `previews/tifa-raster-gameplay.webm`、比較は `tifa-raster-contact.png`、カラーは `tifa-raster-colors.png`。生成された中割りと元絵の間には線・髪の細かな差が残るため、部品を変形して差を隠さない。

撤回した関節方式は Git fd753ca に履歴があるが、登録・補完パーツは削除済み。Sites v18は元49ポーズへの復元版。このパスの公開結果は animation-progress.json に記録する。
