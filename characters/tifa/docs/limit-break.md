# ティファの専用リミットブレイク

短い踏み込みからジャブ、相手の足元へ滑り込む打撃、蹴り上げ、跳び越えながらの蹴り、反転して空中から踵を落とす連撃。着地で相手と向き合い、腰を落としてファイナルヘヴンを打ち込む。盤面を置くアルルと異なり、相手の高度と前後を打撃のたびに変える。対戦で使う衣装と全身素材、キャラ選択の肖像を基準にする。

## カットイン・攻撃素材の改修

対戦用の顔・白いトップス・黒いストラップ・赤いグローブを参照し、拳を手前に出すファイナルヘヴン専用の構図に更新。工業都市の夜景と、拳打・蹴り・フィニッシュで形の異なる赤金の攻撃素材を使用。 ImageGenで新規制作し、全身の対戦素材は同じものを使用する。
