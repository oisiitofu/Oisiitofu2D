# エスタークの専用リミットブレイク

片膝の姿勢から起き上がり、対戦用の四振りの刃で左右を段階的に制圧する。凍てつく波動で相手を押してから、刃を交差させて天上天下断獄斬。ハイデリンの飛翔連撃と区別し、低い重心と踏み込んだ床の割れで重さを出す。

改修では現行の黄金の体、三つの目、二本の角、四腕と四振りの刃を参照した。組み込みImageGenで踏み込んで刃を振る横長カットイン、古い火山宮殿、黒い床の亀裂、凍てつく波動、天上天下断獄斬の重い剣閃を描き起こした。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-quake.webp`、`assets/limit-effects.webp` に収録。踏み込みで地表の亀裂を広げ、決め技の背面に進行方向へ伸びる刃と残光、前面に命中火花を重ねる。

再比較では黄金の四腕と四振りの刃を維持し、前の二本を時間差で交差させ、後ろの腕を大きく開いて重心を落とす。盾を使って相手の裏へ回るアルスとは、相手を前に置いて床を踏み砕き、上下の刃で挟み込む動きで区別する。交差した命中点から前方へ破片が抜け、地表の亀裂へ余韻をつなぐ。

組み込みImageGenで「対戦の黄金の体、三眼、二本の角、四腕と四振りの刃を保ち、前の剣が交差して後ろの剣を開く横長構図」と「上りと下りの厚い刃、黒い石板と赤い亀裂、白金の命中火花」を制作。配信用は `assets/limit-cutin.webp` と `assets/limit-finish.webp`。演出192フレームの重い振りの音から208フレームの専用決め技音へつなぐ。

音バンクにない `impact-heavy` を地面の打撃に指定していたため、149フレームの音を `earth-hit-heavy` に修正した。
