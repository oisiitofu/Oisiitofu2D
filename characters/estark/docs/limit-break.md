# エスタークの専用リミットブレイク

片膝の姿勢から起き上がり、対戦用の四振りの刃で左右を段階的に制圧する。凍てつく波動で相手を押してから、刃を交差させて天上天下断獄斬。ハイデリンの飛翔連撃と区別し、低い重心と踏み込んだ床の割れで重さを出す。

改修では現行の黄金の体、三つの目、二本の角、四腕と四振りの刃を参照した。組み込みImageGenで踏み込んで刃を振る横長カットイン、古い火山宮殿、黒い床の亀裂、凍てつく波動、天上天下断獄斬の重い剣閃を描き起こした。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-quake.webp`、`assets/limit-effects.webp` に収録。踏み込みで地表の亀裂を広げ、決め技の背面に進行方向へ伸びる刃と残光、前面に命中火花を重ねる。
