# 回避と連続撮影からフェイタルタイム

2026-11-06公開。承認済みの `yuri-presentation-portrait.png` と `yuri-poses.png` を顔、髪、白いブラウス、赤茶色のベスト、スカート、ブーツ、古い箱型の射影機の基準にする。通常画像・待機・既存の必殺技は変更しない。

[公式マニュアルの除霊](https://www.gamecity.ne.jp/manual/zero/maiden/jp/3300.html)で、近距離や多くの撮影対象を捉えるほど強くなり、フェイタルフレームの後には連続撮影できるフェイタルタイムへ入ることを確認。[撮影モード](https://www.gamecity.ne.jp/manual/zero/maiden/jp/3200.html)の霊片、チャージとフィルム、[射影機の強化](https://www.gamecity.ne.jp/manual/zero/maiden/jp/3400.html)も参照する。

走りで位置を取り、後退回避と低い構え直しから撮影。相手の周囲へ回り、正面・振り返り・低い位置からの連続撮影で霊片を集め、接近しての決めの撮影へつなぐ。銃の連射や長いビームに置き換えず、シャッターの短い光、相手の停止、霊片の飛散と写し取られる余韻を描く。カメラも狙う角度へ移動し、最後は引きで光と封印の規模を見せる。

全身8枚で走行・後退・低い回避・踏み込み撮影・振り向き・上方撮影・決めの構えを分ける。カメラのレンズ位置から主攻撃を出し、途中のヒットとシャッター音を合わせる。主攻撃は `art.strike`、残光は `art.glow`、カットインは共通 `LimitCinematic` の比率維持描画。画面揺れと明滅は見やすさ設定へ従う。

素材と最終プロンプトは `limit-break-assets.json` に保存する。呂布と合わせて演出・専用音・ローカルと公開での検証を完了した。

## 実装・ローカル検証

全身8枚。撮影の光をレンズへ合わせ、足先を含む画角へ調整。各9回の途中ヒットから決め技へつなぐ。専用効果音2音、両向きの実描画、共通カットインの縦横比、主攻撃のsource-over合成、トレモ補充、密着発動・空振り・ガード・無敵・再試行・多人数停止・最終吹っ飛びを確認。ローカルオンラインは377フレームでダメージ・吹っ飛び・ホスト設定が一致。

連続再生を1440×900で録画し、全身ポーズと左右への回り込みを確認。CPUは同キャラ2体を中央140px間隔で開始し1戦ずつ結果まで進行（夕莉は撃墜、呂布は時間切れ）。既定の離れた開始位置では夕莉同士が攻撃せず時間切れになったため、接敵状態で確認した。通常技やCPU本体は変更していない。
