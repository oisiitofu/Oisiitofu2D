# シェフの専用リミットブレイク

対戦用の帽子、コック服、顔と頭身を全身姿勢とカットインに使う。食材を投げ、移動する調理台へ飛び移り、両手で鍋を受ける。相手は盛り付ける皿に沿って位置を変え、蒸気で浮いたところへ最後の大皿が届く。ウマのコースでは足場が攻撃の起点だったが、ここでは台が動いても手元と鍋をつなぎ、調理の順番でヒットを見せる。通常の追撃間隔は17〜22フレームを目安にする。

- [Team17公式 Onion Kingdomの厨房](https://www.team17.com/games/overcooked-all-you-can-eat)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。調理台を渡り、フライパンと蒸気からフルコースへ。途中7ヒット、決め技26ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
