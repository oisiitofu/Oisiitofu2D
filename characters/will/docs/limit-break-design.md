# ウィル：専用リミットブレイク制作設計

状態：専用素材と演出コードを実装し、ローカルの対戦・トレモ・CPU戦・代表オンライン同期を確認済み。Sites v329へ公開し、公開描画・発動・トレモ・専用音・通信同期まで確認済み。

## 2026-11-06 の動線指定

直近の「左から連撃し、一度右へ抜ける」横移動の構成から変える。ウィルはアーキタイプへの覚醒と終盤の王の力を軸とし、本人の低い踏み込みから上方へ展開し、相手を見下ろす決め技へつなぐ。最終形態の外見とロイヤルソードを原作画面・技データで照合済み。既存 will-summons.png の召喚体を確認なしにプリンスとして流用しない。

| 段階 | 本人と相手の動き | 姿勢・画角の意図 |
|---|---|---|
| 接触 | 近距離で剣を受け流し、半歩下がって低く構える | 退く動作にも専用全身画像を使い、顔・剣・相手を同時に見せる |
| 起点 | 足元から短い踏み込みで斬り上げ、相手を頭上へ浮かせる | 横断せず、本人と相手の上下関係を作る |
| 追撃 | 相手の真下から跳躍し、空中で身体をひねって向きを変える | 同じ斬り姿勢の往復を避け、跳躍・空中の溜め・振り抜き・回復を分ける |
| 覚醒 | 本人が相手より上で覚醒し、上下の間合いを一度開く | 引きの構図で全身と力の規模を見せ、変身の読める停止を置く |
| 決着 | 上から下へ決め技を通し、相手の着弾後に本人が着地 | 決め技の線と身体を重ねすぎず、着地と余韻で終了する |

連撃数を先に決めて同じループへ詰め込まない。原作技の確認結果に合わせて接触回数とタイミングを決める。画面内の位置変更は横移動中心でなく、地上→相手の下→相手の上→着地を主軸とする。

## 比較と検証

- ワンダーのワイヤーと射撃、ナホビノの横方向の螺旋斬、アレインの地上での盾・騎乗アクションと動線を比較する。
- 本人の顔・衣装・頭身は既存の selection / atlas を維持。中間姿勢は全身画像で制作する。
- 接触・浮かせ・空中追撃・覚醒・落下攻撃・着地を連続再生で確認し、静止画の座標移動だけになっていないかを見る。
- 上下関係を変えても本人・相手・斬撃を追えること、左右両向き、カットイン比率、明るい背景での攻撃の芯、見やすさ設定、対戦・トレモ・代表オンライン同期を検証する。

## 実装とローカル検証

本人8姿勢＋プリンス4姿勢。途中5回×3ダメージ＋ロイヤルソード25ダメージ。387フレームの同期が一致。プリンスは原作画面の金冠・顔を覆う黒金の兜・銀髪・橙金の胸の発光・金の腰甲を照合した。専用2音を制作。覚醒後を850pxで描き、本人から形態への切替が小さく見えないよう調整した。
対戦・トレモでゲージ、発動、空振り、盾、無敵、途中ヒット合計、最終吹っ飛び、他プレイヤーと時計の停止を確認。CPUは接敵距離から各1戦、実際の撃墜と結果への進行を確認。左右の実描画、カットイン縦横比、source-overの主攻撃、専用効果音再生も確認。最終素材の連続再生と公開検証も完了。
