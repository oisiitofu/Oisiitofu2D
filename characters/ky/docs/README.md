# カイ / Ky Kiske

添付kai.pngを基準にGUILTY GEAR -STRIVE-のカイをソルの次へ追加。白と紺のコート、短い金髪、青い瞳、サンダーシールを維持。人型サイズ3・98px。

built-in image_genで全身53姿勢・16FX・専用1536×1024上半身肖像を制作。ゲーム用54フレーム、5カラー。保存先は[assets](../assets/)、正確なプロンプトは[image-prompts.json](image-prompts.json)。白い区切り線の透過補修後の待機0を固定し、追加シートの共通姿勢で倍率を校正。関節リグや元ポーズの再生成で中割りを作らない。通常技15種は別の全身実画像。パンチ/キック/肘/剣を使い分け、下スマ後半は専用46を振り返って表示し、空後14を流用しない。専用肖像は実カードのガイル/ソルと顔の寄りと頭頂を比較。

- NBスタンエッジ：8F以降に離すと5F後に発射。24F以上保持で強化、48Fで自動解放。通常9/強化15ダメージ。自身の生存弾1個と発射間隔30Fだけ制限し、普通の近接技は時間式クールダウンなし。空中の保持と解放待ちは着地しても消さない。
- 横Bライトニングストライク：発動時に480px内の自分のスタンエッジを記録。9F時点でまだ有効なら弾を消費してその位置へ移り、12〜17Fに単発11ダメージの近接斬り。弾がない/途中で消えた/ステージ内部なら125px前方への単発落雷12ダメージへ変わる。無敵はない。地上の弾へ移動して着地しても斬りまで保持する。空中で横突進するだけの技にはしない。
- 上Bライド・ザ・ライトニング：7Fまで落下慣性を止め、最初の左右入力で進行側を決定。斜め上への上昇7ダメージ、頂点から前へ弧を描く飛行9ダメージへ自動移行。途中の左右反転で瞬間的に軌道を反転させない。下側に入り込んだときは共通の側面退避後に上昇する。左右の場外から地上へ復帰可能。終端は全身35の不透明な尻もち姿勢へ移り、通常立ち姿を挟まない。
- 下Bドラゴンインストール：テンション50%消費、14F後に10秒強化。移動速度12%、攻撃20%強化。発動自体の攻撃判定/無敵はなし。再発動で時間を無限延長しない。テンションは前へ近づく移動、攻撃の実命中、被ダメージで上がる。待機では増えず、復活で0。
- ショック：スタンエッジ/落雷/横B近接で3.5秒付与し、頭上に雷のマークを表示。次の雷攻撃でマークを消費し追加2ダメージと少し長い被弾硬直。同じ攻撃で再付与しない。ガードには付かず、別のヒットや吹っ飛び停止を追加しない。複数のカイがいても1Fに一度だけ残り時間を減らす。

AttackEffects.imageで切断面を武器の先の判定外縁へ合わせ、近接coverageを一度だけ適用。弾/落雷/つかみへ近接補正を重ねない。素材0/2は右凸、1は上凸、13は下凸。ローカル回転後に左右反転。上スマ/空上は頭上の曲線1つ。空手の上強は肘の打撃火花とし縦長の斬撃に置換しない。雷柱6/飛行リング7/ショックアイコン8/強化オーラ10は小物として描画。通常投げは後ろ撃墜/上浮かせ/下追撃/前位置変更。専用の弱い単発攻撃上がりを維持。
