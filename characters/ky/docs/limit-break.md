# カイの専用リミットブレイク

連撃はスタンエッジを地面に沿わせ、スタンディッパーで低く追い、フードルアークで相手を上へ返す。相手の前で足を止めてドラゴンインストールの雷をまとい、空中の雷へ自分が追いついてライド・ザ・ライトニングで斜め上へ運ぶ。アイルーが地面に残した罠を終点にする構成と異なり、剣・雷・カイ本人が同じ軌道上で追いつく。

発動前と復帰後は現在の対戦素材を参照する。ドラゴンインストールの区間は衣装の形を保ち、実対戦の変化と同じ位置に発光を置く。始めから強化中なら強化中の姿から始める。地上の溜めは寄り、空中の追撃と決め技は二人が収まる引き。連撃の命中候補は47、63、82、101、120、140フレーム目とする。

横長の発動絵、嵐の城壁、雷の斬撃・落雷・上昇軌跡・命中、溜めから突き上げまでの全身姿勢3種を制作した。青い雷に赤紫の芯が加わる場面と、剣と雷が相手に届く場面に別の専用効果音を使う。標準カラーに専用全身姿勢を使用し、別カラーは同じ場面を対戦用の対応姿勢で描く。
