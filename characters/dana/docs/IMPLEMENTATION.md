# ダーナ / Dana

添付 `assets/dana-reference.png` を基準にbuiltin image_genで48全身ポーズ・12エフェクト・高解像度専用上半身画像を制作。元絵の青い髪、冠、白/水色/金の衣装、双月刃を維持。正確なプロンプトは `image-prompts.json`。全身を切り替えて描画し、関節リグは使わない。

ゲーム用アトラスは48全身ポーズとポートレート1枚の49フレーム。通常技15種類は別の全身絵。透過を保持し、標準サイズ2の94px、全動作に同じ身体倍率を使う。髪/青布を5カラーへ変更。キャラ選択は別制作1536×1024の専用画像。登録順はアドル→ダーナ。おまかせ最後、隠し形態は維持。

- 通常必殺「双月連舞」：9/18/29Fの3段近接攻撃。締めで前へ斜め上に飛ばす。別の攻撃窓を持つ意図した3ヒットで、終了後に再使用可能。
- 横必殺「星渡り」：8Fから前方190px以内・上下80px以内の最も近い相手の背後62pxを目標に弧を描いて回り込み、振り向いて20～25Fに斬る。相手がいなければ96pxの短い移動。発動後に目標は追尾し続けず、相手は移動・迎撃で対処できる。無敵は付けない。地上は硬直後に再使用可能。空中は共通の一回制限。
- 上必殺「蒼月旋昇」：8Fまで慣性を抑え、蝶を伴う螺旋上昇。左右入力で上昇方向を連続調整。ステージ真下では外側へ脱出してから上昇。終了後は専用の尻もち絵。左右両側の場外から復帰を確認。
- 下必殺「古代の祈り」：24Fの祈り完了で480F（8秒）強化。攻撃力1.12倍、近接リーチ1.12倍。途中被弾なら発動しない。通常/横必殺へ時間式の再使用待ちは追加しない。

月の斬撃素材0/2は凸側が右、上側素材1は凸側が上。ローカル回転の後に向きを反転し、AttackEffects.image経由で最終判定の外縁に合わせる。上強/上スマ/空上は頭上の曲線1つ。攻撃判定には共通MeleeBalance.coverageの余白を一度だけ適用。後投げは撃墜、前投げは位置変更、上投げは浮かせ、下投げは追撃。

素材の組立てはルートから `node characters/dana/tests/assemble-art.cjs`。伏せた22番の絵がシートの行境界を跨ぐため、22/23だけ確認済み元座標で切り出す。隣のキャラの刃を混ぜない。崖つかまりは38番の上端の手の画素からアンカーを測る。共通登録スクリプトregister.cjsは初回用で、登録済みには再実行しない。

検証：機能118項目、左右24サンプルの実描画、CPU対ビビ1試合（2400F）、49姿勢/12FX/245カラーのchecksum差0。オンラインは実サーバー/2ブラウザで4必殺・180フレーム一致。既存140形態のmanifestを保持。サイズ一覧を141形態へ更新。検証画像/結果はGit管理外のpreviews/。
