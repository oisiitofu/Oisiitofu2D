# ダーナの専用リミットブレイク

『イースVIII』の三つのスタイルをつなぐ。イクルシアンは半月刀で扇形に斬り、下から伸びる氷に片足を置いて反対側へ渡る。グラティカに切り替え、重い槌の振り下ろしで氷を砕き、その下から石柱を持ち上げる。柱を足場にルミナスへ変わり、カタールで短く上下に連撃。石柱の先端から相手を見下ろし、姿勢を固定して閃煌連牙迅の光線で締める。シズナが小さな足運びと静止を見せるのに対し、ダーナは武器と重さが変わり、段差の高さも変わる。青・緑・金の衣装と武器をそれぞれ公式素材で照合する。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中8ヒット、決め技26ダメージ。青髪と半月刀の通常形態を対戦素材に合わせ、公式の緑髪のグラティカ、金髪のルミナスへ切り替わる動きを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
