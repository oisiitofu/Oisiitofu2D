- 通常技は槍の長さを生かす。身体から先端まで連続判定で、密着の穴を作らない。通常攻撃の発生/持続/回復は技データに保持。ダッシュ攻撃は既存の滑走調整へ登録。

- 横Bドラゴンファングは10〜18Fに7.6px/F踏み込み、槍9ダメージ。地上は崖止め、空中1回。実命中した地点に8Fの予告後、4ダメージのチェイサー追撃。空振り/ガードは追撃なし。動作終了後に余分な待ち時間なし。
