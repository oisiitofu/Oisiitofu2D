# サックボーイの専用リミットブレイク

『リトルビッグプラネット』のクリエイトモードとポペットを、戦闘中の手作り仕掛けにする。サックボーイがカードを床に貼り、つまみを引いて段ボール足場を折り起こす。足場へ跳び乗ってボタンを踏み、布のパッドで相手を打ち上げる。下へくぐって反対側のピストンを引き、本人が布の台に乗ったまま大きく上下する。最後は空中でステッカーを貼り、紙の星が折り開いてステージ全体を巻き込む。

ラチェットは裂け目から離れた物体を呼び、クラッシュは既存の箱を壊す。サックボーイはその場で仕掛けを組み立て、本人の接触と仕掛けが動く順序を見せる。既存のニット、縫い目、ジッパー、ボタンの目を基準に、しゃがみ、手で引く、押す、踏み切る、空中で貼る全身を制作する。折り目、布と紙の質感、ピストンが止まる音、紙吹雪を専用素材にする。

- [PlayStation公式 ポペットとクリエイトモードの道具](https://blog.playstation.com/2009/10/09/littlebigplanet-sack-it-to-me-psp-goodness-part-1-edition/comment-page-2/)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音3点を制作。途中6ヒットで21ダメージ、決め技で25ダメージ。段ボールを開き、ボタンを踏んで相手を浮かせ、下をくぐってピストンに乗り、空中でステッカーを貼る。ピストンと足裏の接地、紙の星が開く動きと最終弾きを確認。CPU同キャラ戦はストック切れ。ローカルオンラインは407フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
