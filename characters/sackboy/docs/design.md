# Sackboy from LittleBigPlanet

画像制作前の固有技設計案。ゲーム側で最終調整する。

固有能力・操作：ポペットのステッカーを地形へ貼り、クラフト箱を作ってフックや爆弾と連携する。NBは色を変えてステッカーを投げ、通常は足場に貼る・緑はバウンド・青は加速を与える。DBで時限爆弾を置くが、ステッカーを貼った箱の上へ置けば押し出して転がせる。SB「グラップリングフック」は地形/自分の箱/爆弾へ伸ばすフック。長押しで縄を縮め、離すと振り子速度を保って跳ぶ。相手へ命中した場合は小さく引くが本体突進はしない。UB「クラフトロケット」は自分で打ち上げた紙ロケットへ掴まり、旋回は緩やか、Bを離すとロケットを切り離して慣性ジャンプ。箱にステッカーがあるとロケットが一度だけそこへ向きを変えられる。既存との差：横Bは物体を足場にする振り子、上Bは乗る/切り離すタイミングを選ぶ紙工作。相手の対処：箱の破壊、縄の引き終わりを読む、爆弾の起爆時間を見て離れる、曲がりにくいロケットの外側へ逃げる。固有の布/段ボール/花火音。

原画の顔・体型・衣装を固定し、全身画像を切り替える方式。関節リグは使用しない。選択/勝利には専用の高解像度上半身アートを使う。
