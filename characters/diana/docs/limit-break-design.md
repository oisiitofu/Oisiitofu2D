# オーバードライブとヒューの連携

制作中・未公開。専用素材5点（カットイン、背景、単独4ポーズ、連携4ポーズ、攻撃エフェクト4種）を制作・保存した。既存の選択画像とポーズシートを顔・頭身・青いコート・ヒューの白い宇宙服と青いバイザーの基準にし、通常の画像や技の操作は変更しない。

[PlayStation公式の発売時紹介](https://blog.ja.playstation.com/2026/04/16/20260416-pragmata-launch-reminder-s/)で、グリッドハッキング、弱点の露出、ヒューの銃撃、誘導ミサイルの反転、マルチハック、オーバードライブとスラスター移動を確認した。ハックで止めてから、走行・低いスライド射撃・跳躍・空中射撃・着地へ連携する。最後はディアナの広域オーバードライブでデジタル波面を拡大し、ヒューの追撃と余韻へつなぐ。

専用全身8枚を使い、同じ立ち絵の平行移動だけで済ませない。単独と背負われた状態のディアナの頭の大きさを比較し、ヒューの体格差を維持する。銃口と火花、腕とハックの起点、ミサイルの方向を合わせる。主攻撃は `art.strike`、残光は `art.glow`、カットインは共有 `LimitCinematic` の比率維持描画を使う。

エフェクトの初稿で外周の切れと隣セルへの重なりが出たため、内蔵imagegenで余白と完全な外形を修正した。元画像・最終プロンプト・参照・配信用保存先は `limit-break-assets.json`。

演出コード・専用音・対戦／トレモ／CPU／オンライン同期・実描画と連続再生の検証はこれから実施する。雛子と合わせて公開し、結果をルート進捗表へ追記する。未公開のため、85／162の公開済み作品数には含めない。

ローカルの対戦・トレモ・左右描画・カットイン比率・攻撃の濃さと専用2音の再生を検証済み。60秒1ストックのCPU戦は3601ステップで時間切れの結果まで進行。双方8／7ヒット、残ストック1／1。オンライン382フレームでダメージ・吹っ飛び・ホスト設定が一致。1440×900の連続再生録画と縦横比を保つ比較画像で移動・姿勢・命中反応を確認した。録画は映像のみで、音は実再生診断を別途確認。公開結果はルートの進捗表へ記録する。
