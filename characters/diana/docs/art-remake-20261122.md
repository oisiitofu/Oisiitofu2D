# ディアナの全身画像の再制作

元の子供の顔、淡い金髪、青いキルティングコート、黒いハーネスと靴、ヒューの白い宇宙服を参照し、基本24姿勢・攻撃16姿勢・高解像度選択画像・LB単独4姿勢・ヒュー連携4姿勢・横長カットインを内蔵imagegenで再制作した。参照元・生成先と最終プロンプトの要約は `art-remake-20261122.json`。

選択画像は人物のみの背景透過。左右の顔の位置を動かさず、目・頬・顎を保護する構図で通常カードと拡大カードを確認した。勝利画像も今回の透過原画を使用する。

基本・攻撃の全身画像は見える本人の外形に沿ってセルの矩形を詰め、別セルから混ざった小片を矩形外へ除外した。髪や服の元ピクセルと透過は保持し、3pxの透明なガター付きで配信アトラスへ配置。中割りや関節リグで姿を変えない。対戦の姿勢番号・技の判定・ダメージ・発生・持続・後隙・操作は維持した。

LBの旧連携素材にあった横方向へ伸びる汚れを新しい全身画像で置き換えた。本人と相棒は共通の描画倍率を使い、銃口と最終ハックの手元を新画像の座標で測り直した。銃を下げた最後の構えでは銃口火花を出さず、ディアナの両手からハックを発生させる。カットインは共通の比率維持パネルへ変更。

`tests/art-remake-test.cjs` で全40姿勢の画像・透明な外周・5カラー・選択画面を実描画し、暗い背景上の全姿勢を比較した。`ART_IDS=diana node selection-framing-test.cjs --review` で通常／拡大カードと顔の保護範囲を確認。

通常技の密着・復帰を含む従来のオンライン代表場面109フレーム、LB314フレーム、CPU1戦の結果まで確認した。
