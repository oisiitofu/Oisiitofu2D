# ディアナの設計

- NBは照準内の相手を解析し、必殺を押し直すと弱点を露出させる。射程や向きが外れると解除される。弱点は次のミサイルかマルチハックで消費して追加ダメージを出す。相手は解析中に範囲を離れるか、発動を妨害できる。
- 横Bはヒューのミサイルに進路を指示する。飛行中に必殺を押し直すと、露出済みの相手へ向き直る。相手は軌道変更を読むか、ミサイルをガードできる。横突進や自動の近接追撃を使わない。
- 上Bはヒューが抱えて上昇する。方向で横移動、必殺を押し直すと救助姿勢から離れて慣性を持ち越す。下から来た場合はヒューがまず外側へ移動する。救助中は攻撃できず、しりもち落下までの軌道が見える。
- 下Bは近距離の弱点を同時に消費する電磁波。露出済みの相手だけに強い波が出るため、先に複数の相手を解析する判断が生まれる。
