# エトナ：制作・技設計

添付シートを元に、槍・赤い髪・小さな翼・細い尻尾と衣装を維持。選択画面は顔と肩の専用アップ。人型サイズは2（94px）を基本に、元絵の頭身を維持する。

## 固有の能力と操作

- NB「プリニーレイド」：投げたプリニーが放物線で進む。地面では短く歩き、相手に接触すると爆発。投げ角は上下入力で調整。連打で大量生成できず、最大2体。飛び道具・設置物として扱い、近接補正を重ねない。
- 横B「セクシービーム」：足を止め、ハート状の魔力弾を前方へ発射。地上は低い弾道、空中では下方向の狙いも付けられる。移動突進ではなく射撃。ハートが自分のプリニーに触れると起爆し、到達前のタイミングを選べる。相手は跳び越す・ガード・発生前の接近で対処できる。
- 上B「魔槍跳び」：槍を足元へ突いて支点を作り、入力方向へ弧を描いて跳ぶ。地面・浮遊台の近くでは支点が固定され、空中では短い魔力の支点を作る。上昇開始後は翼で弧を制御し、頂点以降は通常の重力へ移行。突進二連撃や追加入力の二段攻撃にせず、発動時の角度選択と支点から離れるタイミングが復帰距離に影響。空中は1回、着地・崖で再使用可。支点/移動先を見て迎撃可能。
- 下B「カオスインパクト」：槍を地面へ叩きつけ、短い予告の後に紫の魔力柱を発生。空中では落下し、着地してから発生。周辺のプリニーも起爆するため、先に投げた位置へ追い込む使い方がある。溜め続ける無敵やカウンターにはしない。空振りには後隙を残す。

通常技はリーチの長い槍の突き/薙ぎ。空Nは槍を身体の前で回す、空前は突き、空後は振り返り突き、空上は穂先で頭上を刺す、空下は斜め下へ急降下。別々の全身画像と予備/戻りを使用する。プリニー・ハート・爆発を一律の輪状エフェクトにしない。

プリニー設置→横Bで遠隔起爆、設置→下Bで範囲起爆が、単独射撃・近接の槍と異なる判断を生む。撃墜力だけを上げるゲージは付けず、最大設置数と起爆のタイミングを資源とする。ダメージ・命中は同じ対象に同じ爆発から1回だけ。本人が撃墜された時は設置物を消す。CPUも設置数・距離・復帰角度を使い分ける。オンラインでは乱数に依存しない位置/寿命/起爆を同期する。
