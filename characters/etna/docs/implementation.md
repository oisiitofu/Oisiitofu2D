# エトナ 実装・検証

ラハールの直後。人型サイズ2（待機94px）、重量84。生成した全身74ポーズと選択用アップ1枚、専用エフェクト16枚を配信アトラスへ収録。関節変形は使わず、各攻撃は別の全身姿勢を使う。元画像7枚と制作プロンプトは `assets/`・`art-prompts.json` に保存。

基本姿勢は最初の基本動作シートから切り出した `assets/etna-neutral-locked.png` を固定し、再構築時に画素一致を確認する。生成シートは basic/attacks/defense が4×4、specialsは末尾の空セルを除く15体、extraは5×3の15体。専用抽出器は全身の連結成分を保ち、他セルの断片を取り込まない。実際に採用したセル番号は `tests/art-layout.json` のsourcePoses。プリニーの単体素材は隣の魔力片を除き、元の青い本体画素を維持。

必殺技の細部：

- NBのプリニーは最大2体、寿命240F。投げる時の上下で角度が変わり、接地後は歩く。敵・シールドへの接触、横Bのハート、下Bからの指令で爆発。本人の撃墜時は消える。
- 横Bは18Fで射撃。ハートとプリニーの可視幅を含む接触で起爆でき、直撃時は1回だけ命中する。移動突進にはしない。
- 上Bは8Fの支点作りから、横入力の量で高さ/横距離を変えた弧へ移る。37F後に翼をたたんで通常の落下へ戻る。台の下では外縁へ回ってから跳び、壁の高さを越えるまでは内側へ潜り込まない。地上発動も空中の使用回数を消費し、再使用は着地/崖から。謎の浮遊待ち・追加攻撃はない。
- 下Bは予告8Fを挟む魔力柱。近接の叩きつけと遠隔の柱を分け、近接補正は近接ウィンドウだけ。空中版は落下して実際に接触した足場で発動し、浮遊台を押し抜けない。
- 爆発/魔力柱は対象ごとに命中集合を持ち、同じ対象への無限多段を防ぐ。反撃技・シールドにも対応。通常槍はspear、ハートはmagic、爆発はexplosionの命中音。

槍の突きは右向きの直線素材7、薙ぎは凸側が右の曲線0、上の突きは直線素材を上へ回転。前後の反転は攻撃判定の向きに対応し、空Nは槍旋回の両側へ専用曲線を出す。上攻撃に縦長の曲線は使わない。CharacterVFXKit/AttackEffects.imageを通し、可視部分を判定の外縁へ合わせる。選択カードのみobject-positionを下寄りにし、大きな髪で顔と肩が隠れないようにする。

プロジェクトルートから実行：

- `node characters/etna/tests/assemble-art.cjs`：全身の切り出し/梱包、固定待機の一致。
- サーバー起動後 `ART_IDS=etna GAME_URL=http://localhost:4177 node .tools/build-art.cjs`：75ポーズ・16FX・5カラーと専用アップの配信画像。PowerShellでは環境変数を個別設定。
- `node characters/etna/tests/etna-test.cjs`（GAME_URL対応）：84項目。全通常/スマッシュ/空中技の左右/先端/密着、プリニー上限、起爆、反撃、地上/空中下Bの浮遊台、左右と台下の復帰、使用回数、撃墜後の消去。
- `node characters/etna/tests/visual-test.cjs`：75場面の方向/予備/攻撃/戻り/待機色。選択画面・ラハールとの実描画も保存。
- `node characters/etna/tests/cpu-test.cjs`：月影/工場の各1戦、全オブジェクトの生成と命中、有限な位置/速度を確認。
- `node characters/etna/tests/online-test.cjs`：独立2端末、331Fの戦闘/設置/命中/復帰が一致。
- `ART_IDS=etna node art-loading-test.cjs`：75ポーズ・16FX・375色別画像の一致、実行エラーなし。`node build-size-catalog.cjs` で一覧を更新済み。

検証画像/結果はGit管理外の `characters/etna/previews/`。
