# エトナの専用リミットブレイク

槍を返してプリニーを送り出し、地上、低い斜め、真上から来る三つのプリニーの軌道を追いかける。槍を支点に飛び上がり、空中からためを作って地面に槍先を落とす。接地した槍の位置からカオスインパクトが伝わり、残ったプリニーが斜めに飛び出す連鎖で締める。アヌビスが真上で静止して光を真下へ通すのに対し、エトナ自身が放物線を下りて着地し、地面から広がる噴出を見せる。

髪、羽、尻尾、衣装、槍とプリニーの輪郭は対戦素材に合わせる。カメラは空中移動を引きで追い、槍と地面が接する瞬間に寄る。最後の槍の衝撃音とプリニーの連鎖音を重ねず、発生順に鳴らす。

魔界の橋、専用の横長カットイン、槍の軌跡・爆発・落下・地表の噴出、跳躍・振りかぶり・着地の全身姿勢3種を用意した。プリニーは現在の対戦素材を使う。標準カラーでは専用全身姿勢、別カラーでは対戦用の対応姿勢を使う。
