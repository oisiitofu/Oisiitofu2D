# ピポサルの専用リミットブレイク

『サルゲッチュ』のピポヘルとタイムマシンを舞台に、このゲームで実装済みのガジェットをひとつの捕獲作戦にする。ピポサルは低く座り込み、サルレーダーを床に置く。相手が浮くのに合わせてヘリコプターキャップで縦に上がり、リングの高さで停止。マジックパンチのグローブを振り子のように伸ばして引き戻し、その反動で弧を描いて降りる。着地からゲットアミをすくい上げて一緒に上へ。最後にアミの輪郭が広がり、転送光に包んだ相手を反対側へ弾き出す。

ラチェットの裂け目は二地点をつなぎ、サックボーイの高さは床の装置で変わる。ピポサルは自分のローターで静止と落下を選び、伸びるグローブを先に飛ばす。赤ランプ、銀ヘルメット、黄タンクトップ、巻いた尻尾を保つ。グローブの伸縮、ローターと姿勢、ネットの開口と飛び出しをそれぞれ専用素材と音で見せる。

- [PlayStation公式 ピークポイントヘルメットと時間移動](https://blog.de.playstation.com/2011/01/19/replayed-ape-escape/)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中6ヒットで21ダメージ、決め技で25ダメージ。レーダー、ローターの急上昇と空中停止、グローブが弧を描く二度の命中、ゲットアミと転送機を確認。アミの編み目から相手が見える構図にした。CPU同キャラ戦はストック切れ。ローカルオンラインは411フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
