# 専用リミットブレイク

岩陰からスニーキーで入って武器を振り、火と氷へ交互に飛び移る。地上の転がりで相手を押した後、バルーンで真上へ跳ね上がって落下する。魔王の滞空と違い、一度地面を転がってから上空を使う。 対戦用の髪・衣装・装備を使用。

[任天堂のキャラクター資料](https://www.nintendo.com/en-gb/Games/New-Nintendo-3DS/Xenoblade-Chronicles-3D-961136.html)

改修版では、対戦用の橙色の耳と毛、空色と紫のベスト、渦巻き飾り、苔むしたこん棒を参照し、空中でこん棒を振る横長カットインを ImageGen で制作した。森の遺跡を背景に、初撃は金色の打撃、火と氷は別の輪郭、転がりは葉と砂の軌跡で描く。継ぎはぎの風船で垂直に上がり、接地した位置から岩と葉が噴く。決め技では少し引いて落下と相手の吹っ飛びを追う。

配信素材は `assets/limit-cutin.webp`、`assets/limit-forest.webp`、`assets/limit-effects.webp`、`assets/limit-props.webp`。
