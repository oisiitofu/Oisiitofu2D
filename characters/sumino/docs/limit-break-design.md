# 澄野拓海の専用リミットブレイク

『HUNDRED LINE -最終防衛学園-』の防衛戦、我駆力刀、決死必殺を一連の攻防にする。学園の門前で防衛線が点灯し、澄野は膝を落として刀を受ける構え。斜めに隣のマスへ踏み込み、相手を守備線から外へ払い、引いて別のマスへ移る。二度目は広い横薙ぎから腕と刀を低く引き直して、中央の防衛線を踏み越える。最後は公式画面の攻撃範囲に合わせて前方の縦5×横3マスが点灯し、我駆力刀の広い一閃で相手を押し出す。残る炎と防衛線の奥に門を映す。

ユーマは飛来物を弾いて空中から刃を入れる。澄野は守る線から距離を測り、重い切り返しごとに足を止める。制服と武装、既存の刀身と顔を守り、床の攻撃範囲と刀の振り、最後の吹っ飛びを同じ側にそろえる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中6ヒットで21ダメージ、決め技で26ダメージ。防衛線を背に前列と後列を踏み替え、公式画面に合わせて前方5×3マスを点灯させ、紅の連刃へつなぐ。CPU同キャラ戦は時間切れ。ローカルオンラインは410フレームと決め技の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
