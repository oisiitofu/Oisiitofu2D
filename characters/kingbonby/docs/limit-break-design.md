# 悪行連撃からデストロイ号

2026-11-05の大きな動きと高品質アニメーションの指定を適用。紫の肌、炎のような金髪、金の冠と髑髏飾り、赤い布とマント、太い手足と顔を参照に固定し、専用全身ポーズ8枚で巨体の予備動作・跳躍・着地・投げ・指示を描く。

サイコロを大きく振りかぶって投げ、跳び上がりからの踏みつけで連撃へつなぐ。最後は[コナミ公式](https://www.konami.com/games/momotetsu/teiban/play.html)に掲載された最凶形態デストロイ号へ展開する。走行の規模を引きのカメラで示し、相手を巻き込む通過と最後の衝突、余韻まで段階を分ける。通常の上必殺の小さい列車を拡大する代用にはしない。

原作の公式掲載画像で列車の色・顔・角・煙突・車輪を確認して専用素材を制作。角張った汽車の実輪郭、攻撃する先頭、相手の位置を合わせる。途中のヒットに停止・音・火花を付け、巨大エフェクトの前に相手を描く。待機や既存の技は保持する。ローカルで対戦・トレモ・両向き・カットイン比率・攻撃の濃さ・専用音を確認。CPUは60秒1ストック設定の1戦が時間切れの結果まで進行。オンライン357フレームが一致。連続再生を録画し姿勢と移動を比較した。公開検証は `docs/limit-break-rollout.md` に記録する。

内蔵imagegenの最終プロンプト、参照、元出力と保存先は `limit-break-assets.json`。連続再生の録画はGit管理外の `previews/kingbonby/limit-break/playback.webm`（映像のみ）。主攻撃はart.strike、補助光はart.glow、カットインは共有LimitCinematic.portrait。新しい全身画像の間は共通のカメラ時間軸で移動させ、顔・頭身・衣装の連続性を維持する。
