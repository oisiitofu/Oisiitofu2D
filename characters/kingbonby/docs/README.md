# キングボンビー

添付 kingbonby.png を基準に桃太郎電鉄のキングボンビーを追加。画面124／旧登録131、おまかせ直前。130形態・選択可能124・非表示6。紫の巨体、金色の炎状の冠・装飾、赤いマント、牙と大きな手。体格112・重さ120。全身48姿勢＋専用肖像、12エフェクト、5カラー。関節リグを使わず全身の絵で表示。

| 入力 | 動作・対処 |
| --- | --- |
| NB | 14Fでデビルカードを前方へ放つ。命中地点に赤・青・キングデビルが10/26/42F後に現れて攻撃（3/3/5ダメージ）。地点固定なので離れて避けられる。カード2ダメージ、ガード／無敵では召喚なし、150F待ち・同時1組。 |
| 横B | 16〜34Fに2Fおきでサイコロ10個。各3ダメージ、地上で2回バウンド、有限寿命68F。1波につき相手毎に3回まで／14F以上間隔を空ける。110F待ち・前の波が消えるまで不可。本体は突進しない。 |
| 上B | 10Fでデストロイ号に乗り、初めは斜め、その後強く上昇。途中の横入力でカーブ。乗車12F後からジャンプ／必殺の押し直しで飛び降り、30Fで自動離脱。列車は後方へ消え、本体は有限時間でしりもち。ステージ内側下では先に側面へ抜ける。 |
| 下B | 20Fで8方向にカードを散布（各7ダメージ）。相手毎に一度だけ命中。150F待ち、空中でも本人は急降下なし。 |

悪行ゲージは実命中の威力×2、1命中最大18増加（上限100）。ガード／無敵では増えず、受けたダメージ分だけ減り、撃墜で0。MAXで次の横Bを使うと消費し、サイコロが各4ダメージ・半径13・3バウンドに強化。常時無制限に強い飛び道具にはしない。王子の塊魂とは別の専用ルール。

## 素材

**内蔵 image_gen** を使用。全文は [image-prompts.json](image-prompts.json)。制作した [poses](../assets/kingbonby-poses.png)、[motion](../assets/kingbonby-motion.png)、[effects](../assets/kingbonby-effects.png)、[selection](../assets/kingbonby-selection.png)、参照 [reference](../assets/kingbonby-reference.png)、結合元 [native](../assets/kingbonby-native.png) を保存。

`tests/assemble-art.cjs` は承認した絵を再生成せず透過RGBAを保持して切り抜く。隣から離れたカード／サイコロの欠片を身体へ混ぜない。紫の肌だけ色替え、金・赤・目・歯は維持。列車は右向き素材。平行移動→左右反転→ローカル回転で速度の方向へ合わせ、身体より後ろに描く。

## 検証
