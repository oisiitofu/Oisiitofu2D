# レナ

添付のスターオーシャン2デザインに合わせた拳・光と重力のファイター。人型サイズ2（94px）、重さ83。共通登録はregistration.jsonを参照。

- NB：MP10の単発ライトクロス。25F以上長押しして離すと追加MP10で近・中・遠に3個（最大42Fで自動）。飛翔弾の無限連射を避けるため自分のライトクロスが消えるまで再発動不可。着地は詠唱を切らない。
- 横B：MP20。110～260px前方に重力シンボルを設置。22Fの予告と軽い引き寄せから一度だけ打ち上げる。シンボルが消えるまで再設置不可。レナ自身は突進しない。シールドと移動で対処可能。被弾硬直・ヒットストップ・崖つかまりを引き寄せで上書きしない。
- 上B：足元のトラクタービームで22F上昇し、左右入力で進行を変える。起動時に落下慣性を止める。MP20で高さを増すが、MP不足でも復帰用の短い上昇は可能。以後は尻もち落下へ直接移行。ステージ下では縁まで抜けてから上昇する共通脱出を利用。
- 下B：MP20を先払い、26F詠唱後に6%回復し6秒間通常攻撃の威力を12%上げる。被弾で詠唱を止められる。無敵・全体回復・時間クールダウンなし。
- MPは100上限。通常時8.4/秒、必殺中2.7/秒、通常攻撃命中時追加回復。通常技にはMP制限なし。

15種類の通常・スマッシュ・空中技に異なる全身ポーズを割り当て。全身画像で中間動作を作り、関節リグ不使用。上強は掌の星、空上は頭上の曲線1個、上スマは3本のレーザー（判定の外縁をそのまま描画）。エフェクト1は原画の凸側が下のためPI回転で上向きへ正規化。既存素材は反転しない。

本体55枚+専用高解像度選択画像1枚、16FX、5カラー。生成は組み込みimage_gen。プロンプトはimage-prompts.json。立ち姿を先に固定し、以後の補足画像はこれをデザイン基準にした。欠けたターン31は全身のターン4、欠けた登り39は補足53に差し替えた。上スマ13は両腕を広げた補足54を使用し上強8と区別。

`node characters/rena/tests/assemble-art.cjs` はこのフォルダ内だけを再構成する。

検証：`rena-test.cjs` は138チェック（左右15技の密着/方向、MP、詠唱着地、設置の単発命中、回復の中断、上B慣性停止/操舵/左右場外復帰）。`visual-test.cjs` は48場面・54チェックと実カードの比較画像をpreviewsへ出力。`cpu-test.cjs` は2400FのCPU戦を実行。`online-test.cjs` は2クライアント・6代表場面を720F比較する。オンラインは共有サーバーにIDを登録してから実行する。
