# 2Bのリミットブレイク

ポッド042が相手を捕捉し、2Bは廃墟都市の上空で飛行ユニットHo229 Type-Bに搭乗する。弾幕で追い込み、ポッドのレーザーで動きを止める。2Bが機体から跳び出し、白の約定の一太刀を入れる、ヨルハ部隊の出撃をモチーフにした本作独自の連携。

機体は3方向の専用画像を使い、カメラを低くしてすれ違いの速さを出す。銃撃の橙色、索敵の赤、最後の斬撃の白を使い分ける。HUDはポッドの捕捉中だけ現れ、2Bの顔や着弾を覆わない。
