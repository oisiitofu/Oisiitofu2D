# 専用リミットブレイク

低いダッシュで間合いを詰め、ガンブレードの斬撃と射撃で相手を止める。後半は相手の上下を直線で切り返し、雷をまとった斬り下ろしで締める。ヴィンセントと異なり変身せず、接近状態で剣と銃を切り替える。衣装、赤いマント、武器は対戦の全身素材を使う。

改修では現行の対戦用全身素材と選択肖像を参照し、桃色の髪、白い襟と胸当て、赤いマントとガンブレードを合わせた。組み込みImageGenで上空から斬り下ろす横長カットイン、雷雲の工業都市、青白と紫の斬撃、水平の射撃、縦に走る落雷を描き起こした。素材は `assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-effects.webp`。シーンドライブでは先に剣先に電荷を集め、落雷を背面に出し、剣の軌跡と地面へ広がる残光を重ねる。

再比較では、距離を取って蹴るティーダに対し、ライトニングは相手の頭上を越えて刃を起こし、斜めに振り下ろす。落雷の枝は相手の奥に落とし、剣閃との交差と地表へ広がる余韻を順に描く。ライトニングの髪とマント、相手の被弾姿勢を同じ画角で追う。

組み込みImageGenでは「白い襟、赤いマント、桃色の髪を保ち、ガンブレードを前に出す横長構図」と「縁に稲妻が走る斬撃、青白い落雷、床へ散る紫と金の衝撃」を制作した。配信用は `assets/limit-cutin.webp` と `assets/limit-finish.webp`。剣先の電荷音を演出167フレーム、専用の決め技音を178フレームに置いた。
