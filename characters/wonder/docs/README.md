# ワンダー

ユーザー添付 `C:/Users/haro_/Downloads/wonder.png` をデザイン基準に、全身ポーズ56枚（内ペルソナ3枚）と専用高解像度上半身画像、16種のエフェクトを builtin image_gen で制作。元の待機姿勢を固定し、別の全身画像で移動や技を表示する。関節変形は使わない。制作プロンプトは `image-prompts.json`。

配置はウィルの直前。人型サイズ3、立ち姿98px。赤い手袋・マスクをカラー変更の中心とし、肌・髪・黒い制服の明度を維持。

- NB タトラショット：手銃とヤノシークの同時射撃。弾が残っている数を最大2個へ制限し、他の技を時間で封じない。命中相手の頭上に4秒の標的マーク。近接を2回命中させるとマークを消費し追加4%。
- 横B バレットタイム：低いスライドの斬撃から、長押ししていれば斬り上げ、さらに長押しで横斬り。3段それぞれ別の画像とヒットID。無条件な横突進だけでなく、止める段階と空中での浮きが異なる。
- 上B ワイヤーアクション：落下慣性を止めてワイヤーを射出。射程430px以内の足場端を優先し、届く端がなければ上空に支点。巻き上げながら左右入力で振り子を操作し、17フレーム後から必殺を離す／ジャンプで離脱。自動離脱は43フレーム後。離脱方向は左右、下入力で低めの角度を選ぶ。足場の中に入る場合は共通escape経由で外側へ出る。攻撃後は透明化せず尻もち画像35へ移る。
- 下B ペルソナチェンジ：バランス→火力→支援。火力は通常技/射撃が強く、支援は広い弾と高いワイヤー離脱能力。異なる3種類のヤノシーク姿勢を表示する。

通常技15種類はすべて異なる全身ラスターポーズ。近接は共通MeleeBalance.coverageを1回適用。弾・マークには近接補正を掛けない。通常投げは共有ThrowTuningの方向別役割を使用。

曲線素材0は凸側が右、1は上、13は下。ローカルで元画像を正規化し、回転した後にプレイヤーの左右反転を掛ける。上強と空上は頭上の曲線1枚。上スマは元からX字の射撃なので単一Xを最終判定全体に合わせ、身体側の判定ごとに重ねない。ペルソナやワイヤーは判定のない別描画。

プロジェクトルートから `node characters/wonder/tests/wonder-test.cjs`、`visual-test.cjs`、`cpu-test.cjs`、`online-test.cjs`。画像再生成は `node characters/wonder/tests/assemble-art.cjs`。アトラス完成後、親の共通登録・ready生成を経て実行する。検証画像/結果は Git管理外の `previews/`。

ローカル検証：機能112項目（15ポーズ差異、左右密着・方向、射撃制限、3段連携、3slot、マーク消費、左右場外復帰）を通過。実描画43場面で曲線方向・頭上1弧・ペルソナを確認。CPU戦2400フレームで有限値・必殺使用・相互命中を確認。オンラインは実ワンダーをUIから2人選んで開始し、射撃・マーク・横B・ワイヤー・3slot切替の6場面720フレームが一致。エラー0。最終ready再生成後の描画43場面と選択カード比較も確認済。
