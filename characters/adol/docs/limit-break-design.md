# アドルの専用リミットブレイク

『イースX』のマナライドから星方陣、カーマインブラストへ。斬り返して相手を水際に誘い、グリンブルボードで低い波を横切る。風溜まりでボードごと浮き上がり、石の足場へ片足から降りる。剣の軌跡で足元に星形を描き、姿勢を低くして剣先に炎を集め、相手と同じ高さへ熱線を通す。リィンの地上抜刀と騎神召喚に対し、アドルは水上と空中で板に乗り、着地してから剣先で遠距離を攻める。赤髪、既存衣装と剣を基準に、足と板、剣先と熱線を実描画で照合する。

- [ファルコム公式 星方陣とカーマインブラスト](https://www.falcom.co.jp/ysx/system/skill.html)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中7ヒット、決め技26ダメージ。赤白のマントと青黒の鎧を維持し、マナライドの接地、岩棚への着地、星方陣と熱線を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
