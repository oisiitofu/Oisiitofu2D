# ノクティスの専用リミットブレイク

上下に剣を投げてシフトし、低い剣から頭上の槍に移る。投げた武器を座標の目印にし、武器への移動を照明と残像で示す。ティーダの連続軌道と違い、空中の異なる地点へ切り替えてからファントムソードを同時に出す。対戦の黒い衣装、髪、得物を使う。

改修では対戦用の全身素材と選択肖像から、青黒い髪、黒い上着と手袋、銀の剣を参照した。組み込みImageGenで、空中のシフトと武器の召喚を描く横長カットイン、夜の王都の屋上、四種の幻の武器、青白い斬撃とシフトの結晶、ファントムソードの着弾を制作した。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-armory.webp`、`assets/limit-effects.webp` に収録。低い位置、相手の頭上、反対側への三回の移動では武器の投射元と到着点を固定し、最後は剣・大剣・槍・長柄武器が相手へ向きながら集束する。
