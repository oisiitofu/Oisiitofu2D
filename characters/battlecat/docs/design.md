# ネコ — 量産・ネコ缶・ネコタワー

ちいかわの前。丸い白猫の形と黒い輪郭、短い足を維持する。小型特殊体型60px。高解像度の顔/上体画像は別制作する。

- 固有操作: ネコ缶は攻撃されると開き、援軍を1体ストックする。援軍は最大3体、時間で無限増殖しない。ネコ自身は軽く、押し込む力はあるが被弾に弱い。
- NBにゃんこパンチ砲は溜めて青い肉球弾。援軍がいる場合だけ斉射の間隔を短くする。弾は地形とガードで止まる。
- 横Bネコ列車は本体が突進する技ではなく、ストック援軍を右/左へ出撃させる。再入力で前進/停止の号令を出す。地面を歩くためジャンプで回避でき、援軍は被弾で消える。空中では足元へ落ちて着地後に歩く。
- 上Bネコタワーは足元に有限時間の積み猫を生成し、積み上がった塔に自分が乗る。横入力で塔から降り、Bを離すと塔を蹴って斜めへ飛び出す。塔の攻撃は一度だけ、猫は散って消える。通常の二段上昇攻撃とは違い、位置を先に作り出して脱出方向を選ぶ。場外も足場なしで立ち上がるが、塔の高さ/時間には上限を持たせる。
- 下Bネコ缶落としは予告の後に缶を落とす。障害物/1回の弱い打撃。缶を自分で攻撃すると援軍になるが、敵の攻撃でも壊される。
- 使い分け: 缶で援軍準備→列車で進路を制限→パンチ砲。復帰は塔の配置と離脱方向を選ぶ。相手は缶の破壊、援軍への攻撃、塔の離脱地点への先回りで対処できる。

制作は全身画像のみ。手足リグは使わない。投げは位置変更/追撃を基本とし、全方向を撃墜用にしない。命中音は軽い肉球打撃、砲弾、缶の金属音を分ける。
