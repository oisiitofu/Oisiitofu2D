# ネコの専用リミットブレイク

対戦用の丸い白い体と黒い輪郭を維持する。小さなネコが突進を始め、仲間と列になって台を押し、本人は隊列の脇を駆けて城のレバーに飛びつく。仲間の肉球と頭突きが時間差で当たり、最後は引きのカメラで城からのにゃんこ砲と相手の位置を同時に見せる。クォートの手持ち武器と違い、ネコ本人の動きが城の発射につながる。

- [ポノス公式 にゃんこ砲](https://www.ponos.jp/games/thebattlecats/)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。隊列を飛び越え、城のレバーを引いてにゃんこ砲へ。途中7ヒット、決め技27ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
