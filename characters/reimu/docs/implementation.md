# 博麗霊夢

ホーネットの直後。人型サイズ2・94px、重量88。添付シートを基準に built-in imagegen で全身画像5枚、専用の顔・肩アップ、FX1枚を制作。7プロンプトは image-prompts.json。基本の待機画像を固定し、77姿勢・16FX・5カラーへ配信。関節リグは使用しない。選択画像はゲーム用全身を拡大せず、高解像度の専用原画から表示する。

地上NBは追尾する霊符2枚、長押しで6枚。空中NBは速い直線の針3発。横Bは隙間から相手の背後へ出て下降蹴り、再入力を予約すると元の地点付近へ戻って追撃する。単純な横突進と違い、移動途中の接触攻撃はなく、再出現地点への対処と戻りの読み合いになる。終点が地形の中へ埋まらないよう補正し、地上着地でも途中の攻撃を消さない。

上Bは斜め上への蹴り、初段中に記録した方向への二段目、陰陽玉を伴う前方蹴りを固定の時間でつなぐ。追加入力待ちの停止時間はない。場外の左右・ステージ下からの復帰、専用しりもちとその横操作を確認。自由落下中にジャンプを保持すると最大45フレーム、緩やかに浮遊する。被弾・しりもち中には浮遊しない。

下Bは小結界、長押しで大結界。大結界は対応する動く敵弾を受け止め、霊夢所有の弾として返す。遠隔設置やその場の範囲攻撃には無条件に反射を適用しない。命中、動く敵弾のかすり、反射でドリームを最大6まで獲得。短い獲得間隔を設け、最大時の下Bで6つの追尾陰陽玉「夢想封印」を放って消費する。陰陽玉自身はゲージを再獲得しない。

通常/空中/スマッシュ15技の全身姿勢は別画像。空Nはお祓い棒、空前は札の扇、空後は後方の棒、空上は上向きの針、空下は陰陽玉。可視の凸側を確認し、0は右、1は上、5は右、9は右上として方向を扱う。FXは全身画像から分離し、隣のセルを拾わず丸ごとの成分を切り出す。近接の周辺と密着を共通MeleeBalance.coverageで補い、弾・つかみへは広げない。

検証: 113機能項目（通常15技の左右・密着・先端、必殺の各攻撃窓、追尾、反射、ゲージ、復帰）、左右30通常/28必殺/10待機色表示、12派生表示、60サンプルの連続映像、CPU1戦。配信読み込み77姿勢・16FX・385カラーの不一致0。オンライン6場面240Fが2クライアント間で一致。検証画像と動画はGit管理外のpreviews/。
