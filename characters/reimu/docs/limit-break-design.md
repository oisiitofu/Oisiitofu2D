# 博麗霊夢の専用リミットブレイク

対戦用の赤い大きなリボン、白い袖と赤い衣装、黒髪、御幣を基準にする。御札を置きながら空中で一歩ずつ斜め上へ位置を移し、縦に並ぶ札を下から順に光らせて相手を押し上げる。最後は夢想封印の色玉が広い弧を描いて目標へ集まる。騎士の接地反発とは異なり、空中に一拍とどまって札を置く手と弾の軌道を別々に見せる。追撃の間は17〜21フレームを目安にする。

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。空中に札を置いて相手を押し上げ、夢想封印へ。途中7ヒット、決め技26ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
