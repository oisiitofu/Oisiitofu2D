# イデア

参照は `assets/edea-reference.png`。builtin imagegen で透過の全身48ポーズ、追加8ポーズ、12エフェクトを制作。元デザインの頭身・衣装を維持し、関節変形は使わない。元PNGを保存。再組立は `node characters/riesz/tests/assemble-art.cjs edea`。

デフォルトは40F維持でBPを1獲得、最大3。途中解除では獲得せず、被弾で解除される。構え中は被ダメージ/吹っ飛びを0.45倍にするが無敵は付けない。ブレイブラッシュはBP全消費で1〜4段。それぞれ別段のダメージで、演出のために攻撃窓を分割しない。

横必殺は立てた槍を支点とする半円軌道。単純な横突進ではなく上に弧を描いてから下降し、空中でも支点を設定する。上必殺は斜め上へ方向調整して飛び、頂点で短く滞空した後、専用の尻もち姿勢に移る。

ポートレート48、横強49/50、尻もち51、移動追加52..55、NB準備56。上強8・上スマ13・空上45は別の全身姿勢。横強と空前も別の画像。曲線0/8は凸側が右、上側1は凸側が上。上攻撃は頭上の曲線1つ。通常の近接必殺に再使用待ち時間はない。

生成プロンプト: 参照の長い金髪/黒赤のリボン/黒赤白の騎士装束を固定した8列6行48ポーズ、全身、同じ頭身、透過、エフェクトなし。追加は横強と後続、尻もち、歩行2、走行2、NB準備。FXは3列4行、赤い剣曲線、青い上側曲線、橙の回転、槍突き、半円、上昇風、青い守り、金のアスタリスク、連続斬撃、羽根、着地、ヒット。builtin image_gen のみ使用。

共通登録は `tests/registration.json`。検証は `node characters/riesz/tests/newcomers-test.cjs` と `node characters/riesz/tests/cpu-test.cjs` のイデア分。

検証結果（2026-10-20）：共通専用テスト222件成功。初動で即着地して横必殺がキャンセルされる問題を修正し、半円の上昇を実挙動で確認。デフォルトの実被弾で軽減・BP獲得前の中断を確認。CPUは1戦2400F、14命中/3KO、有限値維持。これはCPUによる動作確認で、人間の対戦バランスの完成を示すものではない。

選択画面は専用ポートレートの頭部/肩へ切り抜き範囲を合わせ、他キャラと同程度の顔の大きさで表示。頭頂の飾りを残し、戦闘用ポーズやサイズは変更しない。
