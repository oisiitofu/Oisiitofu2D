# レオンのリミットブレイク

ナイフ、回し蹴り、再度のナイフ、ハンドガン4連射で相手を追い詰め、構えてから赤い弾頭のロケットランチャーを撃つ。弾が相手まで飛ぶ時間を設け、爆発の手前に双方を描いて決め技を見失わないようにする。連撃7ヒットの合計17ダメージ、最後に22ダメージと斜め上への吹っ飛びを適用する。終盤のロケットランチャーを軸にしたゲーム用の再構成で、衣装は既存の紺色の警察服を維持する。

初撃の近接攻撃はガードと無敵で防げる。命中時は1人を捕捉し、ほかの参加者と対戦時間を止める。空振りではゲージを消費し、被弾でため直せる。連撃はダメージと被弾反応を同期し、最後に吹っ飛びを適用する。

ナイフと打撃、銃声を切り替え、発射の圧縮された破裂音から排気の音へつなぐ専用効果音と、爆発の衝撃・低音・瓦礫の専用音を使う。画面揺れと明滅は共通の見やすさ設定へ従う。

ビルトイン画像生成では既存の選択画像を顔・髪・紺の衣装・装備の厳密な参照にした。16対9のカットイン、人物も弾もいない夜の島の鉄製足場、右向きのナイフ・蹴り・拳銃・ロケットランチャーの全身4姿勢、透過のナイフ斬撃・銃弾・赤い弾頭のロケット・爆発を指定した。全身シートの髪とブーツは画像生成による修正で余白を確保した。斬撃の凸側と弾の進行方向は右、画面全体の反転で左向きへ対応する。カットインはLimitCinematicで縦横比を保つ。

発射後は弾頭が残らない専用シートへ切り替える。弾の出現範囲を筒先からに制限して銃本体と重ならないようにし、排気は筒の後ろ側へ出す。

素材はこのキャラの `assets/limit-*.webp`、効果音は `assets/audio/se/leon-limit-*.wav` に保存した。
