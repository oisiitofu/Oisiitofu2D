# アストロ — 実装前の技設計
位置: トロの直後。白い小型ボディ、黒い画面と青い目、アンテナを基準とする。
固有操作: 伸びるフロッググローブを遠距離で当てて引き寄せ、保持中の引っ掛かりを左右で振り、解除で放す。自分の時間停止フィールドに相手/弾を巻き込む間はエネルギーが減り、使用後は再充填を待つ。
横B: バクスターのブーストを方向入力で曲げ、地上の滑走と空中のカーブを分ける。接地のリバウンドは1回のみ、同じ攻撃で持続的に跳ねない。
上B: チキンロケットで最初の上昇を確保し、頂点で保持しているとタコルーンに展開。有限燃料でゆっくり移動し、解除して落ちる。ジャンプ/上B連打で無制限に再上昇できない。
通常: パンチ、キック、レーザーソール、モンキーグローブ/球状アーマーをそれぞれ専用の全身ポーズで表現。空Nは小さく身体をひねるスピンパンチで刀の共通輪を使わない。
既存との差: 単純な突進/二段上Bではなく、伸縮する腕の拘束/スイング、曲げるロケット、頂点で選べる有限の風船、局所時間停止の連携。
対処: 腕が伸び切った隙、停止フィールドの外側、浮遊燃料切れと着地を狙う。停止は無限拘束ではなく1対象ごとの持続上限を持つ。
画像: 全身の中間画像と専用顔アップ、各ガジェットを別素材として制作。

## 実装・検証

専用の全身フレームと16種類の素材、顔と肩の専用選択画像を内蔵 imagegen で制作。元の待機ポーズは neutral-locked.png と一致。前後上下を左右両向きで確認し、近接補正はMeleeBalance.coverageを一度だけ使用する。新キャラ4人とイーノック3武器を対象に通常技の密着/先端・全必殺・有限時間・復帰を440項目確認。CPU戦、2画面オンライン960F、個別の設置/引き寄せ/武器切替/台上発動を確認。実描画と連続姿勢の検証画像・動画は各previewsに保存。

画像と最終プロンプトは同じdocsのart-prompts.jsonに記録。素材はassets、配信はassets/readyのmanifestとハッシュ画像。
