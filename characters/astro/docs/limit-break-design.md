# アストロの専用リミットブレイク

『ASTRO BOT』のツインフロッグ・グローブとブルドッグブースターを使う。アストロは足場の側面へグローブを伸ばし、ひもが張るのに合わせて後ろへ沈む。反動で斜め上に弾かれ、足場の縁を支点に振り子のように回り込む。両腕の伸縮で空中の相手を連打し、反対の腕で着地点に引き戻す。最後は背中にブルドッグブースターを装着し、斜面で滑走した勢いを青い噴射に変え、残骸を突き抜けて決める。

アイアイの球の接触による反転に対し、アストロはグローブがつかむ固定支点と、ひもの張力で軌道が決まる。トロの飛び移りに対しては、張った腕、支点、本人の位置が切れずに動く。カメラは引いて支点と相手を同時に入れ、最後に噴射を追う。白と青の機体、黒い顔の発光する目、伸縮する左右のグローブと背負うブースターを確認し、全身の踏ん張り、振り子、片腕伸ばし、滑り、噴射を制作する。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音3点を制作。途中6ヒットで21ダメージ、決め技で25ダメージ。梁と固定支点をつなぎ、振り子の軌道と伸縮する腕、足元とブースターの位置を確認。CPU戦は時間切れで終了。ローカルオンラインは405フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
