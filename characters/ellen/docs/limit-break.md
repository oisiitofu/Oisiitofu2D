# エレンの専用リミットブレイク

氷の床を斜めに刻み、低い姿勢で滑って大鋏の二枚の刃を順に通す。尻尾で相手を持ち上げ、床の氷へ鋏を当てた反動で跳ね返ってから、上空で刃を開く。最後は左右の刃が相手のところで閉じて氷が割れ、地面に霜が残る。ナルメアが納刀から静止して一閃を通すのに対し、エレンは滑走、反動、鋏の開閉で速度を変える。

対戦と同じメイド服、髪、尾、大鋏を参照する。氷上の足元、鋏の刃先、相手に届く氷を別々に描き、決め技では鋏が閉じる瞬間から割れた氷へカメラを引く。

「終わりなき冬の狂宴」の専用カットイン、凍った街路、氷の軌跡、左右から閉じる氷刃、割れる氷を制作した。標準カラーでは滑走・空中の振りかぶり・着地の3姿勢を使い、別カラーは対戦用の対応姿勢で描く。氷を蹴る音と破砕音を分けた。
