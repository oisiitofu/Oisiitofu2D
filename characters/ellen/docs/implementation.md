# エレン・ジョー

雅の直後（エレンの次がビリー）。サイズ2/94px、重量91。

添付デザインを参照しbuiltin image_genでゲーム用の全身姿勢、氷の16FX、別制作の高解像度な顔と肩の選択画像を作成。正確なプロンプトはimage-prompts.json。basicの先頭を固定し、他シートの校正姿勢から倍率を一度だけ決める。関節変形は使わない。specialsの空きセルは別生成の全身勝利姿勢で補う。元デザイン/比率/足底を保ち、62フレーム/5カラーを配信。

- NB: タップで尾の一撃。22F以上溜めると回転の強攻撃、40Fで自動解放。命中でチャージ1。
- 横B: 低姿勢で左右入力に追従し移動。解放で軽い跳び斬り、30F以上で重い跳び斬り。最大52Fで有限。重い追撃は命中で3、軽い追撃は1。ガードでは増えず同じ技では1回だけ。空中1回。
- 上B: 慣性を止めて回転上昇、氷の急降下、着地または一定距離の降下から反動ジャンプへ直結。静止待ちを入れない。ステージ下では先に端へ抜ける。終了後は専用の尻もち絵、横慣性を維持。
- 下B: 長押しで異なる全身絵の三段。チャージを1/2/3消費し、最後は広い氷刃。足りない段は弱い版を使える。0でも使用可。最大6、復活で0。

通常15技は別の全身姿勢。通常つかみ解放はagile群の方向別役割、攻撃上がりは共通の専用弱単発/長い後隙。曲線0の凸側は右、1は上、2は下と実画像で確認。ローカル回転から左右反転。上攻撃は頭上の広い曲線1個。共通coverageを一度だけ使用し、手元から先端を確認。

検証: ellen-test.cjs 128項目、左右通常30/必殺24/左右5カラー10の実描画、48連続サンプル/動画、CPU1戦2400F。online-test.cjsはジーニアスと共用で実サーバー2ブラウザ8場面800Fを照合。previewsはGit管理外。
