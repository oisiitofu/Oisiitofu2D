# マロ実装

ミドナの直前、表示49。特殊な雲の体型74px・重量78。全身76ポーズ＋選択用切り抜き、16FX、5カラー。最初のゲーム用待機画像をmallow-neutral-locked.pngに固定。選択専用の生成が拒否された時点で停止し、2026-10-25のユーザーによる明示の再開と切り抜き指定を受け、待機の顔・肩を切り抜いた600px画像を使用。専用画像の生成を再試行していない。切り抜き記録はselection-crop.json。全身画像の切り抜きと等比拡縮のみ、関節リグなし。

NBはホールドで予告点を左右に指定し、放して18F後に一本の雷。横Bは本人が移動せず、上下入力で初期高度を決める雪玉を放つ。一定距離/接触で14Fの氷の花へ広がり、一体へ一度だけ命中。下Bは12Fの予告から解析、180Fの印とダメージ/行動状態を表示する。次の天気魔法に一度だけ追加2ダメージ、雷の初期位置と雪の最初の12Fの曲がりに使う。相手は予告後の移動や回避で拒否できる。

上Bは8Fで雲を呼び、その雲に乗って上昇する。横は起点±70pxまで、離す/ジャンプで降り、雲は60Fで消える。空中一回、攻撃・無敵なし。雨の2回復は1200Fのクールダウンを持ち、再発動で回復を繰り返せない。台下は外縁へ抜けてから雲に乗る。下Bは台上で発動し、空中からの最初の浮遊台で着地して継続する。

拳、杖、シンバル、雷、雪の姿勢と命中音を分ける。空Nは腕を広げた雲の身体と両手の雲、空後は背後のシンバル、空下は氷へ落ちる姿勢。FX0の凸側は右、1は上向き星/雲で曲線に分類しない。後方は素材を左右反転。直接近接だけMeleeBalance.coverageを使い、遠隔の雷・雪に適用しない。着地/低い戻りはextra14の着地姿勢。共通戦闘エンジンの挙動変更なし。

検証104項目（通常/スマッシュ/空中の左右・先端・密着60場面）、CPU2戦、75描画場面・必殺14場面。雷の予告、解析の拒否/消費、雪の有限誘導と爆発、回復制限、台下と両崖復帰、カウンターと掴み中の雷被弾による解放を確認。オンライン2端末331F一致、77枚/16FX/385色別画像の読み込み一致。プロンプトはart-prompts.json、実描画と結果はGit管理外のpreviews。

公開オンラインでは上B開始の上入力を8F維持してから横へ操舵する。1F後に横入力へ変えるテストは、通信の入力集約タイミングにより45度の横セクターへ入ることがあった。ゲームの方向判定や入力処理は変更していない。
