# マロ：制作前設計

ミドナの直前。添付mallow.pngの丸いクリーム色の雲の身体、ピンクの一房、黒い縦目、青緑のケープと金縁の青い留め具、紫の靴を維持。特殊体型74px・重量78。全身中間画像を制作し、関節方式で変形しない。選択アップは画像生成拒否で停止した後、2026-10-25のユーザーの明示指定により再開し、ゲーム用待機画像から顔と肩を切り抜く。専用画像の生成は再試行しない。

## 固有の能力・操作

天気魔法とサイコパスの読みを連携。下Bで前方360px以内の相手一人を解析して180Fの印を付け、ダメージと現在の行動状態を表示。印は回避で拒否できる予告12Fを伴い、次の天気魔法一回の命中で消費して追加2ダメージ。NBは印の相手の発動時点の位置を雷の予告位置へ使い、横Bの吹雪は印へ少し曲がる。実際の落雷/吹雪に自動追従を続けず、相手は予告から移動・回避できる。

## 必殺技の使い分けと連携

- NBサンダーボルト：ホールド中は地面の雲/予告点を左右へ動かす。離すと地点を固定し、18F後に一本の落雷。小さい範囲に強い一撃。先端・空中から下向きの位置指定が主で、直線射撃とは異なる。設置雲は1個まで、落雷後に消える。
- 横Bスノーウィ：マロはその場で雪玉を作る。ボタンを離すと前方へ進む吹雪の塊を放ち、入力の上下で初期高度を決める。移動中は一定距離/地形接触/寿命で氷の花へ広がる。既存の横突進と異なり本人は移動せず、弾の減速と爆発位置で通路を封じる。解析対象への曲がりは最初の12Fのみ。盾/飛び道具/距離で対処可能。
- 上B HPレインリフト：自分の下に雲を呼び8Fで乗り、雲の足場に乗ったまま一定速度で上昇。横入力は雲を左右へ最大70pxだけずらす。ボタンを離す/ジャンプで雲から斜めに降り、上昇の出力を再入力して増やせない。雲は消滅まで60F、空中1回、攻撃判定なし。雨で2回復は1200Fの共通クールダウン、発動だけで回復ループにしない。台下は外縁へ抜けてから雲へ乗る。相手は着地点や雲から降りるタイミングを狙える。
- 下Bサイコパス：読みと次の天気魔法を準備。空振りも硬直があり、無敵・直接ダメージは付けない。浮遊台上でその場発動、空中から着地しても解析を中断しない。

## 既存との差・対処

アシュリーの本人が自由飛行するほうきと異なり、マロは一つの雲に乗って固定上昇し、横の調整幅と降りる時刻を選ぶ。横Bは運搬/突進ではなく遅く広がる雪の空間制圧。NBの地面の予告点を狙ってから確定する操作と、解析による一度だけの補助で駆け引きを作る。

## 絵・命中・検証

拳、シンバル、杖、雷、雪のポーズと音を分ける。空Nは雲の身体で横へ丸く腕を振る姿勢、空前は杖を突く、空後は背後へシンバル、空上は頭上へ雲を押し上げる、空下は氷へ落ちる別の全身姿勢。共通の輪と色替えで済ませない。直接近接のみMeleeBalance.coverage、遠隔魔法には適用しない。左右/上下/後方の素材と実描画、先端/密着、有限雲/回復制限/解析消費/掴み中の雷被弾、台上/台下/両崖の復帰を確認。CPU1～2戦、短いオンライン場面を検証し、共通エンジン変更を避ける。
