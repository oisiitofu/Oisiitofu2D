# 動物番長の設計

- 相手にNBのかみつきを当てるとニクを獲得する。重い相手からは赤、軽い相手からは青。最新3個のうち同色2個でクマまたはトリにヘンタイする。撃墜でも獲得し、ストックを失うとブタに戻る。
- クマは地上の強攻撃とスマッシュが強くなる。トリはジャンプ長押しで下降を抑える。相手と距離を取るか、もう一度かみつきを狙うかを選べる。
- 横Bは放物線でとびかかる。命中後だけ、方向を入れて必殺を押し直すと同方向または逆方向へ跳ねる。ガードや空振りでは派生できず、着地後に反撃できる。
- 上Bは短時間トリにヘンタイし、方向を選びながら羽ばたく。上昇中に必殺を押し直すと二度目の羽ばたきが出る。空中では着地・崖つかまりまで再使用できない。攻撃判定を持たず、相手は軌道を読んで迎撃できる。
- 下Bはニクをたたみ、押し直さずに解放すると周囲を攻撃する。ニクを1個消費できれば判定と威力が増す。空中では落下から着地して展開する。溜めの間に逃げたり攻撃して中断させたりできる。
