# レックスのリミットブレイク

命中で時間が止まり、世界樹の軌道施設へ切り替わる。終盤のマスタードライバー姿になったレックスの隣にプネウマが現れ、ゲートの光を剣へ導く。インフィニティブレイドを着想元とする本作独自の演出として、剣を巨大化させ、未来を映す面と相手を一閃で切り裂く。

カットイン、世界樹、レックスの全身ポーズ、プネウマ、結晶のエフェクトを別々に制作する。構えでは武器と顔を近くから見せ、刃の伸長と同時に引いて巨大さを見せる。斬った直後には一拍置いてから、斬線を境に未来の面が離れて砕ける。
