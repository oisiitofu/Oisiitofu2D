# 専用リミットブレイク

バスターソードで低く受け止め、踏み込みから斬り上げ。空中で相手を追いかけた後に先に着地し、相手が落ちてくるところをハードラッシュの最後の斬り込みで受ける。ユフィの遠距離の手裏剣と違い、刃の接触位置を追うカメラと前に抜け続ける剣の運びを使う。既存のソルジャー服とバスターソードを維持する。

改修では現行の全身素材と選択肖像を参照し、黒い逆立った髪、濃紺のソルジャー服、肩当て、バスターソードの幅を合わせた。組み込みImageGenで制作したのは、跳び込んで大剣を振る横長カットイン、ミッドガルを望む夕暮れの岩場、斬り上げ・斬り下ろしの弧とハードラッシュの金色の斬撃。素材は `assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-effects.webp` に保存。決め技は遠くへ抜ける大きな弧を背面に描き、命中火花を別に重ねる。
