# ベロニカ：制作前設計

アルスの直後。添付veronica.pngの赤い頭巾と赤いコート、金髪の二本の三つ編み、紫の瞳、茶色の靴、金と赤の宝玉の両手杖を維持。人型1/78px、重量70。全身中間画像と専用高解像度の顔～肩アップを制作。関節リグは使わない。

## 固有の能力と操作

魔法ごとのクールダウンを配分する小柄な魔法使い。メラは三段階の溜め、バギは設置からの方向操作、メダパニは一回だけ魔法へつながる状態を作る。入力を反転させるなど相手のコントローラーを奪わず、予告と射程に対する防御を残す。

## 各必殺技の使い分けと連携

- NBメラ：タップは高速の小弾、24F以上ホールドで遅いメラミ、42Fで射程の短い大きなメラゾーマ。飛距離、弾速、爆発半径を変える。長い溜めは盾や回避で拒否できる。
- 横Bバギ：その場に小さな渦を作り、ホールド中は渦の設置点を左右へ動かす。離すとその位置から前へ走る竜巻へ変わる。ガード入力で渦をその場に残せる。本人は突進しない。前に置いてから逆方向を入力すれば後ろにも放てる。発射済みの渦は一つまで、有限寿命。メラが設置中の渦を通ると火を含む一度だけの竜巻へ変化し、設置と射撃を合わせる判断が生まれる。
- 上Bルーラ：魔法陣を出して短く上昇した後、方向入力で予告した到着点へ一回だけ転移。設置中のバギが近くにある場合、横方向を入力するとその渦へ転移して渦を消費する。通常は上方向の復帰、渦を先に置けば横へ位置を変える使い分け。到着地点は地形へ埋まらない候補を選び、台下からは上面または外縁へ抜ける到着点を探す。入力待ちの滞空を設けず、16Fで確定して落下へ戻る。空中1回、攻撃判定や無敵は付けない。
- 下Bメダパニ：短い予告を置いた前方の魔法波。命中で180Fの混乱印、次のメラ/バギ一回だけ追加2ダメージと印の解除。直接の吹っ飛びは弱く、永久拘束/多段吸引にしない。盾・回避で拒否可能。混乱印によって相手の実際の入力を変えない。台上発動と着地時の継続に対応。

## 既存キャラとの差、対処

アシュリーの運搬ほうきやリップの同色パネル連鎖と異なり、バギの位置を動かしてから発射する設置点の操作と、メラによる火入り変化が主になる。ルーラは通常の方向転移に加え、設置バギを消費して横方向の退避先にできる。転移先の予告を見て着地/到着位置を狙える。設置の保持にも硬直があり、近距離では杖の先端と小柄な身体で立ち回る。

## 見た目・検証

杖のジャブ、回転払い、炎の空前、後方への氷、頭上の雷、下へのイオを全身姿勢と素材から分ける。空Nは杖を斜めに振る全身動作、共通の回転姿勢や色替えの輪で済ませない。炎/氷/雷/風/光/混乱の命中音も合わせる。直接近接だけMeleeBalance.coverageを使い、弾/設置は独立判定。左右・上下・後方、密着/先端、台下/両崖復帰、設置転移の消費、掴み中の被弾、クールダウン・有限寿命を確認。CPU1～2戦と短いオンライン場面を検証し、共通エンジンの挙動変更を避ける。
