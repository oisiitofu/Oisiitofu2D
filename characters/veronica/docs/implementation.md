# ベロニカ実装

アルスの直後、表示19。人型1/78px・重量70。全身76ポーズ＋1254pxの専用顔・肩アップ、16FX、5カラー。最初のゲーム用待機画像はveronica-neutral-locked.pngで固定。全身画像の切り抜き・等比拡縮で構成し、関節リグは使わない。杖、前方の炎、後方の氷、上への雷、下への光の全身姿勢を分ける。着地・低い技の戻りはextra13の着地姿勢を使う。

NBは12Fから小メラ、24F以上でメラミ、42Fでメラゾーマ。弾速・半径・射程・爆発を変え、クールダウン32/50/75F。横Bは本人を移動させず、12Fで風の種を作る。ホールドで設置点を動かし、離して竜巻、ガードで設置して解放。種へメラを通すと元の炎を消費して一つの火入り竜巻へ変わる。同じ竜巻は同じ相手へ一回だけ命中、種180F・竜巻58Fの有限寿命。

上Bは方向で到着点を予告し、16Fに一回だけ転移。横入力が近い設置バギを指す場合はその渦を消費して横への退避先にする。到着点の地形重なりを調べ、台下は空いている候補を探す。攻撃や無敵はなく、12Fの戻りで通常落下へ復帰。空中一回。下Bは15Fで低ダメージの混乱波、180Fの印を次の天気魔法一回に追加2ダメージとして消費する。相手の入力を反転しない。台上発動と着地継続に対応。

直接近接だけMeleeBalance.coverageを使う。0の凸側は右、1は上、氷は右向き元画像を後方へ反転、雷4は下向きから上スマでπ回転。ローカル回転後に左右反転。元FX下段の実配置は盾・炎・塵・火花の順へ再対応して使用。弾・設置・つかみへ近接の拡大補正を適用しない。共通戦闘エンジンの挙動変更なし。

検証106項目（通常/スマッシュ/空中の左右・先端・密着60場面を含む）、CPU2戦、通常/予備/戻り/色75場面・必殺14場面。台下と両崖の復帰、設置転移と消費、火入り連携、混乱印の消費/期限、カウンターと掴み中の魔法被弾による解放を確認。オンライン2端末331F一致。77枚/16FX/385色別画像を読み込み検証。制作プロンプトはart-prompts.json、実描画と結果はGit管理外のpreviews。
