# 専用リミットブレイク

杖を使い、氷晶で相手を浮かせてから左右の火球と頭上からの雷を連鎖させる。杖先に魔力が集まってからマダンテへ。エスタークの重い踏み込みと異なり、本人の位置と着弾点を空間的に分ける。帽子、髪、杖は既存の対戦姿勢を使用。

改修では対戦用の赤い帽子と衣装、金色の二本の三つ編み、赤い宝珠の杖を参照した。組み込みImageGenで、杖へ火・氷・雷を集める横長カットイン、夕刻の魔法堂、火球・氷晶・落雷と、金白のマダンテを描き起こした。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-effects.webp` に収録。左右の火球を相手に向け、最後に三属性の残光が先に杖側へ集まり、爆発が命中点から相手の飛ぶ方向へ広がる。
