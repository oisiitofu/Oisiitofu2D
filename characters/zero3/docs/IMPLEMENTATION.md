# ゼロ（DOD3） / Zero

ドラッグオンドラグーン3の添付デザインを基準にbuiltin image_genで48全身ポーズ・16エフェクト・専用1536×1024上半身画像を制作。長い白髪、黒いリボン、右目の花、左目の赤い瞳、白黒の衣装と義手を維持。既存のロックマンのゼロ（ID zero）とは別のID zero3。2Bの次、人型サイズ2の94px。おまかせ最後・変身形態非表示を維持。

保存画像は characters/zero3/assets/zero3-poses.png、zero3-effects.png、zero3-selection.png。添付の保存先は同zero3-reference.png、ゲーム用組立ては同zero3-native.png。正確な生成プロンプトとモードは [image-prompts.json](image-prompts.json)。全身ラスターの切替で描画し、関節リグは使わない。通常技15種類は別の全身絵。49フレーム目のゲーム内ポートレートとは別に、選択画面へ専用の高解像度上半身絵を配信する。

- NB「チャクラム」：10Fに1つ投げ、25Fから持ち主へ戻る。往路と復路で各1回命中可能。生存中は同じ弾の追加だけを制限し、通常技や横Bは使用可能。
- 横B「槍による連撃」：10〜13Fの低い突き、21〜24Fの槍を支点とする半円移動、36〜40Fの振り向き突き。横130px・高さ68pxの半円で相手を跨ぎ、逆側から締める。無敵や終了後の時間式クールダウンは付けない。空中は共通の一回制限。
- 上B「ミハイルの加護」：10Fまで落下慣性を抑え、白いミハイルに乗って上昇。上下左右の入力で飛行を調整。上昇10F後から新しくジャンプ/攻撃/必殺を押すと飛び降り斬り、28Fで自動的に飛び降りる。最初の必殺長押しだけでは即降りしない。ステージ下では外へ抜けてから上昇。終了後は専用の尻もち絵。
- 下B「インテナーモード」：血のゲージ100で発動。12Fにゲージを消費し480F（8秒、ヒットストップ中は停止）強化。威力1.25倍、歩き/走り/初速/空中速度1.18倍、通常技の時間0.82倍。攻撃窓の数とindexは維持し、余分なヒットを増やさない。移動値は本人のコピーだけ変更し、終了/復活時に戻す。

血のゲージは与ダメージの0.95倍＋被ダメージの0.8倍、最大100。ヒットストップでも同じダメージを重複計上しない。強化中は再蓄積せず、復活で0へ戻る。強化中に上必殺が飛行/飛び降りへ切り替わっても威力倍率を維持。右目の大きな赤い花は全身絵ごとに計測した花の座標へ描画し、元の身体や衣装を変形しない。

斬撃素材0/2は凸側が右、上側素材1は凸側が上。ローカル回転後に左右反転し、AttackEffects.imageで最終判定の外縁へ合わせる。上強/上スマ/空上は頭上の曲線1つ。ミハイル・花・チャクラムの小物は近接スタンプと区別する。共通MeleeBalance.coverageは近接に一度だけ適用。通常投げは前=位置変更、後ろ=撃墜、上=浮かせ、下=追撃。

組立てはルートから node characters/zero3/tests/assemble-art.cjs。伏せ姿勢22/23、隣の槍先が触れる13、広いミハイル12/13FXはレビュー済み座標と限定した不要画素除去で切り出す。元ポーズの身体寸法と足底は維持。崖つかまりは38番の手から測定。register.cjsは初回登録用なので再実行しない。

検証：機能160項目、左右・通常/強化の実描画48場面、CPU対ビビ1試合2400F。49姿勢/16FX/245カラーのchecksum差0。実サーバー/2ブラウザで5場面・225Fの状態一致、例外0。表示/5色/4必殺/並び/サイズ一覧27項目成功。既存141形態のmanifestは完全一致、サイズ一覧142形態へ更新。検証結果と画像はGit管理外のpreviews/。追加キャラと実変更箇所へ検証を限定し、既存全員のCPU戦や素材再生成は行わない。
