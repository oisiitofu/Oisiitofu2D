- 通常必殺「ウィンドカッター」：風の刃を放つ。溜め半分以上で上下に分かれる二連の刃。発射後10Fで行動可能。
- 横必殺「プラズマスラスト・リターン」：短い細剣の突きから雷の刃を射出。上下入力で角度を調整。命中または一定距離で戻り、移動後の本人の位置を追うため帰り道を変えられる。往路・復路は別に当たり、場に一つまで。
- 上必殺「旋風のスパイラルリフト」：風の輪に乗って最大48F移動。長押し中は左右で横移動、上で上昇を強め、下でゆっくり下降。最初の24F以降に離すと輪から跳び降りる。軌道を選んで崖へ近づく復帰で、崖下の壁に対応。着地硬直18F。
- 下必殺「テンプテーション」：近くの相手へハート。命中すると180F（3秒）の間、地上1.2px/F・空中0.8px/Fで引き寄せる。相手は操作可能で、ガード・回避中・被弾硬直/ヒットストップ中・崖/つかみ中は吸引しない。吹っ飛び速度を変更せず、地形を貫通せず、地上から崖外へ引き落とさない。頭上にハート/残り秒数/時間バーを表示。通常近接攻撃の追撃ごとに本人のダメージを1回復し、回復表示を出す。ガード・無敵で防御可能。追加の再使用待ちはなし、KOで誘惑を消去。周囲の複数相手にも命中する。

横必殺は本人の移動で復路を曲げる遠隔攻撃、上必殺は長押しと方向操作で滞空・離脱を選ぶ復帰。フレーム・性能は添付シートを元にゲーム用に設計したもの。
