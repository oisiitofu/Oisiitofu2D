# ビリー / Billy Kid

添付デザインの銀髪・黒いロボットマスク・黄色い目・赤いジャケット・二丁リボルバーを維持し、雅の次へ追加。ID billy。人型サイズ3の98px、重量92。登録順はselectionOrderで管理し、表示番号は自動。既存の隠し形態とおまかせ末尾を維持する。

## 全身画像と選択画像

builtin image_genで基本16/通常攻撃16/必殺16/防御投げ16の元シートを制作。各シートの共通立ち姿から倍率を一度だけ校正し、61枚の全身姿勢を組み立てる。基本シートの先端がページ上端に近かったため、実装・中割り制作の基準を髪と足先が完全なspecialsセル0に固定してから組み立てた。通常技15種はすべて別の全身画像。脚や顔の関節リグ・パーツ変形は使わない。基本の立ち姿は横を向いて相手を見る。4枚ずつの歩行/走行、各必殺3姿勢、崖の完全な全身絵を持つ。

専用1536×1024の顔と肩の選択画像を別途制作。髪先の見切れをimage_genで補修し、crop [260,0,1276,1024]で大きなマスク/黄色い目/肩を見せる。小さい戦闘画像の拡大で代用しない。選択/戦闘でジャケットだけを中心に5カラー、銀髪・黒い顔・目は維持。ゲーム用ポートレートを加えて62フレーム、専用16FX。

元画像と生成プロンプトはassets/とimage-prompts.json。ルートから `node characters/billy/tests/assemble-art.cjs` で再組立て。登録済みのregister.cjsは再実行しない。サーバー起動後 `ART_IDS=billy node .tools/build-art.cjs` で配信画像だけを更新し、起動時の解析や全キャラ先読みには戻さない。

## 技

- NB「フルファイアパワー」: タップは10Fの立ち射撃6ダメージ。長押しでは低姿勢の2.4ダメージ連射（最大6発）になり、離すか6発を撃つと6F以上間を空けたフィニッシュ10〜12ダメージ。通常9F/最大スター時6F間隔、同時弾6個、寿命26F（強弾32F）。長押しっぱなしでも有限で終了。小弾は削りだけでヒットストップ/硬直へ連続拘束しない。強い最終弾は低姿勢で発射した直後に専用の反動姿勢へ移る。
- 横B「ローリングショット」: 6〜18Fは低いロールで前進。19〜30Fに半円の速度軌道を描いて立ち上がり、31Fで方向入力を選び、34Fに終端射撃。途中は前後への短い射撃を各1発。近接窓は6〜12Fの同一hitID0だけで、弾へ近接coverageを掛けない。スターごとに速度7→8、所持時は8Fから最大5Fだけ無敵のロール区間。空中は一度まで、着地/崖で回復。技終了後の時間式クールダウンはない。
- 上B「フラッシュスピン」: 8Fまで落下慣性を止め、斜め上昇13F→5Fの滑らかな旋回→入力した側への上昇移動へ続く。上昇中5〜12Fの左右入力で出口を選ぶため、最初と逆側へ折り返せる。静止待ちや追加入力ボタンは不要。最初だけ6ダメージの回転近接窓、24F後に最後の10ダメージ射撃。30F後は不透明な専用尻もち60へ直接移行。攻撃等を禁止しつつ、落下中の通常の横移動は共通ルールに従う。ステージ真下は端を抜けてから上昇し、両側の場外から復帰を確認。
- 下B「スタンディスティル」: タップは12/18/24Fの高さを変えた三方向射撃（各4ダメージ）。長押しは24/40Fで強化し、離すか48Fで強射撃10/15/21ダメージ。最大だけ複数相手を貫くが壁/ガードで消え、同じ相手を複数回撃たない。溜め/連射は空中から着地しても技の時間とイベントを保つ。浮遊台では下Bとして止まる。
- スターライトヒーロー: 実命中4回ごとに1スター、最大5。通常技・強弾はonHit、小さな削り弾は実際の命中カウンタ増加を確認して1回だけ加算。ガード/無敵へ当てても増えない。復活で0。連射間隔と短いロール回避を強化し、5つの専用スターと次段階の進捗をHUDへ表示。

NB/下Bに射撃用の間隔と同時数だけを付ける。近接、横B、上Bを共通の射撃クールダウンで禁止しない。技の途中で汎用の待機絵へクロスフェードしないよう、専用animationWindowsで全身画像を描き、既存のwindow index/hitIDは保つ。

## 描画と判定

近接は共通MeleeBalance.coverageを1回だけ使用。通常技・スマッシュ・直接当てる必殺の密着と先端を左右で検査。銃口より先へ弾道/火花を出し、その見える外縁を判定へ合わせる。上スマは広い上向きの銃撃ファン、空上は二本の上向き射線を最終判定の外縁へ合わせる。曲線系として分類せず、汎用の縦長曲線を重ねない。近接スタンプはAttackEffects.image経由、弾/銃口/HUDは独立の描画。

FX0/2/7は右向き、1/14は上向き、6は斜め右上。元の13は下向きを依頼したが実画像では上向きだったため、その素材だけ組立て時に180度回転して下へ正規化。ローカル回転後に左右反転。正常な既存素材の一括反転は行わない。通常投げは前=位置変更、後=撃墜、上=浮かせ、下=追撃の役割。攻撃上がりは専用の弱い単発技を使う。
