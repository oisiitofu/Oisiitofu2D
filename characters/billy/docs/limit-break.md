# ビリーの専用リミットブレイク

二丁を使った近距離連射から横転して間合いを外し、低い擦過、空中での逆さ撃ち、両手を広げた交差射撃につなぐ。スターライトナイトを意識した決めポーズで画面を引き、左右のリボルバーの射線を異なる高さから同じ着弾点に重ねる。エレンの物理的に刃が触れて凍る軌道に対し、ビリーは反動を使う位置変更と二つの射点、着弾の順番で見せる。

通常形態は現在の赤いジャケット、白い髪、黄色い目、二丁の装備を参照する。光が飛んでいく方向を銃口に合わせ、左向きでも両手と相手が見える位置に着弾を置く。

「スターライト、ここに輝く！」の専用カットイン、ネオンが反射する屋上、発射口の火花・光の軌跡・交点・着弾を制作した。標準カラーでは滑り込み・逆さの回転・二丁を構える3姿勢、別カラーは対戦用の対応姿勢を使う。連撃では発射音と命中音をずらし、決め技用の音は二発の発射から着弾へつないだ。
