# 魔王の専用アート

`image_gen` の組み込みモードで制作。キャラデザイン参照は `assets/magus-reference.png`（ユーザーのmaou.pngと同一バイト）。紫の長髪、尖った耳、自然な成人男性の頭身、黒と金の衣装、赤い裏地の外套、大鎌を維持した。元の生成PNGと修正前ドラフトを保存している。プロンプト全文・生成元パス・保存先・モード・SHA256は `asset-generation.json`、元ファイルとのバイト照合は `tests/source-provenance.json`。画像生成の内容拒否は発生していない。

中割り制作前に待機と15通常技を固定した。`magus-neutral-locked.png` と `magus-normal-0..14-locked.png` をアトラスへ直接RGBAコピーし、予備動作15枚・戻り15枚は別の全身画像として追加した。関節リグや部品の変形は使っていない。待機の元ポーズ、顔、衣装を再生成して中割りへ置き換える処理はない。初期の通常技シートは強い魔法の描き込みと下空中の手攻撃を修正し、横への掌打も専用2コマ参照シートで右方向へ修正した後に固定した。

アトラスは106全身画像＋専用高解像度の顔肩画像106番の107枚、エフェクト16枚。0〜15基本、16〜30通常技、31〜45必殺技、46〜60防御・反応・投げ、61〜75追加、76〜90予備動作、91〜105戻り。55番は実際に片手を頭上へ上げた崖つかまり。掌位置は [.306,.037]、身体軸 .43 に対する grip は [-.124,.963]。

各シートは共通待機の頭頂から靴底までを測り、一つの倍率で全ポーズを処理する。基本待機は226×279px、頭頂48・靴底274、身体高226px。鎌込み279pxを身体高として使わない。男性サイズ3の98pxには `98 / (226 * FIGHTER_SCALE)` を使う。全身の立ち姿・通常技・中割り・浮遊も同じ物理倍率。各ポーズを枠へ個別フィットする処理はない。実際の腰・骨盤の水平軸を106枚すべて `native-points.json` に記録した。長髪・外套・武器のalpha外接矩形中心で一律 .5 にしない。`pads` は描画の靴底補正用。

通常15技の掌・鎌の握り・刃先・踵、必殺15枚の発射掌なども同ファイルに記録。上攻撃の鎌は刃先と柄尻を区別し、必要な頂点/刃の外縁を追加した。上スマ・下スマの魔法については手の位置であり、柱/遠隔爆発へ近接補正を付ける指定ではない。

FXの元画像を実見し、0番の凸側は右、2番と3番の元の凸側は下と判定。2番だけをローカルで上下反転して凸側を上へ正規化し、生成元PNGは変更しない。完成アトラスは0右・2上・3下。4雷柱・5氷柱は曲線ではない。左右表示時は、まず正規化済みローカル素材を攻撃方向へ回し、その後に身体の向きの左右反転を適用する。後方攻撃は後ろ側、上/下は判定方向へ配置する。頭上の曲線は1つを基本とし、補助線ごとに弧を増やさない。実ゲームのAttackEffectsへの配置・判定との一致確認は統合側で行う。

選択用はゲーム用の全身画像の拡大ではなく、専用の1254px高解像度な顔〜肩の描き下ろし。推奨元画像crop `[305,20,920,920]` は120px/180pxで実見し、頭頂・尖った耳を保って顔と肩が読める。高解像度元PNGを保持し、アトラス用には600pxへ縮小する。

確認画像はGit外の `previews/magus/`。全106枚の一定倍率・腰軸付き一覧 `constant-native-{0,24,48,72,96}.png`、15技の予備/命中/戻り `transitions-{0,5,10}.png`、98px身体高の連続確認 `normal-transitions.gif`、実掌/刃先の `normal-contacts.png`、正規化済み `effects-normalized.png`、選択サイズ `selection-small.png` を作成し実見した。元PNGと接触シートを比較して、接触シートの枠による見切れを元絵の欠損と取り違えないよう確認した。

再現: プロジェクトルートから、sharpのあるNode環境で `node characters/magus/tests/assemble-art.cjs` → `node characters/magus/tests/art-test.cjs`。PillowのあるPythonで `python characters/magus/tests/preview-art.py`。アート試験は107枚/16FX、透過・矩形、固定待機/15技のRGBA一致、30中割りの個別画像、元12PNGの生成元バイト一致、106身体軸と実際の崖上げ手、2番だけの正規化を確認する。
