# 魔王の専用リミットブレイク

既存の紫のマントと鎌で横・縦の攻撃を出し分け、鎌で浮かせた相手にダークボムを置く。ベロニカの反対側から飛ぶ属性弾と異なり、鎌を足場側へ振ってから浮遊し、空間を折りたたむダークマターへ収束させる。

改修では、長い紫の髪、金縁と赤い裏地の黒マント、大鎌を現行の対戦素材から参照した。組み込みImageGenで、大鎌を振り抜きながら闇を集める横長カットイン、夜の魔王城、紫の鎌の軌跡、ダークボム、ダークマターの黒紫の核と光る亀裂を描き起こした。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-effects.webp` に収録。鎌とダークボムで相手を浮かせ、闇が相手の背後へ収束してから、亀裂が吹っ飛ぶ方向へ伸びる。
