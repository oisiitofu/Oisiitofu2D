# 魔王：制作前の固有技設計

添付maou.pngを基準に、紫の長髪、細い尖った耳、冷静な顔、黒と金の衣装、赤い裏地の長いマント、大きな鎌を保つ。自然な原作寄りの頭身、男性サイズ3・98px。カエルfrogの直後。専用の高解像度な顔・肩の選択画像を制作。基本待機と15通常技を固定し、異なる全身の予備動作・戻りを作る。関節リグは使わない。

## 固有能力と操作

ブラックホールを弾の吸収・影の出発点・帰還口として使う設置魔法使い。魔力は初期60・最大100、実際の攻撃命中で回復するが、ゲージ表示自体を個性とはしない。設置を残して場を制圧するか、影との位置交換／ゲート復帰に消費するかが判断になる。

- NB「ダークボム」：保持で闇の球を育て、離して撃つ。飛行中の球が自分のブラックホールへ届くと吸収し、ホールの爆発範囲・威力を一度だけ強める。フル保持＋魔力20ならダークマター。球・爆発は遠隔判定で、近接補正を掛けない。
- 横B「ブラックウィンド」：本人を残して鎌を持つ影を送り出し、方向入力で進ませる。離すと影が一度鎌を振り、帰る。ブラックホールがある時だけ、必殺を離して押し直すと魔力を使い、ホールへ接続した影と位置を交換して自分が斬る。ホールがない／壊された場合は交換できない。単純な本人の横突進を基本形にせず、遠隔の影と設置を使う条件付きの移動にする。影には元の全身ポーズを使い、身体をリグ変形しない。
- 上B「ダークゲート」：通常は縦長の門の中を有限時間だけ昇り、左右入力／必殺を離す時機で外へ出る。自分のホールがある時に方向を向けて再入力すると、そのホールを消費して出口として使う。通常の上昇と、先に設置した場所へ帰る経路を使い分ける。出口は予告し、門は攻撃で壊れる。真下からは先に横へ抜け、地形を貫通しない。自動の上昇二段攻撃にはしない。
- 下B「ブラックホール」：魔力30で前方に生成。予告後に自由に動ける相手を弱く引く。被弾硬直・ヒットストップ・吹っ飛び予約・つかみ・復活中の相手の速度を消さない。下Bの再使用で起爆。敵の攻撃で核を壊せる。NB吸収、横B交換、上B出口のいずれに使うかを選ぶ。最大1個。

相手は核・門を攻撃して連携を切り、本人の詠唱に割り込むか、影の鎌を回避する。魔力不足や設置の喪失が位置交換のリスク。基本状態には浮遊姿勢に基づく75F・下降速度.9のジャンプ長押し浮遊を明示し、通常の共通予算・行動中禁止・着地／崖／復活での回復を守る。

## 見た目と判定

掌、外套払い、闇の爆発、鎌の横振り・頭上の一弧、後方の外套、急降下の踵を15個別姿勢にする。空Nは原画の闇をまとう回転姿勢を使い、他キャラ共通の輪を流用しない。鎌や手足の近接は実画像のNativeStrikes座標に合わせ、MeleeBalance.coverageを一度のみ。弾・影の遠隔判定・核・門へ無条件に適用しない。凸側を実画像で確認し、前／後／上／下を両向きで確認する。曲線の上攻撃は一つの弧、雷柱・氷柱は元の形を使う。

通常投げは魔力主体のpsion、前後の位置変更と上の高％撃墜を区別。攻撃上がりは専用の弱い単発・44F。新キャラ中心の密着／先端・復帰・CPU1〜2戦・短いオンライン同期・PC選択画像を確認する。
