# ゼロシフト連撃からネイキッド・ベクターキャノン

公開済み。専用演出の通常形態4枚と最終形態6枚を制作し、高速横断・反転斬撃・斬り上げ・空中追撃からキャノンの展開、反動と余韻まで描く。2026-11-05の「基本は大きく動き回る高品質なアクション」を適用する。通常の待機、選択画像、必殺技の操作や能力は変更しない。

通常形態は承認済み `assets/jehuty-reference.png` の紺・象牙色・金、長い鳥型の頭、細い腰と長い脚を固定する。最終形態は[コナミ公式のネイキッドジェフティ](https://www.konami.com/games/zoe_hd/jp/images/products/pic_naked.jpg)で白い顔、灰色の装甲、露出した金色の構造を確認。両形態を混同しない。キャノンは[公式のベクターキャノン装備](https://www.konami.com/games/zoe_hd/jp/images/products/pic_jehuty_vc.jpg)を参照し、大型の砲口と展開部品を表現する。

[公式ゲームシステム](https://www.konami.com/games/zoe_hd/jp/gamesystem_anubis.html)の高速浮遊戦闘、ホーミングレーザーと巨大戦艦へのベクターキャノンを演出の根拠にする。演出内の連携順とカメラは本ゲーム用の構成であり、原作の特定の一場面そのものの再現とはしない。

開始の停止後に通常形態のゼロシフトで左右を横断し、相手側へ凸面を向けた斬撃を出す。斬り上げから空中で追い、レーザーの曲線軌道で再捕捉。ネイキッドへ切り替わった後は連続追撃から距離を取り、巨大砲を展開して画面を貫く決め技へつなぐ。カメラは横断と空中追撃を追い、砲撃前に引いて規模を示す。

主攻撃は `art.strike`、残光は `art.glow`、カットインは共通 `LimitCinematic`。全身画像をそのまま使い、関節リグは用いない。相手を最後に描画して攻防を追えるようにする。形態間の頭身、切り替えの連続性、砲口とビーム起点、左右の反転、明るい背景での輪郭を実描画で確認する。

ローカルの対戦・トレモ・左右描画・カットイン比率・攻撃の濃さと専用2音の再生を検証済み。CPU1戦は2005ステップで結果まで進行（双方17／16ヒット、残ストック0／1）。オンライン377フレームでダメージ・吹っ飛び・ホスト設定が一致。1440×900の連続再生録画（約6.39秒）と縦横比を保つ比較画像を確認し、斬り上げの高さと砲口からのビーム起点を修正した。公開反映と検証は末尾に記録。素材と最終プロンプトは `limit-break-assets.json` に保存する。対戦・トレモ・CPU1戦・短いオンライン同期、連続再生と両向きの画面確認後に公開し、実測結果をこの文書とルートの進捗表へ追記する。

Sites v319へ公開し、GitHub feddd01へ反映。公開URLで発動・トレモ・左右の主要場面・専用音を再確認。画像12点、効果音4点、音声マニフェストとバンドルのSHA-256が一致し、公開バンドル85／162作品を確認した。素材を公開サイト側から取得する公開通信テストでもジェフティ377／ライザ372フレームのダメージと吹っ飛びが一致。
