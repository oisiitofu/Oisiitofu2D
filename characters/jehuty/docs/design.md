# ジェフティ / ANUBIS

ユーザー指定：キングボンビーの次。添付シートを基準に全身・専用の頭部と肩の選択画像を制作。下Bのベクターキャノンは途中で変形しない。同じ砲身の形を固定し、ライフリングだけを回転させる。

## 固有の能力・操作

ENは通常行動中に回復する共通の資源。NBのロック数、横Bのゼロシフト、下Bのキャノンへ配分する。ゲージだけの差にせず、NBのロック対象をゼロシフトの位置取りに利用する。飛行機構はジャンプ長押しの有限浮遊へ対応。細身で長い脚、紺/白/金の装甲とシアンの回路を維持する。巨大ロボなので人間のサイズ段階には分類しない。

## 必殺技と連携

- NB・ホーミングレーザー：保持中に射程内の相手をロック、溜めに応じて1～3発。発射後は初期の短時間だけ誘導し、その後は直進。複数人では対象を分配し、単体への多発時は連続命中を弱める。シールド/移動で対処でき、同じ対象を無限追尾しない。
- 横B・ゼロシフト：突進の接触判定を使わない。ロックした相手の手前、または方向指定した空中の点へ短距離転移する。発動前の残像と到着点の予告を見せる。到着後に攻撃ボタンを押した場合だけ単発ブレードへ派生。相手の背後を選ぶ場合も地形と舞台外限界を検査する。空振り時は短い位置取り、ロック時は読み合い。連続利用にはENと空中使用回数の制約。
- 上B・ブースト上昇斬り：保持で有限の推力を配分し、上下入力で上昇/横滑空の比率を選ぶ。斬撃は最後のボタン解放時の1回だけ。機体の振りと斬撃の凸側を方向へ合わせ、二段上昇攻撃を基本形にしない。ステージ真下は有限距離の側方離脱後に上昇し、終了後はしりもち。
- 下B・ベクターキャノン：発動中は移動と向きを固定。同じ全身の射撃姿勢・同じ一枚の砲身を維持し、砲口内のライフリングの回転速度と光だけを上げる。30F以降の解放/最大72Fで発射。発射後の長い後隙とEN消費。青い貫通ビームは単発の命中ID。0%で即撃墜する基礎吹っ飛びにはしない。途中で砲身を伸縮/展開/変形しない。

## 既存キャラとの差・相手の対処

横Bは移動中の衝突攻撃ではなく、ロックと転移先予告を伴う位置取りで、攻撃は追加入力の別判断。上Bは有限推力と解放斬りの判断があり、ナイトレーベンの無攻撃の垂直離脱/滑空とは異なる。NBでENを使い過ぎるとキャノンを最大溜めできない。キャノンは砲身を固定するため射線外への移動と接近差し込みで対処する。

通常/スマッシュ/空中は、突き・切り返し・前方の一振り・背後の刃・頭上の弧・急降下斬りを個別の全身画像で制作。空Nを共通の身体回転/輪へ置き換えない。腕の刃の弧は素材の凸側を確認して相手側へ向け、上攻撃は頭上の弧一つを基本とする。武器の先端と身体周辺の密着を、共通近接補正を一度だけ使って確認する。
