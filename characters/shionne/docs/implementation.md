# シオン

アルフェンの直後。人型サイズ2/94px、重量88。専用高解像度の顔と肩の選択画像。全身61姿勢と16FXはbuiltin image_genで制作し、basic先頭の元絵を固定。全身の連結成分と持ち物で切り出し、セルの境界で髪や武器を切らない。プロンプトはimage-prompts.jsonとimage-prompts-additional.json。

- NBマグナレイ：タップで5Fずつ遅れて貫通する光弾3発。30F以上の溜めで各弾を強化、45Fで自動解放。相手ごとに各弾1回のみ、有限寿命。
- 横Bイグニス・セレステ：投げた爆弾は地面で跳ね、次の横Bで同じ爆弾を遠隔起爆。投げるまでの本人の突進はない。30F長押しでブラスト1を使う強い狙撃へ。既存の爆弾も強く起爆する。空振りでも爆弾の位置と起爆タイミングを戦術に使える。
- 上Bスコーチ・リコイル：添付の下方射撃と爆発反動を復帰へ発展。初動の慣性を止め、下方射撃の反動で上昇。上昇中のボタン再入力を予約し、一度だけ追加反動と方向変更。ゲージ不要。静止した追加入力待ちはなく、専用の尻もちへ移り、横の操作を維持。両側とステージ下から復帰を確認。
- 下Bヒーリングサークル：ブラスト1で有限の回復陣を足元へ置く。地上で陣内にいる本人だけ少量ずつ回復。1ストック中の合計15まで、1個のみ。空中で出した場合は下の足場に置く。
- ブラストは開始1/最大3、時間と実命中で増加、復活で1。荊の呪いは命中の見た目のみで、追加ダメージやカウンターではない。

空Nは前寄りの銃回し。全周の共通スピン判定を使わず、手元から銃の先へ拾う。専用の金属火花を短い接線と先端の火花として描き、全身を囲う輪にしない。上スマ/空上は3方向の光弾、空下/上Bは下向きの銃口爆発。上向きの弾を曲線フィットへ入れず、元の素材形状を保つ。通常15姿勢は別々の全身絵。
