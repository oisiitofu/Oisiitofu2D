# シオンの専用リミットブレイク

「フェロックスソル」は銃床から近距離で入り、反動で後方・上方へ離れ、下向きに射線を変える。ジーニアスが相手に向けて雷を落とす構成と区別し、上空に先に火球を置き、地上から斜め上に撃って相手を火球へ運び、接触点から爆発させる。[原作の実機映像](https://www.youtube.com/watch?v=v3dJ2DQSRqE)

桃色のポニーテール、赤い髪飾り、白赤の裾と黒金の銃を対戦素材で確認し、ImageGen で上へ狙う横長カットイン、空中のテラス、熱線、火球と爆発素材を制作した。標準カラーでは反動、膝をついた照準、立って銃を上げる姿に専用全身絵を使う。別カラーでは対応する対戦のポーズを使う。

配信素材は `assets/limit-cutin.webp`、`assets/limit-terrace.webp`、`assets/limit-effects.webp`、`assets/limit-solar.webp`、`assets/limit-motion.webp`。最後の爆発には専用音を使う。
