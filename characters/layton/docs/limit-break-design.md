# レイトン教授の専用リミットブレイク

通常形態の参照は対戦で使う `assets/layton-native.png` の待機と全身動作。シルクハットの高さ、顔、コートと襟の色、手足の比率をカットインと全身姿勢で照合する。

『最後の時間旅行』で時計店の仕掛けを動かす場面を元にしたゲーム独自演出。相手の正面で打ち合い、帽子を押さえて斜め奥の階段へ移動する。床を跳ね上げる歯車と柱の振り子で追撃し、教授が階段上の操作盤で最後の一手を入れると、時計の針が大きく回って相手を弾く。C4-621の射撃と制動と異なり、本体は階段を上る。時計の機構と相手は手前に残し、引いたカメラで操作と命中を同時に見せる。

- [レイトン教授と最後の時間旅行 公式ストーリー](https://www.layton.jp/jikan-app/)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中6ヒット、決め技26ダメージ。対戦用のシルクハットとコートを維持し、階段の上りと時計の機構の追撃を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
