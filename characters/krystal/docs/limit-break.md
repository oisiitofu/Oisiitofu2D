# クリスタルのリミットブレイク

『スターフォックス アドベンチャー』のスタッフと、『スターフォックス コマンド』の専用機クラウドランナーを組み合わせた演出。スタッフの冷気で相手を拘束し、専用機に乗り移る。雪山上空へカメラを切り替え、宙返りで砦へ戻り、ロックオンした相手をレーザーで撃ち抜く。氷が砕ける衝撃で撃墜を狙う。

クラウドランナーのシルエットは任天堂の機体画像を参照し、別角度の機体ポーズと専用の全身ポーズを制作した。カットインは元の縦横比を保つ。始動・氷結・照準・レーザー・破砕を音でも区別する。 [公式キャラクター紹介](https://www.nintendo.co.jp/ds/asfj/chara/index.html) · [公式機体と操作方法](https://www.nintendo.co.jp/ds/asfj/operation/index.html)
