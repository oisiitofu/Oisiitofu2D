# 荒神螺旋斬の8連撃から天剣叢雲

制作中・未公開。

[公式原作V](https://megaten5.jp/story_character/)と[公式Vengeanceの姿紹介](https://megaten5.jp/vengeance/story_character/)を参照し、今回は承認済みの青い姿で制作する。技名と8回攻撃、天剣叢雲の性質は[スキル比較資料](https://bozumemo.blogspot.com/2024/07/VV-hero-skill.html)で補足。

承認済みの青い姿、長い髪、回路状の光と金色の関節を保ち、8連撃で高速横断、反転、跳躍、空中追撃、着地をつなぐ。決め技は天剣叢雲の大きな剣撃として、短い溜めから本人が踏み込んで振り抜き、引きの構図で巨大な切断面と相手の位置を見せる。新しい白い姿へ通常の立ち姿を置き換えず、原作Vの青い姿で終盤の代表技を採用する。連携の順序とカメラは本ゲーム向けの構成。

本人の専用全身8枚、カットイン、背景、エフェクト、ワンダーは追加のヤノシーク4姿勢を制作。カットインは共有LimitCinematicで比率維持、主攻撃は濃いart.strike、残光のみart.glow。剣先／銃口と相手、全身の画角、連続した姿勢を実描画で比較する。揺れと明滅は見やすさ設定へ従う。専用効果音とヒット停止、途中ダメージを同期する。

コード実装後、追加2人の対戦・トレモ・左右描画・連続再生・CPU各1戦と短いオンライン同期を検証し、既存サイトとGitHubへ反映する。公開済みは91／162、ディアナの公開同期は引き続き別の残件。

## ローカル実装・検証

専用画像11点（ワンダー6、ナホビノ5）と専用音4点を実装。本人の全身は各8姿勢、ヤノシークは4姿勢。銃口と着弾点を元画像座標から合わせ、ヤノシークは全身絵を傾けて本人と異なる射線から撃つ。ナホビノの大斬撃用セル1だけ、元の凸側が左を向いていたため右向きへ正規化して回転する。他の素材は反転していない。

対戦・トレモの発動、密着・空振り・ガード・無敵・再試行・多人数停止・ダメージと吹っ飛び、左右描画、カットイン比率、攻撃の濃いsource-over合成、専用2音ずつの再生を確認。CPUは接敵距離から各1戦が撃墜で結果へ進行。ローカルオンラインは377フレームのダメージ・吹っ飛び・ホスト設定が一致。連続再生を1440×900で録画し、全身・銃口・刃と相手の読みやすさを比較。通常の立ち姿・既存技・共通エンジンは変更していない。公開検証はこれから実施する。
