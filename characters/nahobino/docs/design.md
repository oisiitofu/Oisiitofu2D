# ナホビノの固有設計

添付の長い群青色の髪・金色の目・黒い装甲服・青い発光線・金色の接続部・青い魔剣を維持。立ち姿を固定し、全身画像で予備/攻撃/戻りを作る。人型3（98px）、重量88を想定。選択画面には専用の顔と肩のアップを制作。

- NB「スキル」：現在の属性をタップで発動。ホールド中に上下左右でアギ/ブフ/ジオ/ザンを選択し、離して発動（最大選択40F）。炎は遅い爆発弾、氷は地面に順次発生する氷柱、雷は距離制限付きの予告落雷、風は発射地点へ戻る鎌状の波。MPを消費し、同じ照準・速度・判定ではない弾を使い分ける。MP不足時は発動せず短く構えを解く。
- 横B「悪魔儀還・召喚攻撃」：本人はその場で指示し、前方へ仲魔を呼ぶ。最初は仲魔の打撃、ホールドで暗黒剣の薙ぎ、下Bのマガツヒ強化中は炎の追撃。再入力は生存中の仲魔を呼び戻して攻撃位置を手前へ変える。本人が突進する技ではなく、召喚地点と呼び戻す時機を使う遠隔牽制。空振り時も有限寿命、最大1体。敵は本人への接近、召喚の予告を見て回避/盾で対処。
- 上B「悪魔儀還・飛翔」：マガツヒの霊道を上方斜めへ描き、スティックで出現地点を指定する短いワープ。選択中の移動はなく、ワープ先に予告が出る。空中1回、方向選択後は途中で修正不可。発動後は通常落下と横慣性へ戻り、その場で待つ謎の追加入力時間を作らない。台下では側縁へ出る経路を先に選び、地形の中に出現しない位置まで探索する。マガツヒ中は到達距離が延長されるが2回上昇にはしない。相手は出現位置で待ち構えられる。
- 下B「悪魔儀還・融合」：通常は構えてMPを回復するが、相手の攻撃を無効化するカウンターにはしない。命中や被弾で溜まるマガツヒが100なら、短い発動で一時融合へ。攻撃の途中で自動無敵を付けず、属性弾の追加効果と仲魔の追撃/ワープ距離を強化。時間切れと撃墜で終了。MP回復中は隙があり、相手に距離を詰められる。

空Nは青い魔剣の剣舞、空前は雷を帯びた突き、空後は振り返る氷の斬り、空上は掌から風を上に放ち、空下は炎をまとった急降下の斬り。スマッシュは横の炎斬撃、上の光柱、左右の氷柱とし、通常の青い剣振りと姿勢/素材/判定を区別する。

既存の突進/二段上昇との違いは、本人と別に残る召喚の呼び戻し、位置を予告する1回のワープ、属性ごとに異なる攻撃形、MPとマガツヒの配分。CPUは距離・MP・設置中の仲魔・復帰方向に応じて選ぶ。オンラインは選択中の属性/ワープ先/召喚と全ゲージを入力フレームから同じ順で更新する。
