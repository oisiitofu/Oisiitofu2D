# ナホビノ実装

ワンダーの直後。人型3/98px・重量88。全身76枚+専用選択アップ、16FX、5カラー。固定した `assets/nahobino-neutral-locked.png` を基準に、全身画像の切り抜きと等比拡縮のみで描く。挑発/勝利3枚は足先まで揃えた修正版を使用。

NBはタップで現在の属性、ホールド中は右アギ/左ブフ/上ジオ/下ザンを選び、離して発動（選択最大40F）。消費MP8/10/12/10。炎の爆発弾、順次発生する氷柱、23F予告の落雷、発射位置へ戻る風を個別に処理。MP不足は構えを解いて終了。横Bは1体の遠隔召喚、タップ打撃/ホールド暗黒剣/融合中炎追撃、再入力で呼び戻す。上Bは15Fで1回の方向指定ワープ、指定地点を予告し、340px（融合390px）内の地形に埋まらない到着位置を探す。追加入力待ちを設けず通常の落下/横慣性へ戻る。下BホールドはMP回復、マガツヒ100で360Fの融合へ。無敵のカウンターにはしない。

近接は各画像の刃/掌座標とMeleeBalance.coverage、遠隔は専用オブジェクトの命中済み集合を使用。カウンター/盾/つかみ中の被弾は共通の命中経路を使う。共通エンジン本体の変更なし。青い斬撃0の凸側は右、1は上、炎2/風7は右、雷6は下。実描画で左右、剣/雷/風/炎/光柱を比較。

検証：108項目（近接の左右/先端/密着60場面を含む）、CPU2戦、通常/予備/戻り/色75場面+必殺14場面、オンライン2端末331F一致。77枚/16FX/385色別画像が配信画像と一致。結果と画像はGit管理外のpreviews、プロンプトはart-prompts.jsonとart-correction.json。
