# オニオンナイト

モーグリの直後。人型サイズ1/78px、重量86。専用の高解像度な顔と肩の選択画像、3ジョブ各61全身姿勢と32FX。基本・忍者・賢者の待機元絵を固定し、同じジョブ内では各シート先頭の待機基準で一度だけ倍率を決める。関節リグや小さい全身絵の選択画面への拡大は使わない。

- 下B：12F目で基本→忍者→賢者→基本。切替後35Fは再切替不可。各ジョブで通常15技の全身画像・技名・威力・機動力が変わる。キャラ共通定義を変更せず、当人の物理値だけを更新する。ストック復活で基本へ。
- 基本NB：タップでファイア、28F以上溜めるとファイラ。44F自動解放。溜め版は着弾時に有限の爆発へ変わる。
- 基本横B：低い踏み込み→浮かせ斬り→背面への返し斬り。各段中に再入力を予約し、最大3段。相手の位置に応じて途中で止められる。
- 基本上B：初動7Fで落下慣性を止め、エアロの斬り上げで弧を描く。上昇中に左右入力で進路を変えられる。終了後は専用の尻もち画像へ移る。
- 忍者NB：小手裏剣、長押しで大きい風魔手裏剣。一定距離後に本人へ戻る。往路と復路で1回ずつ当たり、同時に1個のみ、寿命あり。
- 忍者横B：22Fかけて前方155px/高さ65pxの弧を実際に移動。再入力を予約すると同じ弧を戻りながら斬る。瞬間移動ではなく、移動経路上で相手も対処できる。
- 忍者上B：二刀を使う速い上昇と横への曲がり。基本より速い機動力を使って復帰位置を選ぶ。
- 賢者NB：ホーリー1発、長押しで近・中・遠の3個。各弾は個別の寿命と同じ相手への1回の命中を持つ。
- 賢者横B：その場から少しずつ漂う竜巻を1個設置。次の横Bで同じ竜巻をスティック方向へ射出する。設置中は相手ごとに最大3パルス、射出後は1回の強い命中。本人は突進しない。
- 賢者上B：エアロガの風へ乗り、最初の上昇後も必殺ボタンを押している間は最大48Fまで上下左右を操作。離すと上向きの離脱へ進み、専用尻もちへ。静止した追加入力待ちはない。

空Nは基本の前後の剣弧、忍者の前方X二刀、賢者の3色魔法球に分ける。賢者の他の技も雷・氷・炎・風・メテオを使い分ける。上の斬撃は頭上の曲線1本。元素材の凸側を確認し、メテオは下左から真下へローカル正規化してから描画する。通常攻撃の発生/持続/ヒットIDは分割しない。

検証：機能248項目（3ジョブの通常技の密着/先端、左右復帰、有限寿命、切替）、通常90場面/必殺60場面/待機30場面、連続144サンプルと動画、CPU1戦2400F、184姿勢/32FX/920色の透過・読み込み、2ブラウザ1260F/14場面の同期が一致。公開検証は公開記録を参照。

素材は組み込みimage_genで制作。元画像は同階層のassets/、固定元待機は*-neutral-locked.png。抽出・組立はtests/assemble-art.cjs。検証画像と動画はGit管理外のpreviews/。
