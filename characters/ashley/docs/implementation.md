# アシュリー実装

リップの直後、表示58。人型1/78px・重量74。全身76ポーズ＋専用高解像度選択アップ、16FX、5カラー。待機はashley-neutral-locked.pngに固定。全身画像を切り抜き・等比拡縮し、関節リグは使わない。ジャブ2の向きと空中のほうきの重複を修正した中間姿勢を使用。ポーションとレッドは隣接素材の光点を含めず完全な本体を切り出す。

NBは12Fの呪い弾、25F以上ホールドで低速大弾。命中で呪いが溜まり、100の次は24F予告の地上噴出へ変化して全消費。NB命中後のレッドは20F予告で固定位置に3ダメージの一度だけの追撃、80F再発動制限。移動で避けられる。横Bはほうき滑走、方向転換/一度だけ跳躍し、近いポーション1個を拾い、ボタンを離して投下。被弾などで技が終わっても運搬状態を解放する。上Bは1回のほうき飛行、予算90F、上入力は2倍消費、横の加減速は緩く、早期終了も可能。無敵や常時の攻撃判定なし。下Bは2個までの有限寿命ポーション、ホールドで投げる。最初の浮遊台で着地して技を継続する。

近接だけMeleeBalance.coverageを使い、弾/設置へ適用しない。0の凸側は右、1は上。後方は左右反転で後ろへ、空Nはほうきの斜め方向へ。上スマはレッドと炎、空上は頭上の魔法、空下はポーション破裂で区別。共通戦闘エンジンの挙動変更なし。

検証：109項目（通常/スマッシュ/空中の左右・先端・密着60場面を含む）、CPU2戦、通常/予備/戻り/色75場面と必殺14場面。77枚/16FX/385色別画像の一致、2端末331Fの同期一致。ポーションの運搬・投下・中断解放・同時数/寿命、掴み中の設置被弾による解放、満タン消費・予告、上Bの燃料・空中再使用禁止・台下復帰を確認。ダメージの測定は共通の鮮度/対戦補正とレッド追撃を含めた上限を使用。

制作プロンプトはart-prompts.json、修正分はart-correction.json。実描画と結果はGit管理外のpreviews。
