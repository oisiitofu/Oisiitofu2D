# アシュリー：呪力を使う判断と設置への対処

- 固有操作：呪力100でもNBの短押しは通常の呪文。ポーションへの遠隔起爆と、SBでの運搬を維持する。25F以上溜めて放った場合だけ100を使い、強化魔法陣へ切り替える。発射前の被弾では呪力を失わない。
- 連携：呪力を温存して瓶を狙うか、相手の移動先へ強化魔法陣を置くか選ぶ。既存のNB起爆・SB運搬を新機能とは扱わない。
- リスク：通常弾は12Fから、強化は25F以上の詠唱が必要。発射後21Fの戻りと魔法陣24Fの予告を維持。強化の17ダメージは増やさない。
- 相手の対処：運搬されていない瓶は敵の実際の近接攻撃で壊せる。つかみや飛び道具専用の空の近接判定では壊さない。身体で踏む既存の起爆とは区別する。強化詠唱中の本体を攻めるか、魔法陣の予告を見て離れる。
- 復帰：90の有限燃料、上昇時2/F消費、空中1回を維持。戦闘中の無敵を追加しない。
- 表示：満タン時の「長押しで強化」、詠唱が25Fに達した表示、瓶の起動状態と破壊時の消散を既存素材とCanvasで示す。元の立ち姿・ポーズは変更しない。
