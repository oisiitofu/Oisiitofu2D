# ジェット / VALORANT

添付 jet.png をデザイン・動作の基準とする。人型サイズ2、94px。専用の高解像度な顔〜肩の選択画像を制作する。

## 操作と固有の役割

- NB「ブレードストーム」：5本を構え、タップで1本、押し続けると最大5本を順に投げる。5本目は強い。残り本数はHUDへ表示。接地して攻撃していない間に90Fかけて補充し、無制限な空中連射はできない。
- 横B「テイルウィンド」：攻撃判定を持たない方向指定の短距離移動。斜め上下にも移動可能。再入力で2回目へ連続移動。着地まで合計2回。途中で煙を通ると短い残風を残し、終端の硬直が短くなる。無敵・透明化は付与しない。空振りで突っ込む既存の突進攻撃とは役割を分ける。
- 上B「アップドラフト」：風で垂直上昇する。上昇中の横入力を先行入力し、終端で残りテイルウィンド1回分を消費して横方向へ離脱する。待機浮遊は作らない。分岐しなくても通常の落下へ連続移行し、横慣性を操作できる。下からの復帰と左右両側を確認する。
- 下B「クラウドバースト」：タップは足元、長押しは前方へ煙玉。最大2個、着弾した場所へ短時間の煙幕を作る。双方の姿を薄い煙で隠すが、攻撃判定・無敵・ダメージ・つかみ状態を変えない。移動と視認性による読み合いに使う。

通常技は短剣の射程、低姿勢の斬り払い、投擲姿勢、背後への斬り返しを区別する。空Nは両手の短剣を振り分ける固有姿勢と短い二つの刃の軌跡。全キャラ共通の輪・関節変形を使わない。密着・先端を同一ヒットIDのまま共通coverageで補う。

## アセットと検証

元ポーズは制作後固定し、全身画像で姿勢をつなぐ。素材の凸側を実画像で確認し、局所回転→向きの反転→ワールド配置の順にする。上攻撃の曲線は頭上に1つ。煙は小物として扱い、近接スタンプへ混ぜない。

検証はジェットの見た目、左右の通常攻撃と密着、5本の弾・煙・方向入力・着地リセット・復帰を中心とし、CPU1戦と短いオンライン代表場面を追加する。共通コードは登録の追加に限定する。
