# ジェットの専用リミットブレイク

対戦時の白い結い髪、青い上着、濃紺の脚部、手袋とクナイをカットインと全身姿勢の基準にする。発動前、上昇、着地の左右の実描画を並べて、顔、髪、衣装の縁取りとナイフの輪郭を比べる。

地上の滑り込みからクラウドバーストを奥へ投げ、煙が広がる横でアップドラフトを使う。上昇中は最初のナイフを下へ投げ、風で減速して頭上を斜めに滑空しながら一振りずつ投げる。最後は落下を始めて相手の足元へ複数の刃を収束させ、手を着いて着地する。ゾーイの地表を走る軌道と射撃反動に対し、上昇、静止に近い滑空、降下の高さの変化をカメラで追う。引きの画では相手と着弾点を煙の外へ残す。

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。滑り込みから上昇し、滑空中の投擲を経て降下するブレードストームへ。途中7ヒット、決め技26ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
