# ララフェルのリミットブレイク

対戦設定では初期状態で有効。ララフェルが合計100％分のダメージを受けると使用可能になる。ゲージは撃墜を挟んでも残る。通常攻撃＋必殺技で始動するとゲージは空になる。空振りやガードの後は被ダメージで再充填でき、命中して演出が始まるとその試合では使用済みになる。入力が1〜数フレームずれた場合は、対応する技の最初の4フレームから始動できる。

始動の1〜23フレーム目は無敵。9〜23フレーム目の槍が当たった相手1人だけを専用演出へ移す。演出中は試合の時計、第三者、飛び道具、地形などを止める。連撃、ジャンプ、ハイジャンプ、スターダイバー、蒼天のドラゴンダイブを経て、元の戦場で命中した相手に28％と吹っ飛びを適用する。位置、重量、ずらしによって撃墜ラインは変わる。

演出素材は全身8ポーズ、地上と上空の背景、カットイン、竜、4種のエフェクト。通常対戦の立ち絵とアトラスとは別にし、有効な試合でララフェルがいる場合にだけ読み込む。ゲーム上の座標は演出カメラの座標と分離する。
