# ベルベット：固有の能力・操作・対処

添付velvet.pngを制作基準にする。成人の自然な頭身、琥珀色の瞳、とても長い黒髪、赤い裏地の破れた黒い衣装、ベルト、非対称の脚衣とブーツ、解放される左の喰魔の腕を保つ。サイズ2・94px。専用の顔・肩の高解像度選択画像、全身の個別通常技・予備動作・戻りを制作し、元の待機を固定する。

## 固有の操作と連携

NB「喰魔の腕」：保持で左腕の間合いを選び、離して爪を伸ばす。短い保持は近距離、長い保持は中距離の直線。射程と後隙が変わる接続した腕の攻撃。命中した相手へ有限の獲物の印を残し、ソウルを得る。腕は飛び道具として独立して飛ばさない。

横B「喰魔の突進」：最初は踏み込みと腕の射出。空振りなら短く引いて終わる。自由に動ける近くの相手を腕で捕らえると、本人を残して相手を引き寄せる。獲物の印がある相手には射程を伸ばし、ガードにも捕らえを狙える。保持で引き寄せ、離すと引き倒す。上方向／ジャンプで、捕らえた相手を支点に自分が跳ね上がる空中追撃へ派生する。印の有無、捕らえ、引き寄せ／自分の跳躍という位置の判断を作り、横へ走るだけの共通突進にしない。既に被弾硬直・ヒットストップ・吹っ飛び予約中の相手をつかんで慣性を消さず、自由な相手だけを捕らえる。相手は予告を見て回避し、印がなければガード、捕らえた本人への割り込みやつかみ抜けで対処する。

上B「喰魔の翼」：喰魔の反動で飛び上がり、近くの足場の角へ左腕の爪を掛けられる。腕の支点に寄る／空中で短く翼を広げる間に、次の飛び先を方向入力で狙う。必殺を離して押し直すと、狙った方向へ一度だけ蹴り出す。再入力がなければ有限の滑空で終わる。二段攻撃を自動で出す上昇技にはせず、地形の角、空中での狙い直し、再入力の時機にリスクを持たせる。ステージの真下では先に横へ抜け、地形を貫通しない。角への爪の線と次の方向を表示し、相手は止まる場所や出る方向を読んで攻撃できる。

下B「喰魔の解放」：短押しは明確な受付時間だけのカウンター。成功でソウルを得て爪の反撃。ソウル最大で長押しすると全消費して有限の喰魔解放へ入り、腕の間合いと爪の蹴り出しを強める。解放中は添付の喰魔の影を伴い、空中では翼状の影を広げた全身姿勢を使う。条件付きのジャンプ長押し浮遊は45Fの共通有限予算とし、技・変身・空中ジャンプで回復しない。解放されていない通常の人間状態へ飛行を付けない。

ソウルは攻撃命中・被ダメージ・カウンターで得る。ゲージ自体を個性とはせず、腕の獲物の印と引き寄せ／跳躍、地形の角を使う復帰、解放に使うか残すかの判断へつなげる。NB→印→横B、カウンター→ソウル→解放→長い腕・条件付き浮遊が主な連携。ダメージ・被弾の慣性を入力で消す処理は入れない。

## 描画・命中

通常15技は爪、右手の打撃、肩のタックル、翼状の喰魔、後方の蹴りを別の全身姿勢で描く。空Nは交差する爪の引っかきにし、全身の共通回転や同じ輪へ寄せない。腕の伸長とつかみの線は武器・魔力のVFXとして描き、身体を関節リグで変形しない。近接の実画像の手・剣先・爪へNativeStrikesを合わせ、MeleeBalance.coverageを1回だけ適用する。つかみ、印、小物、支点へ近接補正を掛けない。

素材0/9は凸側右、2は上、3は下。元絵の凸側を見て、ローカルの向き→回転→左右反転の順で適用。上攻撃は原則頭上の1本の爪の弧。左右・密着・先端と、左右および真下からの復帰を実ゲームで確認する。

通常投げはbladeの役割として前後は位置変更、上／下の一方向を高％の撃墜用へ区別する。横Bのつかみ解除は独自の必殺技として通常投げの調整を借りない。
