# ティーダ / Tidus

ティファの直後、人型サイズ3（98px）、重量94。添付 `telida.png` を基準に組み込み画像生成で77フレーム、16エフェクト、専用の顔と肩のアップ画像を制作。生成の9呼出しは `image-prompts.json` に保存。元の待機全身は `tidus-neutral-locked.png` で固定した。

## 操作

- NBアクアシュート：タップは速い直球。30F以上溜めて離すとジェクトシュートになり、少し遅く、大きく強いボールが相手の高さへ緩く曲がる。長押しは60Fで自動発射。連続する弾は最大2個。
- 横Bチャージ＆アサルト：先にボールを投げ、その位置を追って斬り込む。上下入力がボールの初期軌道と追走中の高さを変える。ボールは地面で一度反発し、命中しても追走用の目印として残る。追走8F以降の再入力、または20Fで斬り上げへ。通常の一定方向突進と違い、目印となる弾と身体が別に動き、上下の経路と斬り上げのタイミングを選べる。空中では1回、着地/崖で回復。
- 上Bスピラルライズ：始動で落下慣性を抑え、12Fの跳躍→10Fの空中斬り→8Fの回転→10Fの方向指定離脱。待機/追加入力待ちは挟まない。スティックの最後の有効方向を保持して最後の離脱へ使う。真横にも離脱でき、無入力は斜め上。足場直下では端へ抜けてから上昇。終了時は専用尻もち画像へ移り、横操作は維持。
- 下Bクイックトリック：4種類の全身姿勢で9/17/26/36Fの4連撃。4段すべてを同じ相手へ当てると5秒ヘイスト（移動1.15倍）。空振りや途中までの命中では付与しない。
- オーバードライブ：攻撃命中で100%まで蓄積。最大で次の横/上/下スマッシュを強化し消費。ダメージ1.3倍、専用の紫青水流と少し広い間合い。窓やヒットIDは増やさない。

## 画像と判定

通常0〜60、連撃/離脱/中間全身61〜75、専用選択画像76。通常技/スマッシュ/空中技15種は別の全身姿勢。空Nは身体をひねった頭上〜前方のフック形水流、空後は後ろ蹴り、空上はハイキック、空下は下降斬り。全員共通の輪状空Nへ置き換えない。関節リグ変形は使わない。

全身成分を抽出し、シートごとの待機校正で一度だけ等方倍率を適用。後ろ蹴りの元画像は左顔/右蹴りだったため、その1枚だけ反転して右顔/左蹴りへ正規化。下B初段は剣を前に向けた専用修正版。余分な脚のある未承認の落下セルは使用せず、補足シートの正しい2脚の落下画像を使用。待機は再生成しない。

エフェクトの凸側0/8は右、1/9は上、フック2は右上、下降斬り12は右下。元画像を確認し、ローカル回転の後に左右反転。上攻撃は頭上の曲線1つ、後ろ蹴りは背面、回転攻撃は左右へ描画する。近接は共通coverageを1回だけ適用、ボールへ無条件に拡大しない。カラー変更は髪と肌を避けた衣装の黄色い範囲。

`tests/assemble-art.cjs` → `ART_IDS=tidus node .tools/build-art.cjs` で可逆配信画像とmanifestを更新。起動時の元シート解析は不要。サイズ一覧は `node build-size-catalog.cjs`。
