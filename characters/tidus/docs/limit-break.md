# 専用リミットブレイク

水の球場を駆け、剣で相手を浮かせる。水面を蹴って追い、いったん下がってからブリッツボールを空中で蹴り込む。ジタンの足場連撃と区別し、最後はボールの飛行を追う。衣装と青い剣は対戦素材を使う。

改修では現行の対戦用全身素材と選択肖像を参照し、金髪、左右非対称な黄黒の衣装、白いフードと青い剣を合わせた。組み込みImageGenで水面からボールを蹴り込む横長カットイン、ブリッツボールの水上球場、球体、剣と水の斬撃・着弾を描き起こした。素材は `assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-ball.webp`、`assets/limit-effects.webp`。ボールは蹴りの姿勢に合わせて回転しながら飛び、着弾で背後に波が立ち上がる。
