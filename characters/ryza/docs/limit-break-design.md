# アイテムチェーンからフェイタルドライブ

制作中・未公開。承認済み選択画像とゲーム用アトラスを顔・衣装・頭身・杖の基準にする。専用全身8枚で構え、走り、投げの予備動作、投げ終わり、杖の横払い、空中追撃、着地、魔法放出を描く。通常の立ち姿や既存のアイテム調合・必殺技は変更しない。

[公式の戦闘紹介](https://www.gamecity.ne.jp/atelier/ryza/battle.html)と[公式マニュアルのフェイタルドライブ](https://www.gamecity.ne.jp/manual/ryza2/jp/5300.html)を参照。APとタクティクス、アイテムとスキルの連携を原作の軸とする。[PlayStation公式紹介](https://blog.ja.playstation.com/2020/10/15/20201015-atelierryza2/)でもアイテムの連続使用、スキルチェーンと最大タクティクス時のフェイタルドライブを確認した。

投擲から走って接近し、杖の横払いと跳躍追撃を行う。着地後は相手の反対側へ足で回り、反転して杖とアイテムで追撃。距離を取って錬金の氷・雷・光を連携し、最後にフェイタルドライブの大きな光線と爆発へつなげる。瞬間移動主体のジェフティとは移動方法と攻撃の間を変える。連携順・金白色と虹の配色・カメラは本ゲーム向けの演出設計であり、原作ムービーの色や全動作を完全に再現したとするものではない。

主攻撃の芯は `art.strike`、補助の残光は `art.glow`、カットインは共有の縦横比維持描画。アイテムの投擲は手から放物線を描き、杖の先・光線の起点・相手の位置を合わせる。相手を最後に描画して光の中でも追えるようにする。全身画像をそのまま使い、関節リグで変形しない。

素材、最終プロンプトと参照は `limit-break-assets.json`。対戦・トレモ・左右描画・連続再生・CPU1戦・短いオンライン同期を確認してからジェフティと公開する。結果は本書とルート進捗表へ追記する。

ローカルの対戦・トレモ・左右描画・カットイン比率・攻撃の濃さと専用2音の再生を検証済み。CPU1戦は60秒1ストック設定で時間切れの結果まで進行（3601ステップ、双方11／6ヒット、残ストック1／1）。オンライン372フレームでダメージ・吹っ飛び・ホスト設定が一致。1440×900の連続再生録画（約6.31秒）を確認し、光線の杖先の起点と相手の浮き位置を修正した。録画は映像のみ、効果音はゲーム内の再生診断で別途検証。公開結果はルートの進捗表へ記録する。
