# ラチェットの専用リミットブレイク

『Rift Apart』の次元の裂け目と最終兵器RYNO 8を使う。ラチェットはレンチで相手を浮かせ、クランクを背負ってホバーブーツで床を滑る。床ぎりぎりの裂け目を抜けて高い足場から出て、空中で向きを変え、降りる位置を選んでRYNO 8を構える。最初の小さい裂け目から落ちる金属部品で追撃し、反対側で支え足を固めて、相手の真上に巨大な裂け目を開く。異次元から落ちる巨大な機械の部品が着地する瞬間を引きで見せる。

キトゥンの壁への接地やクラッシュの木箱のバウンドと違い、入り口と出口の位置関係、ホバーブーツで滑ってから停止する間合い、クランクを背負った反動と落下物の質量で動きを作る。既存の顔、耳、装甲、クランクとレンチを基準に全身を制作し、銃口から裂け目が開く方向と落下地点を明確にする。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音3点を制作。途中6ヒットで21ダメージ、決め技で26ダメージ。ホバーブーツで滑り込み、床近くの裂け目から高所へ抜け、着地してRYNO 8で異次元の機械を落とす。武器を紫の開口部と三枚のフィンがある原作デザインに合わせ、引きの画で落下と反対側への吹っ飛びを確認。CPU同キャラ戦は時間切れ。ローカルオンラインは412フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
