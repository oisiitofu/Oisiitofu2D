# ラチェット：距離と地形に応じたクイックセレクト

- 固有操作：DBの短押しは従来どおり次の武器。長押し中は左＝ピストル、上＝リコシェ、右＝エンフォーサーを選び、離すと確定。最長40F、確定後18Fの戻り。確定前に被弾した場合は武器を変えない。
- 距離判断：ピストルは11/17/23Fの3発と42Fの全体時間。エンフォーサーは17Fの単射、全体58Fで大きく隙を作り、近距離16・距離で8→5へ減衰、約180pxで消える。散弾5本は同じ命中履歴を共有し、80ダメージへ重複させない。リコシェは13F、全体48F、最大約550px。地形に跳ね返した場合だけ威力を上げるが寿命は延長しない。
- 連携：地形へリコシェを送り、残った弾は元の武器性能を維持したまま別武器へ切り替えられる。リコシェは1人1発までにして弾幕の重ね過ぎを防ぐ。
- 相手の対処：散弾を空振り・ガードさせて長い戻りに近づく。ピストル3発の軌道を飛び越える。跳弾は光り方で強化を示し、盾・パリィ・既存のカウンターへ対応させる。選択中は本体が無防備で、時間停止や無敵を付けない。
- 復帰：フックの520px制限を真下の例外にも適用する。主床中央のy740からの斜め距離約505pxは維持し、y900の約566pxは掴まず既存のクランク上昇へ移る。無制限の地下アンカーを削除する。失敗時の着地には長めの隙を付け、通常の成功復帰と区別する。
- CPUは距離・相手の位置から武器を選び、選択要求時の横入力残りによって横Bへ化ける不具合を直す。フック操作は実際の主床中央を使う。
- 元の銃・選択・戻り・フックのポーズと専用VFXを使い、体型や立ち姿を変更しない。
