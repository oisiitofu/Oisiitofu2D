# ロックマン.EXEの専用リミットブレイク

対戦用の青いヘルメットと黄色の帯、胸のナビマーク、腕のバスターを基準にする。バトルチップで腕装備を換える間もヘルメット、体格、配色を保ち、決め技の後は対戦時の立ち姿へ戻す。

格子の三列を引きで見せ、バスターを撃ちながら一段奥へ移る。エリアスチールで隣の列を開き、直角にステップして相手の退路をふさぐ。ソード、ワイドソード、ロングソードを順につなぎ、足を踏み込んでプログラムアドバンスのドリームソードへ。イヴの背後へのブリンクと梁の反転に対し、格子に沿った移動と、チップごとに変わる刃の間合いで攻撃順を見せる。

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。格子を直角に渡り、3種のソードをつないでドリームソードへ。途中7ヒット、決め技27ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
