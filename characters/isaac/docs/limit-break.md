# ロビンのリミットブレイク

『黄金の太陽』の地属性召喚アポカリプスを決め技にした。ロビンの斬撃に続き、地のジンが4体現れて召喚へ向かう。引いたカメラに翼のある騎士が降り立ち、獅子の盾から放った光が相手に降り注ぐ。

騎士の銀と青紫の鎧、白い翼、角のある兜、金色の獅子の盾はGBA版の召喚場面を参照した。専用の全身姿勢、騎士のポーズ、ジン、背景、着弾素材を使用する。 [任天堂の精霊召喚の解説](https://www.nintendo.co.jp/n08/agsj/jkoka3/index.html) · [GBA版の召喚画面](https://goldensunwiki.net/wiki/File:SummonJudgment.jpg)
