# ナルメア

シャルロッテの次。人型Tier2・94px。居合いGENJI/神楽KAGURAを下Bで切り替える。別キャラとして登録せず、同じファイターの構え状態として同期する。

## 技と操作

- GENJI通常技は長い間合いと重い一撃。KAGURA通常技は専用の15姿勢へ切替、威力82%、発生2F/全体4F短縮、間合い90%。攻撃窓の分割や追加ヒットは作らない。各ファイターのmotionPlanをprepare時に固定するので、同キャラ二人で違う構えを使っても画像が混ざらない。
- 下B 胡蝶刃：10Fで構え切替、空中でも使用可。ダメージ/無敵なし、短い後隙。構えによる再使用クールダウンはない。
- GENJI NB 斬・刹那：その場で溜め居合い。10F以降ボタンを離すと5F後から1回斬る。30F以上で12→21ダメージ、42Fで自動解放。空中溜めは着地しても継続。
- KAGURA NB 鏡月：10〜14F、21〜25F、32〜37Fに別モーションの3段斬り。初め2段は軽く、最後に吹っ飛ばす。
- GENJI 横B 霧・移ろうせみ：13〜22Fの実移動で相手の側を抜け、23Fに振り向いて24〜30Fに背後から一度斬り返す。距離100〜200px、ワープ/無敵なし。空振りでも後隙が残る。
- KAGURA 横B 千月：10Fに小さく跳び、14〜21Fに斬り下ろし、29Fで反跳し34〜41Fに切り上げる。地上の低姿勢に強く、空中では高度と着地位置を管理する。
- 上B：8Fの落下慣性停止後に上昇。16F後に左右入力で折り返し方向を決める。GENJIは2段の長い斜め軌道、KAGURAは3段の細かい斬り返し。終了は35番尻もちへ直接移行、共通の左右移動は維持。両側の場外と真下の地形からの逃がしを扱う。

## 素材・描画

78frames/16FX。`assets/narmaya-poses.png`と`narmaya-motion.png`がGENJI/移動、`narmaya-kagura.png`がKAGURA通常技24体、`narmaya-specials.png`が下スマ/上B/NBの追加全身5体＋校正立ち姿。元画像の全身姿勢を保ち、関節リグは使用しない。72/73は構え別下スマ、74/75は構え別上B、76は居合いNB。77は専用高解像度選択画像。正確なbuiltin image_genプロンプトは`image-prompts.json`。

実素材0/4は右凸、1は上凸、13は下凸。近接はAttackEffects.image経由で実判定の外縁まで合わせる。上強/上スマ/空上は頭上の大きな曲線1つ。左右反転の前にローカル素材方向を正規化する。
