# ナルメアの専用リミットブレイク

神楽と源氏それぞれの間合いを使う。相手の背後を何度も通過せず、源氏で中距離の居合いを一度当てた後、横へ円を描いて神楽の近距離斬りをつなぐ。蝶が鞘に戻る合図で壇の端に下がり、刀を収めた間を挟んで、胡蝶刃・天鏡女命舞の一閃を放つ。シャルロッテの盾と踏み込みが連撃の起点になる構成と異なり、納刀、空間に残る切断線、抜刀の速度差で見せる。

既存の源氏・神楽の姿を編集の基準とし、発動時と復帰時は対戦中の構えを参照する。髪、角、衣装、刀と鞘の輪郭を左右で確認する。切り替えは蝶の動きと音を合わせ、切断線が出る瞬間と、命中・吹っ飛びの方向をカメラで追う。

専用カットインと月夜の壇、紫の斬撃・蝶・抜刀線・命中の透過素材、納刀・抜刀直前・低い一閃の全身姿勢3種を制作した。標準カラーは専用全身姿勢、別カラーは対戦用の該当姿勢を使う。演出内の構え切り替えは描画にのみ反映し、対戦では選んでいた構えに戻る。
