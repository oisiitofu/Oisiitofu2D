# トロの専用リミットブレイク

『どこでもいっしょ』のコトバを覚える場面から、既存の対戦キャラにもあるジャスティス、トロビ、オニの三形態へつなぐ。トロは畳からちゃぶ台へ飛び乗り、ジャスティスで近距離の蹴りを連続で当てる。蹴りで台から後ろへ跳び、障子を抜ける間にトロビへ。障子の隙間と欄間の高さを変えて手裏剣を投げ、着地と同時にオニの装束へ切り替わる。オニは杵を振り下ろしてモチを跳ね上げ、上から落ちる大きなモチの連撃で締める。最終段は『PlayStation All-Stars Battle Royale』のレベル3スーパーのモチを基準にする。

アイアイの連続した転がりやさくらの機体への搭乗に対して、トロは舞台の家具を踏み台と目隠しにし、衣装と距離を段階的に変える。ちゃぶ台の上下、障子の向こう側と手前、杵の振り下ろしをカメラで追い、変身ごとにトロの顔を見せる。丸みのある四角い頭、耳、黒い瞳と白い体を既存素材に合わせ、形態別の全身姿勢と手裏剣・モチ・杵の衝撃を制作する。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音3点を制作。途中6ヒットで20ダメージ、決め技で25ダメージ。ちゃぶ台の天板に足を合わせ、障子の手前と奥を切り替え、手裏剣の先端を進行方向へ向けた。モチの決め技でもトロの全身が見えるよう描画順を調整。CPU同キャラ戦は無命中で時間切れ。ビビ戦はトロが8回命中し、トロの落下で終了。ローカルオンラインは405フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
