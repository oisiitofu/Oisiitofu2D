# イオのリミットブレイク

『CODE VEIN』の長柄武器による連撃と、終盤でイオが遺骸を受け入れて樹へ変わる場面を組み合わせた。薙ぎ払いと突きから茨で追撃し、カメラを引いて樹と琥珀色の血涙を映す。血涙が相手に届くところで光の柱を立ち上げる。

途中は2・2・3・3・3ダメージ。最後に23ダメージと斜め上への吹っ飛びを適用する。樹への変化は演出区間に適用する。
