# Io from Code Vein

画像制作前の固有技設計案。ゲーム側で最終調整する。

固有能力・操作：血を吸う長柄武器とギフトの支援を使い分ける。NBは溜め血棘弾、命中でイコルを得る。DBはそのイコルを支払い地面へ癒し/守護の小領域を置く。SB「茨の突進」は設置した血棘を先に伸ばし、B追加入力時だけ棘の根元へ滑る、空振り時は棘を残して離れられる。地上は足元の拘束線、空中は斜め下の棘の杭。UB「血英浮遊」は黒い血英の裾で身体を支え、上昇後の有限時間だけスティックで横移動し、Bを放すと早く落下する非攻撃復帰。既存との差：横Bは即時接触ダッシュでなく遅延棘と選択移動、上Bは二段斬りでなく攻撃を伴わない衣の浮遊。相手の対処：棘の予兆から離れる/飛び越す、棘を飛び道具で壊す、支援領域を奪わせない、浮遊終わりを狙う。命中音：槍は金属の斬撃、棘は低い穿刺、支援は明るい鐘。

原画の顔・体型・衣装を固定し、全身画像を切り替える方式。関節リグは使用しない。選択/勝利には専用の高解像度上半身アートを使う。
