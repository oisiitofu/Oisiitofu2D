# アイルーの専用リミットブレイク

「特大タル爆弾の技」は、爪とブーメランを上下に返して相手を罠へ誘導する。銃の反動で射線を変えるシオンと異なり、罠を相手の足元に残し、横から運んだタルを蹴ってそこまで転がす。最後は笛を持って跳び離れ、地上から木片をともなう爆発が広がる。[カプコンのオトモ紹介](https://game.capcom.com/manual/Multi-Platform/en/xone/page/12/1)

対戦のクリーム色の毛、緑の頭当て、赤いスカーフ、背中の小タルを維持する。ImageGen でタルを蹴る横長カットイン、野営地、罠、爆発と、押す・蹴る・笛を抱えて跳ぶ三つの全身姿勢を制作した。標準カラーは専用姿勢、別カラーは対応する対戦姿勢で表示する。

配信素材は `assets/limit-cutin.webp`、`assets/limit-camp.webp`、`assets/limit-effects.webp`、`assets/limit-tools.webp`、`assets/limit-motion.webp`。爆発は笛の短い音と木片の音を含む専用効果音。
