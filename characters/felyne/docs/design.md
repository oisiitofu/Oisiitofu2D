# アイルー 制作設計
小さな直立猫の原デザイン、クリーム色の毛、茶色の耳・手足、緑ベージュの頭装備、首布、背負い道具を維持。特殊体型62px。
## 固有の能力・操作
往復ブーメランとタル爆弾、回復笛、シビレ罠を使い分ける道具型。アイテムは有限寿命・個数制限を持つ。
## 必殺技と連携
NBは投げたブーメランが弧を描いて手元へ戻る。SBはタルを転がし、再入力で乗る／降りる。タルだけを送って罠へ誘導するか、乗って加速するか判断する。UBは回復笛の風を足元へ残して一度跳躍し、風域に触れる味方を小さく持ち上げる。左右入力で風域の傾きを変える。DBは地上にシビレ罠を1つ設置し、短い拘束から追撃へ。
## 既存キャラとの差
SBは本体の接触突進でなく独立したタルの操作と離脱。UBは二段攻撃でなく笛による位置依存の風域を使う復帰。直接の撃墜力と安全性を引き換えにする。
## 相手の対処
ブーメランの帰路、タルの進路、罠の設置光を見て飛び越え・盾・先回り。風域は相手も利用可能にする案。爪は軽い引っかき音、ブーメランは木の風切り、タルは低い木樽爆発、笛は柔らかい金管。
