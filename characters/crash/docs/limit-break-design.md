# クラッシュの専用リミットブレイク

『クラッシュ・バンディクー4 とんでもマルチバース』の量子マスクを使う。ラニロリで木箱を実体化し、跳び箱のように足を乗せて二段に弾む。次の箱はスピンで壊し、クプナワの時間減速で跳ね返った相手を追い越さず、落ちてくる箱の隙間を縫って床の反対側へ移る。アカノが現れて体を大きくひねり、箱の破片を巻き込みながら、ダークマタースピンで決める。

キトゥンの重力方向の切替とは区別し、クラッシュは箱の実体化、接地のバウンド、時間の緩急で移動を作る。アストロの支点とグローブに対しては、箱を連続して壊す手足の動きと音を見せる。既存の橙色の体、顔、青いパンツと赤い靴を保ち、箱の踏み切り、スピン、減速中のすり抜け、アカノの溜めと回転終端を描く。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音3点を制作。途中6ヒットで21ダメージ、決め技で26ダメージ。ラニロリで実体化した木箱の反動、クプナワで減速する瓦礫の下をくぐる反転、アカノのダークマタースピンを確認。CPU同キャラ戦はストック切れで終了。ローカルオンラインは411フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。

Sites v343とGitHub `ebb572b` に反映。公開URLで対戦・トレモ・ガード・空振り・両向きの決め技を確認。配信素材とバンドルを含む更新23点のSHA-256が一致し、専用演出の作品数は108／162。公開オンラインの固定入口はHTTP 503で、同期確認は保留。
