# リィンの専用リミットブレイク

『閃の軌跡』の神気合一と灰の騎神ヴァリマールを使う。リィンが太刀を受け流し、鞘へ戻す間に相手が踏み込む。銀髪と灼眼へ覚醒し、その場の低い抜刀から相手を上へ送る。リィンは剣を立てて召喚し、ヴァリマールが上から片膝をついて着地。腕を伸ばして大太刀を受け取り、機体が膝を伸ばす重さを見せてから斜め上へ振り切る。エステルの跳躍は棍を支点とするが、こちらは本人が地に足を置き、着地で主役の大きさと視点が変わる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中6ヒット、決め技26ダメージ。受け流し、銀髪と灼眼の神気合一、抜刀から召喚、ヴァリマールの降下・着地・振り上げを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
