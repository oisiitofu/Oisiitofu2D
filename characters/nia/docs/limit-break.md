# ニアの専用リミットブレイク

対戦用の姿から双輪を前後に放つ。輪が戻る軌道に沿って水流を通し、相手の足元から水柱を連ねる。メリアの頭上からの砲撃と区別し、水面と輪が交差する横方向の攻めを使う。

改修では、対戦の銀髪、耳、黄と黒の上着、赤白のスカーフと金縁の輪を参照し、双輪を投げる横長カットインを ImageGen で描いた。夕暮れの湖を背景に、連撃で輪の進行方向に合わせて水流としぶきを反転する。決め技では双輪が別々の高さから合流し、引いた画面で地表の波と三本の水柱が立つ。相手のシルエットは水柱の手前に描画する。

配信素材は `assets/limit-cutin.webp`、`assets/limit-lake.webp`、`assets/limit-effects.webp`、`assets/limit-current.webp`。
