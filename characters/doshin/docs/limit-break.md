# ドシンのリミットブレイク

バルド島での地形操作と、愛の巨人から憎しみの巨人ジャシンへ変身する原作の二面性を題材にした。隆起と地表を走る衝撃波を連続で当て、引きのカメラで変身を見せてから爪撃と大地の叩きつけへ移る。火山性の噴火で締める。

4ヒットのダメージは3・3・4・4。最後に22ダメージと斜め上の吹っ飛びを適用する。
