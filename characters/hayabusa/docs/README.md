# リュウ・ハヤブサ

NINJA GAIDEN。選択順は指定がないためおまかせの直前。旧登録番号128、追加時の画面番号121。選択可能121体、隠し形態を含む127形態。

内蔵 `image_gen` を使用。添付の黒い忍装束、銀の額当てと黒い覆面、露出した上腕、長いスカーフ、右手の龍剣を基準に制作。全身48姿勢＋専用肖像の49フレーム、エフェクト12点、5カラー。関節リグを使用せず全身ラスタ画像を表示する。

- `characters/hayabusa/assets/hayabusa-reference.png`: 添付の保存コピー
- `characters/hayabusa/assets/hayabusa-poses.png`: 通常攻撃・待機・投げなど24姿勢
- `characters/hayabusa/assets/hayabusa-motion.png`: 歩行4・走行4・ジャンプ・崖・専用必殺24姿勢
- `characters/hayabusa/assets/hayabusa-effects.png`: 最終12エフェクト。初回に見えた矩形の端を避け、透明な余白を広くして再制作
- `characters/hayabusa/assets/hayabusa-selection.png`: 選択/HUD共通の肖像
- `characters/hayabusa/assets/hayabusa-native.png`: 透過を維持してパッキングしたゲーム用アトラス
- `characters/hayabusa/docs/image-prompts.json`: 全文生成指示（修正分を含む）

体格108、重量97。全身姿勢間の縮尺は一定、姿勢で自然に縮むしゃがみを一律の面積補正で拡大しない。足元と38番の上げた手から接地・崖グリップを設定。カラーは暗い布部分を変更し、肌・銀の額当て・刀を保持。

## 必殺技

- 通常必殺「手裏剣」: 10Fに1発、長押しでは16/22Fも発射して最大3発。威力4、速度12、寿命36F。初期待ち40F、発射ごとに最低34Fを残す。最大3オブジェクト。腕元から判定を連続させ密着にも当たる。ガード・無敵・壁に対応。強化時は威力4.5、速度14、発射数は変わらない。
- 横必殺「飛燕」: 8–20Fに緩い上向きの弧を描いて斬り抜ける。発動時の相手位置から移動を決め、移動95–240px、対象外は145px。追尾し続けない。10–14Fに威力9。21F以降は振り返り、18–28Fの新しい必殺入力で4F後から3F持続の追撃10。長押しのみでは追撃しない。着地で受付を消さず、空中版は1回、使用待ち65F。空振りでも同じ有限軌道と隙を持ち、崖外へ出るリスクがある。
- 上必殺「風の道」: 8F始動。空中で本体の左右壁から85px以内、足元が台より30–260px下なら壁沿いへ寄りながら上昇し、15F後に内側へ蹴り離す。地上/壁なしは斜め上の龍剣から上昇。上昇27F後は重力が戻り、有限時間でしりもち。ステージ内側の下からは先に側面へ抜け、改めて復帰を開始する。強化時の上昇は1.12倍。壁を使うポーズ44の足の向きは専用反転で合わせる。
- 下必殺「闇 / Gleam State」: 18Fで10秒間強化、発動から18秒の再使用待ち。物理技の威力を1.12倍、手裏剣と上必殺を専用強化。元技データを変更せず、その回の攻撃に固定する。青いオーラ、専用二刀の待機、残り時間のゲージを表示。終了/撃墜で解除。空中では急降下にしない。

通常/空中攻撃は体の中心から刀先までカプセルをつなぐ。横強117px＋半径17、横スマ145＋20、後空中110＋17、上方向129pxまで、下空中は足元下33＋17。空中下は実命中で一度だけ小さく跳ねる。エフェクトは判定線分の向き・長さ・厚さに合わせ、RIGHT向きの元素材をローカルX反転→回転の順で使用。上下/背後も両向きで確認。

## 検証

プロジェクトルートから実行。`NODE_PATH` に既存Playwright/sharpランタイムを指定し、ローカルサーバーを起動する。

```text
node characters/hayabusa/tests/hayabusa-test.cjs
node characters/hayabusa/tests/hayabusa-cpu-test.cjs
node characters/hayabusa/tests/hayabusa-online-test.cjs
# ART_IDS=hayabusa を指定して実行
node .tools/build-art.cjs
node art-loading-test.cjs
```

専用198項目、CPU2戦各2400F、独立2クライアントの代表161Fを確認。通常攻撃15種の密着/先端/小さい相手、上下前後/両向き、ガード、手裏剣の有限連射、飛燕の追撃と空中使用、壁あり/なし/左右/内側下からの復帰、崖の手、強化の威力/時間切れ/撃墜、空中下B。49姿勢＋12エフェクト＋245カラー画像の不一致/ブラウザー例外0。CPUは対人勝率の評価ではない。共有処理は登録と専用分岐のみで、無関係な全キャラ総当たりは実施しない。
