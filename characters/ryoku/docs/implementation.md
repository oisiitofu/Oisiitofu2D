# リョク実装

ハチワレの直後。特殊体型64px・重量82、四足の頭身と葉の耳を維持。全身76枚+専用選択アップ、16FX、5カラー。待機を `assets/ryoku-neutral-locked.png` に固定し、関節リグを使わず全身画像で動かす。攻撃シートの最下段は5体であることを認識して切り出し、余分な1体は使用しない。隣の姿勢を混入させない。

NBは13Fで茶しぶき、タップ15/ホールド25のお茶を消費。横Bは茶筒1個を置き、ホールドで左右の転がしと茶筒だけのジャンプを操作、離せば慣性、再入力で呼び戻す。同じ命中済み集合を保ち往復で連打しない。上Bは耳の1回上昇と有限の滑空、発動地点に90Fの上昇風を残す。風は空中の他の人物も一度だけ利用できるが、被弾硬直/ヒットストップ/予約された吹っ飛びへ干渉しない。空中1回、台下では外縁から上昇。下Bは座布団で飲み、24Fホールドで補充と240Fのお茶パワー（走行/空中速度・吹っ飛び耐性）。強化は本人専用のcharacterコピーへ適用し、共有CharacterDataを書き換えない。

前足/耳/上の蒸気/茶しぶき/茶筒にそれぞれの素材を使用。葉0/茶4/風7の凸側は右、頭上1は上。近接拡張は直接攻撃の窓だけ、茶筒としぶきへ適用しない。共通エンジン変更なし。

検証：92項目、CPU2戦、通常/予備/戻り/色75場面+必殺14場面、2端末331F一致。77枚/16FX/385色別画像一致。有限寿命/遠隔方向/茶筒の跳躍/本人の位置/台上の飲茶/風と吹っ飛びの分離を確認。結果はpreviews、制作プロンプトはart-prompts.json。
