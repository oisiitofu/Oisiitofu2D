# リョクの固有設計

添付の緑のお茶犬、白い口元、黒い丸い目、葉脈のある大きな二枚の耳、緑の柄入り襟巻き、四本の短い脚を維持。特殊体型64px、重量82。人型や二足歩行へ置き換えない。選択画像は顔と葉の耳、首元のアップを別制作する。

- NB「お茶しぶき」：湯飲みから茶のしぶきを飛ばす。タップは素早い直射、ホールドは短距離の幅広い扇。お茶の残量を消費し、下Bで補充。茶葉の耳の近接とは判定と命中音を分ける。
- 横B「茶筒ころころ」：本人が低く押し出す茶筒を1個設置。ホールド中は左右で転がし、ジャンプ入力で茶筒だけを跳ねさせる。本人は突進せず指示する。離せば慣性で転がり、再入力は本人へ呼び戻す。相手は本体を攻めるか、茶筒をジャンプで避ける。茶筒は有限寿命で、命中済み集合を維持して往復で同じ相手を連打しない。
- 上B「茶葉くるくる」：耳で一度上昇し、発動位置に葉の上昇風を残す。その後は耳を広げて短く滑空し、攻撃を出せば滑空を終える。上昇風は空中の相手も一度だけ利用でき、設置した茶筒の近くでは強い風になる。被弾硬直や吹っ飛びを風で消さない。空中使用は一度、再入力で上昇を繰り返さない。単なるホールド飛行ではなく、残した風と茶筒の位置取りが復帰経路になる。
- 下B「ほっとひと息」：座布団を敷いてお茶を飲む。24F以上飲むとお茶が補充され、お茶パワーで一時的に移動と吹っ飛び耐性が上がる。飲んでいる間は攻撃を受ける。浮遊台では台上に残り、空中では着地してから飲み始める。短い回復と長い強化を状況で使い分ける。

空Nは葉の耳を使う小さな回転、空前は前足、空後は後ろ耳、空上は二枚の耳を上へ開く、空下は四本足の踏みつけ。四足の全身姿勢を個別に制作し、全員共通の剣や輪で代用しない。耳の打撃、茶しぶき、茶筒の衝突、蒸気でエフェクトと命中音を分ける。

CPUは茶の残量、茶筒の位置、相手との距離で飲む/放水/転がすを選ぶ。オンラインでは茶筒の遠隔入力、風を利用した人物の集合、茶の残量と強化を同じフレームで更新する。
