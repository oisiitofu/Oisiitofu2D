# リョクの専用リミットブレイク

対戦用の緑の体と茶葉の耳、小さな四足の頭身を維持する。茶の盆を足先で押し、茶碗から上がる湯気に乗って弧を描き、庭の飛び石へ順番に着地する。急須の口からこぼれた緑茶の波を先に走らせ、最後はリョクの着地と茶柱の立ち上がりが重なる。ネコの城へ戻る動線と異なり、短い高さの違いを四足の踏み切りで追う。途中の命中間隔は17〜22フレームとする。

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。湯気に乗って飛び石を渡り、緑茶の大波へ。途中7ヒット、決め技26ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
