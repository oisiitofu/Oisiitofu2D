# ユーマの専用リミットブレイク

『超探偵事件簿 レインコード』の推理デスマッチから謎迷宮終盤へつなぐ。ユーマは最初の主張を低い姿勢ですり抜け、青い主張を解刀で弾き返す。弾いた言葉の背後へ潜り、跳びながら解鍵を鍔へ差す。根拠を得た刃で上から矛盾を切り開き、切れた面の向こうに大きくなった死に神ちゃんが現れる。死に神ちゃんが鉄球を蹴って壁を砕き、ユーマが破片の手前で解刀を振り切るところまで追う。

アーロイは固定支点に引かれ、モノクマは円盤の回転で相手を動かす。ユーマは自分に飛来する板状の主張との距離で伏せ、弾き、跳ぶ。縦に並ぶ主張と鍵の前後を描き分け、本人と巨大な相棒の輪郭を別の色で読めるようにする。
