# インパクト百裂パンチ → 口からレーザー

元の青髪・赤い服・白い帯・金のキセルを維持した専用4ポーズとカットインを制作。通常技とスーダンインパクトの変身には変更を加えない。キセルの命中で相手を捕らえ、カメラを引いて巨大インパクトを見せ、8回のパンチ、アッパー、口からレーザーへつなぐ。途中10回のダメージと最後の吹っ飛びを共有時間軸で処理する。

インパクトの姿は[コナミ公式グッズ掲載画像](https://www.konami.com/games/tgs/ja/goods/)を参照。百裂パンチ、激烈アッパー、口からレーザーは[任天堂の公式操作説明](https://www.nintendo.co.jp/wii/vc/vc_gg3/vc_gg3_09.html)を基準にした。胸の砲撃へ置き換えない。専用ポーズは右向きに制作し、共通のworld変換で左向きにも反転する。キセルの曲線は凸側が右、パンチは右に尖る芯を持つ。口レーザーの始点は実描画で口に合わせた。

高品質素材は `assets/limit-{cutin,court,poses,robot,effects}.webp`。内蔵imagegenを使用した最終プロンプト、参照と元出力は同フォルダの `limit-break-assets.json` に記録。共有カットインの縦横比、濃いsource-overの主攻撃、残光の補助合成、見やすさ設定に従う揺れと明滅を利用する。専用音は機械の打撃と回路音を重ねたservo、低域の起動と周波数変化を持つlaserの2音。

ローカルで密着発動、ガード、無敵、空振り後の再充填、1試合1回、他プレイヤーと時計の停止、トレモ、左右描画、カットイン比率と攻撃の濃さを確認。CPUは60秒1ストック設定の1戦が結果まで進行。`LIMIT_FIGHTER=goemon` で既存の `characters/dragoon/tests/limit-break-online-test.cjs` を実行し303フレームが一致。公開結果は `docs/limit-break-rollout.md` に追記する。
