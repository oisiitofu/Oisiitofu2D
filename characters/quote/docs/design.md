# クォート — 武器レベル・反動・バブリン

霊夢の次。特殊体型76px。ユーザー指定のドット絵の見た目を守り、輪郭/塗り/エフェクトも同じピクセル格子にそろえる。赤い帽子とズボン、緑のイヤホン/スカーフ、黒髪を維持。専用の顔/肩ポートレートもドット表現で別制作。

- 固有能力: ダメージを与えて経験値を得ると武器がLv1→2→3へ変化。被弾で経験値を失う。段数だけでなく弾の幅/バブリンの保護数/ファイアボールの地面反射数が変わる。全武器を一括強化せず、その武器の経験値として管理する。
- NBポーラスターは素早い単発、長押しは構えてスパーへ蓄積し、離して貫通弾。溜め中は移動が遅い。近接の代用ではなく射線の読み合い。
- 横Bファイアボールは地面を跳ねる射撃。本体移動なし。下り坂/段差で軌道が変わり、空中は放物線で地面を探す。弾は一定反射回数/寿命で消える。相手は上から越えるか地形で遮る。
- 上Bブースターv2.0は方向入力8方向の短い燃料噴射。Bを離すと噴射を止め、残った燃料で一度だけ再入力できる。燃料は着地/崖/復活まで回復しない。二段攻撃ではなく、推進を区切って射撃の位置を取る復帰。噴射自体の攻撃判定は付けず、反動と方向選択で個性を出す。
- 下Bバブリンは押し続けると弾数/時間に上限のある防護泡をため、離すと入力方向へまとめて放つ。敵弾と接触した泡は消え、後から攻撃弾に変えられない。ガードとは別の弾管理。
- 下空中のマシンガンは下向きの弾を撃ち、空中で有限の反動を得る。弾切れ/高度の上限で永久滞空は不可。

相手の対処は射線/弾道回避、溜めへの接近、バブリンを消費させてから攻撃。剣主体ではないが軽い投げを基本に役割を分ける。銃/レーザー/炎/泡の命中音は分ける。
