# クォートの専用リミットブレイク

対戦用のピクセル絵に合わせ、帽子・髪・衣装・銃のシルエットをカットインと全身姿勢に保つ。崩れる洞窟で床から岩壁へ移り、ブースターを短く噴かせて横穴をくぐる。弾数の多い射撃で相手を退かせ、最後は崩れた足場に片膝で踏みとどまってシュプールの最大溜めを放つ。ヒューマンの吊り荷に体を運ばれる構成とは異なり、自分で短く噴射する方向を変え、狭い通路から射線を確保する。追撃は17〜21フレームを目安にする。

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。ブースターで壁を折り返し、片膝からシュプール最大溜めへ。途中7ヒット、決め技27ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
