# 専用リミットブレイク

糸を左上へ掛け、振り子で相手の下を潜ってから宙返り。張った糸の交点を針で切り上げ、空中でスレッドストームを起こす。ビビの定点詠唱と違い、支点そのものが移動経路を作る。 対戦用の全身と選択肖像を使用。

[Team Cherryのスレッドストーム資料](https://www.teamcherry.com.au/blog/silksong-patch-4)

## カットイン・攻撃素材の改修

白い仮面と赤いマントを参照し、針を前に出して糸で急降下する構図。時計塔の屋上で、針先、刃の曲線、締まる糸、スレッドストームを描き分けた。 カットイン・背景・攻撃素材はImageGenで新規制作。対戦と同じ全身素材を使用。
