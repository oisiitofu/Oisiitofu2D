# Shovel Knight

画像制作前の固有技設計案。ゲーム側で最終調整する。

固有能力・操作：ショベルで地形を掘り、掘り出した宝物とレリックで戦う。NBはレリック選択（フレイルの弧/モバイルギア/フェイズランス）。DBは掘る地点を短押しで選び、次の入力で同地点から宝箱を掘り出す。周期に従い回復/爆弾/足場用宝箱が出る。SB「ショベルダッシュ」はBを離すまでは掘る構えで、置いた宝箱やギアへショベルを掛けて引き寄せ、その反動で自分を押し出す。箱がなければ短距離の地面掘り、壁に達すると壁掘り足場を一つ作る。UB「ショベルジャンプ」はショベルを下に構えるポゴジャンプ。地面/箱/相手へショベル先端が触れると一回だけ跳ね、追加で方向変更できる。触れなければ通常の有限上昇、空中無限更新不可。既存との差：箱を作ってから横移動や上復帰の足場に使う連携で、基本突進/二段上昇の使い回しではない。相手の対処：箱の破壊、ポゴ先端の横から攻める、空振り落下を狙う。画像はドット絵とピクセル輪郭を保持。

原画の顔・体型・衣装を固定し、全身画像を切り替える方式。関節リグは使用しない。選択/勝利には専用の高解像度上半身アートを使う。
