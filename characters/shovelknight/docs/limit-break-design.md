# ショベルナイトの専用リミットブレイク

対戦時の青い鎧、クリーム色の角、黒いバイザー、茶の柄と青いショベル刃を維持する。全身ポーズは対戦用のピクセルアートに合わせる。

ショベルドロップで段差を二度跳ね、掘り起こした石と床の崩落で相手を下段に落とす。本人は上段へ残り、着地して構え直してから掘り上げた岩をショベルで打ち飛ばす。モノが描線の上を走らせる構成に対し、上下に重なる床と相手が落ちる経路を見せる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。青い鎧とショベル刃を対戦素材に合わせ、ショベルドロップの跳ね返り、床の崩落と岩の打ち返しを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
