# カサネのリミットブレイク

『SCARLET NEXUS』のブレインフィールドと赤い糸を題材にした。高さの異なるナイフを連続で飛ばし、念力で引き寄せた瓦礫を上下からぶつける。赤い糸が相手を取り囲むところでカメラを引き、瓦礫を一点に集めて砕く。

途中は2・2・2・3・2・3ダメージ。最後に22ダメージと斜め上への吹っ飛びを適用する。
