# ハイデリンの画像・描画

全身107フレーム（専用選択画像106を含む）と16種のエフェクト。関節リグを使わず、全身の完成姿勢・技ごとの予備動作・戻りを表示する。固定した待機画像は組み立て時にRGBAの完全一致を検査する。

各シートのcell0を基準にシート全体へ単一倍率を適用する。屈みや水平飛行をセルいっぱいへ拡大せず、縦横比と身体寸法を保つ。立ち姿はサイズ4・116px。羽と冠を含む立ち姿、移動、攻撃、復帰、戻りを実ゲームの連続描画で比較した。

横へ伸びた剣先が欠けていた未完成ドラフトのダッシュ攻撃だけ、予備動作の制作前に全身を補完した。元のattacksシートは保持し、neutralと完成ダッシュの2体を含むstrike-completionの単一倍率でframe22へ使う。

判定は実画像の剣先・掌・翼の位置を個別にNativeStrikesでワールド座標へ変換する。ジャブ3は剣を後ろへ引いた掌の光、横強・横スマは翼の斬撃。近接の手元の穴は共通MeleeBalance.coverageを一度だけ適用する。光線と遠隔の柱へ近接補正は掛けない。

抽出後の素材0/9は凸側が右、2は上、3は下。斜めのジャブ2は剣の実線分に沿って回転し、その後に左右反転する。上強と空上は頭上の弧を1本、上スマは曲線ではない結晶柱を使う。前後・上下・両向きのゲーム描画を確認した。

選択画像は独立した1536×1024の顔・肩の描き下ろし。crop=[280,35,1120,800]で冠と頭部を残し、羽・流れる髪の外周は通常の胸像としてフレームから出す。冠の頂点と頭部の左右の位置を実カード座標で確認し、PC3解像度・5色を検証した。

全12回の正確なプロンプトと元生成ファイルはart-generation.json。方式はbuilt-in image_gen。素材と検証結果のパスはverification-2026-10-31.jsonに記録する。
