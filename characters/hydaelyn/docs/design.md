# ハイデリン：固有能力・操作と対処

FFXIVのハイデリン。成人の神秘的な顔、長い銀白髪、青いクリスタルの冠、白銀の装束、広い羽翼、結晶剣。元シートの高い頭身を維持。

NB クリスタルレイ：翼を集めて直線の光線。12F以降の保持で集光し、離して発射。自分のクリスタルを通ると、その設置を消費して光線を強化する。飛び道具の判定で、近接補正を掛けない。
横B ウィングラッシュ：最初は羽の光を自分のクリスタルへ走らせる。準備中の本人はその場に留まり、離してから必殺を押し直すと、その目印へ翼で飛んで斬る。目印の破壊やガード解除でフェイントになる。設置の有無と再入力の判断で移動先と攻撃機会が変わり、通常の横突進と区別する。
上B アセンション：足元の光の輪に乗り、保持中だけ輪が上昇する。本人を左右へ動かして輪を離れる／必殺を離すと有限の滑空へ切り替わる。クリスタルがあるとそちらの上空へ輪を寄せられる。輪は相手の攻撃で壊れるため、乗り続けるか早く降りるか選ぶ。連続の二段攻撃にはしない。真下からは先にステージ横へ抜ける。
下B ハイデリンクリスタル：方向入力で光の紋章を置き、予告の後に光柱が出る。残った結晶は最大2個、有限時間。NBの強化、横Bの行き先、上Bの横位置を支える。結晶は敵の攻撃で壊れる。
相手は予告の紋章から出る、光線を盾やジャンプで避ける、再入力前の本人へ攻撃する、支点や昇降する光の輪を壊す。羽によるジャンプ長押し浮遊は有限90F、着地/崖/復活で回復し、空中の技切替で回復しない。

全身の固定ポーズと専用の予備動作・戻りを制作。関節リグを使わない。近接判定はMeleeBalance.coverageとNativeStrikesを経由し、武器先端と密着を両向きで確認。飛び道具・遠隔設置は近接補正の対象外。選択用は別制作の高解像度の顔・肩。画像生成が拒否された場合はそのキャラの作業を直ちに停止し、再試行や切り抜きで継続しない。
