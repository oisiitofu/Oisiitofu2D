# ハイデリンの専用リミットブレイク

飛翔しながら剣と光で相手を前後から押さえ、氷晶・波・光の順で攻撃。画角を引いてマザークリスタルを見せ、エクソダスの光を下から放つ。既存の翼・結晶・白衣を通して保つ。クライヴの着地から立ち上がる火柱に対し、この演出では上空の本人と床の結晶を別々に追う。

改修では対戦用の全身素材と選択肖像から白い翼と衣装、青い結晶の冠、剣を参照した。組み込みImageGenで、翼を広げてマザークリスタルの光を導く横長カットイン、星海の背景、浮かぶマザークリスタル、光の斬撃・結晶の着弾・光柱と波を制作した。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-crystal.webp`、`assets/limit-effects.webp` に収録。溜めで画角を引き、床から伸びるエクソダスの光柱と上空の本人を別々に追えるようにする。
