# エルザ実装

- アキラの直後。サイズ3・98px、重量99。ユーザーの頭身修正を優先し、原作立ち絵の約7頭身の成人比率で基本・攻撃・必殺・防御・中間の全身を制作し直した。初期の小さい頭身の画像はゲームに登録しない。専用高解像度選択画像、76全身画像、16FX、5カラー。
- NBは構えを解放して剣の連撃。横Bは投射する鎖が命中した時だけ引き寄せて上方向の斬りへつなぐ。実つかみの所有権を使わず、ガードへ拘束を付けない。近い崖へ掛かった場合は鎖を巻き取る。
- 上Bは一度のフリップ斬りと鎖による崖への寄せ。攻撃追加入力で急降下できるが、追加の上昇を付けない。有限時間で落下へ戻り、着地まで再使用できない。
- 下Bはギャザリングの円を一個設置。対応する決定論的飛び道具が円に触れると一個だけ吸収して蓄え、円を通す鎖は射程を延長し、円へ届くNBは一度の風の追撃を出して消費する。相手の近接を防ぐ無敵・常時アーマーは付けない。
- CPUもギャザリングを設置して鎖・剣につなぐ。通常投げは剣キャラの役割へ登録する。
- 元立ち姿の正規化は全身の左右反転だけとし、原画像の頭・脚・胴の比率は変更しない。中間姿勢は全身画像、関節リグなし。斬撃FX0の凸側は右、上攻撃FX1の凸側は上。鎖と領域を曲線へ取り違えない。
- 専用87項目（近接の密着/先端とフリップ斬りの両向きを含む）、通常/連続姿勢/左右/カラー75場面、必殺14場面、CPU2試合、2クライアント331フレーム一致。公開時には追加3人と変更箇所を中心に確認する。
