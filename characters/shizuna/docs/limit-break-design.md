# シズナの専用リミットブレイク

『黎の軌跡』の黒神一刀流と漆黒の大太刀を軸に、相手を追って横断する動きより、間合いをわずかに外して斬り返す動きを見せる。受ける直前に肩と前足を引き、刀の峰で相手を逸らす。斜め後ろへ一歩すべり、石の上に片足を乗せ、相手が通り過ぎるところへ低い斬撃を通す。残像を消した短い静止から黒い大太刀を振り上げ、広い引きの画で相手と刃が離れてから一拍おいて「皇技・零月一閃」の裂け目を開き、桃色の花びらを散らす。リィンの覚醒と騎神の重さに対し、シズナは一人のまま微細な体重移動と斬撃の間を見せる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中6ヒット、決め技26ダメージ。前足を引く受け流し、石段を使った切り返し、斬撃と裂け目の間の静止、皇技・零月一閃の花びらを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
