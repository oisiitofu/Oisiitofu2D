# サクナヒメの専用リミットブレイク

対戦用の `assets/sakuna-atlas.png` を参照し、濃い紫の輪に結った髪と赤い髪紐、金縁の赤い上衣、藍の袴、クリーム色の羽衣、農具を全身姿勢とカットインで照合する。

羽衣で足場に掛かり、軸を中心に振り子のように加速する。最初は空中で農具を当て、次に羽衣で相手を引き寄せ、足場の裏へ放って跳ね返す。最後は高所から農具を振り下ろし、地面を走る衝撃波まで引きの画で見せる。レイトン教授が階段上で機構を操作する構成に対し、羽衣の接点と本人の弧、引き寄せと投げの向きを連続して追えるようにする。

- [天穂のサクナヒメ 公式アクション](https://www.marv.jp/special/game/sakuna/action/)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。対戦用の髪型、羽衣、赤い衣装と農具を維持し、振り子移動、引き寄せ、投げと鍬の振り下ろしを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
