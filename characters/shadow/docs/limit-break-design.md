# シャドウ：カオスコントロールとスーパー化

状態：実装し、Sites v331へ公開済み。公開描画・発動・トレモ・専用音・代表通信同期を確認済み。

## 原作とデザイン

通常形態は既存 selection / actions の黒い体・赤い針のライン・赤い瞳・白い胸毛・白い手袋・金のリング・赤白黒のエアシューズと頭身を維持する。スーパーシャドウは公式グッズ紹介の実物写真と説明を確認し、ソニックの黄色いゴールドとは異なるプラチナゴールド、赤いライン、赤い目を基準にする。通常形態の顔と体格も維持し、単なる全画像の色調変更で済ませず専用全身動作を制作する。

## 動線と専用動作

ウィルの連続上昇下降、アレインの円周、鞍部の重量級兵装連携と区別する。シャドウは時間停止を起点に、直線移動の反復でなく消失→異なる位置・姿勢で出現する瞬間移動でリズムを作る。靴の踏み込み、蹴りの回転、瞬間移動の溜め、放つ手の姿勢をそれぞれ分ける。

1. エメラルドを掲げて時空を固定。相手は同じ位置で凍結し、背景の流れを止める。
2. 相手の手前下側、背後上側、正面上側へ異なる順で瞬間移動し、蹴り・反転・カオススピアをつなぐ。左から同じ攻撃を並べない。
3. 手足を開く覚醒姿勢からスーパー化。全身と赤い目が読める短い停止を置く。
4. 空中で放射するカオススピア、身体を反らして反動を受ける姿勢、両手へ力を集める溜めを制作。
5. 相手の近くへ再出現し、カオスの力を解放。時間再開に合わせて決め技と吹っ飛びを見せ、浮遊の余韻で終了する。

これは既存能力を組み合わせた本ゲームの専用演出。原作の特定カットを完全再現したとは断定しない。主攻撃・命中火花は art.strike、覚醒・時間停止の残光は art.glow。カットインは共通描画で比率を守る。既存の通常技・カオスブーストと上Bの挙動は変更しない。

## 検証予定

瞬間移動の前後で本人と相手の位置を追えるか、毎回異なる全身姿勢か、時間停止・スーパー化・時間再開の区切りが見えるかを連続再生で確認する。対戦・トレモ・両向き・カットイン比率・濃い主攻撃・専用音・CPU各1戦・代表オンライン同期を確認し、公開後にも配信ハッシュと実発動を確認する。

## 実装とローカル検証

専用画像6点（通常8姿勢・スーパー4姿勢、カットイン、背景、攻撃4素材）と専用効果音2点を実装。時間停止中は背景を抑えて相手の姿勢を固定し、正面の蹴り→背後上からの奇襲→前方のカオススピア→スーパー化→左右の空中射撃→チャージ→カオスブラストと構成。途中5回×3ダメージ、最後25ダメージ。相手は専用場面だけ2.3倍で描き、位置を追いやすくした。ローカル同期397フレーム一致。CPU各1戦のうちシャドウは実際の撃墜で結果へ進行。
