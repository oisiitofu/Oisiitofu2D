# ナチュレのリミットブレイク

『新・光神話 パルテナの鏡』第11章でナチュレが初期化爆弾を落とし、戦場が森に変わる場面を再構成した。つるで相手を足止めし、上空に引いたカメラで巨大な種の落下を見せる。着弾すると根が地面を突き破り、花びらと衝撃波の向こうで砦が森へ変わる。

砦と森林の背景はカメラの位置をそろえ、爆発の前後で建物と地形を比較できるようにした。ナチュレの姿、杖、種の造形にはユーザーの参考シートを使い、原作場面の着弾色も参照した。 [任天堂の開発インタビュー](https://iwataasks.nintendo.com/interviews/3ds/kidicarus/0/5/) · [原作の着弾場面](https://www.ssbwiki.com/File:Reset_Bomb_Uprising.jpg)
