ACSは被ダメージ×2で蓄積、90F被弾がなければ1Fに0.6回復。満タンで次の吹っ飛び硬直に12Fを一度だけ追加してゲージを消費。45Fは再発動しない。EDFのダメージのみの射撃など、吹っ飛びがない攻撃だけで硬直を強制しない。撃墜でゲージと再使用待ちを解除する。

## 描画

エフェクトは右へ進む向きの素材。ローカルX反転→回転で、前後上下の判定や弾の速度に合わせる。ブレードは青い弧、キック・打撃は金属の火花、上昇は足元の噴射、ミサイルは弾体と爆発を分ける。選択画面とHUDには同じ専用肖像を使用。
