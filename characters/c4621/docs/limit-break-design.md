# C4-621の専用リミットブレイク

対戦用の白灰の装甲、肩部ミサイル、ライフル、青い左腕ブレードを維持する。肩のミサイルを斜め上から迂回させながら、低いクイックブーストで回避。逆噴射して足を止めた状態でライフルを撃ち、相手がスタッガーした瞬間に片膝から踏み込む。最後は左腕の青いブレードを突き上げ、全身を引きの画で見せる。アドルは板で滑走を続けるが、621は噴射の向き、慣性を止める時間、ミサイルと本体の交差を見せる。

- [公式 AC6のブーストとスタッガー](https://armoredcore6.bn-ent.net/en/information/?p=22)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中7ヒット、決め技26ダメージ。青灰色の機体と武装の配置を維持し、射撃、制動、旋回と青いブレードを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
