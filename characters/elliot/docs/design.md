# エリオットと妖精フェイ：制作前の固有技設計

添付eriotto.pngを基準に、赤い羽根付きの帽子、明るい髪、赤い長いスカーフ、白灰の冒険服、黒いブーツ、剣と青い丸盾を保つ。自然な頭身、男性サイズ3・98px。オディオodioの直後。フェイは淡い金髪と青白い服・透き通る羽の小さな妖精。専用の高解像度選択画像はエリオットの顔・肩を主に、帽子・羽根の見切れを避けてフェイを添える。

## 固有能力と相棒の動作

フェイは全身の独立した待機・羽ばたき・弓を構える・射撃・持ち上げ・帰還／休みの画像で追従する。エリオットの各アクションで反応し、NBの発射位置、横Bの移動支点、上Bの復帰を実際に担当する。本人の各画像へ固定的に貼り付けず、位置・指令・移動・帰還・忙しさを同期する。フェイは一体のみ。

- NB「フェイの加護」：フェイに光の矢を撃たせる。下Bの地図目印があればそこまで飛んでから構え、なければ本人の近くで構える。方向で狙い、保持を離すと妖精の実際の位置から発射。目印が育っていれば矢を少し強化。移動・構え・発射・戻る姿勢を分け、発射待ちには予告を見せる。
- 横B「突進斬り」：まずフェイだけが選んだ目印（なければ前方の指定点）へ飛び、光の支点を作る。到着を待って必殺を離して押し直すと、エリオットが支点へ向かって一度の斬りを伴って移動する。支点が壊された／本人が割り込まれたら成功しない。準備せず横へ走るだけの汎用突進にはしない。フェイを前へ出すか、近くに残して復帰へ備えるかを選ぶ。
- 上B「飛翔の加護」：離れたフェイを先に呼び戻してから、妖精が上へ運ぶ。必殺保持中の方向で経路を曲げ、離すと手を離して終了。最大42F、同じ滞空で一度。フェイが遠いほど呼び戻しが遅れ、位置の準備が復帰に影響する。攻撃を押して途中で降りる選択もできるが、自動の二段攻撃にはしない。真下では先に横へ抜け、壁を貫通しない。エリオットの基本状態へ飛行や追加ジャンプを付けず、妖精による固有復帰を使う。
- 下B「千年の知識」：方向で場所を決め、有限の地図目印を置く。最大2つ、再設置で古いものを消す。フェイは選ばれた目印をNB／横Bの出発点に使う。相手の攻撃で地図を壊せる。目印と妖精の位置を見て、横Bの支点・遠隔の矢・呼び戻しに必要な時間を判断する。

相手は地図を壊す、妖精の構えや光の支点を読む、離れたフェイを呼ぶ間に本人を攻撃する、という対処ができる。妖精を増殖させたり、技の切替で復帰予算を回復させたりしない。被弾硬直・ヒットストップ・吹っ飛び予約を特殊移動で消さない。

## 描画・判定

エリオットの通常15技は剣の斬り・突き、盾押し、足払い、空中の方向別剣技を別の全身画像にする。各技ごとに全身の予備動作・戻りを制作し、基本待機・固定攻撃画像を保持。関節リグは使わない。フェイの補助は常に独立した全身画像で描く。鎌や剣の凸側と実画像の接触点を確認し、近接補正は本人の直接攻撃に一回のみ。光の矢・目印・フェイの指令範囲へ掛けない。

通常投げはblade、前後は位置変更、上は高％の撃墜、下は追撃。攻撃上がりは専用の弱い単発・44F。PCの選択画像、左右の密着／先端、左右・真下の復帰、相棒位置と指令の連続動作、CPU1〜2戦と短いオンライン同期を確認する。
