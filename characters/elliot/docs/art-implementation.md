# エリオット／妖精フェイの画像実装

制作は built-in `image_gen` のみ。添付元 `C:/Users/haro_/Downloads/AI/eriotto.png` を直接参照し、赤い羽根付き帽子、明るい髪、赤いスカーフ、白灰の冒険服、青い丸盾と剣、自然な男性の頭身を保持。元PNG・全プロンプト・生成先・保存先・SHA256は `generation-*.json`、`asset-prompts.json`、`../tests/source-records.json` に保存した。

`../assets/elliot-native.png` は2560×6941、全身106枚と専用高解像度ポートレート106番、独立FX16枚。エリオット全身にはフェイを貼り込んでいない。フェイはFX4～9の独立した全身6枚（待機／羽ばたき／弓構え／射撃／持ち上げ／帰還・休み）。身体・羽・足先は各画像内に収まる。本人69番も妖精に持ち上げられる全身姿勢で、本人に羽は付けない。

基本0～15、固定接触16～30、必殺31～45、防御・リアクション46～60、投げ等61～75、予備76～90、戻り91～105。通常技の元待機と15接触画像は、中間画像の最初の生成前に固定済み。欠けていた上スマ／空上の剣は固定前に専用補完画像で完成させた。以後は固定画像を再生成していない。`originals-lock.json` と `art-test.cjs` はアトラスのRGBAが固定画像と完全一致することを確認する。アトラスの梱包はRGBAの直接コピーで行い、合成時の半透明RGBの再丸めを防いだ。

各シートは共有待機から1つだけ倍率を決め、全ポーズに同じ倍率を適用。ポーズごとの高さ合わせ、関節・部品リグ、縦横比の変形は行わない。`sourcePoses` は生成時に省略されたセルを暗黙にずらさず明示対応する。必殺の矢指令後の33番はシート内の待機へ戻る姿勢、上強の予備80番は別途描いた専用の全身画像。

全106枚の腰／骨盤の接続点を `source-anatomy.json` に記録。水平値が `ElliotArtRects.anchors`、足底の透過余白が `pads`。崖55番の実際に上げたグローブは normalized `[0.167,0.032]`、腰軸0.27に対する `grip=[-0.103,0.968]`。盾・剣・帽子・スカーフの外形中央を身体軸として使わない。

接触点16～44は `native-points.json`。盾接触は19／22／25、足払いは21。16番の上向きジャブは実画像の剣が拳から左上へ伸びるため、前右向きと仮定しない。`rising-jab-edge.json` と `previews/elliot/rising-jab-edge.png` が実際の剣先・拳・切断面を示す。時間軌道の参照は76→16→91。

FX0の凸側は右、2は上、3は下、矢10は右。まず素材のこのローカル向きを基準に回転し、その後キャラの左右向きへ反転する。上攻撃の弧は2の一つの広い曲線、下は3、後方へは0を後ろへ向ける。盾／足の接触へ斬撃を無条件に使わない。透過の青い魔法円13は薄いリングを保持するため専用の可視範囲から元アルファをそのまま保持した。

選択106番は小さい全身画像の拡大ではなく、顔と肩を中心に一枚で制作した専用画像。帽子の羽先・帽子・添えたフェイの羽と足を保持。ポートレートには24px以上の上余白を加え、128pxでの確認画像を `previews/elliot/selection-small.png` に保存。

検証はルートで `node characters/elliot/tests/art-test.cjs`。107／16枚、透明画素と可視画素、アトラス範囲、固定画像の完全一致、15接触の個別性、30全身中間画像、6枚のフェイの個別性、106身体軸、実グローブの崖接触、生成元PNGのバイト保持を確認。ゲーム上の技・描画・操作・CPU・同期・公開の検証は親担当が続ける。
