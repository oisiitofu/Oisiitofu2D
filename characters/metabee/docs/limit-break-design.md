# メタビーの専用リミットブレイク

対戦用の `assets/metabee-native.png` を参照し、黄色の装甲、黒い顔と緑の目、頭の二本の砲口、左右の腕の砲、白い胸とつま先を照合する。

メダフォースの一斉射撃を元にする。スライドしながら片腕で撃ち、反動で後方へ回って着地する。片膝をついた状態で腕の追撃を止め、両足を踏ん張って両腕と頭の砲を順にそろえ、最後に全弾を相手の位置へ集中させる。ラハールの上空での岩の乗り継ぎに対し、銃口が向く方向、射撃間の姿勢の切り替え、地面へ伝わる反動を見せる。

- [メダロット公式 メタビーのパーツ](https://www.medarotsha.jp/classics/pdf/medarot1-kabuto.pdf)
- [メダロットG公式 一斉射撃](https://www.medarotsha.jp/classics_plus/pdf/medarot_g-kabuto.pdf)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。対戦用の黄色い装甲と頭・腕の砲を維持し、片膝の着地、砲口の切り替えと一斉射撃を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
