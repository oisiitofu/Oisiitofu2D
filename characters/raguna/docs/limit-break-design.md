# ラグナの専用リミットブレイク

対戦用の全身素材 `assets/raguna-native.png` を基準にする。茶髪、青い目、革装備、白い幾何学模様の赤茶色の腰布、丸盾と片手剣を通常形態とカットインで照合する。技中に杖を取り出す区間は対戦中のルーンファイア姿勢を参照する。

農作とルーン、武器・魔法の戦闘をつないだゲーム独自演出。盾で押し返し、石畳から畑の畝へ後退しながら二箇所にルーンを置く。円弧に沿って走って畝を切り替え、芽吹きで相手を押し上げ、片手剣から杖へ持ち替えてルーンファイアを交差させる。サクナヒメの羽衣を支点とする空中運動に対し、ラグナ自身は畑に足をつけ、畝と設置位置を高めのカメラで見せる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。対戦用の革装備、腰布、盾と剣を維持し、畝への設置、芽吹き、杖のルーンファイアを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
