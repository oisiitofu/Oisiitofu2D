# ラグナ — 剣・農具・RP・仲間

鬼助の次。人型サイズ3（98px）。原画の茶髪/青い瞳、赤茶の刺繍入り裾、肩の革防具を保持する。立ち姿を固定し、全身の中割りと技別の姿勢を使用する。関節リグは使用しない。選択/紹介/勝利は専用の高解像度上半身画像。

- NB ルーンファイア: RP12を消費して火球。RP不足では小さい火花。初期発射は単発、長押しで段数を増やさない。火球が耕地を通ると作物の収穫を進める。
- 横B モンスター連携: 22RPでモコモコを呼び、ラグナ自身は移動せず行動可能へ戻る。再度横Bで方向を指示し、地上は転がり、上方向は山なりの飛びかかり。呼び出し直後は待機するため相手は距離を変えて避けられる。1体、1回の指示で退場。空中の召喚は着地するまで攻撃しない。
- 上B 旋風跳躍: 固定中心の風の渦を発生し、その周りを上昇。通常の直線上昇/自由飛行ではない。最初に中心を固定し、左右入力で渦の横断位置を変える。Bを離す/ジャンプで渦から指定方向へ飛び出す（攻撃せず復帰の位置を優先）。長押しには有限時間があり、上昇後の剣の一振りだけが近接判定。RPで渦の持続が変わるがRP0でも復帰可能。ステージ下は有限の横脱出後に中心を作る。
- 下B 大地のハンマー: 大振りのハンマーで地面を叩き、近接1窓と前方の地面衝撃。耕地を1か所作り、NBの火球が通るとルーンの実を生成。自分で回収すればRP回復、敵が耕地を踏めば壊せる。空中版は着地してから耕地を作る。空中で無制限に設置しない。
- RP上限100。通常の剣/農具の命中で少量回収、耕地の収穫で18回復、時間で緩やかに回復。投げや遠隔物でRPを無制限に増殖しない。
- スマッシュは剣/斧/鎌を使い分ける。攻撃の前後/上下と斜めを実画像で確認し、凸側を相手へ向ける。近接だけ共通coverageを一度適用。

検証はラグナの密着/先端・特殊技・RP・召喚/収穫・場外復帰を中心にする。CPU1〜2戦、短いオンライン代表場面、サイズ一覧とホーム更新履歴、公開後の表示/主要技を確認する。
