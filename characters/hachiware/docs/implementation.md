# ハチワレ

- ちいかわの次。専用の高解像度な顔・肩の選択画像、77枚の全身画像、16種のエフェクト。
- 元の待機姿勢は `assets/hachiware-neutral-locked.png` に固定。体の可視高さ76pxを基準にし、さすまたの長さで身体が縮まない。白い体・顔・頬を維持し、青い部分だけ5色へ変更。
- NBは短い直接突き、32F以上保持で全力突き。横Bは跳躍→急降下→地面に接触すると跳ねて突進。空振りは有限時間で落下へ戻り、空中連打不可。
- 上Bはさすまたの支点を巡る弧から飛び出す。専用しりもち姿勢で終了し、横慣性操作は可能。ステージ下からの脱出・左右の崖復帰を確認。
- 下Bはカメラの単発フラッシュ。30F以上保持で範囲と威力を強化。光の範囲で1回だけ命中し、近接武器の補正は適用しない。
- 通常15技はそれぞれ別の全身画像。空Nはさすまたを持ち上げて振る動きと非対称の軌跡。上スマッシュは頭上へ振り上げる専用画像へ修正。
- 元画像の凸側を実画像で確認。0は右、1は上、3の打撃先端は左なのでローカル反転。回転→キャラの左右反転の順。既存素材は変更しない。

検証：専用動作98項目、通常30場面、必殺28場面、待機左右5色、60サンプルの連続映像、CPU戦1回、77姿勢/16エフェクト/385カラー画像の読み込み検査。オンラインと公開版確認は今回の追加3キャラをまとめて実施する。

画像制作は組み込みimagegenを使用。各元画像とプロンプトは `assets/`・`docs/image-prompts.json` に保存。
