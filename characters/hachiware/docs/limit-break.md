# ハチワレの専用リミットブレイク

対戦用の白と青の毛色と青いさすまたを使用する。走って先端で相手を押し返し、さすまたを支点に跳ぶ。高い位置から振り下ろし、着地したら相手の横でカメラを構えて一瞬のフラッシュ。フラッシュの後、小さく退いてから全力で踏み込み「なんとかなれッ!!」を当てる。ちいかわの演出で行う二人の押し出しと区別し、本人による進退、上方向の技、カメラの間を使う。

改修では、対戦素材の丸い体、青い耳と尾、ピンクの頬、青いさすまたを参照し、カメラが光る草原でさすまたを手前へ突き出す横長のカットインを描き起こした。組み込みのImageGenに草原、風の軌跡、打撃火花、カメラの閃光、草を巻き上げる白青の衝撃波を指定し、`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-effects.webp` に収録。決め技の命中点を金色の火花で示し、衝撃波の広がりで相手の飛ぶ方向を見せる。
