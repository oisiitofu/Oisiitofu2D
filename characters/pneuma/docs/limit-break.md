# 専用リミットブレイク

対戦時のプネウマの姿で始め、空中の光点を順に通過しながら剣を返す。機体を切り替えるハナと区別し、同じ外見で一度大きく上昇してからインフィニットブレイドの斬り下ろしへ入る。[原作のLv.IV必殺技の実機映像](https://www.youtube.com/watch?v=aChUnByxDgI)

緑の長髪、白・黒・金の装甲、宝石と刃を対戦素材で確認し、空中で剣を構える横長カットインを ImageGen で制作した。軌道施設を背景に、連撃の位置を示す立体の結晶が剣へ集まる。決め技は画面の上側から斜め下の相手を貫き、引いた画面で射線と着弾後の破片を見せる。

配信素材は `assets/limit-cutin.webp`、`assets/limit-orbit.webp`、`assets/limit-effects.webp`、`assets/limit-prisms.webp`。
