# イヴの専用リミットブレイク

緑と白の対戦用スーツ、長いポニーテール、ブラッドエッジを通常形態の全身姿勢とカットインに使う。タキモード区間は対戦用に制作された黒とマゼンタの装備を参照し、最後は通常スーツへ戻す。

タキモードは梁を蹴った後の演出194フレーム目から。黒い装備とマゼンタの刃を区間全体でそろえるため、一部の空中姿勢は既存の `assets/eve-tachy.png` の全身フレームを使用する。最後は通常スーツの構えへ戻る。

低い構えで受け流し、後方へブリンクして追撃。崩れた梁を蹴って反転し、空中でタキモードへ移る。降下と同時に斬撃を二方向から重ね、着地後に地面へ刃を通して締める。星見雅の納刀と地上の静止に対し、梁への接地、空中の反転とフォーム切り替えを追えるカメラにする。

- [PlayStation公式 ブリンクとバーストスキル](https://www.playstation.com/en-us/games/stellar-blade/stellar-blade-beginners-guide-to-combat/)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。通常スーツからブリンクと梁の反転を経てタキモードに入り、着地後に通常スーツへ戻る描画を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
