# グランの専用リミットブレイク

対戦用の `assets/gran-native.png` を参照し、茶髪、銀色の鎧、青いフードと腰布、茶色のズボン、金の鍔の直剣を照合する。

テンペストブレードから解放奥義カタストロフィへつなげる。騎空艇の甲板で剣を切り返し、跳び越えるのでなく、風を受けて片足で滑りながら横の間合いを開ける。甲板奥へ剣を向けるとバハムートが雲を割って現れ、グランが踏み込むのと同時に斬撃と光線が相手の位置で交わる。ラグナの畝の設置と遅れて発生する魔法に対し、剣の切り返しと甲板奥から来る召喚を一つの画面に収める。

- [グランブルーファンタジー ヴァーサス公式技一覧](https://versus.granbluefantasy.jp/campaign/assets/common/pdf/gbvs_instructioncard_ver220730.pdf)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。青いフードと銀色の鎧、金の鍔の剣を対戦素材に合わせ、甲板での切り返しとカタストロフィを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
