# グラン

Tier3 / 98px。15通常技・スマッシュ・空中技は別の全身ラスターポーズ。関節リグは使用しない。0番の承認済み待機のデザインを固定し、追加シートの等身を基準待機で合わせる。

## 必殺技

- NB レギンレイヴ：9F以降離して放つ。25F以上で幅広い多段波、48F自動解放。最大2発だけ場に残せる。強化波は接触時減速し、4Fごと2/2/9ダメージの最大3段。初めの2段は追加ヒットストップ/吹っ飛びを発生させず、最後で打ち上げる。弾の待ち時間制限は近接技には適用しない。空中で溜めて着地しても継続。
- 横B デシメート：その場で8〜12F、18〜23Fの二連斬。22〜30Fの必殺再入力で34〜41Fの切り上げへ派生。位置を飛ばさず、斬り合いで追加入力を判断する。空振りでも派生できるが追加後隙あり。
- 上B ライジングソード→オーバードライブ：8Fまで空中慣性を止め、斬り上げで上昇。頂点で18F目に左右と上成分を読み、折返し斬りで別の方向へ移動。ワープも無敵もなし。真下の地形からは側面へ逃がして復帰。終了後は36番の尻もち画像へ直接移行し、共通の横移動を維持。
- 下B パワーレイズ：長押し15Fごとに強化ゲージ1段階、最大4。離すか68Fで終了。ガード/攻撃判定/無敵なし。攻撃命中と被弾でも少し溜まる。
- エディプトアーツ：25ポイントごとにLv1、最大100/Lv4。NB/横B/上B発動時に現在の段階を消費し、その技の威力を1段階13%増加。強化弾はサイズも増す。通常攻撃は消費せず溜められる。
