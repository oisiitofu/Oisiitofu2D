# チョコボのデザイン復元（2026-10-12）

初回の中間アニメーションは、生成したパーツの頭・首・胴・脚の比率が元デザインと異なっていた。ユーザーから首が長く立ち姿が変わったと指摘されたため、リグ描画と部位の読み込みを撤回した。

現在は強化前の43ポーズ・5カラーを使用する。待機だけを元絵へ戻す方式ではなく、移動・攻撃・空中・防御・被弾・崖をすべて元素材で表示し、動作の開始時に異なる体型へ切り替わらないようにした。発生・持続・硬直、威力、入力、当たり判定、エフェクトは変更していない。

初回の生成パーツとプロンプトは比較資料として残しているが、ゲームや公開バンドルからは読み込まない。再制作する際は元の待機画像を寸法とシルエットの基準にする。初回に行った「生成パーツの骨長が一定」という検証だけでは、元デザインの維持を保証できなかった。

## 今回の確認

- 元の43ポーズ・8エフェクト・5カラー・選択画像のチェックサムを維持。
- 実描画の待機姿勢を元の立ち絵と左右・5カラー・5時点でピクセル比較。
- 全攻撃の開始から終了、移動・空中・ガード・回避・被弾・崖で元素材だけが描画されることを確認。
- 専用描画テスト2,888項目、動作テスト89項目、2クライアント同期104項目が成功。
- 全113形態のサイズ114,063項目が成功。アート5,277ポーズ・932エフェクト・26,385カラー画像も差分なし。
- 比較画像は previews/stance-before-fix.png と previews/stance-restored.png（Git管理外）。

チョコボのアニメーション強化は完了扱いを取り消した。次のキャラへ自動で進まない。元デザインの維持を満たす形で作り直す必要がある。

node characters/chocobo/tests/chocobo-animation-test.cjs
node characters/chocobo/tests/chocobo-test.cjs
node characters/chocobo/tests/chocobo-online-test.cjs
