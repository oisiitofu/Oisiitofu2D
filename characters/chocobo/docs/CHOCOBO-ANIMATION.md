# チョコボの元の立ち姿を基準にしたアニメーション（2026-10-12）

初回に生成した部位は首・頭身が元デザインから変わったため撤回した。今回の基準は元の立ち絵 frame 0（213×240px）。頭・短い首・胴を同じ骨で動かし、元画像の羽・尾・脚を独立した関節で動かす。頭の交換、首の伸縮、動作時だけの全体拡縮を行わない。待機は元の画像をそのまま描き、地上攻撃の開始・終了も同じ画像へ戻る。

## 描画

- 歩行32F・走行18Fの周期、蹴り・羽の打撃、空中回転、羽ばたき、予備動作と戻りを連続した関節姿勢で描く。脚は固定長の2本の骨で解く。
- 発生・持続・硬直は既存の CombatData の区間を参照する。多段は段間のためを挟む。攻撃の威力・判定・入力・CPU・物理データは変更しない。
- ジャンプ・着地・ガード・回避・被弾・ダウン・起き上がり・つかみ・投げ・崖に対応。崖は元の爪位置を左右とも接地点へ合わせる。ダウンと起き上がりは画像の透過部分を除いた輪郭を使って接地する。
- 黒魔道士へ変わる下必殺の衣装と専用ポーズ40〜42は元の描画を維持する。この衣装には今回の通常体型用の関節を流用しない。
- 元の43ポーズ・8エフェクト・選択画像・5カラーのチェックサムは維持。羽を開いたときに隠れていた胴だけを built-in image_gen で補完し、44番目のフレームとして増分で事前生成する。元から見えていた革具・胸・腹・頭・首は元画像を上に描く。胴の小さな描画用画像はカラー別にキャッシュし、毎フレーム大画像を縮小しない。
- 初回の v1 パーツ・プロンプトは比較資料として残すがゲームでは読み込まない。今回の補完画像と最終プロンプトは assets/chocobo-torso-underpaint-v2.png と assets/chocobo-animation-prompts-v2.json。

## 検証

- 専用アニメーション9,708項目：元の待機とのピクセル一致（左右・5カラー・5時点）、攻撃開始・終了、元の頭・首の剛体変換、固定骨長、実際の画像の縦横比、各攻撃の中間姿勢、発生・持続区間、接地・崖の爪、ヒットストップ、シミュレーション時間だけで決まる姿勢。
- 動作89項目、実際の2クライアント同期104項目。同期比較には中間姿勢も含める。
- 全113形態のサイズと通常・空中攻撃41,913フレームを確認。サイズ検査は2引数の原寸画像描画も測定し、部位の剛体変換を検査対象に含めた。
- 全113形態の行動可能フレーム16,922項目を維持。
- アート5,278ポーズ・932エフェクト・26,390カラー画像の読み込み・透過・色を確認。元の43ポーズのハッシュも別途照合。
- CPU対戦はチョコボ対ちいかわ・スカポン・シズナの各1,800Fを実描画し、命中・被弾・回避・つかみなどで破綻がないことを確認。人間同士の勝率やキャラバランスの証明ではない。
- 連続画像と60fps動画は previews/chocobo-animation-contact-v2.png、chocobo-animation-v2.webm、chocobo-states-colors-v2.png（Git管理外）。4体の描画計測は画面を毎フレーム消去する実際の描画手順で行う。
