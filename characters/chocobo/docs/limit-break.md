# 専用リミットブレイク

低いチョコキックから足場へ跳ね上がり、地面へ急降下。斜面を駆け直して着地で呼び寄せるチョコメテオで締める。ホーネットが上から糸にぶら下がるのに対し、チョコボは足場と接地を使って速度を変える。 対戦用の全身と選択肖像を使用。

[スクウェア・エニックスのチョコメテオ紹介](https://eu.finalfantasy.com/topics/372)

## カットイン・攻撃素材の改修

黄色い羽毛、青い目、茶色の装具を参照し、隕石を背に足場を蹴る構図。峡谷の背景、羽の軌跡、土煙、燃える隕石を描き分けた。 カットイン・背景・攻撃素材はImageGenで新規制作。対戦と同じ全身素材を使用。

蹴りと羽の残光、砕ける隕石、火柱、地面に沿う砂の衝撃波の4枚を新規制作した。足場から高度を変える6連撃の後、カメラを引いて隕石の進行方向を見せ、着弾で寄ってから相手の吹っ飛びに合わせて引く。着弾点を峡谷の地面に固定し、火柱は相手の後ろに描く。カットインは元の比率を保つ。両向きの連撃間隔は16〜19フレーム。
