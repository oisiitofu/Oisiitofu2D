# リオンのリミットブレイク

PS2版『テイルズ オブ デスティニー』の「魔神煉獄殺」を題材に、シャルティエと短剣で上下の斬撃を刻む。地下の水路を背景に、踏み込みを寄りのカメラ、地面から噴き上がる闇を引きのカメラで描く。闇の裂け目から踏み込んだ一撃を最後の噴出につなげる。

途中は2・2・2・2・3・3ダメージ。最後に22ダメージと斜め上への吹っ飛びを適用する。
