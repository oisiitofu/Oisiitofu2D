# リオン・マグナス / Leon Magnus

テイルズ オブ デスティニーのリオンをエマの次に追加。IDはrion（既存のバイオハザードのleonとは別）、小柄な男性として人型サイズ2・94px。短い紫黒の髪、紺黒の金縁の鎧、灰色の裾、ピンクのマント、シャルティエと逆手ダガーを添付に合わせる。元画像はassets、専用data/art/vfxとtests、メモはdocs、検証画像はGit管理外のpreviews。

builtin image_genで通常/移動の全身48姿勢、必殺用の追加5姿勢、16FX、専用1536×1024上半身選択画像を制作。関節リグは使わず全身ラスターを切り替える。通常技15種は別の実画像。追加シートは立ち姿/歩きの同じポーズを校正用にして全身一律縮小し、元の0番の立ち姿は再生成しない。前方の横強には剣の先が前へ出る追加の踏み込み姿勢を採用し、通常技同士での実画像の使い回しを避ける。背後突き49だけ元画像が左向きなのでローカル右向きへ反転してから実際の向きを掛ける。崖用は上端の空いた手、2本の脚とブーツを確認。53全身＋ポートレートの54フレーム、マント中心の5カラー。高解像度の選択画像は専用生成し髪の頂点を補修、エマ/ルークの実カードに合わせて寄せた。正確な生成・補修プロンプトとモードは[image-prompts.json](image-prompts.json)。

- NB「魔神剣」：CC1を消費し11Fで地を進む8ダメージの波。18Fで長押ししていれば25Fに10ダメージの二発目「双牙」を追加する。1回の技で最大2発、長押しの追加消費なし。地形の端では波が落ちる。波の生存中と発射間隔28Fだけが再射出を制限し、近接技へクールダウンを広げない。波が実際に相手へ当たるとCC1を回復。同一cast tokenにつき1度だけで、双牙の両方が命中しても回復は合計1。ガードでは回復しない。
- 横B「幻影刃 → 月閃光」：CC1。8〜13Fの短い踏み込み斬りから16Fに近く185px/高低差75px以内の相手を確認し、背後58pxへ回り込んで振り向く。18〜22Fに逆方向へ斬る。相手がいない/離れた場合は移動だけで長距離ワープはしない。23〜35Fの再入力で月閃光の小さな跳躍と頭上への曲線へ派生する。空振り/相手の距離/再入力により用途が変わる。無敵や透明化を加えない。空中の再使用もCCがあれば可能。
- 上B「空襲剣 → 飛燕連刃」：CCがあれば1を消費。最初の7Fは落下慣性を止め、左右入力で方向を決めて二段で上昇する（6/7ダメージ）。上昇開始から22〜36Fの再入力で、入力方向へ飛ぶ空中連斬（10ダメージ）へ派生する。斜め移動と攻撃エフェクト/判定もその方向へ向ける。CC0では初段だけの控えめな緊急復帰版が使え、CCを負数にしない。真下からは既存の端へ抜ける復帰処理を使用。終了後は専用尻もち画像へ不透明なまま移行し、着地/崖まで次の上B不可。左右の場外から地上へ復帰可能。
- 下B「獣哮雷」：CC1。6〜26Fの構え中に14ダメージまでの攻撃を1回耐える。18Fで3秒間の効果を得て、その後の攻撃動作には8ダメージまでの軽い一撃を1回耐える効果を付ける。重い攻撃や連撃には突破され、ダメージ自体は受ける。反撃や飛び道具の自動発射はせず、魔法陣と青い粒子で状態を表示する。空中版も同じ効果。

CCは最大4、開始/復活時4。ヒットストップを除く90F（1.5秒）ごとに1回復し、最大時は時計を止める。CC0でも通常技は使用可。上Bの緊急版以外の必殺はCC1以上が必要。HUDに青い炎のアイコン4個、所持数と次の回復進捗を表示。オンラインは乱数やローカル時計を使わずフレーム/入力/命中から決定する。

曲線の実素材は0/2/4/5が右、1が上、7/13は下を凸側として確認。回転をローカルで行ってから左右反転する。上強/上スマ/空上は頭上の曲線1個、回転技は左右へ。AttackEffects.imageで可視の切断面を武器の先の最終判定へ合わせる。MeleeBalance.coverageは近接へ一度だけ適用し、魔神剣/つかみ/遠隔エフェクトには使わない。通常投げはbalancedの後ろ撃墜/上浮かせ/下追撃/前位置変更。専用の弱い単発攻撃上がりを保持。
