# タコガール

参照: ユーザー添付 `C:/Users/haro_/Downloads/takogirl.png`。元のピンクのタコ髪、ヘッドホン、黒い服、靴を維持した全身48ポーズとインク専用16素材。画像は built-in image_gen で作成。関節リグなし。待機から歩行・走行・各攻撃へ全身画像を切り替える。選択画像は待機の既存画素に透明余白を追加したもの。

制作プロンプト: 8列×6行の透明な全身アトラス、参照の頭身・顔・衣装・髪の寸法を維持、各セル完全な人物、文字・他キャラ・切れた武器・攻撃残像なし。生成後、背景抽出の指示でピンクの背景と崖の灰色壁のみ除去した。エフェクトは4列×4行、インクの右向き飛沫、上に凸の広い飛沫、チャクチの輪、銃口、ボム、弾、ローラー、タコ、上昇噴射、床インク、爆発、命中星、溜め渦、噴射軌跡、タンク、波紋。

NBは25インクを使う時限ボムで一個まで。横Bは地上を押し進むローラー、長押し中に少量ずつ消費し最大52F、離すと終了。単一の攻撃窓なので同じ相手への無限多段にはならない。上Bはインク不要のタコジャンプ、初期慣性を止めて23F上昇、左右へ誘導、後半は尻もち画像。下Bは35インクのチャクチ、地上なら一度上昇して急降下、着地時に単発の広いインク飛沫。インクは技終了後の待ち時間後に自然回復し、しゃがみ中は速い。

ボム以外の技に時間式の再使用待ちはない。横BとNBの違いは直接押し進む攻撃と、投げた後に自由に動ける設置爆発。復帰はインク不足でも使える。

元素材の方向: effects0の凸側は右。effects1の凸側は上。上強・上スマ・空上は頭上の広い飛沫一つに統一し、下から縦長の弧を足さない。身体と当たり判定の補正は共通MeleeBalanceのみ。画像の縦横比と元の足底を保つ。

生成済みファイル: assets/octoling-poses.png、octoling-effects.png、octoling-native.png、octoling-selection.png。再現用の切り出しは tests/assemble-art.cjs。統合用 metadata は tests/registration.json。
