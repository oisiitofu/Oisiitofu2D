# タコガールのリミットブレイク

『スプラトゥーン3 サイド・オーダー』の8号が、秩序の塔でカラーチップを集めて強化する仕組みを決め技にした。白い装備に切り替えた8号がインクを浴びせ、ヒメドローンにカラーチップが集まる。ドローンの音波と8号の追い撃ちが重なり、無彩色の足場にインクが広がる。

専用の全身姿勢とドローンの角度差分を用意した。ヒメドローンの王冠、白い十字の目、金色のボタンは任天堂の画像を参照した。 [『サイド・オーダー』公式サイト](https://www.nintendo.com/jp/switch/av5ja/sideorder/index.html) · [8号とヒメドローンの公式紹介](https://splatoon.nintendo.com/en/expansion-pass/)
