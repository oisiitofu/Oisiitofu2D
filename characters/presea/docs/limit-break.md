# プレセアの専用リミットブレイク

「緋焔滅焦陣」は、低い斧の軌道で始まり、跳び越えて逆方向へ振り下ろし、着地後は最初の打ちつけで地面に亀裂を作る。相手を追って階段を詰め続けるエーデルガルドと異なり、亀裂を目印に真上へ跳ね、二度目の打ちつけで同じ場所から岩と火柱を噴き上げる。[原作の技の実機映像](https://www.youtube.com/watch?v=AwmAxEpujF0)

対戦の桃色の髪と髪留め、紫と金の衣装、茶色の手甲と靴、銀の刃と真鍮の留め具がある両刃斧を参照した。ImageGen で採石場のカットイン、軌跡、石片、亀裂、火柱と、斧の接地から跳躍・振り下ろしへつなぐ三つの全身ポーズを制作した。標準カラーは専用ポーズ、別カラーは対応する対戦用全身ポーズで描く。

配信素材は `assets/limit-cutin.webp`、`assets/limit-quarry.webp`、`assets/limit-effects.webp`、`assets/limit-fault.webp`、`assets/limit-motion.webp`。決め技には着地音と岩の破裂を重ねた専用効果音を使う。
