# プレセア

コレットの次へ追加。人型1/78px、重量108。承認済み待機を固定し、全身77姿勢・16エフェクト・専用の顔と肩の高解像度画像を組み込みimagegenで制作。元画像とプロンプトはassets/とimage-prompts.jsonに保存。

- NBは地面の岩柱。溜めに応じて1/2/3段となる。空中では斧を落として着地後に発生。浮遊台の端は最初の岩柱を台上へ収め、それ以降は地面がある範囲だけ発生。
- 横Bは回転→空中上昇→方向を選ぶ急降下→着地薙ぎ払い。上昇中の再入力で降下を早める。空振りは有限時間で通常落下へ戻る。
- 上Bは弧を描く二段の斬り上げ。二段目は自動接続し、謎の浮遊待ちを挟まない。終了後は専用しりもち姿勢で左右操作可能。ステージ下の脱出と左右の復帰を確認。
- 下Bは地空陣。構え中は被ダメージ・吹っ飛びを0.65倍へ。軽い攻撃を耐えるが強い攻撃やつかみには崩される。上入力で構えから跳び出せる。攻撃判定はない。
- 空Nは大斧の重い旋回、前空中は振り下ろし、後空中は背面へ薙ぐ。上攻撃は頭上1つの弧。通常15技の画像・姿勢を比較。
- 原画で背面/上方の配置が違った空前・空後・空上を並べ替え。二段目ジャブは右へ切り返す専用画像へ。特殊シートの20コマから使用する16姿勢を明示して抽出。防御/追加シートの2か所の接触を1pxの分離線で切り分け、隣接ポーズの混入を除く。
- 斬撃素材0/2/10/15の凸側は右、1は上、11は下。打撃3は左向きなのでローカル反転。既存素材は変更しない。
