# キトゥンの専用リミットブレイク

『GRAVITY DAZE 2』の重力スタイル切替を使う。最初はノーマルで地面を滑り、ルーナに切り替えた瞬間に軽くなって真上へ抜ける。頭上に浮かせた相手を、建物の側面を新しい足場にして斜め下から蹴り上げる。最後はユピトルで姿勢と光を重く変え、落下方向を地面へ戻して強い一撃で着地する。足場から見た落下方向を瓦礫の軌道と画面の傾きで伝える。

アストロが固定支点を軸に回るのに対し、キトゥンは支点なしで重力の向きを変え、壁を床にする。パラッパは小物との接地が拍を決め、キトゥンは空中の長い間と急落で速度差を作る。原作の衣装と既存キャラの顔・頭身を維持し、滑走、軽い跳躍、壁への接地、反転蹴り、ユピトルの溜めと着地を全身で描く。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音3点を制作。途中6ヒットで21ダメージ、決め技で26ダメージ。低い滑走から月の重力で上がり、壁の接地点で向きを変え、瓦礫と赤い急降下で締める。壁蹴りの足裏と壁面、旋回と相手の位置を確認。CPU同キャラ戦はストック切れで終了。ローカルオンラインは415フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
