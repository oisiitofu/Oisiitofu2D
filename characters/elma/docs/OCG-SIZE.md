# OCG搭乗時のサイズ修正（2026-10-12）

通常エルマの細い人型の画素量を、幅の広いOCGにも共通適用していたため、搭乗後の立ち姿が110pxから72.38pxへ縮んでいた。

OCG専用の基準ポーズ40を設け、立ち姿を135pxに調整。既存の当たり判定の高さ比145/118に合わせ、通常時より約23%大きく見せる。40〜55の全16ポーズは、OCG立ち姿の色分布と画素量で個別に校正する。しゃがみ・前傾・伸びのある姿勢は元の形と縦横比を維持する。人型0〜39と他112形態の倍率は変更していない。

降機後の攻撃終了ブレンドがOCGの待機ポーズ40へ戻る問題も修正。地上は人型0、空中は人型5へ戻す。威力、発生・持続・硬直、移動、搭乗時間、物理判定、オンライン用の状態データは変更していない。

## 再校正

サーバーを起動して、PlaywrightのあるNode環境から次を実行する。画像の変更がないため、今回の修正で画像キャッシュの再生成は不要。

```text
node characters/elma/tests/calibrate-ocg.cjs
```
