# エルマのリミットブレイク

二丁拳銃で相手を捉えたエルマがドールに搭乗し、オーバークロックギアを起動する。惑星ミラの大地でフォーミュラSTの砲撃を重ね、最後の砲弾を追うカメラで着弾と吹っ飛びを見せる。機体の輪郭・塗装・武装は任天堂の紹介資料を参考にした。機体選択、搭乗、照準、砲撃の組み合わせは本作独自の演出。
