# ウェルチ・ビンヤード

スターオーシャン1の添付指し棒デザインに基づく追加。選択順はウェルチ、レナ、フェイト。人型サイズ2・立ち姿94px、重さ86。待機0を固定した全身55姿勢、専用高解像度上半身portrait55、16FX、5カラー。中間姿勢も全身画像で制作し、関節リグは使用しない。

- NB：タップは一発。押し続けると10/22/34/46/58Fに異なるビンタを出し、最終段は巨大な掌。途中で離すと現在段の後隙へ進む。着地で連係を切らない。
- 横B：指し棒ですくい上げ、命中後も押していると空中で振り回して叩きつける。空振りでは追撃せず33Fで終了。相手を自由にワープさせない。
- 上B：初動で落下を止め、最初の跳躍の頂点で左右を選んで指し棒の弧に沿って再度上昇。床下では外側へ出てから上昇し、終了後は専用35の尻もち落下。落下中は通常の左右移動。
- 下B：タップで短い回転、長押しで回転を維持。18F以降は6ダメージ以下の攻撃に耐える。判定は同じ一つのhitIDを維持し、延長中に余分なヒットを加えない。74Fまで回すと48Fの目回しの隙。

通常技15種は別々の実画像。上攻撃の曲線は頭上の一つ、指先突きは打撃星、下スマは地面の破片を使う。元FXの凸側は0/7右、1上、11/13下と実画像で確認。共通MeleeBalanceで密着と先端を補い、AttackEffects.imageを通して最終判定へ描画を合わせる。

画像は組み込みimage_genで制作し、正確なプロンプトはimage-prompts.jsonへ記録。assets/welch-poses.pngを初期の承認済み姿勢として保持。モーション・追加技・専用選択画像・FXは同フォルダ内。組立はtests/assemble-art.cjs、機能検証はtests/welch-test.cjs、視覚検証はtests/visual-test.cjs、CPUとオンラインは各専用テスト。

機能99チェック、描画60場面、CPU1戦2400F、左右場外復帰を確認。詳細はvisual-qa.md。オンラインの結果はpreviews/online-results.json（Git管理外）。
