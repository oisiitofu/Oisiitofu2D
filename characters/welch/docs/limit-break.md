# ウェルチのリミットブレイク

指差し棒で相手を小突き、頭上へ投げる。ウェルチが先に着地して見上げたあと、画面いっぱいに大きくなった指差し棒が降り、床にぶつかって大きな衝撃を起こす。「にーべるんなんとかー」をもとにした演出で、小突きの軽い音と落下の重い音を使い分ける。
