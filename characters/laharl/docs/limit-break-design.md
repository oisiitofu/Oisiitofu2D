# ラハールの専用リミットブレイク

対戦用の全身素材 `assets/laharl-native.png` を基準にする。青い髪と二本の長い毛束、赤い目、尖った耳、裸の上半身、赤い襟巻き、金縁の手甲と黒い短パン、大剣の寸法をカットインと全身ポーズで照合する。

メテオインパクトを元にした専用演出。剣の打ち上げから一度上空へ抜け、落下する隕石へ横から飛び乗って重心を落とす。岩が砕けるたびに次の岩へ飛び移り、最後の一塊を拳で叩いて地上の相手へ落とす。鬼助の地上での持ち替えと居合に対し、地上の相手と上空のラハールを別の高さに置く。隕石の飛び移りで横から俯瞰へ引き、着弾直前に両者を同じ画面に戻す。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。赤い襟巻きと青い髪、大剣を対戦素材に合わせ、岩の乗り継ぎと着弾を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
