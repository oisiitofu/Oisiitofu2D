# イザナギとの追撃から幾万の真言へ

制作中・未公開。顔・制服・体型・武器は承認済みのselectionとatlasを基準にする。通常の立ち姿と既存の技は変更しない。

[公式P4U2調整表](https://www.arcsystemworks.jp/p4u2/images/imp/list_ver.2.00.pdf)で幾万の真言、[公式コマンド表](https://www.arcsystemworks.jp/p4u2/chara/p4u2_commandlist.pdf)で刀と雷撃の技を確認。[魂ウェブ公式商品](https://tamashiiweb.com/item/10046/)で伊邪那岐大神の白い外套、金の輪、尖った足、頭部の長い帯と武器を確認した。

本人が駆けて刀を振り、逆側への回り込みと低い返し斬りを挟む。空中では本人の振りかぶりとイザナギの斬り上げが別の姿勢で連携し、着地の切り下ろしと雷撃で追う。終幕は伊邪那岐大神の白い姿、金の輪が付いた長大な武器、引きの構図を使い、幾万の真言の白金の光へつなぐ。単なる黒イザナギの色替えにはしない。連携の順序・カメラ・攻撃エフェクトは本ゲーム用に構成する。

本人の全身8枚とペルソナ4枚、専用カットイン・背景・攻撃エフェクトを制作する。縦横比を保つ共通LimitCinematic、濃いart.strike、補助のart.glowを使用。相手・本人・ペルソナ・武器先端を実描画で追えることを確認し、見やすさ設定に従う。専用音と途中ヒットを同期させる。

素材・最終生成プロンプトはlimit-break-assets.jsonへ保存する。コード実装後、対戦・トレモ・両向き・連続再生・CPU各1戦と短いオンライン同期を検証し、既存公開サイトとGitHubへ反映する。登録・公開済み作品数は89／162、ディアナの公開同期は別途未確認。

## 実装とローカル検証

全身8枚とペルソナ4枚、専用カットイン・背景・エフェクト、専用音2種類を実装。斬り上げを振りかぶりから前方へ刃を出す全身姿勢へ修正し、ペルソナの可視の剣先を900×800セル上で測り、相手へ合わせてから左右反転する。途中9回のヒット、対戦とトレモの補充・発動・空振り・再試行・ガード・無敵・多人数停止・終幕の吹っ飛び、両向き描画、カットイン比率と攻撃のsource-over合成、専用2音の実再生を確認。CPUは接敵距離から同キャラ2体を1戦ずつ確認し、両者とも撃墜で結果まで進行。ローカルオンラインは387フレームでダメージ・吹っ飛び・ホスト設定が一致した。公開検証はこれから実施する。

最終修正後の連続再生を1440×900で録画し、全身の動き・剣先・相手・ペルソナの切り替えを比較した。待機や既存の通常技は変更していない。
