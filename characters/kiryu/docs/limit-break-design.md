# 桐生一馬の専用リミットブレイク

『龍が如く８』の堂島の龍と絆覚醒を基に、三つのスタイルを一つのヒートアクションへつなぐ。神室町の濡れた路地を舞台に、初動はラッシュの沈み込みから短く踏み込み、相手の正面で重心を移しながら拳と蹴りを当てる。途中で壊し屋に切り替え、相手を掴んで軸足を支点に向きを入れ替え、路地の壁へ投げる。跳ね返った相手に正対して構え直し、ヤクザの重い拳で決める。投げで二人の位置関係が同時に変わることを動きの中心に置く。

ナイツは空中で輪を描き、ミクはステップの拍で飛び道具を送る。桐生は地上の接地と相手を動かす組み技を軸に、相手との距離が詰まる過程を横の画角で見せる。投げの瞬間は足元まで入れて軸足と落下地点を見せ、最後は少し引いて吹っ飛び先を確保する。既存の灰色のスーツ、赤いシャツ、髪型と顔を基準に、沈み込み、踏み込み、拳と蹴り、掴み、投げ、構え直し、決め拳を全身で描く。専用の拳の火花、靴の水しぶき、壁の衝撃と効果音を各接触に合わせる。

## ローカル検証

全身12姿勢、専用背景、カットイン、主攻撃素材、オリジナル効果音2点を使用。途中6ヒットで21ダメージ、決め技で25ダメージ。拳・蹴り・掴みの接触位置、壁と瓦礫の位置を調整し、相手を持ち上げる間も両者が追えるようカメラを引いた。CPU戦は時間切れで終了。ローカルオンラインは384フレームと決め技の吹っ飛びが一致。 対戦、トレモ、ガード、空振り、無敵、4人戦、両向きの描画と吹っ飛び、カットイン比率、主攻撃の濃さ、専用音、決め技の撃墜を確認。
