# 鬼助の専用リミットブレイク

対戦用の `assets/kisuke-native.png` を参照し、濃い茶の髪、青緑の長い襟巻き、袖なしの藍色の装束、金と赤の縁取り、草鞋、赤い鞘と銀の刀を通常姿勢とカットインで照合する。

公式の鍛冶と妖刀の奥義を元にしたゲーム独自の連撃。刀を交差させて相手を崩し、踏み込んで低く斬る。折れた刀を手放し、地面に刺した別の妖刀を拾いながら踏み替えて、正面から居合。刀を鞘へ納めるまで一拍置き、遅れて大きな斬撃が走る。ジバニャンの縦連打と壁蹴りに対し、交差・持ち替え・居合の間と相手との横の間合いを見せる。

- [朧村正怪奇譚 公式アクション](https://oboromuramasakaikitan.marv.jp/system/)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中6ヒット、決め技26ダメージ。青緑の襟巻きと藍の装束を対戦素材に合わせ、妖刀の持ち替えと納刀からの一閃を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
