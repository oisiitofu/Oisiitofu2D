# ルークのリミットブレイク

『テイルズ オブ ジ アビス』の「ロスト・フォン・ドライブ」を題材にした。連斬の途中で原作後半の短髪の姿へ切り替わり、剣で斬り上げた相手に超振動の衝撃を重ねる。引きのカメラで赤と金の直線状の波動を描く。

途中は2・2・2・2・2・2・3ダメージ。最後に21ダメージと斜め上への吹っ飛びを適用する。
