# 薙刀の踏み込みから仮面の連撃

制作中・未公開。承認済みの `hinako-presentation-portrait.png`、`hinako-poses.png`、`hinako-beast-poses.png` を顔・制服・武器・変身形態の基準にする。短い黒髪、紺のセーラー服と赤いスカーフ、プリーツスカート、仮面、巨大な灰色の腕を保ち、通常の立ち姿や既存の技を変更しない。

[PlayStation公式の試遊紹介](https://blog.ja.playstation.com/?p=268603)で鉄パイプ・鎌・懐剣・薙刀と集中を確認した。銃を使わず近距離の踏み込みと見切りを軸にし、薙刀の横払いと跳び上がる斬撃から仮面の連撃、巨大な腕の振り回しと跳躍、叩きつけへ展開する。連携順、巨大な花と霧の攻撃エフェクト、カメラは本ゲーム用の構成である。原作の最強武器として挙がる霊刀も調査中だが、正確な形状と動作の参照を取得する前に架空の刀で代用しない。

[PlayStation公式の作品紹介](https://blog.ja.playstation.com/2025/09/01/20250901-this-month/)で正式名「深水雛子（しみずひなこ）」を確認。既存のキャラ名「清水 雛子」は今回の登録時に「深水 雛子」へ修正する。

専用全身8枚を使い、走行・踏み込み・斬り上げ・巨腕の突進・横振り・空中の振りかぶり・着地の打ち下ろしを分ける。斬撃は薙刀の刃の先、打撃は巨大な手の動きへ向きを合わせ、相手を手前に描画して攻防を追えるようにする。主攻撃は `art.strike`、補助光は `art.glow`、カットインは共通の縦横比維持描画。

素材と最終プロンプトは `limit-break-assets.json`。演出コードと専用音、対戦・トレモ・左右描画・連続再生・CPU・オンライン同期の検証後にディアナと公開する。未公開のため、85／162の公開済み作品数には含めない。

ローカルの対戦・トレモ・左右描画・カットイン比率・攻撃の濃さと専用2音の再生を検証済み。60秒1ストックのCPU戦は1714ステップで結果まで進行。双方7／16ヒット、残ストック0／1。オンライン379フレームでダメージ・吹っ飛び・ホスト設定が一致。1440×900の連続再生録画と縦横比を保つ比較画像で移動・姿勢・命中反応を確認した。録画は映像のみで、音は実再生診断を別途確認。公開結果はルートの進捗表へ記録する。
