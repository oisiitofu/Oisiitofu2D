# 清水 雛子

ツインビーの次に配置。通し番号はRosterの順序から自動採番し、おまかせは最後。進化・変身専用の非表示キャラは追加しない。

制服の48ポーズと変身後の48ポーズ、専用ポートレート、8エフェクトを組み込みimagegenで制作。元の添付モーションシートに加え、追加の実写ゲーム画像を変身デザインの基準とした。最終形態は制服を維持し、灰褐色の狐の半面、細長い灰色の右腕、肩の棘／毛状の突起、大きな右手と長い指。左腕は袖を着た人間の腕と肌色の手を維持する。初期の黒い獣毛・巨大な爪・和服の案は使用しない。変身中は全て武器を持たず、右手の打撃・引っかき・つかみ・投げを描く。左手が誤って灰色になった未使用ジャブ案の代わりに、承認した右手の前方リーチ画像を選定した。関節変形は使用しない。

## 必殺技

- 通常必殺：フォーカスアタック。短押しでパイプの重い一撃、長押しで最大50F溜め。変身中は異腕・集中打になり、大きな右手の一撃、最大30Fの溜めになる。溜めは任意に解除でき、発射物や連射はない。
- 横必殺：鎌・彼岸巡り。最初の鎌が命中した時だけ相手の位置を基準に回り込み、逆向きの低い鎌の払いへ移る。空振りでは短い踏み込みの後に止まり、長い突進にはならない。変身中は異腕・引き寄せ。右手で相手をつかみ、短く保持して右腕で投げる。相手のつかみ耐性・無敵・ガード、被弾・撃墜による中断に従う。
- 上必殺：薙刀・飛翔。発生前の横入力で方向を選び、武器を使う斜めの跳躍。途中から横方向を調整でき、ステージ側面に当たると一度だけ外向きに反動上昇する。変身中は武器を持たず、異腕による跳躍と同じ壁反動を使う。崖下からの復帰、下面から外側へ抜ける処理、被弾後の復帰技再使用は共通ルールに従う。
- 下必殺：仮面の少女。18Fで変身し720F（12秒）持続。終了後480F（8秒）の再使用待ち。変身の再発動による無限延長を防ぐ。変身中は右腕の近接判定が18%長くなり、攻撃の基礎威力が12%増える。変身時間が攻撃途中で切れた場合は、その一撃の姿と判定を終わりまで維持し、終了してから通常姿へ戻る。撃墜時は解除。空中下必殺は急降下入力として扱わない。

通常状態のパイプは長柄、変身後は素手として近接判定の最低範囲を使い分ける。攻撃の絵と判定が異なる手へ移らないように、変身状態を攻撃開始時にも保持する。エフェクトは右向きの元素材をローカル反転してから、実際の攻撃判定の線分へ回転する。前後上下を左右両向きで確認する。

## アートと検証

assets/ の制作画像を固定し、hinako-native.pngへネイティブ画素で収納。97フレームのうち0〜47が通常、48〜95が変身、96が選択画像。動作のサイズ補正は通常／変身それぞれの待機を基準に行い、大きな手で胴体が縮まないようにする。ポートレートは選択画面と戦闘HUDで共有。色違い、透過、接地、崖の手の位置を維持し、起動時の元シート解析は追加しない。

専用テストはこのキャラの tests/、実描画・測定結果はGit管理外のpreviews/。CPU結果は動作確認であり、対人勝率や完成したバランスの評価ではない。生成プロンプトは image-generation-prompts.json に記録。
