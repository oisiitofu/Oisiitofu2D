# サンズの専用リミットブレイク

ゲーム内の青いパーカー、短パン、丸い頭蓋骨、靴の配色と頭身を維持する。目の点灯は重力を切り替える瞬間に限定する。

箱を模した暗い空間へ移り、サンズが一度だけ重力を反転。相手を天井から骨の低い波へ落とし、壁面に沿って移動したサンズが手を下ろすと、相手を横の床へ滑らせる。ガスターブラスターの照準を時間差で回し、最後の収束が始まる前に相手と出口の方向が見える画角へ引く。DEEMOの木に沿った上昇に対し、箱の境界と重力方向の切り替えで動きが生まれる。白い骨とビームは画面の明度差で読み分ける。

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。重力を反転し、骨の波を経てガスターブラスターを交差させる。途中7ヒット、決め技26ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
