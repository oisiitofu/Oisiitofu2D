# スカポンの中間モーション実験（2026-10-12）

ユーザー指定によりスカポンだけを対象に、頭・胴・拳・足の独立パーツを使った60Hzの中間姿勢描画を実装。画像のクロスフェードではなく、各部位の位置・回転を補間する。組み込みimage_genで参照絵に合わせた12パーツを作成し、透過を保持して既存の配信アトラスへ追加した。生成プロンプトは ../assets/sukapon-animation-prompts-v1.json。

## 仕様

- 通常・強・スマッシュ・空中攻撃は、予備動作→振り出し→判定位置→戻り。持続中の打撃部位は元の判定終点に固定し、支える部位を動かす。二段技の段間も補間。
- 頭発射、往復する頭、方向指定の回転復帰、方向入力投げの挙動は既存のまま。回転開始／終了を補間し、飛ばす頭にも同じ新素材を使用。
- 待機、歩行、走行、ブレーキ・反転、しゃがみ、ジャンプ踏切・上昇・下降・着地、ガード、回避、被弾・吹っ飛び・ダウン・起き上がり、つかみ・投げ・崖を個別に描画。崖の手は物理アンカーに合わせる。
- 攻撃はf.timer、状態はf.stateFrameでサンプル。描画で時刻や状態を更新しないため、ヒットストップ・溜め・一時停止・オンラインで絵だけ先行しない。
- 技の発生・持続・全体時間、威力・吹っ飛び・入力受付・着地隙は変更していない。元の49ポーズ、選択画像と5カラーの既存チェックサムを保持。他112形態の配信データも同一。12パーツはframes[49..60]、選択画像は従来の48。
- サイズは待機約90pxを基準に固定。部位の変形や足の位置でポーズを表し、攻撃時だけ全身拡大しない。

## 検証

専用アニメーション検証4,720項目（全28技×左右、発生／持続、打撃部位と判定の一致、補間、状態別、静止中の時計、崖、回転、カラー）。専用メカニクス214項目、オンライン2クライアント115項目を検証。オンラインの同一フレーム比較には中間姿勢も含める。

共通検証：melee-balance-test.cjs（113形態・681,451項目）、.tools/motion-actionability-test.cjs（16,922項目）、art-loading-test.cjs（5,277フレーム・932FX・26,385カラー、透過／画素差0）。

旧専用テストは、前の浮遊台に衝突する空中発射開始位置と、共通補正前の投げ硬直を期待していた。描画変更を外しても失敗することを確認し、開始位置を台の上へ、投げ終了の検証を現行FAFとの整合性へ更新した。崖／回転の描画検証は、新しいパーツの手／胴を測定するよう更新。ゲームの判定・威力には手を加えていない。

検証用の中間姿勢一覧とWebMはGit管理外の ../previews/sukapon-animation-contact-v1.png と ../previews/sukapon-animation-v1.webm。

全113形態のサイズ検証も成功：motion-size-test.cjs（114,063項目、41,913攻撃フレーム）とbattle-size-test.cjs（21,544項目）。各パーツは元画像の縦横比を維持。CPU対戦113組・203,400フレーム・5,158ヒットで実行エラー0。CPU結果は人間同士の勝率やバランス完成を示すものではない。
