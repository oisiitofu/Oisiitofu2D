# アルルの専用リミットブレイク

2026-11-14の指定に従い既存素材で制作を再開した。カットインは選択用の原画、全身とカーバンクルは既存の対戦用シートを使う。二組のぷよを空中で回転させて盤面へ置き、同色4個以上になるたびに消去し、残りのぷよを落とす。連鎖数とともに相手側へ落ちるおじゃまぷよが増える。消去時の色別の粒とおじゃまぷよの軌道を専用に描画する。

連鎖は演出187・207・227・247フレーム目で20フレーム間隔。四連鎖後は盤面からカーバンクルに乗って跳び、空中から「ばよえ〜ん！」を当てる。直近のリョクの飛び石渡りと違い、前半は盤面を挟んだ攻防、後半は一度の大きな跳躍で間合いを詰める。消去音と決め技音は専用サンプルを使う。
