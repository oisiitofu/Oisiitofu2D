# ハナの専用リミットブレイク

発動時の機体の姿から入り、対戦で採用しているJS・JK・JDの全身素材を使う。パーツ展開と駆動音に合わせて機体を切り替え、地上の打撃、空中の急停止、JDの決め技へ。リキのバルーン落下と違い、噴射方向を切り替えて相手の横を取る。

改修では、各機体の対戦素材を参照し、JSは白いベレーと拳のピストン、JKは白いヘッドドレスと交差した真鍮の腕、JDは長い薄紫の髪と黒赤の刃が見える横長カットインを ImageGen で制作した。炉の中で拳の火花、噴射と爆発、JDの斬撃を別々に描く。機体切り替えのフレームに展開する装甲を重ね、クァンタムジャッジメントでは機体の横から伸びる刃と命中火花が見えるようにした。

配信素材は `assets/limit-cutin.webp`、`assets/limit-forge.webp`、`assets/limit-effects.webp`、`assets/limit-parts.webp`、`../hanajk/assets/limit-cutin.webp`、`../hanajd/assets/limit-cutin.webp`。
