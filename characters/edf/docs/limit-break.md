# 地球防衛軍のリミットブレイク

既存の兵士の白い装甲、青いバイザー、赤いスカーフを基準に、廃墟の市街戦を制作。ライフル3発からロケット弾へつなぎ、無線で誘導した4発の支援爆撃のあとにギガンティック・アンローダー バルガが踏み込み、重い一撃を放つ。原作の複数兵科の要素を持つゲーム内の兵士に合わせた構成。無線の信号と拳の着弾音を専用で制作。

途中の8ヒットは合計14ダメージ。最後に22ダメージと斜め上への吹っ飛びを適用する。
