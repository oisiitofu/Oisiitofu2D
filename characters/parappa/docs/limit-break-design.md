# パラッパの専用リミットブレイク

『パラッパラッパー』の終盤ライブとCOOLモードのフリースタイルを軸にする。音をまねる最初の小節では足を止めて拳、蹴り、受けの順を刻む。次の小節でスケートボードに飛び乗り、床から低い手すりへオーリー、体を後ろ向きに開いてグラインドし、板を蹴って着地する。着地と同時にフロアで手をついてブレイクダンスへ移り、足を振り切って姿勢を起こし、最後は客席と掛け合う決めポーズとビートの衝撃で締める。

ミクの音符やスピーカーによる連撃に対し、パラッパは拳・靴・板の接触が拍を作る。アイアイのコース上の転がりとは、板を手すりへ乗せる高さ、板から足が離れる時間、手を床について回る動線を変える。紙のように平たい輪郭と既存の帽子・顔・衣装を維持し、足技、オーリー、滑走、着地、床の全身姿勢を描く。専用音はオリジナルの打楽器と板の音で組み、歌詞や原曲を流用しない。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音3点を制作。途中9ヒットで21ダメージ、決め技で25ダメージ。112.5 BPMのオリジナルビートに拳、蹴り、ボードの音を合わせ、手すりと板の高さ、逆側への着地を調整。CPU戦は時間切れで終了。ローカルオンラインは410フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
