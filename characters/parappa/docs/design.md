# パラッパ / PaRappa the Rapper

添付シートを基準に、オレンジのニット帽・緑のカエルバッジ・黒い耳・クリーム色の平たい顔・青いタンクトップ・紺のズボン・赤いスニーカーを保つ。紙のような平面的な形と太い輪郭を維持する。特殊体型の個別78px、専用高解像度の顔〜肩の選択画像を制作。

## 固有の能力・操作

- リズム：自分のボクシーが刻む4拍（30F間隔）に合わせて攻撃を開始し、その攻撃を当てるとゲージが多く増える。通常の命中でも少し増える。GOOD（40以上）は威力と吹っ飛びを軽く強化、COOL（80以上）は必殺技に派生を追加。リズムはシミュレーションのフレームで管理し、音声の再生時刻でゲーム結果を変えない。HUDで拍と入力の判定を見せる。被弾でゲージを失う。BGMがなくても操作可能。
- NBカムヒアー：マイクとコードを前方へ伸ばし、命中した相手を手前へ軽く引き寄せる。通常つかみの状態へ拘束しない。長押し時は近くまで来た相手へパンチ、COOLではチョップ。飛び道具の引き寄せと近接窓を分け、同じ窓に重複ヒットを作らない。空振りはコードを戻す隙がある。ガード・飛び越しで対処できる。
- 横Bスケーターフロー：地上ではスケボーで低く進み、途中のジャンプ入力でオーリー、さらに上下方向でフリップ/着地トリックを選ぶ。ジャンプを選ばず地上で走り抜けるルートもある。空中開始はボードを足元で回して短く進む別の姿勢と軌道。直線突進の往復ではなく、地上経路と跳び越しの選択で対処を変える。COOLはトリックの着地まで専用音符を残すが無敵は付けない。
- 上Bジャンプ！アッパー！ターン！キック！ポーズ！：開始時の斜めアッパーの後、上昇中に左右入力を予約して空中ターンの向きを決める。上/横/下入力で後半の蹴り出し方向を選び、終端のポーズから落下へ連続移行。単なる上昇の二段斬りではなく、リズムの掛け声に合わせて折れ曲がる経路を選ぶ。GOOD/COOLでは旋回可能幅が広がる。待機浮遊を作らず、左右の場外から復帰できることを確認する。
- 下Bボクシーグルーヴ：タップは足元へボクシーを置き、一定時間4拍の小さな音符を周囲へ発生。設置は1個、被弾や死亡で古い音源を無限に増やさない。長押しはボクシーを抱えて一度の前方音圧にする。設置の維持と目の前の牽制を使い分ける。音符は遠隔判定として近接補正を付けない。

## 既存キャラとの差・相手の対処

マイクの手前への引き寄せ、スケボーの地上/ジャンプ/フリップ、4拍に合わせる入力とGOOD/COOLの派生を組み合わせる。ジェットの風ダッシュやオクタンの自己負担/共有パッドを流用せず、リズムに合わせる判断と移動経路の選択が中心。相手はボクシーから離れる、マイクをガードする、オーリーの着地点を狙う、被弾でゲージを崩すといった対処ができる。

## アート・命中・検証

通常技はパンチ/チョップ/キック/ボードを使い分け、全身姿勢と星・音符・短い蹴りの線を個別制作。空Nは踊りながらの片脚キックで、全員共通の輪へ寄せない。既存の窓番号/ヒットIDを保つ共通coverageで密着と先端を確認。専用の漫画風打撃音・ボードの打撃・マイクの音響を合わせる。関節リグを使わず全身画像で連続性を確認する。追加キャラ中心の左右の見た目・技・復帰、CPU1戦、短いオンライン同期を検証する。
