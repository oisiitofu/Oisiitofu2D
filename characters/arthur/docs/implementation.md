# アーサー

成歩堂龍一の直後、ジョーの前。サイズ2、94px。125枚の全身画像（銀・鎧なし各61、盾の中間2、専用上半身肖像1）、16種のVFX。

- NBは槍1本、長押しで角度の異なる短剣3本。黄金時は威力・速度強化。射出後の姿は空手で、飛び道具を身体画像へ重ねない。
- 横Bは前へ転がる鉄球。床で弾み、壁では1回だけ反射。本人は突進せず、1個制限と有限寿命で制御。
- 上Bは斜めジャンプ→上昇中の再入力で反対向きにも跳べる2段目。先行入力を取り、待機浮遊しない。黄金時は任意の追加入力でサンダーストーム。専用尻もち姿のまま左右慣性を操作できる。
- 下Bは隙のある修復。鎧なしから60Fで銀、銀から100Fで黄金へ1段階だけ修復。銀は累計14、黄金は20ダメージで1段階破損。体重は鎧なし80／銀94／黄金108。共有CharacterDataを変更しない。
- 黄金は承認済みポーズの金属部分のみを描画時に着色するキャッシュ。全身形状、透過、顔・ひげ・肌を保持し、眼や歯の小さい白成分も除外。鎧なしは全技・移動・防御・被弾・復帰の専用全身素材を使用。戻り描画も鎧状態へ写像。
- 空Nは盾を前へひねる2姿勢。剣の円弧の使い回しはしない。通常技も盾・槍柄・槍先・ハンマー・クロスボウ・聖水を個別に描画。
- 生成シートで接触した鉄球放出／再ジャンプは分離した素材を制作し直した。原シートの混ざった成分を実行時に使わない。

検証: 専用130項目、通常技の密着・先端を左右両向き、各鎧・修復・破損・黄金マスク、左右／台下復帰、通常30場面・特殊24場面・待機10場面、連続映像48サンプル、CPU1戦。既存ビビのspriteFor参照が変わらないことも確認。新4キャラの読み込み照合で不一致ゼロ。
