# テラリアンの専用リミットブレイク

対戦時のピクセル絵の頭身、鎧と武器のシルエットを全身フレームに保つ。長いカットインでは元の装備色を使い、ゼニスを握るまで武器の切り替えを手元で追えるようにする。

足元のブロックを掘り下げて斜め下へ降り、開いた坑道の底で剣を取り出す。先に星が落ち、壁沿いに上がる本人の後ろを複数の剣が弧を描いて追い抜く。最後は採掘で開いた地表の穴を引きで見せ、左右の剣の弧が一つのゼニスの斬撃へ合流する。マエルの水平な踏み込みと間合いに対し、坑道から地表まで高低差のある軌道と武器が先行する連撃で構成する。

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。足場を掘り、星と剣の連撃からゼニスへ。途中7ヒット、決め技27ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
