# テイルスの専用リミットブレイク

対戦用の頭身、靴、二本の尾、ガジェットの形を使用する。ダミーリングを時間差で起爆し、跳び上がる相手の外側をツインテールで上昇。本人は画面上を回って空中にガジェットを展開し、ラストは地上と空中の電撃を交差させる。ホーネットの振り子と異なり、空中に留まりながら飛び道具の射線を組む。主役とガジェットは上下に離して、起爆元を明示する。

改修では、現行の全身素材と選択肖像を参照して、二本の尾を広げながら夕暮れの空中甲板上を旋回し、ガジェットを操作する横長のカットインを描き起こした。組み込みのImageGenに甲板、透過の機体、ダミーリングの起爆、電撃、上昇気流、横長の光線も指定し、`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-drone.webp`、`assets/limit-effects.webp` に収録。決め技は機体の発光から二方向の射線が交差し、命中点の大きな電撃とリングの残光へつなぐ。
