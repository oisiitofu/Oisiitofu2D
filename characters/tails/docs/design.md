# テイルス：固有技・操作の設計

添付シートの黄金色の毛・白い口元と胸・青い目・白い手袋・赤白の靴・白い先端の二本の尾を維持。特殊体型の小型マスコットとして扱い、人型の身長段階へは入れない。顔と肩の選択用アップを別制作する。

- NB「ダミーリングボム」：タップで放物線に投げ、長押しでは足元に置く。最大2個、予告点滅後に爆発。相手が範囲外へ逃げる/ガードする余地を残す。設置ボムは横Bのしっぽ回転で転がして再配置でき、時間差の進路妨害に使う。
- 横B「サイクロン」：押し始めは加速し、尾を回して低い位置を滑る。押し続ける間は短く慣性を残し、離すとしっぽの薙ぎ払い。ガード入力で無敵なしの制動、ジャンプ入力では勢いを上へ変える短い跳ね上がりへ派生。地上では転がしたボムと一緒に進み、空中では移動量を控える。無制限に往復突進させず、1回の空中使用と有限の回転時間を持つ。設置ガジェット付近を通ると一度だけ電気を帯び、フィニッシュを電撃に変える。相手はブレーキ/薙ぎ払いを見て間合い外で待つか、上から攻められる。
- 上B「ツインテールフライト」：尾をローターにして飛行。ホールドで上昇・水平入力で移動、ボタンを離すと緩く滑空し、再ホールドで残り飛行時間を使って上昇できる。最大飛行時間は1回の空中で共有し、押し直して増えない。地上発動も空中の使用分を消費。攻撃の二段上昇ではなく、残り時間と高度・横移動の配分が判断になる。飛行後は自然に落下し、着地/崖で回復。頭上のローターには弱い近接判定を持ち、敵は横・下から迎撃可能。台下では外縁まで回り込んでから上昇し、台の底へ引っ掛かったまま浮遊し続けない。
- 下B「サポートガジェット」：タップで小型機雷ガジェットを置き、設置済みなら再入力で周囲へ電気パルス。長押しでは設置地点の周囲へ薄い一時シールドを展開。単なるカウンター/ゲージではなく、設置場所からの距離が重要。空中設置は落ちて最初の足場に着地。本人が浮遊台で下Bを使った時は台に残る。1台のみ、有限寿命、撃墜時に消去。無敵を付けず、シールドは本人が近くにいる時だけ一度のダメージを軽減して壊れる。

尾の動きは、空Nの丸いスピン、空前の二段キック、空後の尾払い、空上の上向きフリップ、空下のドリルで全身姿勢を分ける。スマッシュは前方尾ドリル、上のガジェット打ち、足元の尾スイープ。拳・工具・尾・爆発・電撃の命中音とエフェクトを使い分ける。

設置ボム→横Bで転がす、ガジェット→横Bの電撃フィニッシュ、ガジェット→設置地点を守るパルス/シールドが固有の連携。飛行のホールド/離し直しと有限時間は他の単発上昇と異なる。CPUは距離/設置物/飛行残量で選択し、オンラインでは入力・残り時間・設置物の位置/寿命を同じフレームで処理する。
