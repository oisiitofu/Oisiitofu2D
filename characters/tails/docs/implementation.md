# テイルス

シャドウの直後、表示114。特殊体型80px、重量76。76枚の全身画像と専用の顔・肩アップ、16枚の専用エフェクト、5カラー。元の待機画像は `assets/tails-neutral-locked.png` に固定。全身画像の切り抜き・等比縮小・アトラス化で表示し、関節リグは使用しない。スパナ/前方ドリルは修正版の全身絵を使用。

## 操作

- NB：タップでボムを投げる。発生14F時点でホールドなら足元へ置く。最大2個、155Fで起爆。横Bで蹴って再配置。
- 横B：9Fで低いサイクロンへ。8F以上回転してから離すと尾のフィニッシュ、最長32F。ガードで無敵なしのブレーキ、ジャンプで低い跳躍。空中は1回、移動を抑制。設置ガジェット付近を通過するとフィニッシュが電撃強化。
- 上B：8Fで飛行。ボタンを押して上昇、離すと滑空、再ホールドで再上昇。飛行と滑空は共有120Fを消費、空中で回復しない。台下は外縁へ回り込んでから上昇する。頭上に弱い単発判定。燃料切れ後は無防備に落下し、横入力は維持。着地/崖/復活で回復。
- 下B：16Fでガジェットを1台設置。再入力で近くへ電撃、ホールドで90Fの防護を展開。距離115px内で一度だけ被ダメージを25%軽減して壊れる。通常ガード時は消費せず、無敵にはならない。420Fで消失、空中設置は最初の足場へ落下。

近接は NativeStrikes と MeleeBalance.coverage を使用。ボム/ガジェットの遠隔判定へ近接拡張は適用しない。各遠隔オブジェクトの命中済み集合で多重命中を防ぎ、カウンター/ガード/つかみ解除は共通の命中経路を通る。共通エンジンの変更は combat-system.js のテイルス被弾時の専用防護呼び出し1か所のみ。

エフェクト0の凸側は右、1は上、ドリル2と電撃7は右。ローカル回転後に向きを反転し、実際の武器・尾と攻撃外縁へ配置。上強/空上は頭上の曲線1枚、上スマは電撃、工具/拳/キックは小さな命中閃光。予備・攻撃・戻りは専用data.jsの全身姿勢で管理。
