# アッシュ / Asch

テイルズ オブ ジ アビスのアッシュ（ash）をルークの次へ追加。長い赤髪、黒い軍服風のコートと赤い模様、灰色の袖、片手剣を添付に合わせる。人型サイズ3・98px。

builtin image_genで全身53姿勢・16FX・専用1536×1024上半身画像を制作。ゲーム用54フレーム/5カラー。保存先は[assets](../assets/)、正確なプロンプトは[image-prompts.json](image-prompts.json)。部品リグは使わず全身画像を切り替える。待機0を固定し、追加シートは同じ立ち姿で校正。通常技15種は異なる実画像。下スマ後半は専用の低い薙ぎ46で振り向き、空後14を使い回さない。window index/hitIDと時刻を維持。横スマ12の引いた準備姿勢は、前へ剣を出す追加全身48へ変更。元が後ろ斬りの49はローカル右向きへ正規化してから実際の向きへ反転。専用肖像の頭頂を補修し、ルーク/ジューダスの実カードと比較。

- NB魔神剣：15Fに9ダメージの青い地上波。12Fに保持していれば15Fの7と28Fの8ダメージの二連弾。生存中の自身の弾と発射間隔30Fだけ再射出制限。他の近接技へクールダウンを加えない。空中から着地しても二発目を保持。
- 横B飛燕瞬連斬：8〜12Fの7ダメージの踏み込みが命中し、16Fに保持していれば18〜22Fの逆方向5ダメージ、29〜33Fの前方9ダメージへ追撃。最後は小さく後退。空振り/早いボタン離しでは短く終わる。瞬間移動や無敵なし、空中でも硬直後に再使用可能。
- 上B翔破裂光閃：8Fまで慣性を止めて上昇斬り7ダメージ。頂点付近で短く溜め、20F後に左右入力の向きへ再上昇し、真上へ11ダメージの光柱。二段上昇は自動、相手の有無に依存しない。左右から地上へ復帰し、終了後は専用尻もち35へ不透明なまま移行。
- 下B閃空裂破：24〜29Fに前方の地面へ17ダメージの衝撃。遅い発生と長い後隙、1ウィンドウの近接技。飛び道具は発生させない。空中は落下する。

AttackEffects.imageで可視切断面を武器より先の最終判定へ合わせ、近接coverageを一度だけ適用。弾/つかみへ適用しない。素材0/4/5/6は右凸、1は上凸、13は下凸。ローカル回転後に左右反転。上強/上スマ/空上は頭上の曲線1つ。噴出10は元の上向きを維持し横倒しにしない。投げは後ろ撃墜/上浮かせ/下追撃/前位置変更。専用の弱い単発攻撃上がりを維持。

機能126項目、左右50描画、CPU対ビビ2400F、54姿勢/16FX/270カラーのchecksum差0。実サーバー2ブラウザ6場面720F同期一致。previewsはGit管理外、公開結果はBALANCE.md。
