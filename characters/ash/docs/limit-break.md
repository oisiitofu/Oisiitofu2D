# アッシュの専用リミットブレイク

「絞牙鳴衝斬」は地上の踏み込みから相手の横を跳び越え、返し斬りで正面へ戻る。プレセアのように斧で跳ね直す動きと区別し、最後は足を止めて剣を高く掲げ、光をまとった剣を譜陣へ突き立てて石床を走る衝撃波を出す。

赤い長髪、黒いコートの赤い縁、灰色の前腕と細身の剣を対戦素材で確認し、ImageGen で剣を掲げる横長カットイン、決闘場、金と青緑の斬撃素材を制作した。標準カラーでは構え、剣を掲げる姿、地面に突き立てる姿に専用全身絵を使う。別カラーでは対応する対戦のポーズを使う。

配信素材は `assets/limit-cutin.webp`、`assets/limit-duel.webp`、`assets/limit-effects.webp`、`assets/limit-fonic.webp`、`assets/limit-motion.webp`。決め技の金属音と地面の衝撃には専用音を使う。
