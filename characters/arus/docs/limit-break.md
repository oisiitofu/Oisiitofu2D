# アルスの専用リミットブレイク

盾受けから連撃に入り、岩場を蹴って相手を上から追い、床へ落とした剣に雷を集めてギガスラッシュを放つ。オニオンナイトの衣装切り替えと違い、盾と剣の持ち替えを攻防の節目に使う。対戦の盾・剣・衣装を保つ。

改修では、現行の緑の帽子と服、青と金の丸盾、銀の剣を参照した。組み込みImageGenで、盾を前に出し雷をまとった剣を振る横長カットイン、嵐の島の丘、石の足場、盾の打撃と剣の軌跡、ギガスラッシュの雷刃を描き起こした。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-ledge.webp`、`assets/limit-effects.webp` に収録。溜めの縦の稲妻と、剣を振った方向へ進む金白の斬撃を別に描く。

再比較ではアルスが盾で受けて足場から回り込み、相手の右側へ着地して雷をまとった剣を左へ振り抜く。ハイデリンの地表から上へ伸びる光柱、オニオンナイトの杖からの射線とは、盾・足場・着地からの剣の切り返しで区別する。剣に集まる縦の雷を決め技の前に収め、横へ抜ける刃と地表の圧力を時間差で描く。

組み込みImageGenで「対戦の緑の帽子と服、黒髪、青金の盾と銀剣を保ち、盾を手前に出して剣を引く横長構図」と「銀白と金の雷刃、縦の稲妻、地表の雷と石片、命中の閃光」を制作。配信用は `assets/limit-cutin.webp` と `assets/limit-finish.webp`。演出176フレームの雷の溜め音から193フレームの専用決め技音へつなぐ。

音バンクにない `impact-heavy` を盾の命中に指定していたため、45フレームの盾打撃と発動の接触音を `shield-hit` に修正した。
