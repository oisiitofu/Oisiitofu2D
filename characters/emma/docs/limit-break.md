# エマのリミットブレイク

エマの剣とクーの花の技を交互に当てる。地上斬りからクーの飛びかかりと花の蔦で相手を浮かせ、エマが空中追撃する。最後はクーが逆側から回り込み、花と蔦の中でエマが強い一閃を放つ。笠・衣装・刀と、クーの白い毛並みや背の植物を既存資料に合わせた。

途中の連撃は2・3・3・2・2・2ダメージ。最後に22ダメージと斜め上への吹っ飛びを適用する。
