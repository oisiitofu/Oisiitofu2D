# 一本木龍太 — 拍・応援隊列・踏み台

キュービィの次。人型サイズ3の98px。黒い長ラン、金ボタン、白手袋、赤い腕章/長い鉢巻、逆立つ髪を保つ。専用高解像度の顔と肩の画像は別制作。

- 固有能力/操作: 必殺を開始すると3拍の円が順番に近づく。必殺ボタンを拍に合わせて追加入力するとGOOD。無入力でも最低限の技は成立し、誤入力連打では加点しない。成功は行動ごとの判定で、ゲージが満ちるだけの仕組みにしない。
- NB応援の一喝は前方へ短い音波。2拍目の入力で射出時刻を遅らせ、3拍目で幅が広がる。早く撃つ/待ってタイミングをずらすの二択。被弾/ガードで簡単に永久拘束しない。
- 横B団結突撃は龍太自身の突進ではなく、応援仲間2人を隊列として召喚。最初はその場で足踏み、追加入力で先頭→後尾の順にキック。上下入力で前方/上方の隊列を選べる。龍太は後隙後に行動へ戻る。仲間は被弾で退場、1隊列のみ、再呼出に間隔。地上の圧力と対空の使い分け。
- 上B応援大ジャンプは仲間が足元に組んだ踏み台で押し上げる。最初の拍で方向を決め、押し出しの拍で入力すると追加の横移動を得る。上昇中の二段攻撃ではなく、タイミング入力で着地点を変える無攻撃復帰。空中の仲間は一度の押し出し後に消え、場外でも有限。失敗でも基本復帰距離を残す。上昇後の一喝は見た目のみか別行動として処理する。
- 下B全力コールはその場で手拍子/足踏み。3拍の入力で前後に広がる衝撃の発生時刻を選べる。長時間拘束や恒常強化ではなく、強い予告を見せる設置的な迎撃。空中は着地後に足踏みする。

対処は音波の溜めへ接近、仲間を先に倒す、コール範囲から離れ、踏み台の飛び出し先を狙う。命中音は白手袋のパンチ、硬い靴の蹴り、足踏み、声/拍の音を分ける。通常技15種の姿勢は別々に制作する。
