# ヒューマンの専用リミットブレイク

対戦用の顔と衣装を全身姿勢とカットインの基準にする。両手で梁の端をつかんだ後、片手ずつ持ち替え、落ちた足を使って振り子の勢いをつける。箱を押して足場を作り、最後に両手で吊り荷へ飛びつくと、傾いた足場が相手を弾き出す。シェフの手際と違い、つかんだ手と遅れてついてくる足で動きを見せる。連続命中は15〜22フレームを目安にして、落下前の一拍を決め技に置く。

- [Human Fall Flat公式](https://www.humanfallflat.com/)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。梁と吊り荷をつかみ、木箱を押して傾斜する足場へ。途中7ヒット、決め技26ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
