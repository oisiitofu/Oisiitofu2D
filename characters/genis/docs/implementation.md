# ジーニアス・セイジ

コレットの直後。サイズ1/78px、重量75。

添付のデザインからbuiltin image_genで全身ポーズ/16FX/専用高解像度の顔と肩の選択画像を制作。プロンプトはimage-prompts.json。basic先頭を固定基準としてシートごとに校正。全身がセル境界を越えるため、人物の連結成分と専用のけん玉所有表で各ポーズを抽出する。赤い玉・糸・持ち手を保持し、隣の髪や靴を取り込まない。魔法が本体絵に入った初回specialsはimage_genで除去し、描画するFXを分離。空上/空下は別の全身画像で補修。通常15姿勢の違いを実描画で確認。関節リグは使わない。

- NB: タップで時間差の3火球、32F以上で前の火柱、62F以上でさらに先の大爆発。最大72Fで解放。TP6/14/24、不足時は弱い版。
- 横B: 溜め中の左右で設置位置を調整し、解放で予告から氷柱→左右へ分裂。38F以上で水レーザーへ変化。本人の横突進ではなく、遅延・場所・地形を使う技。TP12/18。
- 上B: 慣性を止めてエアスラストで上昇、入力でサイクロンの位置を調整し、ボタン解放で斜めに飛び出す。最大30Fで自動脱出。静止した追加入力待ちはない。TP不要、左右場外/ステージ下から復帰可。
- 下B: 前に重力場を残し、相手を引き寄せて最後に下へ落とす。無敵・つかみ・被弾停止中の位置/状態は引き寄せで変更しない。TP18。
- TP: 開始30/最大100。時間と命中で増加、100時の上スマは全消費してインディグネイション。専用の全身姿勢と雷に変わる。復活で30。

弾/場/分裂は同時8個・有限寿命・対象ごとの命中Setで制限。弾へ近接coverageを使わず、上Bの接触窓だけ適用。上スマの岩柱は前へ置き、術者を隠さない。通常投げはcasterの方向別役割。上攻撃の曲線は上向きの1枚、炎/岩/雷は別素材のまま。

検証: genis-test.cjs 130項目、通常30/必殺24/左右5カラー10、48連続サンプル/動画、CPU1戦2400F。エレンのonline-test.cjsで本キャラを含む2ブラウザ8場面800F照合。previewsはGit管理外。

## 2026-10-22 画像混入の修正

等分セル切り出しが、隣接ポーズの髪/靴を取り込み、自分の頭/足/けん玉を欠落させていた。元の全身絵を描き直さず、塗られた身体全体と各ポーズに属する独立したけん玉を抽出する専用extract-poses.cjsへ変更。待機0はgenis-neutral-locked.pngで固定し、再梱包後もRGBA完全一致を確認。修正した矩形に合わせて接地余白と崖の描画アンカーのみ更新。技の入力、フレーム、判定、TP、吹っ飛びには変更なし。

pose-isolation-test.cjsは61ポーズの余分な非武器部品を検出し、修正前画像で失敗/修正後で成功を確認。genis-test.cjs 130項目、実描画の通常30/必殺24/左右5カラー10、連続48サンプル、art-loading-test.cjsの62姿勢/16FX/310カラーを確認。画像QAはpreviews/all-poses.png、normals-directions.png、motion-filmstrip.png、motion.webm。
