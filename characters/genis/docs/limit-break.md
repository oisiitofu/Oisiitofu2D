# ジーニアスの専用リミットブレイク

「インディグネイト・ジャッジメント」はけん玉の打撃から火球、氷槍、重力、二度の雷につなぐ。光柱の間を飛んだコレットと異なり、投射の間合いを前後に変えながら地上へ戻り、重力で止めた位置に空から一本の大きな雷の剣を落とす。[原作の技の実機映像](https://www.youtube.com/watch?v=ackY8PJsduU)

対戦の銀髪、青い目、白い縁と丸い飾りがある青い服、木のけん玉と赤い玉を参照した。ImageGen で天文台でのカットイン、魔法、けん玉を戻す姿から腕を掲げるまでの三つの全身ポーズを制作した。標準カラーは専用ポーズ、別カラーは対応する対戦用全身ポーズで描く。

配信素材は `assets/limit-cutin.webp`、`assets/limit-observatory.webp`、`assets/limit-effects.webp`、`assets/limit-spells.webp`、`assets/limit-motion.webp`。決め技には放電と落雷を重ねた専用効果音を使う。
