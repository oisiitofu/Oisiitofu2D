# サムの専用リミットブレイク

『デス・ストランディング』でサムがタールに引き込まれ、キャッチャーと交戦する場面を軸にする。サムは荷物を載せたままよろめき、オドラデクの指す方へ振り返る。タールに足を取られたところから膝を抜き、フローターに乗って坂を横切る。荷物ケースを片手で押さえて足場へ跳び、キャッチャーの波が届く前に着地して身体の向きを変える。血液グレネードを投げ、赤い煙でタールから出る巨体の輪郭を見せる。前脚が水面を打つ瞬間に引き、サムは最後まで足場から相手を見据える。

ピポサルは自力で垂直に上がり、ラチェットは裂け目を抜ける。サムは荷物と足場の傾きで速度を変え、斜面の降下から一度だけ大きく跳ぶ。青いBRIDGESスーツ、胸のBBポッド、荷物、オドラデクを元デザインに合わせる。黒い波と人物を逆光で分離し、手で荷物を支える中間ポーズとタールが引く余韻を見せる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中6ヒットで21ダメージ、決め技で26ダメージ。フローターのデッキと足裏の接触、坂から岩棚への跳躍、振り返って投げたグレネードとタールのキャッチャーを確認。暗い景色でサムと相手が読めるように稜線と波の反射を使った。CPU同キャラ戦はストック切れ。ローカルオンラインは418フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
