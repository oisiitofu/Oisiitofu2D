# サム実装・検証

ピポサルの次にサムを登録。成人男性サイズ3（身体98px）。専用の高解像度顔〜肩ポートレート、77全身/肖像フレーム、16エフェクト、5カラーを制作。立ち姿は sam-neutral-locked.png の画素を固定。全身画像を表示し、関節リグは使用しない。画像生成は built-in imagegen、プロンプトは art-prompts.json。

NB：単発ボーラ、35Fまでのホールドで3連射。拘束は通常の有限ヒットストップ/硬直と28Fのストランド表示。Grabbed/所有者参照を作らない。
横B：キャリア投擲→低空停止。再入力で回収。停止中は両者が足場として利用でき、所有者が乗れば横入力で運ぶ。ジャンプで降りる。
上B：6F目の方向入力で射程520px以内の実地形を選び、フック到達後に巻き取る。地形に届かない場合は空振り硬直から落下。巻き取り中のジャンプで離脱。崖際では通常の崖つかまりへ接続する。
下B：短押しで追加荷物を置く/近くの荷物を回収。長押しで追加荷物を増やす（最大2）。積載で速度と荷物攻撃の威力が変わり、12%以上の被弾で1個落とす。基本装備・元の背負い荷物の絵は固定。置き荷物は所有者ごと最大3、600Fまで。足場は下入力で通過し、下B中は着地を維持する。
通常投げは後投げを撃墜、前を位置変更、上を浮かせ、下をコンボ用とし、サムだけ実飛行で校正。

検証：sam-test.cjs 90項目（15通常技×左右×密着/先端を含む）、CPU1戦2400F、オンライン2画面6場面240F完全一致。通常30場面、必殺28場面、待機左右5色、連続動作60サンプル/WebMを実描画。art-loading-test は77フレーム・16FX・385カラー画像の不一致0。既存ビビ/アルルとサムの台降り・下Bを含む回帰20項目が成功。サイズ一覧を更新。

サンズ横スマ：吹っ飛び角度を-.82rad（約47度）へ。ビーム進行向きへ飛ばす。後隙が共通の短縮処理で消えないよう復帰アニメを27Fにし、実行動全体33→49F（+16F）。通常必殺の角度は維持。左右の実被弾・43F拘束・51Fまでの終了を専用テストで確認。

チームランダム：ローカル対戦設定とオンライン部屋主ロビーへボタンを追加。4人2対2、3人2対1。オンラインは現在の参加者で均等に分け、既存の部屋主専用settings経路で送信。準備中/対戦中/ビンゴの選択確定後は変更不可。4人のブラウザで全員への反映と開始時設定一致を確認、均等な全6パターンの抽選分布とローカル3/4人も検証。
