# サム：荷物・キャリア・アンカー

追加位置はピポサルの次。立ち姿は青い配達スーツ、BB、茶髪、背負った荷物を基準とし、成人男性サイズ3（身体98px）。荷物の高さを身体の高さに数えない。

- NB ボーラガン：単発の拘束弾。長押しで3発。命中時の有限の移動制限はつかみ状態を使わず被弾後に解除。設置・投げとの干渉でもつかみ関係を壊さない。
- 横B フローティングキャリア：低空へキャリアを投げる。再入力で呼び戻す。停止したキャリアに乗ると横入力で運搬でき、ジャンプで降りる。相手も足場にできる。前進する本体へ攻撃を当てる技とは異なり、離れた運搬機と足場を操作する。
- 上B クライミングアンカー：上方向をスティックで狙って射出、実際の足場・崖付近に引っ掛けてロープを巻き取る。横入力で接近方向を調整、ジャンプで離脱。外した場合は短い反動のみ。上に飛ぶ二段攻撃ではなく、届く地形を選ぶ復帰。射程内の崖へ両側・下側から戻れるよう検証する。
- 下B 荷物管理：短押しで荷物を足元へ置き、踏み台として残す。近くで再入力すれば回収。長押しで荷物を積み直し、重い荷物状態になる。積載数が多いと移動が遅くなり、荷物攻撃が強くなる。強い被弾で追加の荷物を落とす。
- 空Nは手持ちの荷物で周囲を払う。空後は蹴り、上攻撃は箱を持ち上げ、下攻撃は荷物を叩き落とす。15通常技の全身姿勢をそれぞれ作る。
- 立ち姿を固定して全身画像で中割り。関節リグは使わない。専用の顔〜肩アップを別途制作。

検証は追加キャラの見た目・通常/必殺の密着・先端・復帰、CPU1戦、短いオンライン同期。今回のロビー・サンズ変更は専用検証する。
