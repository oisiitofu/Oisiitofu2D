# ちいかわの専用リミットブレイク

対戦用の小さな白い体、桃色の頬、さすまたを維持する。一度よろけ、さすまたを地面に立てて横へ跳び、ハチワレの合図に合わせて低い押しと上向きの押しを交互に当てる。最後は二人が踏ん張り、柄がしなる力で相手を送り出す。霊夢の札が離れた位置から効果を出す演出に対し、持ち替える手と足元の踏ん張りを軸にする。

- [ちいかわマーケット公式 ちいかわのさすまた](https://chiikawamarket.jp/collections/all/products/4573256438102)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。さすまたを支点に跳び、ハチワレと二人で討伐。途中7ヒット、決め技26ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
