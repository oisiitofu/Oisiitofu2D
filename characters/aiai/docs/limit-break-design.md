# アイアイの専用リミットブレイク

『バナナランブル』の傾くコース、スピンダッシュと段差ジャンプを使う。アイアイ本人が駆けて跳び込み、透明な球の中で重心を移して斜面を下る。バンパーへ斜めに入り、高さを変えて跳ね返りながら相手を巻き込む。上段でバナナを回収し、『たべごろ！スーパーモンキーボール 1＆2リメイク』のゴールデンアイアイに切り替わる。最後は坂を一度上って溜め直し、ゴールの輪をくぐるスピンダッシュで相手を飛ばす。

さくらの後方への跳躍やリーンベルの空中射撃とは軌道を変え、斜面とバンパーの接触で進行方向と高さが変わる。カメラは地面の傾きを少しだけ追い、バンパーの前後とゴールではコースと相手を同時に収める。球の中には走り、足を止めて身体を傾ける姿勢、踏ん張り、跳ね返りで腕を開く姿勢を全身で制作する。通常のアイアイの顔・耳・服を基準にし、ゴールデンアイアイの表面と透明球の反射を分ける。速度の残光、バンパーの衝撃、ゴールの紙吹雪と音に専用素材を使う。

- [セガ公式 ゴールデンアイアイ](https://www.sega.jp/topics/detail/210914_2/)

## ローカル検証

全身8姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音3点を制作。途中5ヒットで20ダメージ、決め技で26ダメージ。斜面、バンパー、透明球、ゴールを分け、球の回転の間も顔と踏ん張り姿勢が見えるようにした。CPU戦は相手が落下して終了。ローカルオンラインは403フレームと最後の吹っ飛びが一致。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
