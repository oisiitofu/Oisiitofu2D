# タナトスとの交差連撃からメサイアへ

2026-11-06公開。顔・制服・体型・武器は承認済みのselectionとatlasを基準にする。通常の立ち姿と既存の技は変更しない。

[公式ペルソナチャンネル](https://p-ch.jp/news/13065/)の結城理（メサイア）イラストで、白い衣装、金髪、側頭部、背部と棺の構成を確認。[公式ライセンスのタナトス](https://www.goodsmile.com/ja/product/57485/PLAMATEA%2Bタナトス)の棺と鎖も参照。メギドラオンの習得は[スキル資料](https://megatenwiki.com/wiki/Messiah)で補足する。

走り込む本人の剣撃、反転からの交差斬り、本人の空中の振りかぶりとタナトスの斬り上げ、着地の追撃を組み合わせる。最後は白いメサイアが降臨し、本人が手を伸ばす姿勢でメギドラオンの大きな爆発へつなぐ。タナトスの鎖と棺、メサイアの白い姿を専用素材で分ける。大いなる封印の物語上の代償をそのまま通常の撃墜技へ置き換えず、今回は終盤に得られるメサイアの力を採用する。連携の順序・カメラ・攻撃エフェクトは本ゲーム用に構成する。

本人の全身8枚とペルソナ4枚、専用カットイン・背景・攻撃エフェクトを制作する。縦横比を保つ共通LimitCinematic、濃いart.strike、補助のart.glowを使用。相手・本人・ペルソナ・武器先端を実描画で追えることを確認し、見やすさ設定に従う。専用音と途中ヒットを同期させる。

素材・最終生成プロンプトはlimit-break-assets.jsonへ保存する。演出・専用音・ローカル検証と公開検証を完了。登録・公開済み作品数は91／162、ディアナの公開同期は別途未確認。

## 実装とローカル検証

全身8枚とペルソナ4枚、専用カットイン・背景・エフェクト、専用音2種類を実装。斬り上げを振りかぶりから前方へ刃を出す全身姿勢へ修正し、ペルソナの可視の剣先を900×800セル上で測り、相手へ合わせてから左右反転する。途中9回のヒット、対戦とトレモの補充・発動・空振り・再試行・ガード・無敵・多人数停止・終幕の吹っ飛び、両向き描画、カットイン比率と攻撃のsource-over合成、専用2音の実再生を確認。CPUは接敵距離から同キャラ2体を1戦ずつ確認し、両者とも撃墜で結果まで進行。ローカルオンラインは397フレームでダメージ・吹っ飛び・ホスト設定が一致した。

最終修正後の連続再生を1440×900で録画し、全身の動き・剣先・相手・ペルソナの切り替えを比較した。待機や既存の通常技は変更していない。
