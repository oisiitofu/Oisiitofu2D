# カラテ家

リズム天国。添付 karateka.png の丸い白い顔・短い黒い髪・白い道着・黒帯・太い黒輪郭を維持。スカポンの次、画面46/登録135。134形態・選択可能128・非表示6。体格96/重さ90/ECB85。きあい中も大きさは固定。

## 技

- 通常技は拳の56〜64、蹴り68〜80程度の間合い＋半径18。身体から先端へ連続判定で密着の穴を防ぎ、拳と蹴りの間合いを分ける。最初の実描画でヒットの星が身体から離れすぎたため、新キャラの値だけ調整。上方向112、下方向18。星の位置は実際の判定先端、蹴りには薄い白い軌跡。黄色のパンチ0と軌跡6は素材の右向きを基準に回転→左右反転→平行移動。ダッシュ攻撃は既存の滑走処理へ登録。
- 通常必殺「ジャストラッシュ」は8〜10Fの3ダメージ。13〜19Fの押し直しで20〜22Fに3ダメージ、25〜31Fの押し直しで32〜35Fに8ダメージ。最大3段、最初の2段は固定吹っ飛び12、最後だけ通常の吹っ飛び。長押し自動連打なし、入力を増やしても無限に延長しない。単発24F、2段36F、3段45Fで動作終了、別の再使用待ちはない。リズムの受付中は小さい星と3点で表示。
- 横必殺「ステップカウンター」は最初の8Fに後ろへ下がり、4〜11Fに受けた打撃を反撃（5〜9F/13ダメージ、受けた技が強い場合は共通カウンターの威力補正）。つかみで崩せる。空振り時も12〜18Fに押し直すと6〜9F/8ダメージの返しパンチ。返しを出さない場合は24Fで終了。地上は崖止め、空中1回。近接技に余分な再使用待ちを付けない。
- 上必殺「かべけりジャンプ」は8Fに方向を指定して跳び、最初の8Fは強い上昇。近い壁際か相手への実命中で1回だけ蹴り直し、vy=-18。相手には5ダメージ＋蹴り直し4ダメージの窓。途中の横入力で軌道を変えられる。壁も相手もない場所では普通の有限ジャンプ、必ずしりもち。内側下からは側面へ抜けて復帰。被弾で再使用資格が戻る。
- 下必殺「きあい！」は18Fで240有効F/約4秒強化、600有効F/約10秒の固有再使用間隔。移動1.12倍、通常技の発生を2F早める（最短3F）、持続を保つ。通常技の基礎吹っ飛び1.12倍/成長1.08倍、ダメージは維持。ラッシュのリズム・カウンター受付時間は加速しない。終了で硬直・慣性・サイズを変えない。撃墜で時間と待ちを解除。空中下Bは急降下にしない。

## 検証

プロジェクトルートから実行。Playwright/sharpのあるNode環境を使う。

```
node characters/karateka/tests/karateka-test.cjs
node characters/karateka/tests/karateka-visual-test.cjs
node characters/karateka/tests/karateka-cpu-test.cjs
node characters/karateka/tests/karateka-online-test.cjs
ART_IDS=karateka node art-loading-test.cjs
node characters/karateka/tests/karateka-public-test.cjs
```

専用353項目合格。通常/気合の小さい相手への密着・先端・両向き・上下前後・ガード、ラッシュ押し直し/最大3段/長押しと拍外入力/有限動作、横B自動反撃/返し入力/即再使用、気合の発生短縮/持続維持/終了時の吹っ飛び維持、壁と相手の蹴り直し・左右と内側下の復帰・崖の手を確認。保持ボタン検証は毎フレームの新規押下を送らない条件へ訂正し、壁蹴りは先に崖をつかまない配置でも確認。描画の先端位置・方向・顔の白と道着色替え30項目合格。半透明素材に対して完全不透明255だけを検査していた条件を240超へ、顔の検査範囲を道着の入らない上部へ訂正。アート49姿勢・12効果・245カラー不一致0/例外0。CPUヴィヴィ/フィオルン各2400F、実命中・必殺・気合・有限座標。CPU結果は対人勝率ではない。独立2クライアント201Fで3段ラッシュ/カウンター/上B/気合と終了、座標・ポーズ・段数・残り時間・移動速度・発生を比較して一致。無関係な全キャラ検証なし。
