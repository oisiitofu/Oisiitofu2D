# クライヴの専用リミットブレイク

フェニックスで間合いを詰め、タイタンの地面を使った打撃で止める。氷の足場から飛び込み、対戦用の外見のまま炎をまといイフリートの力を使った決め技へ。ライトニングの射撃と剣の連続切替と違い、地表と高度の変化で召喚獣の技を出し分ける。

改修では対戦用の全身素材と選択肖像から、黒い髪と鎧、赤い胴とマント、幅広の剣を参照した。組み込みImageGenで、剣を振るクライヴの背にイフリートの影が浮かぶ横長カットイン、火山地帯、フェニックスの火、タイタンの砕ける岩、シヴァの氷、イフリートの火柱と影を制作した。`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-ifrit.webp`、`assets/limit-effects.webp` に収録。イフリートは本人の背後に現れる炎の影として扱い、地獄の火炎では背面の火柱と前面の命中火花を重ねる。
