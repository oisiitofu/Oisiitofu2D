# ナイツの専用リミットブレイク

ツインシーズの夜空で、イデアの光を追いながら飛行する。最初は低空のドリルダッシュで相手を浮かせ、上へ急旋回して星の軌跡を描く。相手の手前を下降し、背後へ回ってパラループを閉じる。閉じた軌跡が相手を引き寄せる間にナイツは大きく離れ、斜めのドリルダッシュと星の放出で締める。直近の機兵の砲撃やシャドウの瞬間移動と比べ、姿が見えたまま曲がり続ける飛行と、軌跡の閉鎖が連撃の起点になる。

既存の青い瞳、紫の帽子と衣装、ピンクの襟、赤い胸の宝石、白い袖と金の装飾を基準に全身を描く。上昇、横滑空、下降、旋回、両手を開く姿勢、ドリル、制動と余韻に専用姿勢を割り当てる。軌跡は実際の飛行位置から描き、閉じるまでの星は背景演出、閉鎖後の攻撃と最後の放出は輪郭の濃い専用素材で示す。

世界観と終盤の光はセガ公式のツインシーズ・イデアの紹介、飛行とパラループの関係はセガサターン版説明書を参照。ゲーム内では機敏な飛行、方向転換、パラループの中心と相手の位置、両向きのカメラ、カットイン比率を連続再生で確認する。

## ローカル検証

途中5ヒットで17ダメージ、決め技で24ダメージ。最初のドリルを手元の高さに合わせ、星の軌跡を二重線と星で見せた。ローカルオンラインは402フレーム一致。 対戦、トレモ、ガード、空振り、無敵、複数人戦、決め技の撃墜、両向きの描画、カットインの縦横比、専用効果音と全編の連続再生を確認。CPU戦は1戦を実施し、時間切れで結果へ進んだ。

## 公開検証

Sites v333とGitHub 05f829dへ反映。公開URLで対戦・トレモ・発動・ガード・空振り・決め技の撃墜を確認し、専用素材とバンドルのSHA-256を照合した。公開オンラインは固定入口のHTTP 503で部屋作成に進めず、同期は未確認。
