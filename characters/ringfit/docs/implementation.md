# リング実装

- カラテ家の直前。サイズ2・94px、重量94。女性主人公のリングコン・灰色ウェア・オレンジの髪と黒いレギンスを維持する。専用高解像度選択画像、76全身画像、16FX、5カラー。
- 下Bは短押しでスクワット→プランク→チェストプレス→ヨガを選択し、長押しで実行。命中で蓄積したエネルギーを25消費して攻撃を強化。ヨガは付近で集中するとエネルギーを少量回復する。
- NBは選択スキルに応じて通常の空気砲、引き寄せ、低い地面向け、上向きへ変化。横Bは短いステップから発射点を操作する圧力攻撃。敵へ高速突進する共通動作を使わない。
- 上Bはスクワットの保持と解放による跳躍と、上昇後の有限のリング支え。空中再使用を制限する。下Bの選択は短く終わるため、空中からの着地は最初の浮遊台への接触時点で確認する。
- CPUもスキル選択・エネルギー消費を使う。固有のクールダウンと選択は通常の決定論的更新で進み、オンラインの同じ入力から同じ状態になる。
- 関節変形をせず全身画像で運動姿勢を切り替える。抽出時の細い接触で隣のコマが結合しても、各身体からの領域分割で全16コマを保持する。中間作画の前の待機画像はneutral-locked.pngで維持する。
- 検証は専用83項目、通常/連続姿勢/左右/カラー75場面、必殺14場面、CPU2試合、2クライアント331フレーム一致。原画の通常技・スマッシュ・空中技を別姿勢で確認する。
