# 専用リミットブレイク

赤い衣装と対戦用の斧で、階段を一段ずつ詰めながら低い薙ぎと頭上からの振り下ろしを連ねる。プネウマの浮遊と区別し、足を止めて斧を返し、最後は床を割る斬撃へ。

銀髪、紫の瞳、金の角飾り、赤い皇帝衣装とアイムールの輪郭を対戦素材で確認し、斧を振り抜く横長カットインを ImageGen で制作した。左右の進行に合わせて玉座の階段を反転させ、打撃、低い薙ぎ、高い位置からの打ち下ろしを異なる火花と土煙で描く。狂嵐では斧の軌跡を大きな赤い刃にし、石床の亀裂を起点に破片と残り火を広げる。

配信素材は `assets/limit-cutin.webp`、`assets/limit-throne.webp`、`assets/limit-effects.webp`、`assets/limit-debris.webp`。
