# ゾーイの専用リミットブレイク

対戦用の黒髪とマゼンタの差し色、黒い衣装を維持する。エレパンダも黄色と黒の体、耳と爪を維持し、二人が一緒に映る構図を優先する。

ゾーイの合図でエレパンダが床を踏んで相手を弾ませ、いったん離れて円弧を描いて走り込む。爪の追撃で位置を変え、斜めに滑りながらイエロータンクを撃つ。最後は武器を下ろし、両腕で放電を地面へ通す。ウルグリムの裂け目で位置を入れ替える構成に対し、騎乗したままの重心移動、足元の接地と射撃の反動で軌道を見せる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。ゾーイとエレパンダの対戦用デザインを維持し、旋回、爪、イエロータンクと放電を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
