# ゾーイ＆グリズボルト / Zoe & Grizzbolt

添付zoe.pngを基準にパルワールドのゾーイをイヴの前へ追加。大きな黄色いグリズボルトと肩に騎乗した小さなゾーイを常に一体の全身画像として表示。人型段階へ入れず、ペア全体156px・重量128の特殊体型。

built-in image_genで全身55姿勢、16FX、専用1536×1024上半身選択画像を制作。ゲーム用56フレーム/5カラー。保存先は[assets](../assets/)、正確なプロンプトは[image-prompts.json](image-prompts.json)。待機0を固定し、移動シート/追加シートの共通姿勢で倍率を校正。関節リグを使わず、全身の中間画像を表示。通常技15種は別の全身実画像。横強54、空前53、横必殺49/50、上必殺51、溜め放出52は追加専用画像。下スマ後半は同じ専用低い両腕薙ぎ46で振り返り、空後14を流用しない。崖38は肩のゾーイと両足を含む全身と上に伸ばした爪を保持。高解像度の専用肖像を実カードのバトルメイジ/イヴと比較。

- NBイエロータンク：12Fの単発5.5ダメージ。10Fに保持していると12/20/28/36/44/52Fに1.8の小弾、60Fに7ダメージの帯電弾。途中で離すと17Fの後隙へ。小弾は削りのみで連続被弾硬直を作らない。弾は32Fで消え、同時4発まで。通常の近接必殺に時間式クールダウンを付けない。空中から着地しても射撃を保持。
- 横Bライトニングクロ―：8Fに小さく跳び、13〜17Fに5ダメージの爪。実命中して18Fも保持していれば、最大150pxの実移動で相手の反対側へ回り、28〜33Fに5ダメージの逆側の爪。35Fも保持すると40〜46Fに10ダメージの両爪の叩きつけ。空振りでは追撃せず32Fで終わる。無敵/長距離ワープはない。空中でも再使用可能。
- 上Bライトニングストライクバウンド：9Fまで落下慣性を止めてから、最初の左右入力で斜めに跳ぶ。14〜19F後の頂点で雷の反動を溜め、20F後にその時点の左右入力へもう一度跳ねる。二つの攻撃窓は7/8ダメージで独立。下側に入り込んだときは側面へ退避して上昇。左右の場外から崖へ復帰可能。終端は不透明な専用尻もち35へ移り、通常立ち姿を挟まない。落下後隙でも共通の通常空中横移動が可能。
- 下Bディスチャージ：9F以降に離し、5F後から単発の電撃放出。24F/42Fで強化、48F自動解放。9/13/18ダメージ、半径115/158/205px、帯電25/35/45。両側へ広がる。空中の溜めは着地で消さない。
- 帯電：電気属性の爪/雷/強化弾で通常25ずつ増え、最大100の次の電撃で消費。通常の吹っ飛びを維持しつつ被弾硬直を17Fほど伸ばし、28FのSTUN表示。別の追加ヒット/吹っ飛び停止は作らない。相手の頭上にゲージ、最大時は電気を表示。3秒無命中後から減少。ガードには付かず、復活でリセット。複数のゾーイでも減衰は毎F一度。

近接coverageを一度だけ適用し、爪より先の切断面と判定を一致。素材0/2は右凸、1は上凸、13は下凸。ローカル回転後に左右反転。空上は頭上の曲線1つ。上スマは3本の雷柱で、それぞれ同じhitIDの最終capsuleに直接サイズを合わせるauthoredEffectCoverageを指定し、汎用補助スタンプの二重描画を避ける。曲線扱いにはしない。FX8は隣セルへ少し広がる元の円環を切らずに抽出し、隣のFX9へ混入させない。弾/小物/ガードに近接拡張を適用しない。通常投げは後ろ撃墜/上浮かせ/下追撃/前位置変更、攻撃上がりは専用の短い単発蹴り。

機能134項目、左右実描画50場面、CPU対ビビ2400F、56姿勢/16FX/280カラーの読み込み照合を実施。オンラインと公開結果はBALANCE.md。検証画像/結果はGit管理外のpreviews。

実サーバー2ブラウザで7場面840Fの同期一致。ゾーイの射撃/長押し/命中追撃/頂点で方向変更/溜め放出/空中射撃着地に加えて、ソルの上B後の通常横移動を確認。例外0。
