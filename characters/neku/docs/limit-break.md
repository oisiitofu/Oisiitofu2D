# ネクのリミットブレイク

ネクとシキがシンクロし、渋谷の交差点が漫画のコマのように割れる。ネクのサイキックとシキのぬいぐるみ・にゃんタンで挟み込み、最後は左右のコマが合流する地点に大きな一撃を入れる。原作のバッジ、パートナー、渋谷のビジュアルを使った本作独自の連携。

- [サイキックとバッジ](https://www.jp.square-enix.com/subarashiki-final-remix/system/index.html)
