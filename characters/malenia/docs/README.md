生成時の全文指示は同フォルダの `image-prompts.json` と `repair-prompt.txt`。体格110・重さ96。刀と翼の幅で身体がずれないよう、ポーズ別の身体の中心と足元を設定。第2形態の小さい元画像は別途縮尺を補正。崖の手の位置も両形態で設定する。色替えは主に暗い赤の服へ適用し、金の装甲と明るい髪の色・明度・透過を保持する。

腐敗領域は半径70、18/42/66Fに各2ダメージ。毎フレーム命中しない。花・分身・領域には無敵/ガードの判定と、各攻撃の命中回数制限を適用。撃墜で形態・待ち時間・残留物を解除する。空中下Bは急降下にならない。

刀の実命中で0.4％ずつ、1技で最大1％回復する。ガード・無敵・空振り・分身・花・腐敗領域では回復しない。変身中に始めた技は完了までその姿で終わり、次の技から通常形態へ戻す。

## 判定とエフェクト

長い刀の前後・上下へカプセル判定を配置し、密着への接続も維持。弱1の外端174px、横強164px、横スマ217px。刀が特に長い突き姿勢を基準にしている。水鳥は回転の素材、突きは細い赤白の光、花と腐敗は専用の素材を使う。右へ進む素材へローカルX反転→回転を適用し、実判定・分身の進行方向へそろえる。
