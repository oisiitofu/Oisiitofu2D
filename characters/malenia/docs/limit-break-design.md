# マレニアの専用リミットブレイク

対戦用の金の翼兜、赤髪、赤いマント、義手の長刀を維持する。水鳥乱舞では、低い踏み込みから一度高く浮き、短い滞空で間を取ってから上段・中段・地表すれすれの順で連撃する。最後に相手の上で向き直り、対戦にある腐敗形態の衣装と翼を基準に、落下する蕾から緋のエオニアへ開花する。ダーナは足場を渡って武器を切り替えるが、マレニアは空中で軸足を止める間と、落下から円形に開く花で動線を変える。対戦用の通常形態と腐敗形態の全身アトラスを、それぞれ生成の参照と実描画の照合に用いる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中7ヒット、決め技26ダメージ。金色の翼形兜、赤髪、義手、片刃を対戦素材に合わせ、水鳥乱舞と緋のエオニアを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
