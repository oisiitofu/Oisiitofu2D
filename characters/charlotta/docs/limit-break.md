# シャルロッテの専用リミットブレイク

低く盾を構え、相手の踏み込みを受け流す。盾で止めた位置から回転斬りで押し上げ、ノーブル・ストラテジーで跳び越えず相手の手前に着地して剣を引く。そこから盾の上で光を受けて同じ側に踏み込み、ノーブル・エクスキューションの光の刃を縦に振り切る。エトナの空中からの自由落下と異なり、盾で接触した地上位置を起点にして、低い足運びから剣を振り上げる。

対戦素材の小柄な体型、冠と鎧の形、盾、幅広の剣を参照する。発動時は顔と盾を見せ、最後の寄りから引きへは、剣の長さと相手の吹っ飛ぶ高さが同時に分かる構図を使う。

専用の横長カットイン、城の中庭、盾の衝撃・剣閃・上昇する光の刃・飛散の透過素材、盾の構え・踏み込み・切り上げの全身姿勢3種を制作した。標準カラーは専用全身姿勢、別カラーは対戦用の該当姿勢を使う。盾で受ける音と、決め技が当たる音を個別に作った。
