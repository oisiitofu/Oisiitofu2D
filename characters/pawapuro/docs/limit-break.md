# パワプロくんのリミットブレイク

球の高さを変える4連投からバッティングへ持ち替え、4連打のあとに溜めた大きなホームランを放つ。投打の能力と勝負を決めるホームランを基準にした、このゲーム用の専用演出。途中8ヒットは合計17ダメージ、最後に22ダメージと斜め上への吹っ飛びを適用する。実在の選手の専用能力をパワプロくんの原作技として扱わない。

初撃の近接はガードと無敵で防げる。空振りではゲージを消費し、被弾でため直せる。命中時は1人を捕捉し、ほかの参加者と対戦時間を止める。途中の球とスイングはダメージ・被弾反応だけを刻み、最後に解放する。最後は球と相手を上方へ追うカメラから引きへ移り、HOME RUN!の文字は画面の向きにかかわらず読めるように描く。

ビルトイン画像生成では既存の選択画像と添付済みモーションシートを参照にした。大きな頭、丸い手、短い手足、口や鼻を描かない顔、赤白の服、Kの帽子を保つ。16対9のカットイン、夕方の球場、投球の溜め・リリース・バットの溜め・振り抜きの透過全身4姿勢、投球・バットの軌跡・命中火花・ホームランの透過4種を指定した。リリース画像の放出済みの球は生成で除去し、飛ぶ球は独立して動かす。

球とバットの曲線の凸側は右、最後の球は素材自体が右上へ進む。画面全体の反転で左向きへ対応し、カットインはLimitCinematicで比率を保つ。攻撃はart.strike、溜めの補助光はart.glow。揺れと明滅は見やすさ設定へ従う。専用の投球音は空気を切る音と短い接触音、ホームランは木製バットの硬い音から球の伸びと短いスタジアム風の音へつなぐ。

素材はこのキャラの `assets/limit-*.webp`、効果音は `assets/audio/se/pawapuro-limit-*.wav` に保存した。
