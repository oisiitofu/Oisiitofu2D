# ジューダス / Judas

テイルズ オブ デスティニー2のジューダスをロイドの直前へ追加（judas）。骨の仮面と角、青い飾り、黒紫のマント、銀縁の鎧、右の短剣/左の長剣を基準とする。小柄な男性として人型サイズ2・94px。

builtin image_genで全身53姿勢、16FX、専用の高解像度1536×1024上半身画像を制作。保存先は[assets](../assets/)、正確な生成/補修プロンプトは[image-prompts.json](image-prompts.json)。ゲーム用54フレーム（全身53＋肖像）・5カラー。通常技15種はそれぞれ別の実画像。部品リグを使わず全身ラスターを切り替える。元の待機0は固定し、追加シートの同じ立ち姿で倍率を校正する。戻り斬り49の元絵だけは左向きのためローカル右向きへ正規化。FX7の元絵は下にふくらむため上下反転し、上向きの凸面へ正規化。仮面の角が切れた専用選択画像を補修し、リオン/ロイドの実カードで寄りを比較した。

- NB「月閃光 → 月閃光法」：SP12。9〜13Fの直接斬撃6ダメージから25Fに前方へ三日月を放つ（9ダメージ、45F生存）。三日月は少し上昇後に落ちていく。生存中の同じ弾と発射間隔30Fだけを再射出制限とし、他の近接技へ制限を波及させない。
- 横B「幻影刃 → 幻影回帰」：SP16。8〜13Fに一歩20pxで斬り抜け（7ダメージ）、22〜27Fに振り向いて元の位置へ戻りながら斬る（9ダメージ）。リオンの相手位置への移動と異なり、相手の有無に関わらず自身の開始位置へ帰る往復技。帰路にも隙と喰らい判定があり、無敵/透明化は付けない。地上では足場端を超えて前進しない。空中でも元の位置へ戻り、硬直が解ければSPの範囲で再使用可能。
- 上B「飛連衝 → 萬葬展開」：SP18。7Fまで落下慣性を止め、斜め上へ飛び上がる6ダメージの斬撃と、その場寄りの空中回転斬り7ダメージへ進む。上昇開始22〜34Fに必殺再入力で向きを選び、さらに斜め上へ12ダメージの追撃。リオンの任意方向空中突進と異なり、追加入力も上へ伸びる復帰/縦追撃。SP不足時でも初段の緊急復帰は可能。技の最後は専用の不透明な尻もち絵35へ移り、着地/崖まで上Bを再使用しない。左右の場外から地上へ戻れることを確認。
- 下B「ネガティブゲイト → イビルスフィア」：SP30、34Fの詠唱後に前方145pxへ68Fの渦を開く。12/28/44Fに2.5ダメージ、60Fに11ダメージの爆発。範囲内の行動可能な相手へ弱い横引力を加える。被弾硬直/ヒットストップ/予約吹っ飛び/つかまれ/ガード中の速度は引力で書き換えず、拘束・瞬間移動もしない。既存の渦の間は同じ技を重ねない。他の技は通常通り使用可能。空中でも使えるが詠唱中は落下する。

SPは最大100、開始/復活時100。通常攻撃2消費、命中6回復。無行動時は毎F0.8、攻撃中0.25、下B詠唱中0.1回復。被弾硬直/ヒットストップ/つかまれ中は回復しない。SP0でも通常技と上Bの緊急版が使える。フレームと入力だけで決定し、オンラインへ同じ状態を同期する。HUDに紫炎5個、残量、連続バーを表示。

近接は武器の先と密着までMeleeBalance.coverageで一度だけ広げる。飛び道具/渦/つかみへは拡大しない。AttackEffects.imageで可視の切断面を最終判定の外縁へ合わせる。上強/上スマ/空上は頭上に広がる曲線1個、回転技は左右へ。右向きに正規化した素材をローカル回転した後、実際の向きへ反転する。通常投げは後ろ撃墜/上浮かせ/下追撃/前位置変更。専用の弱い単発攻撃上がりを維持。

検証：機能153項目、左右48描画場面、CPU対ビビ2400F、54姿勢/16FX/270カラーのchecksum差0。結果画像/JSONはGit管理外のpreviewsに保存。オンライン同期と公開版の結果はBALANCE.mdへ記録する。
