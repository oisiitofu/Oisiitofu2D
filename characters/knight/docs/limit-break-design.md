# 騎士の専用リミットブレイク

対戦時の白い角の仮面、暗い外套、小柄な体格と釘を基準にする。釘を真下へ打って二度跳ね返り、壁から向きを替えて下降。着地で影が床に走り、最後は引きの画角で足元から上へ伸びる虚無の攻撃と相手を映す。モーフィーズロウの大きくなった四肢による跳躍と違い、釘先の接触点で高さと向きを変える。連撃は15〜22フレームを目安にする。

- [Team Cherry公式 Hollow Knight](https://www.hollowknight.com/)

## ローカル検証

全身12姿勢、専用カットイン、背景、画面内小物、攻撃素材、専用効果音を制作。釘で二度跳ね、壁から折り返して虚無の奔流へ。途中7ヒット、決め技27ダメージ。 対戦、トレモ、CPU戦、4人戦、左右の実描画、カットイン比率、攻撃の濃さと専用音を確認。
