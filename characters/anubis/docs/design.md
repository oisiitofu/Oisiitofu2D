# アヌビス / ANUBIS

ユーザー指定：ジェフティの次。添付シートを基準に、6枚のベクターウイングと長い節状の尻尾が待機・移動・攻撃で動くようにする。専用の頭部/肩アップを制作。

## 固有の能力・操作

ジャッカル状の頭、黒/金の細い装甲、白銀の6枚羽根、赤いセンサー、長槍と尻尾を維持する。全身フレームで羽の開閉と尻尾のうねりを描き、身体の部品リグで変形させない。待機用の8段階ループと飛行用ループを追加。機体の姿勢ごとに、尾が動きに遅れて追従する。姿勢の基準0は固定し、頭・胴・脚・接地は維持する。巨大ロボなので人型の5段階には入れず136px基準。

赤いレーザーは追尾→追尾終了、転移は予告→横側へ到着→槍の一突き、バーストは発射位置の射線と着弾遅延を区別する。羽を動かすだけのゲージではなく、攻撃と飛行で開き方が変わる全身モーションを使う。

## 必殺技と連携

- NB・ホーミングレーザー：18Fに3方向へ赤いレーザーを射出。一定時間のみ追尾し、その後は直進する。長押しで強化ではなく、早い拡散発射で相手の回避を追わせる。回避と地形で外せる。無限追尾・恒常的な多段拘束にしない。
- 横B・ゼロシフト槍撃：入力方向を予告し、相手が範囲内にいればその側方へ転移して一突き。ジェフティのロック共有/任意追撃と異なり、アヌビスは相手の位置を読み、一度確定した場所へ単発の槍撃を置く。発動中のB再入力で一度だけ貫通斬りへ派生できるが、後隙とクールダウンを増やす。出現点の予告・空振り後の長い隙で対処。空中は1回、到着点が地形内なら短縮。
- 上B・ベクターウイング旋回上昇：6枚羽を順に開き、左右入力で弧を描く飛行。ボタン保持で旋回半径を広げ、解放で向きを固定する。上昇中は無攻撃、終端の槍薙ぎ一回だけ。ジェフティの上下による推力配分/解放斬りとは別の軌道操作。真下は有限の側方退避後に旋回上昇し、終了後しりもち。
- 下B・バーストショット：溜めて球体を投げ、距離/地形接触で大きな爆発。長押しで飛距離と爆発範囲が増える。射線固定のジェフティのキャノンとは異なり、離れてから爆発する弾で場所を制限する。ボタン解放後は相手を追わない。爆風は単発ID、0%での境界直接撃墜を避ける。相手は球の下/後ろへ回るか、爆発前に離れる。

## 通常技・相手の対処

長い槍の先端と尾払いの範囲を区別し、空Nは槍を片腕で前方へ回す浮遊姿勢。空後は後方へ槍を振り、空上は翼と槍を頭上へ、空下は槍を下へ向ける。共通の身体回転と輪エフェクトにしない。翼を開くスマッシュ・旋回飛行では体勢が大きく、読み違いを差し込める。通常投げは長柄/剣主体として前後が位置替え、上/下の役割はThrowTuningのキャラ別ルールを利用し、必殺技へは波及させない。

飛行機構は90Fのジャンプ長押し浮遊。被弾/ヒットストップ/しりもち中は使えず、空中の行動回数とクールダウンを有限にする。
