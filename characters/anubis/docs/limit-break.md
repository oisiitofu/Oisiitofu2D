# アヌビスの専用リミットブレイク

短い槍の接触からロックオンし、相手の下、対角の背後、真上へゼロシフトで移る。出現点を赤いスラスターの軌跡で先に示し、槍の切っ先を到達点から出す。最後は地上から一方向に駆け上がるカイと異なり、真上で静止してスラスターを開き、槍で示した一点へバーストを撃ち下ろす。カメラは移動中に両者を収め、発射後は着弾点から引いて欠片と相手の吹っ飛びを追う。

細い外装、逆関節、槍、背中から離れたスラスターを対戦素材から確認する。移動を立ち姿の位置変更だけで表現せず、構え、出現後の突き、槍を下へ支える姿勢を描き分ける。連撃の命中候補は45、62、80、98、119、139フレーム目。

横長の発動絵、軌道リング、転移・槍撃・下降する光・着弾の専用透過素材と、空中制動・真上での溜め・撃ち下ろしの全身姿勢を制作した。転移の音は機体が真上に出現する区間、バーストは光が地面に届く区間に合わせる。標準カラーに専用全身姿勢を使用し、別カラーは対戦用の対応姿勢で描く。
