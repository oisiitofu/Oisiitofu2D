# アヌビス追加

- 登録: ジェフティの次。非人型メカの136px。全身92枚、専用上半身ポートレート1枚、効果16枚。
- 翼・尾: 元の立ち姿0を保持。全身中割り77〜83の待機往復ループと84〜87の空中ループ。足元の画素重心を表示アンカーに使用し、尾の左右移動で本体がずれないようにした。部分リグ変形は使用しない。
- NB: 18Fで3本を分散発射。初期18Fのみ旋回制限付き追尾、その後は直進。
- 横B: 8Fで到着点を固定、12Fでゼロシフト、16〜20Fで槍撃。22〜32FにB再入力で追加突き。追撃のリスクは後隙とクールダウン増。空中1回。
- 上B: ベクターウイングを開いて曲線を操縦する飛行。長押しは旋回範囲を広げ、離すと向きを固定して終端の単発斬りへ。ステージ下は有限の横移動で抜けてから上昇。最大43F飛行、着地まで再使用不可。
- 下B: 12〜56Fの溜めで射程と爆発範囲が変わる時限オーブ。着弾/地形/導火時間で一度だけ爆発。追尾なし。最大威力で0%の相手が直接境界へ飛ぶことも検証。
- 通常技の近接だけ共通coverageを適用。同じ窓の先端/密着のカプセルを維持。投射物へcoverageを適用しない。槍の前/後/上下/斜めと尾払いで素材と向きを個別指定。
- CPUは距離別のレーザー/バースト/槍撃、復帰の舵取りと長押し終了を使用。

検証: 専用109項目、左右75描画、必殺20描画、翼尾56フレーム、CPU2戦、オンライン2クライアント331F一致。ベイク93/16/465で透過・カラー不一致0。公開後の結果はpublication-oct25-anubis.jsonを参照。
