# レイマン — 浮遊グローブ・ヘリコプター・ルミ

メタビーの次。特殊体型82px。腕/脚のない原デザインが最重要。頭・胴・左右グローブ・左右靴を全身画像の中で離して描き、間を透過にする。連結する棒や腕/脚を追加しない。専用の顔/肩ポートレートでは赤いフードと紫の上体を含める。

- 固有能力: 独立した手足を使うリーチ。手を出している間は本体の接近攻撃を弱め、手が戻ってから通常攻撃を再使用できる。空中ジャンプ長押しの有限ヘリコプター浮遊を付与し、攻撃/被弾中は適用しない。
- NBグローブシュートは往復する手。長押しで距離と大きさ、離して発射。手は地形で戻り、戻りに本体を動かして射線を変えられる。同じ手が何度も当たる無限連打にしない。
- 横Bヘリコプターは横突進ではなく、髪を回して一定位置を中心に横へ漂う有限浮遊。B再入力で風の輪をその場に残して通常落下へ移り、輪はルミを運ぶ。相手を追い回す攻撃技ではなく間合い調整とルミ運搬。空中で自由に時間を回復させない。
- 上Bロケットパンチは先にグローブだけを斜め上へ放つ。最大距離で停止し、Bをもう一度押す/一定時間で胴と靴が手の地点へ引き寄せられる。到達後は無攻撃で落下。髪浮遊/風の輪の近くなら到達方向を横に変更できる。グローブの狙い→引き寄せの位置選択が復帰の核。手に対する接触や地形で手の位置を制限し、無限ワープは不可。
- 下Bルミ召喚は光るルミを1体置く。通常攻撃が当たるとルミが短く反応して光を放つ。グローブ/ヘリコプターの風に触れるとそちらへ流れ、一定時間/一度の反応で消える。巨大ゲージだけで個性を表現しない。

相手は手が出た後の本体、引き寄せ先、ルミを破壊して対処する。パンチ/靴の蹴り/髪の風/ルミの光は別のモーションと命中音を持つ。
