# レイマンの専用リミットブレイク

対戦用の橙色の髪、赤い襟巻き、白い輪のある紫の胴、浮いた白手袋と黄白の靴を維持する。

テレスコピックフィストとヘアコプターをつなぐ。足場を跳ねて相手より高く上がり、滑空しながら手袋だけ先行させる。相手を弾ませた後、本人は別の足場に着いて拳を溜め、戻ってきた相手を大きな拳で弾く。メタビーの固定射線と異なり、足場、飛ぶ手袋、本人を一つの引き画で追える構成にする。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。対戦用の髪・襟巻き・胴・手袋・靴を維持し、跳ね上がり、滑空と飛ぶ拳を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
