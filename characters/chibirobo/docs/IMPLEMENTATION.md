# ちびロボ

ユーザー添付 `tibilob.png` をデザイン基準とし、全身ラスターポーズ48枚と独立した12エフェクトを画像生成。頭・胴・脚の比率を保持し、関節リグを使用しない。

NBは短いプラグの往復打ちで、命中すると反動で少し戻る。SBは溜めて投げる独立プラグで、地面に一度だけバウンド。既存の横突進とは異なり本人は残る。上Bは最初に上昇し、その後左右に操舵可能なチビコプター。回避で尻もち落下へ移行。下Bはマグカップを構えたまま低速移動できる防御で、攻撃しない。

SBは同時に1個まで、通常近接技に再使用クールダウンを設けない。下Bのダメージ軽減は共通ダメージ計算へ `chibiroboGuarding(o)?.6:1` を1回追加する。上B・下Bの入力中もヒットストップ/被弾硬直の吹っ飛びを消さない。

エフェクトはキャラ絵に焼き込まない。弧の凸側は右を基準とし、ローカル回転後にキャラの左右を反転する。サイズは特殊体型72px、全身倍率を共通化。元シートは `assets/`、組み立ては `tests/assemble-art.cjs`、検証用画像はGit対象外 `previews/`。

## 制作と検証

- 画像生成は添付シートを参照した24コマ×2枚と12エフェクト1枚。等間隔6×4配置、全身、文字/背景/焼き込みエフェクト無し、銀色の頭・体・黒いプラグとケーブルを保持する指示で制作した。
- `node characters/chibirobo/tests/chibirobo-test.cjs`：122チェック成功。小さい相手への密着と先端、左右、SBの溜め/単独配置、DBの移動/軽減/終了、UBの操舵/キャンセル/左右崖外復帰を確認。
- `node characters/chibirobo/tests/chibirobo-cpu-test.cjs`：ヴィヴィ相手に3000Fの1戦、双方命中、必殺使用、有限座標、ブラウザ例外なし。CPU結果を人間同士の勝率とは扱わない。
- `node characters/chibirobo/tests/chibirobo-visual-test.cjs`：15姿勢を左右で実描画。横強が上向きの腕に前方判定を付ける不一致を修正し、前へプラグを振る姿勢へ変更。上強/上スマッシュ/空上は空中プラグ打ち上げ・地上の上振り・プロペラ姿勢で分けた。選択画面も頭部の見切れ無し。
- オンラインの短い代表場面確認と公開後QAはrootの統合時に実施。
- 統合時の追加素材QAで、FXの等分切り抜きに次行の色片が混入していたため、`assemble-art.cjs` の `rowEdges` を列ごとの可視境界へ修正。プラグ軌跡/歯ブラシ/スプーン/マグを含む12枚を再確認し、他セルの色片を除去。49ポーズの内容と寸法、判定/操作データは変更していない。
- 最新配信素材を `AttackEffects.draw` 経由で左右30コマ撮影し、曲線系上攻撃を頭上の広い1弧へ統合した見た目を確認。FX3の地面噴出は斬撃と同じ回転をかけず、元の上向きの噴出を保持。
- `node characters/chibirobo/tests/chibirobo-ledge-art-test.cjs`：左右とも崖の手位置が誤差0.00001px未満で一致し、実画像でも手頂点が崖角に接続。専用の握り座標を使うため首/頭/足でつかまらない。
