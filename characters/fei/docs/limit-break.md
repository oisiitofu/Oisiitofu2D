# フェイのリミットブレイク

フェイが掌打と回し蹴りから飛び上がって終盤の機体「ゼノギアス」に搭乗する。機体の足元まで見える構図へ引き、片手に力を集めて「機神黒掌」を放つ。掌の先から黒い衝撃が伸び、相手に届いたところで赤紫の破裂と破片に変わる。機体の白い装甲、大型背部ユニットと頭部の形はスクウェア・エニックスの彩色見本を参考にした。搭乗の流れとカメラは本作独自の演出。
