# リーンベル：制作前の固有技設計

添付leanne.pngを基準に、成人の自然な頭身、金髪のボブ、青灰色の瞳、黒と灰青の上衣、白灰のプリーツ、黒いブーツ、ハンドガンとマシンガンを保つ。サイズ2・94px、桐生kiryuの直後。専用の高解像度な顔・肩画像を制作する。原作の銃の使い分けとインビンシブル・アクションを対戦ゲーム向けに構成し、関節リグは使わない。

## 固有の能力・操作

マシンガンの射撃は通常の小ダメージに加え、相手に有限の青いスクラッチ（最大24）を残す。スクラッチだけで大きな確定ダメージを与えず、NBのハンドガン弾の命中で消費して追加ダメージへ転換する。ガードされた弾は変換しない。相手は青い蓄積が消えるまで距離を取るかハンドガンを避ける判断ができる。

I.S.は初期60、最大100。実際の攻撃命中とスクラッチの変換で増え、横Bの経路実行、上Bの追加反動に消費する。空中で技を替えても復帰回数は戻さない。ゲージを見せるだけではなく、MGで仕込む→HGで確定するか、移動に使うかを選ぶ。

## 必殺技と連携

- NB「ハンドガン・チャージショット」：長押しで狙いを定め、離して直線弾。保持時間で威力・後隙が変わり、相手のスクラッチを命中時だけ変換する。本人の近接判定を長く引き伸ばす代用はせず、独立した弾として当てる。
- 横B「インビンシブル・アクション」：まず本人を残して方向入力で経路の終点を決める。必殺を離して押し直すとI.S.30で経路を実行。途中の再入力で低いスライドから跳躍射撃へ切り替え、MG弾でスクラッチを仕込む。予告経路は相手にも見え、開始前はガードで中止できる。置いたグレネードを通過射撃で起爆できる。長い単純突進を基本形にせず、経路の計画、開始の再入力、途中の跳躍、弾と設置の連携を中核にする。無敵は付けない。
- 上B「エアリアル・ガンアクション」：初動の跳躍後、方向入力で次の反動方向を選ぶ。必殺を離して押し直すたびI.S.10を消費し、選んだ方向へ一度の反動移動と逆方向への銃撃。追加反動は同じ滞空で最大3回。再入力せずに終える場合は落下へ。自動二段攻撃にせず、反動をいつどの方向に使うかを選ぶ。左右と真下からの復帰を検証し、真下では地形の外へ先に抜ける。近くの自分のグレネードの爆発には一度だけ爆風反動を合わせられるが、回数は増えない。
- 下B「グレネード・トリック」：保持で短く調理し、離すと弧を描いて投げる。残り導火線は保持中も進み、地面で一度跳ねる。自分のHG/MG弾が当たると早期起爆、放置すれば導火線で爆発。最大2個。敵の攻撃で押し返せる。弾と爆風は別物であり、近接のMeleeBalance.coverageを掛けない。

MGでスクラッチ→NBで変換、下Bを投げる→横Bの経路と射撃で起爆、上Bの反動方向と爆風を合わせる、という位置と時機の判断を作る。経路中の本人や上Bの照準中には相手が割り込める。I.S.不足、経路の空振り、グレネードの押し返しもリスクになる。

## 描画・判定・移動

通常15技はHG単射、MG連射、肘打ち、銃床、足払い、スライディング、空中の方向別射撃をそれぞれ別の全身画像で制作。空Nを共通の回転姿勢・輪状エフェクトへ寄せない。元の待機と15技を固定してから予備動作・戻りを制作する。銃口・手足の短い直接攻撃はNativeStrikesで描画倍率と接地に合わせ、近接補正は一度のみ。独立弾・爆発・つかみは補正対象外。

基本状態は飛行しない人間。上Bの反動だけで移動し、通常の追加ジャンプや浮遊は付けない。通常投げは剣系ではなく軽量の射手として位置変更・追撃・一方向の高％撃墜を区別し、攻撃上がりは専用の弱い単発と長い後隙にする。

画像生成が内容理由で拒否された場合は、このキャラの作業を直ちに停止する。再試行・別経路・切り抜きで続行しない。
