# リーンベルの専用リミットブレイク

バーゼルの歯車が見える足場を舞台に、原作のインビンシブル・アクションと、マシンガンで蓄積したスクラッチダメージをハンドガンで確定する関係を描く。相手の頭上を越える跳躍を起点に、身体をひねりながら下へ青い連射。落下地点から離れる方向へ低く滑り、膝を着いて射線を切り替える。離れた位置で身体を起こして一拍構え、ハンドガンの単射で蓄積を解放する。青い蓄積と決め技の橙色の衝撃を色と形で区別する。

ナイツの曲線飛行はループの閉鎖が起点で、ミクは拍と左右の音源で攻撃の位置が変わる。リーンベルは高低差で射線を変え、着地の反動を受ける滑りで間合いを広げ、遠距離の精密射撃に落ち着く。カメラは跳躍と相手を同時に収め、着地の瞬間は低め、最後は本人・銃口・相手を同じ画角に収める。既存の衣装、髪と顔を保ち、踏み切り、反転、空中射撃、着地、膝滑り、銃の持ち替え、狙い、反動を全身で描く。青い曳光弾、火花、スライドの火の粉、最後の衝撃と専用効果音を制作する。

## ローカル検証

全身12姿勢、専用背景、カットイン、主攻撃素材、オリジナル効果音2点を使用。途中6ヒットで15ダメージ、決め技で27ダメージ。機関銃の青い軌跡、膝滑りの火花、拳銃の橙色の射線を区別した。反対側からの決め技に合わせ、最終吹っ飛びの方向を反転させた。CPU戦は撃墜で終了。ローカルオンラインは389フレームと決め技の吹っ飛びが一致。 対戦、トレモ、ガード、空振り、無敵、4人戦、両向きの描画と吹っ飛び、カットイン比率、主攻撃の濃さ、専用音、決め技の撃墜を確認。
