# 赤兎馬の突入から真・覚醒乱舞

2026-11-06公開。承認済みの `ryofu-selection.png` と `ryofu-arsenal.png` を顔、黒金の龍の鎧、赤いマント、冠と長い2本の羽、方天戟、赤兎馬の基準にする。通常の立ち姿・既存技は変更しない。

[公式の呂布紹介](https://www.gamecity.ne.jp/smusou7/window/ryofu.html)で方天戟と赤兎馬を確認。『真・三國無双7 Empires』の[公式配信マニュアル](https://cdn.akamai.steamstatic.com/steam/apps/322520/manuals/Steam_musou7Emp_JP.pdf)にある、覚醒乱舞で一定以上のダメージを与えると真・覚醒乱舞へ移る構成を軸にする。他シリーズ限定の神術や神格化は追加しない。連携の順序とカメラは本ゲーム用に構成する。

赤兎馬で突入し、騎乗の薙ぎから跳び降りて方天戟の大薙ぎ・反転・斬り上げ・回転追撃を連続させる。武器と足運びを大きく変え、最後は高く跳び上がる振りかぶりから重い打ち下ろしと地面を割る衝撃へつなぐ。終盤は引きの構図で規模を見せ、刃の到達、相手の停止、最後の打ち上がりと余韻を分ける。

歩兵の全身8枚と専用の赤兎馬4姿勢（走行2枚・騎乗薙ぎ・跳び降り）を制作し、同じ構えの平行移動だけで済ませない。方天戟の刃、柄、羽とマントの端を切らず、全姿勢で頭身と鎧の形を比較する。斬撃の凸面を相手側へ向け、刃の先から攻撃が出るよう合わせる。主攻撃は `art.strike`、残光は `art.glow`、カットインは共有の縦横比維持描画。

素材と最終プロンプトは `limit-break-assets.json`。夕莉と合わせて演出・専用音・ローカルと公開での検証を完了した。

## 実装・ローカル検証

歩兵8枚と赤兎馬4枚。騎乗斬りの刃・相手・斬撃の高さを合わせた。各9回の途中ヒットから決め技へつなぐ。専用効果音2音、両向きの実描画、共通カットインの縦横比、主攻撃のsource-over合成、トレモ補充、密着発動・空振り・ガード・無敵・再試行・多人数停止・最終吹っ飛びを確認。ローカルオンラインは387フレームでダメージ・吹っ飛び・ホスト設定が一致。

連続再生を1440×900で録画し、全身ポーズと左右への回り込みを確認。CPUは同キャラ2体を中央140px間隔で開始し1戦ずつ結果まで進行（夕莉は撃墜、呂布は時間切れ）。既定の離れた開始位置では夕莉同士が攻撃せず時間切れになったため、接敵状態で確認した。通常技やCPU本体は変更していない。
