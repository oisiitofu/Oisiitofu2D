# ジャンゴ — 実装前の技設計
位置: ゴエモンの直後。金髪の少年、額のゴーグル、赤いマフラー、茶の装備、太陽銃とおてんこさまを基準とする。
固有操作: 太陽エネルギーをNBの通常射撃/チャージ弾へ消費し、下Bで無防備に日光を集めて回復する。残量不足時の弱い火花と満タンの銃撃を分け、強弾連射に浄化/再充填の判断を作る。
横B: 長いソル・デ・バイスの槍を伸ばし、先端が当たると引き戻す。方向入力で途中解除でき、飛び道具のような射線/長い後隙を持つ。身体を横へ飛ばす突進として作らない。
上B: テンペストフレーム。太陽銃の反動で回転上昇し、スティックで上昇中の重心を左右へ動かす。エネルギーを追加消費して維持できるが、短い基本上昇は空でも保証。有限時間で解除し、着地するまで再使用しない。
通常: 格闘/ソード/スピア/ハンマーの持ち替えを各全身ポーズに反映。空上の銃撃、空下のハンマー、横スマのソル・デ・バイスで判定とVFXを描き分ける。
既存との差: 固定の長い槍の先端で引き寄せて銃撃、充填時間を確保して復帰/撃墜へエネルギーを分配する。横Bは移動技ではない。
対処: 槍の空振りと充填を攻める。エネルギー残量を見て強弾と長い復帰を読み、太陽弾の直線から離れる。
画像: おてんこさまは味方サポートの小物としてキャラ本体と区別。専用顔～肩アップを制作。

## 実装・検証

専用の全身フレームと16種類の素材、顔と肩の専用選択画像を内蔵 imagegen で制作。元の待機ポーズは neutral-locked.png と一致。前後上下を左右両向きで確認し、近接補正はMeleeBalance.coverageを一度だけ使用する。新キャラ4人とイーノック3武器を対象に通常技の密着/先端・全必殺・有限時間・復帰を440項目確認。CPU戦、2画面オンライン960F、個別の設置/引き寄せ/武器切替/台上発動を確認。実描画と連続姿勢の検証画像・動画は各previewsに保存。

画像と最終プロンプトは同じdocsのart-prompts.jsonに記録。素材はassets、配信はassets/readyのmanifestとハッシュ画像。
