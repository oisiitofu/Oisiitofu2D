# ソル / Sol Badguy

添付sol.pngを基準にGUILTY GEARのソルをガイルの次へ追加。人型サイズ4・116px。赤いジャケット、ヘッドバンド、白いズボン、太いベルト、大剣を保持。専用コードは同キャラのdata/art/vfx、元画像はassets、テスト/配置計測はtests、検証画像はGit管理外のpreviewsへ保存。

builtin image_genで48全身ポーズ、肘・崖・派生の追加全身ポーズ、16FX、1536×1024の専用上半身選択画像を制作。関節リグを使用せず、全身ラスターを切り替える。通常技15種はそれぞれ別の全身絵。最初のシートの低姿勢0と立ち姿31を入れ替え、元の立ち姿を再生成せず基準とする。追加画像は同じ頭身へ補修し、全身の一律縮小で基準絵へ合わせる。頭上の手・2本の脚・ブーツを含む崖用画像。ゲーム用は50全身＋ポートレートの51フレーム。立ち姿の可視高さ139pxを基準に、歩き1/24/25/26とダッシュ開始27だけ縦横比・足底を維持して高さ補正。正確なプロンプトとモードは[image-prompts.json](image-prompts.json)。

- NB「ガンフレイム」：18Fで前方へ地を走る炎を1つ放つ。18Fまで必殺を長押ししていると、煙だけのフェイントへ変化して8Fで戻る。放った炎は42F、速度6、10ダメージ、1体1ヒットで消える。段差外へ出たら自然落下する。生存する本人の炎と34Fの発射間隔だけが再発射を制限し、近接技へクールダウンを課さない。
- 横B「バンディットリヴォルヴァー」：空中へ踏み込み、10〜14Fと23〜28Fの別姿勢の二段蹴り（7/10ダメージ）。8Fまで長押しすると「バンディットブリンガー」へ派生。跳び上がった後に斜め下へ拳を振り下ろす単発16ダメージ、24〜31F。単なる水平突進と違い、通常版は二段で前を取る、長押し版は頭上から着地先を狙う。空中でも技終了後に同じ横Bを再使用できる。地上に着地した場合は既存の着地硬直。
- 上B「ヴォルカニックヴァイパー」：最初の7Fは落下慣性を止め、左右入力で踏み切り方向を選んで斜め上へ上昇。初段11ダメージ。上昇から13〜25Fの間に必殺を離して再入力すると「サイドワインダー」（14ダメージ）へ派生し、入力方向へ横に拳を叩き込む。初段上昇を長く使うか、横復帰/空中追撃へ転じるかを選ぶ。真下では既存のステージ下端脱出処理を使う。最後は専用の尻もち絵で操作不能へ自然に移行。無敵は追加しない。
- 下B「ロマンキャンセル」：テンション50%を開始時に消費。技の途中・自身の攻撃ヒットストップ・着地硬直・尻もち状態からも受け付け、技を切って8Fの短い動作へ移る。近く190pxの相手へ40Fだけ1/2速度を適用する。赤い輪の演出に攻撃判定はない。相手の被弾ヒットストップ・被弾硬直・予約吹っ飛び・つかまれ中からは脱出できず、既存の吹っ飛び保護を維持する。スローも被弾中/予約吹っ飛び/崖/無敵には掛けない。ガード入力中は防御を優先。空中の行動制限解除も50%の消費が必要。

テンションは前進距離に応じて獲得し、命中時にダメージ×0.85（1ヒット上限14）、被弾でダメージ×0.7。最大100%、復活でリセット。HUDに赤〜金のバー、50%の境目、所持率を表示する。下Bは不足時に発動不可。乱数やローカル時刻を使わず、ゲージ/派生/スローの時刻は固定フレームから決定する。

通常投げはThrowTuningのbalancedに登録し、前=位置変更・後=撃墜・上=浮かせ・下=追撃へ役割を分ける。弱い単発の攻撃上がりは既存専用技を保持。近接はMeleeBalance.coverageを一度だけ使い、拳/武器周りと密着を拾う。ガンフレイムには近接補正を掛けない。

斬撃0/6は凸側右、1/13は上、7は下と実素材で確認。ローカル回転→左右反転の順。AttackEffects.imageで可視部分を最終判定へ合わせ、上強/上スマ/空上は頭上の曲線1個。打撃とロマンキャンセルの隣素材混入を防ぐため2つの専用画像を追加生成し、確認した範囲で抽出して置き換えた。VFXは全身画像へ焼き込まず別描画。選択画像は専用の高解像度な頭肩画像を使用し、ガイル/ダンテの実カードと寄りを比較。

機能131項目、左右実描画40場面、CPU対ビビ1試合2400Fを確認。51姿勢/16FX/255カラーのchecksum差0。オンラインは実サーバー・2ブラウザで7場面630F同期一致。部屋が0件であることを確認し、ソルのオンライン許可リストを読み込むためゲームサーバーだけを再起動。既存の固定URL・ランチャー・QUICトンネルは停止しない。既存キャラの素材は再生成しない。

## 2026-10-21 戦闘画像の高精細化

ユーザー指摘の戦闘中の粗さを、元の姿勢を保つbuiltin image_genの画質修復で改善。固定済みゲーム画像50ポーズを5組に分け、顔・髪・輪郭・ベルト・衣服を描き直した。元の立ち姿/全身ポーズを変える新しいモーションや関節リグには置換しない。専用肖像は変更しない。[元画像と修復プロンプト](hd-image-prompts.json)、新しい素材はassets/sol-hd-0〜4.png。

assemble-hd.cjsは元のassemble-artを先に実行して、基準の寸法/足底/エフェクトを復元する。修復画像は各元フレームの可視境界へ2倍の画素数で合わせ、描画倍率を半分にして、ゲーム内の116px・縦横比・元ポーズごとの描画寸法と足底を維持。待機の元画像可視高さ139→278px。50ポーズの世界幅/高さ/基準線を152項目で検証し、通常倍率とカメラ1.5倍の実描画で比較。技データ・発生・持続・判定・ダメージは変更しない。16FXと専用選択画像も保持。機能131項目を再確認。
