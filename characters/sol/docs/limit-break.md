# ソルのリミットブレイク

大剣のガトリング連係、拳、タイランレイブ、ガンフレイムから、一撃必殺技のナパームデスへつなぐ。公式で紹介される技を組み合わせたゲーム用の演出。途中8ヒットは合計17ダメージ、最後に22ダメージと斜め上への吹っ飛びを適用する。

初撃の近接が命中すると1人を捕捉し、ほかの参加者と対戦時間を止める。ガードと無敵で防げる。空振り時はゲージを消費し、被弾でため直せる。途中は打撃と炎の反応を刻み、最後に解放する。炎の拳からしゃがみ込む姿勢へ移り、火柱で跳び上がって膝を当てる。引きの構図で火柱と、その手前のソル・相手を見せる。

ビルトイン画像生成で、元の選択画像を顔・髪・赤い鉢巻き・赤い上着・黒いベルト・金のバックル・赤黒い長方形の大剣の参照にした。既存の全身シートに合わせて白いズボンを保つ。16対9のカットイン、廃れた鋳造所の背景、横斬り・斬り上げ・拳・低い姿勢の透過全身4姿勢、炎の斬撃・拳の炎・地面の炎・巨大火柱の透過4種を指定した。ナパームデスの上昇する膝蹴りには専用の全身画像を追加した。

斬撃の凸側と炎の進行方向は右、斬り上げは上へ回転し、画面全体の反転で左向きへ対応する。火柱は上端の炎が素材のセル境界で切れない矩形を使う。カットインはLimitCinematicで比率を保ち、主攻撃はart.strike、溜めはart.glowを使う。専用の炎の拳は粗い打撃音と火炎、ナパームデスは大きな噴出音から低い轟音と瓦礫音へつなぐ。見やすさ設定へ揺れと明滅を合わせる。

素材はこのキャラの `assets/limit-*.webp`、効果音は `assets/audio/se/sol-limit-*.wav` に保存した。
