# ダンテのリミットブレイク

剣の突きと斬り上げ、空中の二丁拳銃5連射から真魔人へ変身する。真魔人の4連斬りと溜めを挟み、広い引きの構図で最後の斬撃を見せる。連撃11ヒットの合計18ダメージ、最後に22ダメージと斜め上への吹っ飛びを適用する。通常の技や立ち姿の画像は維持する。

初撃の近接攻撃が命中すると演出へ移る。ガードと無敵で防げる。空振りではゲージを消費し、被弾でため直せる。演出中は1人を捕捉し、ほかの参加者と対戦時間は停止する。途中の連撃には吹っ飛びを付けず、最後の一撃で解放する。

真魔人の覚醒音は低い唸りと金属の上昇音、最後の斬撃は複数の切断音から低い衝撃と残響へつなぐ。明滅と揺れは共通の見やすさ設定に従う。

素材はビルトイン画像生成で制作した。既存の選択画像を顔・髪・赤いコートの参照とし、16対9のカットイン、廃都の背景、右向きの全身4姿勢、真魔人の全身4姿勢、透過の攻撃エフェクト4種を指定した。真魔人の角と顔は公式画像を参照した。斬撃は凸側が右、銃弾は右へ進む。回転をかけた後に共通の画面反転を使い、左右の向きへ対応する。全身素材は同じ倍率でアトラスへ収め、カットインはLimitCinematicで縦横比を保つ。

素材はこのキャラの `assets/limit-*.webp`、効果音は `assets/audio/se/dante-limit-*.wav` に保存した。
