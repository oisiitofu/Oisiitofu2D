# ティナ / Terra Branford

配置はティファの直前。人型サイズ2（94px）、重量88。添付 `telina.png` を元に、組み込み画像生成で通常・トランスの全身素材、独立したエフェクト32種、顔と肩の選択専用画像を制作。生成時の全プロンプトは `image-prompts.json`。最初のゲーム用待機画像は各 `neutral-locked.png` に保存した。元ポーズを関節変形していない。

通常0〜60、選択画像61、トランス62〜122。通常技・スマッシュ・空中技15種は、両形態とも異なる全身画像。空Nは剣とS字の風、空前は5つのホーリー光、空上は3本の氷晶、空下は下向きの氷槍と命中時の反発。上強の曲線は頭上1つ。サンダガ・水柱は曲線に置き換えない。

## 操作と使い分け

- NBメルトン：タップ、28F、55Fの溜めで初期段階を選ぶ。飛行15F/29Fで段階が進み、中型は緩く追尾、大型は重力と1回だけの地面バウンド。トランス中は時間差2発。
- 横Bフラッド：自分は突進せず、水柱を地面へ順番に配置。下/後ろ入力は近距離1本、初期の中距離は2本、上/前入力は遠距離3本。溜め中に選んだ距離を保持し、離すと発動。トランスは4本＋折り返し。空中では下方の足場に配置。既設のフラッド中は再配置できない。
- 上Bトルネド・スパイラル：始動は落下慣性を抑え、3つの小竜巻で螺旋上昇。スティックで進行を調整し、最後に竜巻が合体して斜め上へ離脱。足場の真下では先に端へ抜ける。終了後は専用尻もち画像へ移り、横移動は可能。単純な一定方向の上昇突進とは異なる、上昇→螺旋→合流→離脱の4段階。
- 下Bトランス：時間・与ダメージ・被ダメージでゲージが増加。100%で9秒変身、移動/攻撃と魔法を強化。変身中の下Bは広範囲アルテマを放ち、その場で解除。通常/変身を共有CharacterDataへ書き戻さない。

上スマは前→中央→後ろの雷。下スマは前後の重力球が短く引き寄せて爆発。空前の5発は命中対象集合を共有して同じ相手に5倍のダメージを与えない。近接の補助判定は共通coverageを一度だけ適用し、飛び道具・遠隔設置に拡大を波及しない。

## 素材処理

`tests/assemble-art.cjs` が全身の連結成分を抽出し、各シートの校正待機から一度だけ倍率を決める。トランス必殺の6/10が接する透明余白の3行だけを分離。空下の剣先は専用修正版を元の身体高へ合わせた。エフェクトの切り抜きは実画像を見て矩形と隣接断片のマスクを指定。凸側を確認した素材をローカル回転し、その後に左右反転する。

`node characters/terra/tests/assemble-art.cjs` → `ART_IDS=terra node .tools/build-art.cjs`。元画像、manifest、ハッシュ付き配信画像を一緒に配信する。起動時の元シート解析や全カラー生成は行わない。
