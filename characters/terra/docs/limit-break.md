# 専用リミットブレイク

通常形態の剣で受けてから、地面の魔法で相手を浮かせる。対戦と同じトランスの色と輪郭に切り替え、上空を斜めに移動して着弾点を囲む。対戦でも使うメルトンを赤白の熱波として回収する。光で変身と解除の区間を示し、通常とトランスの既存対戦素材を使用する。

改修で参照したのは、通常・トランス両方の現行対戦シートと選択肖像。組み込みImageGenで、緑髪の通常形態が剣を構えて魔力を集める横長カットイン、紫の結晶遺跡、金の斬撃、紫の着弾、縦の変身光、メルトンの赤白い光線を制作し、`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-effects.webp` に保存。変身と復帰は現行の全身ポーズの切り替わりに光を合わせ、決め技は手元の溜めから相手に向けて発射する。
