# ボンバーマンのリミットブレイク

ボムを構え、蹴って起爆し、設置したボムを十字の爆風で連鎖させる。最後は大きなボムを蹴り込み、広い引きの構図で強化された十字の爆風を見せる。原作のボム運搬・キック・連鎖・火力強化を組み合わせた専用演出。途中9ヒットは合計15ダメージ、最後に22ダメージと斜め上への吹っ飛びを適用する。

初撃の近接はガードと無敵で防げる。空振り時はゲージを消費して被弾でため直せる。命中時は1人を捕捉し、ほかの参加者と対戦時間を止める。途中は連鎖のダメージと被弾反応だけを刻み、最後に解放する。爆弾と爆風の位置は演出時間から計算し、オンラインでも同じ位置とタイミングで描く。

素材はビルトイン画像生成で制作。既存の選択画像と全身シートを頭身・顔・白いヘルメット・ピンクの小物・青い胴体の参照にした。16対9のカットイン、夜の石造りのタイル場、爆弾を構える・蹴る・置く・跳ぶ全身4姿勢、黒い爆弾・小さな爆発・十字の爆風・強化十字爆風の透過4種を指定した。爆風の上下左右の先端が切れない切り出し範囲を使う。通常キャラの立ち姿や技の画像は維持する。

カットインはLimitCinematicで比率を保つ。攻撃と爆弾はart.strike、溜めの補助光はart.glow。カメラの揺れと明滅は見やすさ設定へ従う。連鎖は短い破裂音を重ねた専用音、最後は硬い破裂から長い低音と破片音へつなぐ専用音を使う。

素材はこのキャラの `assets/limit-*.webp`、効果音は `assets/audio/se/bomberman-limit-*.wav` に保存した。
