# ウルグリムの専用リミットブレイク

対戦用の髪型と髭、藍色の長衣、金の縁取り、革装備と直剣を全身姿勢とカットインで維持する。

対戦用の「影渡りの剣」と「最初の剣・断空」をつなぐゲーム独自演出。正面で受け流し、後退して裂け目を開け、相手から離れた奥の石段へ移る。そこから段を降りながら低く構え、裂け目の輪郭を一撃で断つ。ショベルナイトの足場の跳ね返りに対し、影を渡る間と石段で足を止める瞬間を見せる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中7ヒット、決め技26ダメージ。藍色の長衣と直剣を維持し、受け流し、裂け目、石段と断空を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
