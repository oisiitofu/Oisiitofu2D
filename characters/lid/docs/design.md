# リド：設計と検証方針

添付 `assets/lid-reference.png`（元ファイル `rido.png`） がデザインと技の基準。作品名はユーザー指定の「ファイナルファンタジーレゾナンス」。クライヴの直後へ追加する。赤茶の跳ねた髪、額のゴーグル、黄色の作業着、赤茶の七分丈、工具ベルト、金属ハンマーを維持。人型サイズ2（94px）。待機は静止。

## 固有の能力・操作

メカボは本人と別に前方へ走る相棒。横Bは本人がその場で指示してメカボを送り、長押し中の上下入力で相棒の高度を調整する。ボタンを離すと蹴り込んで戻る。本人の横突進とは操作と対処が異なる。相棒と土魔法で遠くを押さえ、本人はハンマーの間合いを取る。

NBはハンマーを構え、押し続けると一定間隔で発明を進める。離したときのレベルに応じて威力と叩きつけの範囲が変化する。被弾で構えを潰されるリスクがある。通常技の実命中で発明の進みを少し速める。

上Bはメカボへつかまって上昇し、方向入力で飛行する経路を変える有限時間の救出。ジャンプか必殺の押し直しで任意に離脱し、少し跳ね上がってしりもち落下。上昇を繰り返す攻撃技ではなく、搭乗中に横へ逃げるか早く離れて崖へ寄る判断を作る。崖下の潜り込みを共通escapeで処理。

下Bは本人の少し前を予告してストンガを発生。近くにメカボがいればその位置から後続の小さな土柱を立て、離れて操作する意味を持たせる。崖外では空中の鉱石弾として落とし、着地点の土柱へ変える。土魔法は床でのみ連鎖する。

## 使い分けと対処

横Bのメカボをガード・回避して本人へ近づく。下Bの地面の予告から移動する。NBの溜めには差し込む。ハンマーのスマッシュは発生と後隙が長く、空振りへの反撃が可能。上B中は身体が無防備で飛行時間も有限。リソースだけの強化ではなく相棒の位置と発明の段階を判断材料にする。

## リミットブレイク：エンタープライズ

ハンマーの導入命中後、メカボを横へ走らせて跳び乗り、頭上へ離脱して端末で飛空艇を呼ぶ。大型艦が斜め後方から横切り、爆撃が奥から手前・左右の順に交差し、最後は広い連鎖爆発。本人は一方向から殴り続けず、低い搭乗→高い指示→画面端での離脱を通る。モーグリの縦の竜巻、ベロニカの杖の固定射線と構成を分ける。連撃は18〜20フレーム、決め技前だけ溜めを取る。カットイン、艦、砲弾と着弾は専用素材を使い、本人と相手の位置が読める空間を残す。

左右の対戦・トレモ、近接の密着と先端、メカボ遠隔操作、NBの段階、土柱連鎖、場外復帰、CPU1〜2戦、オンライン代表場面とLB同期、選択画像の寄り、通常形態の発動前中後を確認して公開する。
