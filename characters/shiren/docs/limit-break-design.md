# シレンの専用リミットブレイク

『風来のシレン６』の道具による位置取りとドスコイ状態をつなぐ。狭い通路で杖の魔法弾を当て、次は相手を床罠のある段へ誘う。シレンは階段の手前でおにぎりを食べ、ドスコイになって罠を踏み潰す。杖で動くのは変身前。変身後は両足で踏ん張り、一歩ずつ重く進み、刀で壁を掘り抜く。崩れた石と刀の輪郭で最後の一撃を読ませる。

ユーマも壁を崩すが、シレンは食事で体型を変え、本人が接地したまま罠と壁を順に壊す。動線は狭い通路から階段へ下がり、変身後に中央へ踏み込む。笠、マントと刀を既存素材に合わせ、変身前後の足元と石の接触を確認する。

- [公式 ドスコイ状態と道具](https://www.spike-chunsoft.co.jp/pages/shiren6/system/)

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音4点を制作。途中6ヒット、決め技26ダメージ。杖と階段、おにぎりを食べる動作、ドスコイ姿の踏みつけ、罠と壁の破壊を確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
