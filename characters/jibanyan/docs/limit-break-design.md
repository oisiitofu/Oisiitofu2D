# ジバニャンの専用リミットブレイク

通常形態の参照は対戦で使う `assets/jibanyan-native.png` の待機と全身動作。丸い顔、耳、赤と白の境界、腹巻き、二本の青い尾炎の位置をカットインと全身姿勢で照合する。

「ひゃくれつ肉球」を低い間合いの連撃にする。最初に前足で飛びかかり、命中した相手の真下を滑り込んで連打を真上へ向ける。続けて壁を蹴って上から戻り、着地で尻尾の青い炎を残しながら、最後に体重を乗せた両前足で相手を押し出す。マレニアの滞空・横断・落下と異なり、拳の位置でカメラを一段ずつ持ち上げ、壁蹴りで引いて本体と相手の上下関係を見せる。

## ローカル検証

全身12姿勢、専用カットイン、背景、ゲーム内小物、攻撃素材、オリジナル効果音を制作。途中8ヒット、決め技26ダメージ。赤い体、黄色い腹巻きと二本の尾を対戦素材に合わせ、下からの連打と壁蹴りを確認。 対戦・トレモ・ガード・空振り・無敵・4人戦・両向きの描画と吹っ飛び・カットイン比率・主攻撃の濃さ・専用音を確認。
