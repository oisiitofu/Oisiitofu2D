# 鞍部十郎：第13番機兵の専用リミットブレイク

状態：実装し、Sites v331へ公開済み。公開描画・発動・トレモ・専用音・代表通信同期を確認済み。

## 原作とデザイン

本人は既存 selection / human-poses の茶髪・黒い金ボタンの学生服・顔と頭身を維持。第13番機兵は既存 mecha-poses とユーザー参照シートの角張った灰色の装甲・箱型センサー・オレンジの推進器を基準にする。原作の終盤まで強化できる第二世代機兵の兵装を連携させる。公式が鞍部に割り当てた腕部ピアッシングキャノンと高出力プラズマアーク溶断機を採用し、他パイロットの専用兵装を混ぜない。

## 動線と専用動作

直近のウィルの上下剣技・アレインの一周旋回とは異なり、機兵の起動→後方への反動を伴う砲撃→横への短い姿勢変更→前進して溶断、を主軸にする。巨大機体を高速で何度も往復させず、脚の踏み替え、膝を曲げる重量感、腕部兵装の展開、発射の反動と冷却を全身中間画像で見せる。本人の起動操作も専用全身画像にする。

1. 本人が腕の起動部へ触れ、決意を込めて機兵を起動。
2. 大きく引いた画角で第13番機兵が着地し、膝を曲げて重さを受け止める。
3. 腕部砲を構え、貫通機関砲の短い連射を反動姿勢と組み合わせる。
4. 相手の位置を保ったまま機体が斜めへ踏み替え、ロケットの弧状の射線と着弾で進路を作る。
5. 前へ踏み込み、プラズマアーク溶断機を展開。短い停止から複数の溶断接触を見せ、大きな最終放電と冷却で締める。

相手と機兵を常に追えるよう、砲撃の銃口・弾道・着弾をつなげる。攻撃は art.strike、補助の蓄電・推進器残光のみ art.glow。共通カットインの縦横比を守り、関節リグへ置き換えない。通常技・既存の機兵ゲージと変身仕様は変更しない。

## 検証予定

起動から着地・兵装切替・連射反動・溶断・冷却を連続再生し、同じ射撃姿勢の座標移動だけにしない。対戦・トレモ・両向き・カットイン比率・明るい背景での主攻撃・専用音・CPU各1戦・代表オンライン同期を確認し、公開後にも配信ハッシュと実発動を確認する。
