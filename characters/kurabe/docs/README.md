# 鞍部十郎 / 第13番機兵

添付kurabe.pngを基準に十三機兵防衛圏の鞍部十郎を追加。アレインの次、画面86/旧登録133。132形態・選択可能126・非表示6を維持。人間は短い茶髪、黒い詰襟学生服と金ボタン、体格98/重さ89。搭乗時は重厚なガンメタルと白灰色装甲の第13番機兵、体格148/重さ133。人間48姿勢＋機兵48姿勢＋専用肖像、12エフェクト、5カラー。全身の絵で表示し、関節リグは使わない。

## 起動ゲージと搭乗

- 人間時に0.06/Fで時間回復。実命中は技の基礎ダメージ×1.25（1命中最大14）、被ダメージ×1.1（1回最大16）で加算。ガード/無敵で命中分は増えない。上限100。
- 通常必殺は12Fで端末にアクセスして4加算、長押し中は0.32/F追加。最大192Fまでの有限動作で、離す/満タンで8F後に解除。被弾で中断し、無敵はない。
- ゲージMAXの下必殺は24Fで搭乗、ゲージ0へ。約15秒/900有効フレームで自動解除。搭乗中はゲージをためない。ヒットストップ中は搭乗時間を止める。
- 機兵中の下必殺は14Fで任意離脱。解除後は48Fの移動速度低下と地上36F/着地24Fの隙。被弾硬直/予約済み吹っ飛びを解除で消さない。撃墜で人間・ゲージ0に戻る。
- 形態で絵・攻撃データ・被弾範囲・重さ・移動・盾サイズを変更。操作するファイターIDは同じなので選択枠を増やさない。両形態に別の崖の手の位置を計測。

両復帰はステージ内側下では側面を経由し、左右から帰還できる。人間の通常攻撃は拳・蹴り・肘。機兵は腕・膝・プラズマの絵と長い間合いへ変わり、通常攻撃の発生+3F/総動作+8F・威力1.22倍。一部動作中のみ5ダメージまでの軽い攻撃を受け止め、強い攻撃には被弾する。空中下必殺の急降下なし。通常の近接技に追加のクールダウンを設けない。

## 制作画像

**内蔵 image_gen** を使用。全生成指示は [image-prompts.json](image-prompts.json)。参照 [reference](../assets/kurabe-reference.png)、生成した [human-poses](../assets/kurabe-human-poses.png)・[human-motion](../assets/kurabe-human-motion.png)・[mecha-poses](../assets/kurabe-mecha-poses.png)・[mecha-motion](../assets/kurabe-mecha-motion.png)・[effects](../assets/kurabe-effects.png)・[selection](../assets/kurabe-selection.png)、配信用結合元 [native](../assets/kurabe-native.png) を保存。

`tests/assemble-art.cjs` は承認した絵を再生成せず透過RGBAを保持して切り抜く。基礎シートは各行6体、移動シートは8/6/6/4体。照準の細い線に中心検出が効かず、ホログラムと混ざっていたため、エフェクトの切り抜き範囲を元画像座標で固定した。人間と機兵を別の固定倍率で描画し、動作中だけ同じ高さへ引き伸ばさない。通常0/プラズマ2の先行する凸側とミサイルは右向き。素材ローカル補正→回転→左右反転→平行移動の順で実判定へ向ける。色替えは黒い制服/灰色装甲を対象に、髪・顔・金ボタン・炎を保つ。
