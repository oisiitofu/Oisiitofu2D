# ジタンの専用リミットブレイク

短剣の左右と回し蹴りを出し分けながら走り、相手の足元から上へ追う。対戦用のトランス発動ポーズと発光を再利用し、グランドリーサルの光を交差させる。ホーネットの糸による引き上げと区別し、踏み台への着地からの蹴り返しと、左右に異なる高さの斬り込みを使う。

改修では現行の金髪、青緑の衣装、茶色の尾、二本の短剣を参照した。組み込みImageGenで跳び込みざまに短剣を交差させる横長カットイン、リンドブルムを想定した空港の遠景、宙に浮く石と木の足場、短剣と蹴りの軌跡、グランドリーサルの白金と桃色の斬撃を制作し、`assets/limit-cutin.webp`、`assets/limit-court.webp`、`assets/limit-dock.webp`、`assets/limit-effects.webp` に収録。既存のトランス発動姿勢で光を溜め、決め技の二方向の斬撃は相手の背面、接触点の閃光は前面に出す。
