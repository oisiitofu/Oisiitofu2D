# ロクサスのリミットブレイク

『キングダム ハーツ 358/2 Days』の二刀流ロクサスが使うマジックアワーを題材にする。夕暮れの時計塔でキーブレードを交差させ、上空で光を集めて複数の光柱を落とす。最後の太い光柱で戦場に戻り、当たった相手だけを吹っ飛ばす。ゲーム内のシステム表示は「リミットブレイク」。通常必殺技の光弾は区別のため「ライトオーブ」と表示する。

ゲージ・空振り時の再充填・命中時の一度限りの消費・試合の停止はララフェルと共通。始動は無敵の二刀交差斬り。ガードでき、空振り・ガード時は演出が始まらない。静止した命中から専用カットインを挟み、演出は命中位置や他プレイヤーの動作から独立する。時間・カメラ・素材・効果音・フィニッシャーはロクサス専用。
