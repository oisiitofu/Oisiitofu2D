# キュービィ実装

- カラテ家の直後。特殊体型60px、重量80。白い四角と黒い目・短い脚を維持する。専用高解像度選択画像、76全身画像と16エフェクト、5カラーを配信する。
- NBは1〜3個の連結箱を発射し、同時に出せる射出列は一つ。横Bは箱フックで一度だけ引き寄せ、崖へ掛かった場合は物理的に引き寄せて通常の崖掴みへ渡す。
- 上Bは有限寿命の3段の箱を生成し、各足場へ踏み進んで跳躍する。空中再使用を制限し、箱は最大3個。足場の箱と全身ポーズの箱を重複描画しない。
- 下Bは単発のハコプレス。浮遊台で停止して発動する。近接の補完は共通MeleeBalanceを経由し、飛び道具へは重ねない。
- 全身画像を抽出・等比縮小して使用し、関節リグは使用しない。元待機をneutral-locked.pngに固定。箱の伸長で身体の中心がずれないよう、二つの目を囲む白い面から横アンカーを計測する。武器が脚より下へ延びるコマの足底も補正する。
- FX0は生成素材の最大の白い面と黒縁を切り出して単独の箱として使用。FX15は元絵が左へ進む向きだったため全身反転と独立してローカルで正規化する。箱と矢印を剣の曲線に分類しない。
- 検証は専用83項目、通常/連続姿勢/左右/カラー75場面、必殺14場面、CPU2試合、2クライアント331フレームの一致。画像読み込み検証は3人合計231ポーズ・48FX・1155カラーで差分なし。
