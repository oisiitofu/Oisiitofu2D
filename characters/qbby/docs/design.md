# キュービィ — 箱を足場と間合いへ変える

基準はユーザー添付 Qbby.png。白い四角い身体、黒い二つの目と短い二本脚を保ち、腕・口・衣装を付けない。カラテ家の直後。特殊体型として立ち姿60px。

## 固有の能力・操作

NB「ハコストレート」は長押しで箱を最大3個まで伸ばし、離すと連結箱を発射する。直線的で、ジャンプ・ガードで対処できる。消えるまで一つだけ。
横B「ハコフック」はその場からL字の箱を伸ばす。敵へ当てると一度だけ内側へ引き寄せる。ガードへは拘束を付けない。近くの崖を優先して掛け、自分を崖へ寄せる。空振りには後隙を残す。
上B「ハコホップ」は固定された階段箱を作り、方向入力で階段を登る。長押し中だけ二歩の踏み直しが可能で、離すと上端から跳ぶ。箱は短時間で消え、着地まで再使用できない。単なる二段斬り上昇とは異なり、足場を作る場所と離すタイミングで復帰位置が変わる。
下B「ハコプレス」は頭上に重い箱を作って落とす。空中では落下するが、浮遊台を最初に踏んだ位置で停止して潰す。発動中に箱をガードされると反撃されやすい。

## 連携と対処

横Bの引き寄せから近接箱攻撃、上Bの階段上端からNBの水平線を作る。箱は最大数・寿命を持ち、無制限の空中足場や再上昇を許さない。通常技とスマッシュはそれぞれ別の全身ポーズ。円形斬撃を使わず四角い延長・破片・押し込みで可視判定を示す。空中Nは身体の四辺へ箱を出す専用モーション。

## 検証

密着と先端、前後上下の左右描画、箱の失効、フック空振り/命中/ガード、左右場外からの復帰、浮遊台下B、CPU1〜2戦と短いオンライン同期を確認する。
