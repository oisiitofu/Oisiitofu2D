# キャラ選択とエフェクトの前面描画

2026-11-01の依頼に対応。

- ナミネの専用高解像度選択画像を顔・肩中心へ寄せた。cropは`[340,180,840,600]`。元画像・ゲーム画像・全カラーのポーズは変更なし。
- ユーマのselectionOrderを苗木誠の直後へ移動。重複なし、表示番号は自動採番、おまかせは最後、非表示形態は維持。
- エリオットの元待機・歩行画像0/1/2/14/71/73は左向きだったため、身体軸を中心に描画時だけ反転。元PNG・全身比率・足底・武器は保持。攻撃や後方斬りへ一括反転を掛けていない。
- 戦闘描画を全員の本体→設置物／弾／相棒→全員の斬撃・魔法・ガード→名前などの表示に変更。プレイヤー番号に依存せず、攻撃を相手や本人の本体で覆わない。
- コレット、エステル、ライトニング、ニア、リィンのVFX内に残っていた本人の再描画を削除。分身の描画は保持。本体の変身・搭乗機・身体の一部に当たる描画、影、背景は本体側に残す。
- リキ以外の火／毒使いが状態表示を共有する場合、リキのアトラス未読み込みで描画が停止していた。参加者以外を先読みせず、未読み込み時も炎／毒の表示を描く。

## 検証

`node foreground-effects-test.cjs`で全212形態・左右の弱／上スマ／下スマと下Bの1,484場面を実描画。相手の本体を不透明に覆う場面でもエフェクトを確認し、エフェクトの後から本人を描き直していないことを追跡。テラ・ボンバーマン・メタビーのスマッシュは初期化時点では弾が未発生なので実際の連続75Fで追加確認。下Bで攻撃を出さない構え／選択などは、発動前の画像を無理に作っていない。

`node portrait-facing-layout-test.cjs`でエリオット60描画（6姿勢×左右×5色）の向きと身体軸、ナミネ15カード（PC3解像度×5色）の顔位置、206人の順番と重複、212形態の既存ゲーム画像のハッシュ維持を確認。

配信アート検証は321ポーズ・48FX・1605カラーで不一致／エラーなし。3人の既存メカニクス244チェックとオンライン321フレーム・3端末の一致を確認。描画変更に伴うサイズ一覧212形態も更新。検証画像・連続トレースはGit管理外のpreviews/foreground。

ホームへ実施日時と短い修正内容を記載。公開済み音声のハッシュは維持し、無関係な未完成作業を配信に含めない。
