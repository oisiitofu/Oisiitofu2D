# スマッシュ連打時の吹っ飛び

ララフェルで120％から上スマだけを繰り返すと、相手の％増加よりワンパターン相殺の低下が勝つケースを再現した。相殺は与ダメージに掛かり、その減ったダメージがさらに吹っ飛び式の乗算項へ入っていた。

修正前の中量級（ララフェル）、中央・無溜め・DIなし・1対1のダメージ補正なしでは、120％の初速27.197が、212.395％で25.353まで落ちた。同じ技で初めて上境界へ届くのは305.895％だった。

スマッシュは相殺で減ったダメージの75％を、吹っ飛び計算用だけに戻す。実際の与ダメージと相殺キューは従来通り。相殺倍率mのとき、吹っ飛び式に使うダメージは、相殺前ダメージ×(0.75＋0.25m)。新品の技の強さは維持する。公開用の計算プレビューも実際の相殺倍率を使い、実命中と揃えた。

修正後は120％から24回の連打で初速が毎回増加し、同じ中量級では202.45％で上境界へ届いた。重量・重力・DI・溜め・ステージにより撃墜％は変わる。180％で全員が必ず撃墜する調整ではない。

- `smash-stale-growth-test.cjs`：中量級とプネウマ・ザックス・エスターク、上／横／下スマ、両向きで1779項目。実命中、相殺キュー、毎回の％と初速、プレビュー一致、境界への到達を確認。
- `smash-launch-test.cjs`：215形態、42237項目。新品のスマッシュ、溜め・重量・％・怒り、実飛び道具のスマッシュ属性と軌道を確認。新規に作るテスト用キャラにも専用ルールの初期化を適用した。
- `smash-stale-online-test.cjs`：2クライアントで上スマ連打の326フレームが一致。

検証結果はGit管理外の `previews/smash-audit/stale-growth.json` と `stale-growth-before.json`。広範な `launch-control-balance-test.cjs` は、既存のテスト用クォートの初期化不足（quoteXP未定義）で停止したため、当該テスト全体の合格とは扱わない。
