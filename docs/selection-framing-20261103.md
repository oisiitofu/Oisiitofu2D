# キャラ選択画像の構図調整

全206体をPCのキャラカードと同じ比率で比較。顔の輪郭の中心を横方向の基準にし、目線の高さは別に記録した。リィン・ナミネ・ライトニングは切り抜き幅を約2割広げた。ビビは帽子のつばの下に見える顔を中央に置いた。見切れは目・頬・顎と、胸元の透明な隙間を優先して確認した。

元絵の顔や配色を参照して再制作した49体の元画像は `characters/<id>/assets/<id>-selection-framed-v3.png` に保存。生成時は参照画像の顔、衣装、色、描き込みを保ち、顔と肩を大きく描いた横長の透過画像で、欠けていた顔や身体の輪郭を補うよう指定した。ラチェットまでの承認済み画像を構図の比較に使った。

新規画像は `selection-framing-guides.json` に元画像、目の位置、顔の中心、顔幅、保護範囲を記録する。`node align-selection.cjs` で確認して `--apply` で適用。配信用の画像を生成後、`ART_IDS` に対象IDを指定して `node selection-framing-test.cjs --review` を実行し、カードと拡大表示を比較する。勝利用の元画像と切り抜きは独立して管理する。
