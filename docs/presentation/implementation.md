# 対戦の開始・終了演出

battle-presentation.jsは表示専用。既存の開始180F/開始後32Fを使い、対戦の座標・入力・ヒット・勝敗処理を変更しない。開始は2〜4人の顔肩の専用画像を斜めパネルへ切り込み、フラッシュからFIGHTへ。終了はFINISHの一拍→勝者の大きなアップ→金の光/月桂冠/紙吹雪→再戦操作。チームは勝ったチームの全員、引き分けではキャラを勝者扱いしない。

assets/presentation/cinematic-atlas.pngをbuiltin image_genで制作。4つの部分（フラッシュ/金の光/斜めパネル/月桂冠）を移動・拡縮・不透明度でアニメーションする。プロンプトはimage-prompt.txt。キャラ画像はArtLoader.prepare済みの実参加者の専用選択画像だけを使い、全キャラのアトラスを追加読込しない。追加の音はGameAudio.cinematicの短い金属音/和音で、既存のSEとマスターの音量・ミュートに従う。

終了通知/ビンゴ開放は従来通り即座に実施し、結果の操作表示だけ2.15秒後に出す。描画はperformance.nowの表示時間で進めるため、結果でシミュレーションが止まっても進行する。モーション軽減設定では動きを省き、結果操作もすぐ出す。小画面では操作を下へ、ビンゴの結果カード表示は全画面を維持。

presentation-test.cjsは2/4人の開始8場面、個人/チーム/引き分けの終了6場面、小画面操作、表示で戦闘座標が変わらないことを確認。画像はpreviews/presentationに保存する。throw-base-balance-test.cjsは158形態×4方向の632通りについて低％の速度増加・％成長・原データ不変を検証。
