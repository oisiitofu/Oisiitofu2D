# 入力の暴発・取りこぼしの改善（2026-11-01）

## ゴールと実装

強攻撃／スマッシュ、振り向き、斜め入力、先行入力を改善する。PCのキーボードとゲームパッドを対象とし、既存の移動、防御、固有技、被弾時の吹っ飛び予約を維持する。

- キー・パッドの技ボタンを押した瞬間の方向を保存する。その後の反転・ニュートラル復帰で技の方向を変更しない。移動用の生入力は維持する。キーボード2・パッド1〜4は独立管理。
- 右スティックの短い入力を一度の技入力として保持する。スティックが中心へ戻った後やニュートラルの通信が届いた後でも消さない。溜めは実際に倒し続けている間だけ有効。強攻撃モードとシールド解除後の強攻撃も維持する。リセット・フォーカス喪失・設定画面の後は中央へ戻してから再度攻撃可能とする。キーの自動リピートで新しい入力を作らない。
- スマッシュの弾きは正負のX/Yそれぞれで判定する。横の弾きで上強が上スマッシュへ化ける問題、横を保持したまま上へ弾いても反応しない問題を修正。中心付近から強く倒す猶予は4F、成立した方向への攻撃猶予は6F。D／明示的な強攻撃はスマッシュへ変えない。
- 技の方向は基本45度で分類する。直前の方向がある場合は境界に1.12倍の差を設けて小さな揺れを吸収し、明確な倒し直しで切り替える。右スティックは左スティックの方向履歴から独立。移動・回避・固有技の操舵用アナログ軸は変更しない。
- 先行入力の消費時に古い技の方向・ボタンを混ぜない。通常移動と空中操作には最新の軸を使い、技には予約時の方向を使う。上必殺の初期の向きは予約時の横入力を維持する。同時押しの優先順位を即時発動と先行入力で一致させる。必殺／つかみが勝つ場合に右スティックの方向を混ぜず、スマッシュが勝つ場合に別の強攻撃入力の補助指定を混ぜない。空中で予約した攻撃を着地時のスマッシュへ変えない。
- 先行入力は9Fを維持し、キャラ別／全体のヒットストップ中には期限を減らさない。通常の硬直中には従来どおり期限切れになる。ジャンプ＋攻撃は一体として保持する。入力によってヒットストップ・被弾硬直・予約済み吹っ飛びを消さない。
- 空中のスマッシュボタンも方向に対応する空中攻撃として受け付ける。振り向き中の地上攻撃は押した方向へ出し、空中の後ろ攻撃は向きを反転せずに出す。
- オンラインは同じサーバーフレーム内の新しい技入力を優先し、その方向を保存する。ニュートラルで技を消さず、以前の別技のフラグや方向を混ぜない。ジャンプと明示的なストック共有は別に保持する。compact-v2／従来のJSON形式を維持する。

操作案内とホーム更新情報も更新する。技のダメージ、判定、キャラ素材、待機姿勢は変更しない。

## 検証

- `input-intent-test.cjs`：実際のDOMキーイベント・模擬パッドを用いた131項目。入力後の反転、ニュートラルで押した攻撃、サブフレームの方向＋攻撃／右スティック、強攻撃モード、溜め解除、シールド解除、4台のストック共有分離、斜め境界、弾き直し、期限9F、長い停止中の予約、吹っ飛び予約、実際の小ジャンプ攻撃、既存キャラの強攻撃を確認。全合格。
- 修正前HEAD `1923a97` を固定した比較用サーバーでは、初期83項目のうち44項目が失敗。修正後は初期83項目・追加48項目とも合格。
- `input-intent-online-test.cjs`：2ブラウザ、256F。実キーによる押した後の反転、戻し済み右スティックのスマッシュ／強攻撃、全体停止中の下必殺予約を実送信。技・向き・位置・入力方向・弾き履歴・予約状態が一致。`heavy / smash / up / gale` を確認。
- `directional-input-server-test.cjs`：従来の3種類の入力に加え、5種類の通信バーストを確認。生の方向付き技→ニュートラル、戻し済み右スティック2モード、新しい技による置換、ジャンプ／ストック共有の保持。compact-v2と従来のJSON形式が一致。
- 既存の `directional-tap-test.cjs` 34項目、`input-edge-test.cjs` 14項目、`training-reset-input-test.cjs` 258項目、`input-codec-test.cjs` 190ラウンドトリップ＋方向20件が合格。
- `characters/leanne/tests/mechanics-test.cjs` 110項目で固有の経路指定・復帰・操舵・ゲージ・密着命中を確認。`idle-ledge-test.cjs` 81項目と描画26件で崖つかまり／走り抜け等を確認。
- `hit-feedback-test.cjs` 67項目とCPU戦2試合各1800Fが合格。命中停止、音・火花、吹っ飛び予約、既存戦闘を確認。

旧テストには既存の不整合がある。`stick-smash-ledge-test.cjs` と `dodge-input-test.cjs` は初期ステージがなく物理更新で中断し、変更前でも同じ。`stock-share-input-test.cjs` はポーズ中のメニュー入力にパッドが吸われるため、変更前も同じ箇所で失敗する。ストック共有は今回、対戦状態の4台・両順序で独立検証した。`battle-input-regression-test.cjs` は14,461項目中8,852件の既存失敗があり、変更前後の失敗項目は一致した。これらを全合格と扱わず、今回の対象には上記の独立再現テストを使う。
