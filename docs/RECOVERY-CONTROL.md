# 2026-10-19 上必殺の発動前と方向指定

クリスタルで、落下速度15が重力0の溜め中にも14のまま残り、20F時点で294px落ちることを再現した。受理した空中上必殺の入力時だけ、横慣性を35%、下向き速度を15%・最大2へ抑える。発生前の下向き慣性は毎フレーム半減し、溜めの早期returnより前に適用する。急降下も解除する。上向き速度とキャラ固有の離陸/反動/突進はその後の専用処理に任せる。被弾硬直・ヒットストップ中に入力しただけでは発動せず、吹っ飛びも停止しない。

|キャラ|上必殺の指定|
|---|---|
|ノクティス|5〜15Fに任意角度を指定、16Fに距離210の転移。真横/下も可能。ニュートラルへ戻すと最後の指定を保持。無入力は真上。予告先は3点から1点へ変更。主足場を横切る経路は従来通り止める。|
|ネク|4〜19Fに任意角度と距離を指定、22Fに転移。スティックの強さで110〜320。方向入力なしの初期先は上185。入力を戻すと選んだ先を保持する。上185を起点としたカーソル加算で真横に届かなかった制約を除去。|
|カサネ|8Fまでに任意角度の距離260を指定。従来の上方固定から真横/下方も選択可。8F以降の方向固定と12Fの再出現、再入力の追撃は維持。|
|テラリアン|8方向への丸めを除き、スティック角度をそのまま正規化。距離380と既存の地形/下面の処理は維持。|

ミドナ/サンズ/鳴上は既に任意方向を扱うため、方式を変更しない。各キャラの転移後の硬直、無敵、攻撃、再使用制限は維持する。CPUは選択済みカーソルの高さを基準に方向を交互変更せず、発動元からステージ上の復帰先を狙う。

メリアの翼は初期上昇18→28F、初速9→12.5、最大飛行60→84F、横速度6→7.2（風7.2→8.4）。短押しでも飛行を続け、離陸32F以降の必殺再入力で早期終了。上昇後は上下にも操舵可能。既存の尻もち落下/再使用制限/下面脱出は維持する。

無障害空間の同条件では、メリア短押しの上昇128.34→289.52、横移動144.92→561.01、上入力を続けると上昇443.12。ステージ上の実到達距離や対戦の強さとは区別する。

`recovery-control-test.cjs`は540項目（12体の発動前、硬直/ヒットストップ、ノクティス16方向、ネクの方向/距離、カサネ/テラリアン、地形阻止、実ステージ復帰、メリア対ハナJDのCPU1戦、ポーズ混入の回帰）。`recovery-online-test.cjs`は独立2画面の82時点一致と代表操作を含む91項目。既存の各キャラ専用テストも変更した箇所に絞って実行する。
