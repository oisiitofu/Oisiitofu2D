# スマホ操作モード

2026-11-02。タッチ端末では自動で有効。ホームの「スマホ操作」と詳細設定で切り替えられ、auto/on/offをブラウザに保存する。

- 左スティックはアナログ移動と技の方向。中心の遊びと広い上下左右の入力範囲を設け、小さな指の揺れによる斜め入力を抑える。
- 右に攻撃・必殺・ジャンプ・強攻撃・スマッシュ・ガード・つかみ。複数ポインター、押し直し、長押し、攻撃＋必殺のストック共有に対応。
- 押した瞬間の方向と短いタップを、既存のControls.consumeまで保持する。強攻撃とスマッシュの指定を分け、既存InputFramesの先行入力・被弾中の吹っ飛び予約を使う。
- 入力は主操作席（primary/keyboard）だけに渡し、keyboard2やpad専用席、CPUへ混ぜない。オンラインは従来のcompact-v2形式を使い、送信ごとのconsumeも共通。
- 指を離す・pointercancel・キャプチャ喪失・フォーカス喪失・非表示化・回転・設定/ポーズで入力を解除する。ゲーム速度は既存の60Hzを維持。
- 横持ちは操作パネルを左右へ分け、対戦画面に重ねない。縦持ちは下に配置。ノッチ・ホームバーのsafe-areaとdynamic viewportを考慮する。キャンバスの実際の表示寸法に描画解像度を合わせる。
- キャラ選択は読める大きさのカードをスクロールして選択。名前リスト・検索・お気に入りも維持。練習設定はボタンから開閉する。

検証：Edge/Chromiumのタッチ端末エミュレーションで実際のマルチタッチイベントを入力。390×844 / 844×390 / 360×640 / 667×375 / 320×568の表示、PC表示、設定保存、ポーズ・ガイドの解除を確認。スマホ実機での検証は未実施。

`mobile-controls-test.cjs` は3本指による移動＋ジャンプ＋空中攻撃、短いタップ保持、押した方向の保持、溜め、専用強攻撃、方向必殺、既存コーデック、席の分離、解除とレイアウトを確認する。`mobile-controls-online-test.cjs` はタッチ端末とPCの2クライアントで実際の操作を送信し、共通110フレームの戦闘状態一致を確認した。既存のinput-intent-testは131件、training-reset-input-testは258件成功。
