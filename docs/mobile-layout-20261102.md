# スマホ専用の画面整理

2026-11-02。ユーザー指定：スマホのキャラ一覧を広げる。PCのUIへ影響を与えない。戦闘操作ボタンはバトル画面の上に薄く重ね、画面を全面に使う。

変更は `mobile-controls.css` の `body.touch-mode` / `body.touch-mode.touch-battle` に限定。ゲームのロジック、PC用CSS、キャラ画像・読み込みは変更しない。

- キャラ選択のヘッダー32px、ステージ・設定欄60px、参加者/カラー32px、下部詳細/開始48pxへ縮小。作品名、性能紹介、対戦設定、詳細設定、名前リスト、ステージ・カラー選択は維持する。
- 縦持ちと横持ちで読めるカードサイズを使い、残りの高さをスクロール一覧へ割り当てる。4人と団体戦の出場枠にも表示領域を残す。
- スマホの戦闘キャンバスはビューポート全面。操作パネルは不透明度45％で重ね、操作中は80％。ゲーム内ヘッダーを畳み、ポーズ・練習設定・全画面ボタンは上部へ残す。従来の16:9のゲーム描画範囲を維持するので、端末の縦横比による余白は残る。

検証：`mobile-layout-test.cjs`。変更前のCSSを同じページへ適用して比較。PC 1440×900 / 1920×1080 / 844×390は配置とスクリーンショットの全画素が一致。スマホは390×844 / 360×640 / 844×390 / 667×375 / 320×568で確認。360×640の一覧は291→452px、2→4段。844×390は115→202px、1→2段と次の段の一部。設定・リスト・性能紹介のタップ、最後のキャラまでのスクロール、戦闘の全画面寸法・半透明表示・全ボタンの到達範囲を確認。

4人・3人団体戦の横持ち一覧は180px / 173pxを確保。既存の `mobile-controls-test.cjs` と `mobile-display-test.cjs` が成功。PCの戦闘入力やゲーム速度は変更していない。スマホ実機は未確認。
