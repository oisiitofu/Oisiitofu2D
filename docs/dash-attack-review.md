# ダッシュ攻撃の全形態確認 — 2026-10-14

実際の攻撃姿勢（発生直後／持続後半）と走行から出した移動距離を確認。攻撃画像・姿勢・発生・威力・ふっとばし・リーチは保持し、移動姿勢に合わせて3段階で滑走と持続を調整。立ち止まった鞄回し・ジャブ・直立した銃撃／レギオン姿勢の5形態は変更しない。

地上の発生前は走りの慣性を残し、持続中は前方へ滑りながら徐々に減速。途中で反転・再加速の連打を受け付けない。崖外へ出たら通常の空中移動へ戻り、攻撃専用の滑走加速を再適用しない。被弾・終了・形態変更で専用移動は消える。最後の攻撃窓を伸ばし同じhit IDを使うため、延長だけで二重に命中しない。

移動距離はステージ0中央、キャラの通常走行速度から発動、相手に当てず攻撃が終了するまでの座標差。ヒットストップ、床の端、変身・速度強化、相手との接触では変化する。本家のパラメータの複製ではない。
