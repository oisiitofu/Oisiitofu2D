# 命中の手応え：停止・音・火花（2026-11-01）

目的は軽打・重打・斬撃・銃撃・魔法を、色だけでなく停止時間・音の立ち上がりと余韻・火花の形から区別できるようにすること。

`hit-feedback.js` の純粋な問い合わせで接触の種類と重さを決め、ヒットストップ、SE、命中火花が同じ結果を使う。元の武器／属性別96音を保ち、音量・再生速度・末尾の減衰を種類別に調整する。命中音の追加重複再生はしない。BGM・移動音・UI音・音量設定・ミュートは維持。

|接触|停止の目安（10ダメージ・補正なし）|音と火花|
|---|---:|---|
|軽打|9F|軽い高めの接触音、短い小型の五方向火花|
|重打|16F|低く重い音、太い破裂形・破片・圧力の波|
|斬撃|11F|鋭い切断音、攻撃の線分方向に合わせた細長い切断光|
|銃撃|6F|短く乾いた音、小さな閃光と飛び散る破片|
|魔法|13F|属性の音と余韻、炎・氷・雷・風・水・土・光・闇の形と色|

停止はダメージ・既存の `hitlagMultiplier`・電撃補正・上限30Fを反映。明示的な0と無停止の削りは維持する。盾・パリィ・捕獲の専用時間は変えない。銃などの独立弾で射手まで停止させない。ダメージ・吹っ飛び・硬直・攻撃窓・ヒットIDは変更しない。停止中／被弾硬直中の入力で吹っ飛び予約を消さない。

軽打／重打の分類には溜めを含む技の威力を共通で渡す。ワンパターン相殺や1対1のダメージ補正が閾値をまたいでも、停止だけ重打・音と火花だけ軽打という分裂を起こさない。実ダメージは音量・火花の大きさへ反映する。

命中時だけ新しい形の火花を前面に重ね、既存のキャラ別命中画像は薄く残す。攻撃モーション、武器の軌跡、召喚や弾の固有画像、元の立ち姿は変更しない。全攻撃へ共通の大きな輪や粒子を重ねる処理を外し、重打の波と魔法の属性表現に役割を分けた。カメラの揺れ・明滅も銃撃と軽打では控えめにする。

既存の `soundFamily`／`element` と実際の接触を使い、全飛び道具を銃撃とは扱わない。必要なら技の `contactKind` で明示できる。ザックスの実ファイア弾だけを火属性音へ修正し、同じNBから変わる八刀一閃は剣を維持。肩タックルは打撃へ、ビビの杖払いは杖の音へ修正。

検証結果と比較画像・比較音はGit管理外の `previews/hit-feedback/`。

- 対象検証67項目：同じダメージで5種類の停止が異なること、実際の5キャラ×左右の命中、ファイア／八刀一閃、ガード・アーマー・削り、停止中の連打、相殺時の分類一致、前後上下の向き、CPU2戦各1800フレーム。
- 既存命中音テスト：96素材の波形・32接触・11種類の混合技、連射、ガード／空振り、ミュート、4音同時のピーク。方向入力テスト34項目。
- 変更前HEADとの15接触比較で、ダメージ・吹っ飛び予約・硬直・盾・命中回数は一致。停止時間と演出を除く。
- 実オンライン2人・5場面160フレームの状態一致。音あり／ミュートの結果も一致。既存の音同期3場面120フレームも通過。
- 旧一括検証には、ティナの上／下スマッシュに関する5つの速度倍率検証失敗、クォートの未初期化テスト状態、battle-feelテストの主床未設定がある。いずれも変更前HEADを配信する比較サーバーで再現し、今回の変更による回帰ではないことを確認した。
