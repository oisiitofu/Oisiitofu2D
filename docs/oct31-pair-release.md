# ベルベット・リーンベルの追加

ベルベットはアッシュの次、リーンベルは桐生一馬の次。両者ともサイズ2・94px。添付の衣装・顔・自然な頭身を保ち、106枚の全身画像と専用の高解像度選択画像、16種のエフェクト、5色を制作。元の待機・15通常技を固定してから全身の予備動作と戻りを制作し、関節リグは使用していない。

ベルベットはNBの伸びる左腕で獲物の印を付け、横Bで自由な相手を捕らえ、引き寄せ／支点からの跳躍を選ぶ。上Bは足場の角へ腕を掛けて方向を狙い、必殺の再入力で蹴り出す。下Bはカウンターとソウルを使う一時解放で、解放中のみ45Fの有限浮遊。技・変身で浮遊予算は戻らない。

リーンベルはMGの有限スクラッチをNBのHG弾で確定ダメージへ変換。横Bは方向で経路を選んでから再入力で実行し、途中の再入力で跳躍。下Bのグレネードは銃撃で早期起爆でき、敵が押し返せる。上Bの再入力ごとにI.S.を使う反動を最大3回。空中で予算は戻らず、基本状態に浮遊は付けない。盾・盾の硬直・アーマーに対する変換の一回性、投げた時点の弾／爆風の鮮度と向き、足場側面／裏面の衝突も確認する。

通常投げはベルベットがblade（前後は位置変更、上が高％の撃墜）、リーンベルがbalanced（後ろを主な撃墜方向）。中量級90・DIなし・新品で、実つかみから両向きを測る。リーンベルの後ろ投げは160％で硬直中の境界到達、140％ではその条件に達しない。入力で行動可能になった後の流れと、復帰しない落下死を分けて記録する。両者の攻撃上がりは7ダメージ・単発・44F。
