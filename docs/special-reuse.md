# 必殺技の再使用待ち時間の整理（2026-10-17）

ユーザー指定：飛び道具の無限連射を防ぎたいだけで、普通の必殺技が動作終了後もしばらく使えない仕様は不要。全キャラを確認し、近接攻撃・移動・通常の切り替えから余分なタイマー条件を外した。発生・攻撃持続・動作の硬直は維持する。

## 確認範囲

130形態の604必殺技エントリを実行時に列挙。各キャラ専用のCooldownフィールドを単独で999にした場合の発動可否を測定した結果が `special-reuse-audit.json`。残る待ち時間は投射物・召喚・持続する設置物、回復・一定時間の強化などの固有制限。武器燃料・シルク・ソウルなどの資源と空中使用回数も維持した。通常攻撃や画像の総当たりは行っていない。

## 主な修正

- マレニア：通常形態の横Bに付いていた55Fの待ち時間を撤廃。第2形態は分身の110F再装填中でも本体の踏み込み斬りを使える。分身を追加で増やさない。腐敗の持続領域・変身の制限は維持。
- フィオルン：110Fのドローン再装填と本体の技を分離。ドローン待ちの横Bは既存の踏み込み斬り（8F開始、16〜20F攻撃、30F動作終了）へ。新たなドローンは出さず、最大2個と元のドローン→追加入力の挙動を維持。CPUも待ち時間中に本体の技を使える。
- C4-621・ハヤブサ・ロックマンエグゼの横B、クリスタルの下B、夕莉の撮影/構え、ホーネットの近接スピア/ストーム、塊魂の吸引/転がり/収集、ロックブーケの誘惑、アキラの同調攻撃、シャドウの近距離爆発、ドシンの拍手、パワプロの守備アクション：動作後に残るタイマー待ちを撤廃。
- 鬼助・メリア・ニーア・キトゥン・モルフィ・オメガモンの通常の武器/属性/スタイル/サイズ切り替え：動作後のタイマー待ちを撤廃。
- トロ：正義の近接コンボ、正義/雷の横Bとフォーム変更は即再使用可能。忍者の手裏剣/鎖、雷のもち投げの制限は維持。
- シェフ：スプレー本体は再使用可能、水たまりだけ70Fの設置間隔と同時1個を保持。
- ピポサル：ガジェット変更/接近用バトンは再使用可能。レーダー/飛ぶグローブの放出のみ45Fと同種1個の制限を保持。

画像・斬撃方向・音声・通常攻撃の威力・被弾硬直・吹っ飛び・オンライン通信形式は変更していない。

## 検証

- `node special-reuse-test.cjs`：130形態/604エントリ、33ケース×左右×実入力3連続、通常の硬直の維持、近接への切り替え、独立した投射物制限、ゲージ/強化/空中回数、計640項目合格。
- `node projectile-balance-test.cjs`：130形態の94投射プロファイル、2070項目合格。連射間隔・共通再装填・長押し・ガードや脱出の検証を維持。
- `node special-reuse-cpu-test.cjs`：フィオルンとマレニアを入れ替えたCPU2戦（各2400F）。実命中・必殺使用・有限座標・例外0を確認。対人勝率の評価ではない。
- `node special-reuse-online-test.cjs`：独立2クライアント241Fでドローン再装填中の斬り/通常と腐敗形態の横B/分身の制限、座標・状態・ポーズ・タイマー・オブジェクトが一致。

実行時の詳細結果はGit管理外の `.tools/special-reuse-*-results.json` と `.tools/special-reuse-report.json`。素材の再生成は不要。
