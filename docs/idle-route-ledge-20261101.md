# 待機・リーンベル・崖つかまりの調整（2026-11-01）

リーンベルとザックスの専用高解像度選択画像を顔へ寄せた。元の画像、ゲーム用全身画像、カラー用マスクを維持し、選択画像と解像度別サムネイルだけを再生成。実際のPCカードで頭と顔の見切れ、名前との位置を比較した。

待機画像が周期的に切り替わっていたエリオット、ユーマ、魔王、リーンベル、ベルベット、ナミネ、ハイデリン、ナイツ、ナルガクルガ、アヌビスを基準の待機画像へ固定した。スカポンの待機中の呼吸揺れと、共通描画の空中idleの上下揺れも除去。移動、攻撃、空中動作、相棒や攻撃エフェクト、トロなどの形態別の立ち姿は維持した。

リーンベルのI.S.は実命中3→8、スクラッチ変換の追加9→16。初期60・上限100・上Bの追加反動10と滞空中3回の制限は維持。横Bは開始条件と30の消費を外し、0から経路を実行できる。経路を計画→離して押し直す→任意の跳躍という操作、予告・キャンセル・硬直・空中使用回数を維持し、CPUと性能説明も対応した。

崖の退出フラグは地上から走って外へ出た場合だけ付ける。空中で崖の上を横切る下降まで退出扱いにしていた問題を修正した。下降は前後の位置を結ぶ線分でも既存のつかまり範囲を調べ、高速落下の取りこぼしを防ぐ。つかまり範囲を拡大せず、下入力・硬直・再つかまり待ち・上限・tether技の制限と上昇復帰は維持した。
