タイトル画面・キャラ選択画面 共通BGM

このフォルダ直下に、使いたい音楽ファイルを入れてください。
対応拡張子: .mp3 / .ogg / .wav / .m4a / .aac / .flac
ファイル名は自由です。日本語や空白も使用できます。

配置後、ゲームのページを再読み込みしてください。
画面をクリックするかキーを押すと、音楽が再生されます。
タイトル画面とキャラ選択画面の移動では曲は途切れません。
対戦開始時はステージBGMへ切り替わり、キャラ選択へ戻ると共通BGMを再生します。

1曲ならその曲をループします。
複数曲ならファイル名順で、対戦からメニューに戻るたびに次の曲をループします。
空の場合は無音です。ブラウザが対応する形式・コーデックの曲を使用してください。
音量はゲーム内のBGMスライダーで調整できます。
